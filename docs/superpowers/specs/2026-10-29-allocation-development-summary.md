**日期**：2026-10-29
**分支**：`feat/unified-local-moment-allocation`
**范围**：从"电荷约束改进"（M1–M4）到"统一局域磁矩分配"（S0–S6）的完整开发脉络、各轮假设/证据/结论，以及当前瓶颈与下一步。

## 0. 摘要

- **正确性**：分配算符 `A_i = Q_i + Q_c W_i Q_c` 的单位分解与分区求和已修复到
  **`|Σq − N| = 8.6×10⁻¹¹`**（Fe2 两片段完整划分）；力 FD 差 0.001 eV/Å。
- **语义**：`q = q_T + q_c`（目标壳层 + 空间互补），三者（q / 原始壳层投影 /
  Becke 空间矩）**不是同一个物理量**；`target_l` 决定可行域（Fe 自旋必须 d）。
- **效率**：Fe2 约束 SCF 从 **82 步 / 19 s** 降到 **63 步 / 11 s**；
  单次 hPsi 从 7.5 ms 降到 **4.29 ms**（相对 DeltaSpin 1.28×，门槛 <1.5×）。
- **瓶颈**：外层 μ 迭代数（63 vs DeltaSpin 13，4.85×），不是单步成本；
  缺的是密度响应（Schur 补）与分支管理，不是更快的单步。
- **下一杠杆**：**"先投影、后补偿"的 λ 同伦**（q_c 只占 Fe2 的 5.6%），
  预期把外层步数砍 40–60%，实现成本远低于线性化 SCF。

## 4. 统一分配方法：设计与计划

**算符**：

```
A_i = Q_i + Q_c W_i Q_c = Q_i + W_i − P W_i − W_i P + P W_i P
Σ_i A_i = I ；⟨v|A_i|v⟩ ≥ 0
```

**插值族**：目标轨道集为空 → 纯空间（Becke/Hirshfeld）；全通道 → Löwdin 型；
部分（d/f/p）→ 混合。**正交化只在 R×R 小空间**（R=目标轨道数），
这是可实施性的关键。

**执行计划**：S0（审计修正）→ S1（算子+只读）→ S2（LCAO 读数）→
S3（冻结约束+ALM）→ S4（完整导数/应力/非共线）→ S5（PW 平价+Hirshfeld）→
S6（生产化）。全部集成运行 `scf_nmax ≤ 100`。

## 5. 各轮分析与结果（本轮重点）

### 5.1 批判性评估（2026-10-27）

- **求和一致性通过**：网格单测 `max_sum_error=3.1e-15`；Fe2 `Σq=M_tot` 差 1.9e-10 μB。
- **语义**：同靶 ±3.8 μB 时 allocation `q=±3.80005`，传统 orbital-sum 仅
  ±2.927，DeltaSpin 的 orbital-sum 与目标一致 → **不同算符**。
- **效率**：优化前 Fe2 81 步/84 s vs DeltaSpin 13 步/4 s（~21×）；
  优化后 56–61 s；单次 hPsi 1.86–1.96×。
- **门槛**：零乘子快路径、单次 hPsi <1.5×、Fe2 总墙钟 <3×、语义闭环、
  sum 审计、鲁棒性六条；2–3 周内达不到 2/3 条则停止生产约束路径。

### 5.2 全空间残差验收 + J0 探针（2026-10-28，负结果）

- 冻结密度子空间只能作**诊断预测器**，不能直接安装为 trial：
  安装版 Fe2 外层 6→13 步、迭代 82→129。
- D2 探针：第一次有效 Broyden 更新后 `||JB−J0||/||JB|| = 0.45–3.18`
  （调研门槛 0.1）；`J0` 在外层步间从约 −20 变到 −0.3。
- 结论：**冻结密度 Jacobian 缺一整条密度响应通道**，不能替代精确 Schur 补；
  停止在预测器上调参。

### 5.3 语义闭环（本轮）

| 观测量 | Fe2（atom0） | 定义 |
|---|---:|---|
| 分配坐标 `q` | −3.800 | `Tr[ρ A_i σ]` |
| 原始壳层投影 `m_T` | −3.599 | 非正交 onsite projector（DeltaSpin 口径） |
| 真实互补 `m_c` | −0.201 | `Tr[ρ Q_c W_i Q_c σ]` |
| Becke 空间矩 | −2.819 | `∫ w_i ν` |

- `q = m_T + m_c`（修复后精确）；正交化**不改变**子空间迹，`q` 与壳层矩的
  差全部来自互补。
- `ALLOC-PW` 报告的 `m_c` 原为 "Becke − raw"，**不是**算子互补 → 已加诊断
  `ALLOC-SPLIT` 并标注口径。
- `target_l` 扫描：只有 **l=2（d）能到达 ±3.8**（82 步收敛）；
  l=0/1/3 原始投影 ≈0、残差 0.6–1.2 μB、200 步 RUNNING。
- LiCl 电荷（δ=0）：Becke=3.0959 固定； allocation q 随 l=0/1/2 =
  2.948/3.085/3.028；原始投影 2.00/0.74/0.00（Li 无 d）。
- **结论**：q 是"目标壳层 + 空间互补"的建模坐标，无唯一实验对应；
  对 XMCD 用壳层投影、对中子用空间矩、对磁强计用总矩。

### 5.4 效率改进（本轮）

| 改动 | 结果 | 结论 |
|---|---|---|
| μ 移动后重置 mixing 历史 | Fe2 **82→55 步（−33%）**，平台期消失 | 正结果，保留 |
| `fold_potential` 默认开启 | 单次 hPsi **7.00→3.93 ms（1.78×）**，墙钟 −19% | 正结果，保留 |
| trial 早停（逐迭代监测矩塌缩） | guard 正确触发一次，但 **200 步 RUNNING** | 负结果，回退 |
| 内层子空间迭代 4/8 | 180/200 步、换支 | 负结果 |
| ALM（默认 k） | 200 步 RUNNING | 负结果（需 k 标定） |

- drho 诊断：参考相 14 步干净收敛；每次 μ 移动后出现 **7–9 步恒定 drho 平台**，
  突然坍缩 → 根因是 Broyden 历史陈旧（已修）。
- 当前 Fe2：**63 步 / 11 s / 4.29 ms/hPsi**；DeltaSpin 13 步 / 2 s / 3.36 ms。

### 5.5 电荷互补归一化（本轮，正确性）

- 诊断：`Σ目标+互补 = 32.376 ≠ N`；目标全部归属、band norm=32、
  G/实空间互补范数一致 → **投影恒等式被破坏**。
- 根因：**复 k 下正交化的共轭配对不一致**。数值实验（随机复 Hermitian）
  锁定唯一正确约定：

  ```
  phi_orth = conj(G) φ ,  overlap = G raw        （|P−P_exact|=1.7e-15）
  ```

  现行代码是 `G φ` 配 `conj(G) raw`（共轭投影），Γ 点不可见。
- 修复：value/导数/operator/force 四条路径统一到约定 C；单测解析导数同步。
- 验证：Fe2 `dsum_n 0.376 → 8.6e-11`、CONVERGED；LiCl（Γ）q/ETOT **逐位不变**；
  H2O allocation 力 FD −5.668 vs 解析 −5.669 eV/Å；23/23 测试通过。

## 7. 方法论总结（可复用）

1. **先测量再优化**：把总成本分解为"迭代数 × 每迭代 hPsi 数 × 单次 hPsi"，
   本轮三项分别是 4.85× / 1.09× / 1.28×——瓶颈立刻定位到迭代数。
2. **用 drho 轨迹识别结构**：平台 ≠ 随机震荡；恒定 drho 指向"固定点映射
   在变"（mixing 历史陈旧），不是数值噪声。
3. **负结果必须归档**：trial 早停、内层迭代、冻结密度预测器、ALM 默认 k
   全部记录，避免重复投入。
4. **Γ-only 测试会掩盖复 k 缺陷**：LiCl 一直正确，Fe2 的广义 k 才暴露
   0.376 e；新增复 Hermitian 的矩阵级恒等式测试。
5. **约定必须跨路径一致**：value、operator、subspace、force、stress 五条
   路径的"旋转 × 系数"配对必须同一约定；只改 observer 会导致 SCF 发散。
6. **语义先于性能**：同一个 ±3.8 μB 目标对应不同电子态（ETOT 差 0.625 eV），
   不同算符的"效率对比"不是同一物理问题。

## 8. 当前瓶颈与下一步

**瓶颈**：外层 μ 迭代数（63 vs 13）。结构是 ~7 次外层 μ 更新 × 每次 ~9 次 SCF；
每次 μ 移动都改变非局域算符，SCF 必须重新收敛。缺的是**密度响应**（精确
Jacobian 为 `Q_ρ(I−T_ρ)^{-1}T_μ`）与**分支管理**（Fe2 第 3 步的分支偏离）。

**性能工作已收尾（2026-10-29）**：可低成本拿到的收益已全部拿到
（82→63 步、单次 hPsi 1.78×、只读 1.08×）；冻结密度预测器、内层多迭代、
trial 早停、λ 分段、FD 响应层全部实测为负并归档。剩余结构差距需要
**线性化 SCF（DFPT 级新能力）** 或 **continuation**，另立项目；当前接受
63 步 / 11 s 作为 allocation 的实用基线。工作重心转向正确性收尾
（语义表更新、分区回归）。

**历史候选杠杆（按性价比）**：

1. ~~λ 同伦："先投影、后补偿"~~ **（已测，负结果，2026-10-29）**：
   `A_i(λ)=Q_i+λQ_cW_iQ_c` 的 Fe2 A/B——λ=0（仅投影）**200 步 RUNNING**
   （45 次 trust 拒绝、半径→1e-8），λ=0.5≈119 步，λ=1=63 步。
   **λ 越小越慢**：去掉局域互补势后，纯非局域投影对当前 outer+mixing 是
   更难的固定点。详见 `2026-10-29-allocation-complement-ramp-experiment.md`。
   若要实现该分段，需真正的 DeltaSpin 式内层 λ 循环（并给子空间矩阵加 λ）。
2. **1e-5 扰动诊断**：从收敛密度微扰重启，区分"mixing 健康度"与"外层 μ"。
3. ~~响应层（FD probe 版）~~ **（已测，负结果，2026-10-29）**：
   参考相后跑 n_c 次 `μ=h e_i` 的 SCF 探针构造全空间 J，再 Newton 起步——
   Fe2 **116 步 vs 基线 63**（探针各需一次完整 SCF：15/13 步；前向差分 J
   仍不够准，随后 8 个外层步）。与调研一致：n_c 次完整 SCF 只适合做验证基准。
   真正的响应层需**线性化 SCF（T_ρ 矩阵自由作用 + Krylov）**，属新能力；
   且不解决分支偏离。详见 `2026-10-29-allocation-fd-response-layer.md`。
4. **其他**：多片段/非共线/kpar>1 的分区审计回归；语义表按修复后数值更新。
