## 1. 测试计划

唯一核心问题（R4 判决）：**离子体系的电荷约束线性可达域是否显著宽于 H₂O 的
±0.3 e？** 否定结果同等重要（收紧适用范围声明）。

| 步 | 内容 | 判据 |
|---|---|---|
| S1 | 网格阶梯（60/240 → 160/640），delta=0 参考相读 Q_ref(O) | Q_ref 网格稳定 <3e-5 e |
| S1X | 分离 ecutwfc / ecutrho | —— |
| S2 | 校准网格参考态，靶文件覆盖两个完整子晶格 | 收敛；Q_ref 落文献带；sum rule = nelec；maxdev ~1e-16 |
| S3 | 单 O（原子 4）±0.3/±0.5/±0.8/±1.0 e，两条热启动链 | 全点 CONVERGED 无熔断；μ(δ) 单调；线性区宽度 |
| S4 | 单 Mg（原子 0）±1.0 e | Mg⁰ 侧可达；Mg³⁺ 侧预期熔断 |
| S5 | 与 H₂O（±0.3 e，\|dμ/dδ\|≈1.7 Ry/e）对比 | 离子体系线性区是否 ≥2× 于 H₂O |

## 4. 分析

1. **R4 判决：成立（正向）**。单 O 电荷约束的线性区为 **−1.0 … +0.8 e**
   （负侧全程 dev ≤4.0%，正侧到 +0.8 e 为 +12.2%，仅最后一段 +0.8→+1.0
   越 20%）。即 **线性区宽度 ≥ ±0.8 e ≈ 2.7× H₂O 的 ±0.3 e**，满足
   "≥2×" 的立项判据。设计方案"DeltaQ 的正当适用域 = 电荷局域、位点可
   分辨的离子/缺陷体系，且其线性可达域显著宽于共价小分子"得到判决实验支持。
2. **κ 的口径与不对称**：O in MgO 的 \|dμ/dδ\| ≈ 1.9–2.3 Ry/e，与 H₂O 的
   1.7 Ry/e 同量级、略**更硬**（每电子代价更高）；且强烈不对称——**减电荷
   （−1.0 e，1.90 Ry/e）比增电荷（+1.0 e，2.53 Ry/e）软 ~25%**。所以
   "宽可达域" 的来源不是"离子体系更软"，而是**离子体系在大扰动下仍保持
   近似二次能量曲面**（共价体系在 ±0.3 e 外即偏离线性）。这是比原假设更
   精确的结论，应写回设计方案。
3. **Mg 侧**：Mg 的电荷响应（1.31 / 2.12 Ry/e）比 O 软（前者），Mg⁰ 化
   （+1.0 e）最容易。Mg³⁺ 化在 2.12 Ry 内即可达，说明 8 原子胞 + 2×2×2
   网格下这个片段的"电离极限"远未触及——原计划把它当熔断用例是估计失误。
4. **稳健性充分**：κ 对网格的敏感性 <0.02%；能量恒等式 μ* = −dE_tot/dδ 在
   全部 8 个 δ 区间闭合到 <0.8%，说明外环读数（μ）、约束达标（Q）与总能
   记账三者内部自洽，判决不依赖任何单一读数通道。
5. **成本模型修正**：`MuSolverParams::step_max = 0.05 Ry` 是硬编码上限，
   而本体系 \|dQ/dμ\| ≈ 0.45–0.5 e/Ry，于是 \|μ*\| / 0.05 决定外步数
   （δ=+1.0 e 用了 47 外步 / 788 SCF 迭代）。生产网格从 160/640 降到
   60/240 后单点 3–8 min；S1–S4 合计约 2.5 h（含并行），落在计划
   "1–2 h" 的上沿。若要扫描更大 \|δ\| 或更贵体系，**把 step_max 提为
   INPUT 参数（默认 0.05 不变）是最直接的杠杆**（未实施，需批准）。
