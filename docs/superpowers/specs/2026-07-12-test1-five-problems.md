# Test 1 五问题公式级分析 (2026-07-12)

## 总览

单电子步 dγ/dλ 测量失败经历：HK correction 正确施加（|δH|~0.02Ry→λ 缩放），但总 gamma 非单调且在不同运行间交替于两个值（-0.008 vs -0.133），证明 gamma 数值受 3 个算子级错误和 1 个算法级非确定性主导。

## 问题 1：SVD 的 U·V† 重建错误（已修复）

**SVD 理论的数学推导**：对于占用子空间重叠矩阵 M = W_{j-1} · O_j，其酉群上的最强投影为极化因子 X∗ = argmin_{X†X=I} ||M - X||_F。通过 SVD M = U Σ V† 求解：

目标函数：||M - X||²_F = ||U Σ V† - X||²_F = || Σ - U† X V ||²_F

设 W = U† X V。由于 X 酉且 U,V 酉，W 也酉，且 ||X - M||²_F = ||U (W - Σ) V†||²_F = ||W - Σ||²_F = tr[(W-Σ)†(W-Σ)] = ||W||²_F - 2 tr(Re[W Σ†]) + ||Σ||²_F

由于 ||W||²_F = tr[W†W] = tr[I] = n，且且 Σ 的对角元为 σ_i ≥ 0 为实：
||X - M||²_F = n - 2 Σ_i σ_i · Re(W_{ii}) + Σ_i σ_i² = Σ_i (σ_i - Re(W_{ii}))² + Σ_i (1 - |W_{ii}|²) + Σ_{i≠j} |W_{ij}|² + n - Σ_i 1

当所有 i≠j 的 W_{ij}=0 且所有 |W_{ii}|=1、Re(W_{ii})=1（即 W_{ii}=1），即 W=I 时，||X-M||²_F = Σ_i(σ_i - 1)² 达到最小。因此 X∗ = U · I · V† = U · V†。

**代码错误**（第 592 行，已修复）：LAPACK zgesvd 返回 VT = V†，列主序存储：VT_svd[i + j*ndim] = V†(i,j)。正确的 U·V† 乘积索引为：

```
(U·V†)(i,b) = Σ_k U(i,k) · V†(k,b)
             = Σ_k U_svd[i + k*ndim] · VT_svd[k + b*ndim]   (不对 VT 取 conj!)
```

原错误代码（`std::conj(VT_svd[b + k*ndim])`）将 VT(b,k) 取共轭，实际计算的是 U·V（右奇异向量的非共轭产品），破坏了酉性，导致 zgeev 返回 |λ|≈0（而非 |λ|=1）。

**修复后验证**：特征值恢复到单位圆上（3/4 |λ|=1.000，1/4 |λ|=0.906），总 gamma 从恒为 0 变为非零。

## 问题 2：跨运行二元交替的根源—zgesvd 奇异向量相位不确定性

**现象**：相同 λ=0.01 的 5 次独立运行产生交替于 -0.008 和 -0.133 的总 gamma。已排除：MPI 并行性（单进程）、branch file、Broyden、HK correction 确定性。

**根因推导**：zgesvd 的奇异向量 U_i 和 V_i 被归一化到单位范数，但每个向量的复相位 e^{iα} 和 e^{iβ} 是**独立且任意的**。SVD 仅保证：

U_i†U_i = 1,  V_i†V_i = 1  （归一化）
U · Σ · V† = M  （SVD 重建一致性）

但 **不保证** α_i = β_i。U_i 和 V_i 的相位独立变化时：

```
(U · V†)_{kl} = Σ_i U_{ki} · conj(V_{li})
              = Σ_i e^{iα_i} ũ_{ki} · e^{-iβ_i} conj(ṽ_{li})
              = Σ_i e^{i(α_i - β_i)} ũ_{ki} · conj(ṽ_{li})
```

相位差 Δ_i = α_i - β_i 在不同 SVD 调用间取任意值。这导致：
1. U·V† 的特征值 phase 在不同运行间偏移
2. 累计到 Wilson loop 的最后一步，特征值 argument 可以跳变约 2π
3. 这解释了为什么 zeta arg 交替于 -0.008 和 -0.133（差异 = 0.125 ≠ 2π 是因为特征值的相对相位差被 SVD 压缩）

**拟修复方案**：强制在 SVD 后统一相位约定：
- 对每个 i，令 V_i 的最大幅度元素变为正实
- 对应的 U_i 用相同相位因子调整：e^{-i arg(max(V_i))}

或采用 QR 分解替代 SVD（QR 的 Q 矩阵相位约定更稳定）。

## 问题 3：n_dim=4 与 O_j 的秩亏损——占据子空间的物理局限性

**物理背景**：Wilson loop 的占用子空间重叠矩阵：

```
O_j(m,n) = <u_{m,k_j}|u_{n,k_{j+1}}>    (m,n ∈ 1..nocc)
```

完整基组（26×26）的重叠矩阵是酉的（U_full†U_full = I），因为 {|u_{n,k}>}_{n=1}^{26} 在各 k 点构成完整基。但占用子空间（4×4）的投影矩阵 O_j = P_occ U_full P_occ† 一般不是酉的。

**秩亏损的度量**：O_j 的奇异值 {σ_i}。实测：
```
σ = [1.039, 1.016, 0.995, 0.581]
```

σ_4 = 0.581 表示第 4 个占据带与相邻 k 点的高能空带有显著重叠（~42% 的平方范数泄漏到空带子空间）。SVD 酉投影将 σ_4 强制设为 1，引入约 Δθ_4 ≈ |1-σ_4| × θ_4 ≈ 0.42 × characteristic_phase 的误差。

**理论缓解**：增大 n_dim 至收敛（如使用所有 14 条带），使 O_j 的条件数接近 1。

## 问题 4：zgeev 特征值排序不确定性

**根因**：`gamma_unwrapped[n] = arg(evals_j[n])`（第 581 行）在 j=0 时取 zgeev 返回的第一个对角化结果。zgeev 的特征值排序是 IMPLEMENTATION-DEFINED（LAPACK 内部排序算法保证降序的 |λ|），但在 |λ|≈1 的酉矩阵中，所有特征值幅度相同，排序退化为按相位排序（实际也是随机的）。

若运行 A 的 j=0 对角化得到顺序 [λ1, λ2, λ3, λ4]，而运行 B 得到 [λ2', λ1', ...]，则后续 j>0 的匹配算法会在不同的 band 索引上追踪 phase 演化。虽然 **特征值的总和的 argument**（= arg(det W)）在任意排序下不变，但**各特征值的单值 phase**（γ_unwrapped[n]）会在重新排序后赋予不同的 per-atom gamma。若总和的偏差落在 2π 倍数内，就会产生交替效应。

**修复**：在 j=0 对角化后，对 evals_j 按其 argument 从小到大排序，并将 VR 的列对应重排。这样所有运行有确定性的初始排序。

## 问题 5：1-step SCF 的 frozen-charge 近似误差

**物理原理**：scf_nmax=1 的 SCF 不更新电荷密度。有效势 V_eff[ρ] 使用固定 ρ（来自之前收敛的 SCF），但 HK correction δH 改变了 Kohn-Sham 哈密顿量：

```
H[ρ_old] + δH(λ) → 对角化 → ψ_new
```

新的波函数 ψ_new 对应电荷密度 ρ_new ≠ ρ_old。自洽性被破坏：V_eff[ρ_old] ≠ V_eff[ρ_new]。由此产生的 gamma 误差为：

```
Δγ ≈ (dγ/dV_eff) · (dV_eff/dρ) · (ρ_new - ρ_old)
```

对 BN（绝缘体），dV_eff/dρ ~ 1/ε(0)，而 (ρ_new - ρ_old) 在单步后约 0.01 e/bohr³，估算 Δγ ~ 0.005-0.02 rad。这解释了测试中约 0.01 rad 的附加噪声。
