## 0. 从混合规范提炼的三条可推导纪律

混合规范在 rt-TDDFT 中的成功不是因为"在原子中心加相位"这个动作本身，而是因为它
满足三条结构性纪律。把这三条作为推导公理，可以避免上一版文档中"贴标签式类比"的错误：

```
HG-1（载体纪律）：约束必须作用于被约束物理量的载体自由度。
    外场的载体是相位/动量通道（p + A），不是密度通道。混合规范把修正做进
    轨道相位 e^{−iA·Δr}，正是让场直接作用于相位载体。
    ⇒ 对 DeltaP：γ_I 的载体是 k-string 上的链接相位（重叠矩阵 M_j 的辐角）
       与投影权重 w_In。约束算符必须直接微分这些对象，而不是微分某个
       "和 γ 相关"的代理观测量。

HG-2（规范一致性 = 记账一致性）：哈密顿量、能量、力、应力必须由同一个
    观测量定义生成，不允许在不同模块使用不同的"规范"。
    ⇒ 对 DeltaP：约束用 γ、记账用 Γ、PW 用旧 γ，三者并存即规范混用，
       是 T2 轮失配与 PW 旧记账的共同根源。

HG-3（效率保持）：任何修正必须可表示为双中心积分或近邻-k 形式，
    不引入格点积分、不破坏 k 点块结构以外的现有并行结构。
    ⇒ 对 DeltaP：所有新项只能是 (a) 双中心积分及其导数，
       (b) k-string 上最近邻链接 (k_j, k_{j+1}) 的矩阵元。
```

下面的推导将表明：现行 Route A+ 在 HG-1 上只做到了一阶（H_HK 是链接相位算符的
对称化线性近似，H_HR 是权重项的几何代理），在 HG-2 上存在三处违反（Γ/γ 双观测量、
PW 旧记账、H_HK 应力缺失），在 HG-3 上恰好具备升级所需的全部结构（KPAR=1 硬限制
反而使近邻-k 算符的实现零额外通信）。

## 1. 精确约束算符的推导：Ô_I ≡ δγ_I/δρ

### 1.1 γ_I 的泛函结构

k-string：k_j = k_0 + j·dk，j = 0,…,N_k−1，周期闭合（j = N_k ≡ 0）。
占据带 n = 1,…,N_occ。SMO 投影态系数 C(k_j)（LCAO 广义本征问题 H C = S C ε 的解）。

```
链接矩阵：  M_j = C†(k_j) · S_dk(k_j, k_{j+1}) · C(k_{j+1})      (N_occ × N_occ)
Wilson 环： W = Π_j M_j  =  M_0 M_1 … M_{N_k−1}
本征系统：  W u_n = z_n u_n，  v_n† W = z_n v_n†（左/右本征矢，W 非厄米）
相位：      θ_n = Im ln z_n（分支由 Hungarian 匹配 + 连续性锚定维持）
原子分解：  γ_I = Σ_n w_In · θ_n，  w_In = Σ_{lm∈I} |D_{I,lm,n}|²
            D_{I,lm,n}(k) = ⟨SMO_{I,lm}|ψ_n(k)⟩
```

γ_I 对波函数的依赖有两条独立通道：

- **通道 θ**（链接相位通道）：M_j → W → z_n → θ_n；
- **通道 w**（投影权重通道）：D_I → w_In。

精确约束算符必须对两条通道同时取泛函导数。现行 H_c 对两条通道都做了近似，
这就是全部问题的结构性来源（§1.4 定理）。

### 1.2 通道 θ 的泛函导数（链接算符 Ô_θ）

**第一步：Wilson 本征值的变分。** W 非厄米，用双正交左/右本征矢（v_m† u_n = δ_mn 归一）：

```
δz_n = v_n† δW u_n  =  Σ_j Tr[ A^{(j)}_n · δM_j ]

其中截断 Wilson 乘积（ propagator ）：
A^{(j)}_n ≡ W_{>j} · u_n v_n† · W_{<j}
W_{<j} = Π_{j'<j} M_{j'}，  W_{>j} = Π_{j'>j} M_{j'}（周期闭合下均有定义）
```

**第二步：链接矩阵的变分。** SCF 内 k 网格与 S_dk 固定，

```
δM_j = δC†(k_j) · S_dk · C(k_{j+1})  +  C†(k_j) · S_dk · δC(k_{j+1})
```

**第三步：链式法则。** 定义两个 SMO 基下的矩阵（μ 为基函数指标，p 为带指标）：

```
L^{(j)}_n ≡ S_dk(k_j,k_{j+1}) · C(k_{j+1}) · A^{(j)}_n        （右链接梯度）
R^{(j)}_n ≡ S_dk†(k_{j−1},k_j) · C*(k_{j−1}) · A^{(j−1)}_n    （左链接梯度）
```

则 γ_I 对系数矩阵的 Wick 梯度为：

```
∂γ_I/∂C*_{μp}(k_j) = Σ_n w_In · (1/2i) · [ z_n^{−1} · L^{(j)}_n
                                            − (z_n^{−1} · R^{(j)}_n)* ]_{μp}
                                          └ 通道 w 项见 §1.3 ┘
```

（指标级代数见附录 A。第二项来自 δM_{j−1} 中的 δC(k_j)，经取复共轭并入反全纯梯度；
γ_I 为实数保证整体厄米。）

**结构结论（Ô_θ 的三个性质）**：

1. **最近邻-k 非局域**：Ô_θ 只耦合 (k_j, k_{j+1}) 两个相邻 k 点——k 空间
   最近邻 hopping，即离散意义下的**矢量势**（Peierls 相位）。这是"λ 扮演
   矢量势"唯一严格成立的位置：不是比喻，而是 Ô_θ 的矩阵结构。
2. **状态依赖**：A^{(j)}_n、z_n、u_n/v_n 由当前迭代态决定——Ô_θ 是
   DFT+U / SIC 型的状态依赖算符，SCF 内滞后更新（与现有 Wilson 环
   每迭代重算的节奏天然一致）。
3. **零阶齐次**：γ_I 在 ψ → cψ 下不变（M_j 对归一化不变），故
   Tr[ρ·Ô_θ] = 0（Euler 定理）。该性质决定记账结构，见 §2.2。

### 1.3 通道 w 的泛函导数（权重算符 Ô_w）

w_In = Σ_{lm∈I} D*_{I,lm,n} D_{I,lm,n}，D = S^{SMO}·C。直接微分：

```
∂γ_I/∂C*（通道 w） ⇒  Ô_w |ψ_n(k)⟩ = θ_n · P̂_I |ψ_n(k)⟩

P̂_I = Σ_{lm∈I} |SMO_{I,lm}⟩⟨SMO_{I,lm}|   （SMO 投影算符，度量意义下）
```

即：**权重通道给出的精确算符是"以带分辨 Berry 相位 θ_n 为权重的在位投影"**——
对每个带施加一个正比于其当前 Wilson 相位 θ_n 的 DFT+U 型在位势
（带依赖有效 U_n = λ_I·θ_n）。

### 1.4 核心定理：现行 H_c 是 Ô_I 的何种近似

**定理（近似的精确定位）**。精确约束算符 Ô_I = Ô_θ + Ô_w 与现行
H_c = H_HR + H_HK 的关系为：

```
(1) H_HK = Ô_θ 的【w 冻结 + 对称化一阶】近似：
    把 Im ln z_n 在 M_j 附近展开到一阶并取 (i/2)·sym，且冻结
    w_In、A^{(j)}_n 的态依赖（略去 δw/δψ 与 δA/δψ 项）。
    → 链接通道的方向正确，但只保留了线性响应核。

(2) H_HR = Ô_w 的【长度规范代理】近似：
    精确形式 Ô_w 的带分辨权重 θ_n 被替换为几何常数 τ_α(I)：
        θ_n  →  τ_α(I)（对所有带均匀）
    物理含义：假设"原子 I 上所有带的相位中心都恰好坐在原子位置，
    且相位—位置换算系数对所有带相同"（γ = 2πτ/L 型对应）。
    → 误差算符：ΔÔ = λ_I Σ_n (θ_n − θ̄_I)·P̂_I|ψ_n⟩⟨ψ_n|
       其范数由 θ 的带内散布 control：
       spread_I ≡ [ Σ_n w_In (θ_n − θ̄_I)² / Σ_n w_In ]^{1/2}
```

**证明要点**：(1) 对 ln z_n = ln v_n†Wu_n 做一阶变分并代入 W_eff[n] = Σ_I λ_I w_In
的占据带权重形式，即得 Route A+ 文档 §2 的 H_HK 表达式（(i/2)·sym 约定即
Im 的厄米化）；(2) 对比 §1.3 的 Ô_w 与 Route A+ §2.2 的 H_HR，逐项即见
替换 θ_n → τ_α(I)。∎

**推论 1（可检验的失效判据）**。H_HR 代理的误差 ∝ λ_I·spread_I。
对局域平带（绝缘体深价带，θ_n 聚集在原子相位附近）spread_I 小，代理好；
对色散/纠缠带（界面态、近金属体系——恰是 DeltaP 的目标应用）spread_I 大，
代理系统性失真。**这把"Route A+ 何时可信"从经验问题变成了可计算判据**（§7 V-H5）。

**推论 2（弱耦合窗口的结构性解释）**。Route A+ 实测 dγ/dt_Γ ≈ 0.07。
在线性响应框架下（推导见附录 B）：

```
dγ/dt_Γ = χ^{γΓ}/χ^{ΓΓ} ≡ η（耦合效率）

χ^{ab} = Σ_n f_n Σ_{m∈unocc} 2 Re[ ⟨ψ_n|Ô_a|ψ_m⟩⟨ψ_m|Ô_b|ψ_n⟩ ] / (ε_n − ε_m)
```

η = 0.07 的物理含义：**代理场 Ô_Γ 的作用只有 7% 进入相位通道，93% 泄漏到
与 γ 无关的密度畸变通道**（Ô_HR = τ·P̂ 的带间矩阵元连接的是"位置加权电荷"
通道而非链接相位通道）。这与速度规范在 NAO 中的失效完全同构：场耦合到了
错误的通道。混合规范的修法——把约束直接做成相位载体的泛函导数——使
η → 1（构造性保证，§2.4）。

## 2. 改进一（核心）：精确泛函导数约束（EFC，Route A++）

### 2.1 约束哈密顿量

```
H_c^EFC = Σ_I λ_I · Ô_I，  Ô_I = Ô_θ + Ô_w   （§1.2、§1.3 的精确形式）

SCF 方程： (H_KS + H_c^EFC) C = S C ε
  · Ô_θ 项：对 k_j 的态施加由 (k_{j−1}, k_j, k_{j+1}) 三点态构造的梯度势
    （滞后一迭代，类杂化泛函 ACE 的外层滞后）
  · Ô_w 项：对 ψ_n(k) 施加 λ_I·θ_n·P̂_I（θ_n 每迭代由 Wilson 环更新）
  · KPAR=1 硬限制 ⇒ 整条 string 的态在同一进程内，近邻-k 耦合零额外通信
    （现行 LIMITATION #4 转化为实现优势）
```

效率核算（HG-3）：Ô_θ 每个 k 对的构造代价 = 2 次 N_occ 阶矩阵乘（A^{(j)} 的
增量式传播可沿 string 递推：A^{(j+1)} 由 A^{(j)} 右乘 M_{j+1} 并左除 M_j 的
截断更新，O(N_k·N_occ³) 每迭代，与现有 Wilson 环计算同阶）；Ô_w 与 DFT+U
在位项同价。**不引入任何新积分类型。**

### 2.2 能量记账：零阶齐次性的红利

由 §1.2 性质 3，γ_I 对 ρ 零阶齐次 ⇒ **Tr[ρ·H_c^EFC] = 0 恒成立**。推论：

```
代码打印量：  E_tot = E_KS(ψ*)           （不含任何约束期望项，无需 escon 扣除）
FD 一致性量： E_phys = E_tot + λ·(γ_meas − t_γ)   （约束焓，力的 FD 判据对象）
纯 KS 能量：  直接读 E_tot               （跨构型/跨约束态比较，Route A+ 的 E' 角色）
```

与 Route A+ 对比：

```
Route A+：  E_tot = E_KS + λΓ，escon = −λΓ，E' = E_KS   （双口径相减，T2 全迹敏感）
Route A++： E_tot = E_KS（恒等，无近似），escon 概念退役
            E' 的两种读数（E_tot / E_phys）分别服务"物理比较"与"FD 判据"
```

**整类消除的问题**：T2 轮的 Γ/γ 失配（∂E'/∂λ 的 O(1) 泄漏）、Gram 全迹
敏感性（Ô_θ 不经过 Tr[ρH] 记账，T·Π 全迹约定随之退役）、以及 LIMITATION #5
（单项 FD 不闭合——Γ/γ 双观测量消失后该问题不复存在）。

### 2.3 力公式推导

冻结 λ，约束焓 E_phys(R) = E_KS(ψ*(R), R) + λ(γ(ψ*(R), R) − t_γ)。
SCF 驻点条件 ∂E_phys/∂ψ = 0 ⇒ 响应项消失，

```
F_exact = −∂E_KS/∂R|_ψ* − λ·∂γ/∂R|_ψ*（显式几何导数）
        = F_std（含 Ô 的 Pulay）+ F_θ^geom + F_w^geom

F_θ^geom = −λ Σ_I Σ_n w_In Im[ z_n^{−1} Σ_j Tr(A^{(j)}_n ∂S_dk(k_j,k_{j+1})/∂R
           · C C† 形式) ]        （∂S_dk/∂R = 现有双中心导数积分 + 相位 ∂(dk·R)/∂R 项）
F_w^geom = −λ Σ_I Σ_n θ_n · ∂w_In/∂R|_geom  （SMO 基组随核移动的投影导数，snap cal_deri=1）
```

约束路径（γ = t_γ，λ*(R) 随动）：

```
F_exact(path) = F_exact − λ·(∂γ/∂λ)·(dλ*/dR)
```

与 Route A+ §4.2 形式相同，但两点实质区别：
(1) 响应 susceptibility 是**精确的** ∂γ/∂λ（可直接两点差分测得，物理意义为
极化磁化率），不再是被代理污染的 ∂Γ/∂λ；
(2) 平移不变性 Σ_I F_I = 0 成为**精确恒等式**（γ 只依赖重叠相位，均匀平移下
S_dk 相位 dk·R 对 R 的集体平移不变），现有 ΣF=0 验收从"单列测试"升级为"定理检验"。

**Born 电荷一致性（新可检验推论）**：对原子 J 施加位移 δR_J，约束焓对
均匀 Δγ 的响应满足 ∂²E_phys/∂R_J∂γ = −Z*_J（混合二阶导 = 有效 Born 电荷）。
EFC 框架下这给出独立于有限电场模块的 Z* 提取通道，且与 A2 项
（Route A+ 的 Born 电荷型主动力）在均匀 λ 极限下必须一致（§7 V-H6）。

### 2.4 耦合效率：弱耦合窗口的消除

**命题**。EFC 下代理-观测量耦合效率 η ≡ 1（构造性），剩余响应

```
dγ_I/dλ_J = χ^{γγ}_{IJ}   （精确的极化相位磁化率，物理量而非算符失配伪影）
```

达到目标 Δγ 所需乘子 λ* = χ^{−1}·Δγ，其大小由体系的真实介电响应决定，
不再被 0.07 的通道失配放大 14 倍。换言之：**Route A+ 的"弱耦合窗口"
不是物理约束太弱，而是代理算符把 93% 的约束强度泄漏到了错误通道；
EFC 在算符层面堵死该泄漏。**【待验证：V-H3 实测 η 从 0.07 → ≥0.9】

### 2.5 λ 更新：外层 secant 代理环的退役

Route A+ 需要三级调节（内层 Γ 残差 + 外层 secant 校准 t_Γ ← t_Γ + κ(t_γ−γ)），
根源是约束观测量（Γ）≠ 物理观测量（γ）。EFC 下残差直接是 γ − t_γ：

```
内层（SCF 每迭代）：λ += step·(γ_meas − t_γ)（γ_meas 用连续性锚定读数，§7 纪律不变）
外层（离子步）：  阻尼 Newton：λ ← λ + (χ^{γγ})^{-1}·(t_γ − γ_meas)
                  χ^{γγ} 由相邻离子步两点差分维护（Broyden 更新）
代理目标 t_Γ、κ clamp [0.3,20]、限幅 1.0 rad 全部退役
冻结协议不变：λ 文件 + Newton off
```

分支纪律的继承与简化：target-aware 分支的 γ 仍不可作判据（该纪律与
算符选择无关，来自测量链本身）；连续性锚定下 γ_meas 对 (ψ, λ) 可微，
Newton 良定义。分支跳变点是不可微点，需在 Broyden 更新中检测并重置
（附录 A.3）。

### 2.6 均匀 λ 极限：E_eff 校准的严格化

**命题**。取 λ_I = λ（全原子均匀），且 SMO 投影完备（Σ_I w_In = 1，§6），
则 H_c^EFC 退化为对整条 string 的均匀 Peierls 相位推移——即现代极化理论中
Berry 相位型有限电场的标准算符（Nunes–Gonze / Souza 形式）。

**推论**：
(1) EFC ⊃ 标准极化-电场方法：均匀极限提供了与 ABACUS 现有 efield 模块
    直接对拍的内置检验（§7 V-H1/V-H6）；
(2) E_eff 的换算不再是"从 ramp 势读出的工作定义"，而是严格恒等式

```
E_eff = λ·(∂γ/∂λ)/(∂μ/∂λ)   【EFC 下为恒等式，非交叉验证】
```

Route A+ §6.2 的焓斜率交叉验证式升格为定义本身；§6.1 的算符斜坡定义
E_eff = λ/(2a_α) 成为其在 H_HR 代理极限下的近似。【待验证：V-H1】

## 3. 改进二：Wannier 中心约束（Route W，实空间版混合规范）

### 3.1 动机与定义

混合规范的另一面：周期体系中 r 发散，严格的位置信息在 e^{iG·r} 中
（G = 2π/L 沿 gdir）。定义单 k 点版本的位置中心：

```
z^G_n(k) = ⟨ψ_n(k)|e^{iG·r̂}|ψ_n(k)⟩ = C†(k)·S^G·C(k)
x̄_n(k) = −(1/G)·Im ln z^G_n(k)
S^G_{μν} = ⟨φ_μ|e^{iG·r̂}|φ_ν⟩   （平面波核的双中心积分，TwoCenterIntegrator 同型）
```

原子分解约束观测量：γ^W_I = Σ_k w_k Σ_n w_In·(−Im ln z^G_n(k))（全 k 网格，

### 3.2 算符与力（完整推导）

## 附录 A：泛函导数的指标级代数

### A.1 左/右本征矢与一阶变分

W 非厄米（M_j 为重叠矩阵之积，非幺正），谱分解 W = Σ_n z_n u_n v_n†，
双正交归一 v_m†u_n = δ_mn。一阶微扰（非简并）：

```
δz_n = v_n† δW u_n，  δW = Σ_j W_{<j} δM_j W_{>j}
⇒ δz_n = Σ_j Tr[A^{(j)}_n δM_j]，  A^{(j)}_n ≡ W_{>j} u_n v_n† W_{<j}
```

### A.2 梯度分量

由 δM_j = δC†_j S_dk C_{j+1} + C†_j S_dk δC_{j+1}：

```
Tr[A δC†_j S C] = Tr[δC†_j S C A] = Σ_{μp} δC*_{μp}(k_j)·(S_dk C_{j+1} A)_{μp}
Tr[A C†_j S δC_{j+1}] = Σ_{μp} δC_{μp}(k_{j+1})·(S†_dk C*_j A)_{μp}
```

θ_n = Im ln z_n = (1/2i)(ln z_n − ln z*_n)，δγ_I = Σ_n w_In δθ_n + Σ_n θ_n δw_In。
收集 δC* 系数即得 §1.2 的 L/R 梯度公式；δw 项给出 §1.3 的 Ô_w。
γ_I 为实 ⇒ 全纯梯度为反全纯梯度之共轭，有效哈密顿量厄米。

### A.3 分支、简并与可微性

- Hungarian 匹配固定的带指标对应 ⇒ θ_n 沿 SCF 轨迹分段光滑；
  匹配跳变处 ∂θ_n/∂ψ 不连续：检测 |Δθ_n| > π/2 的迭代并冻结该步
  Broyden/Newton 更新。
- 简并（z_n = z_m）：逐带梯度失效，改用 det 形式：
  γ_tot = Im ln det W，δγ_tot = Im Tr[W^{−1}δW] = Σ_j Im Tr[M_j^{−1}δM_j]
  （沿 string 的递推无需本征分解），对占据子空间幺正重混合不变。
  Ô_θ^det 作为金属/简并体系 fallback，代价相同。
