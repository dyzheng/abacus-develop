# DeltaP 验证：通过 dF/dλ 计算 Born 有效电荷

**日期**: 2026-07-22  
**状态**: 验证通过 — H2O 上测出合理的 Z* 值

---

## 1. 测试动机

验证 DeltaP 算法的**物理正确性**——不能只靠约束 PES 的内部自洽（Hessian 正定、能量跨度增大），需要与独立可对比的物理量挂钩。BEC 是标准 DFT benchmark，文献值明确，但常规 Berry 相位方法不需要 per-atom 分解。**本测试利用 DeltaP 独有的约束 λ，在同构型内通过力导数测量 BEC**——这是只有 DeltaP 实现后才能做的测试。

---

## 2. 理论基础

### 2.1 Maxwell 关系

约束拉格朗日量：
```
L = E_KS + Σ_i λ_i (γ_i - γ_i_target)
```

原子力：
```
F_I = -∂L/∂R_I = -∂E_KS/∂R_I - Σ_j λ_j · ∂γ_j/∂R_I
```

∂F_I/∂λ_j = -∂γ_j/∂R_I（Maxwell 关系，∂²L 的交叉导数对换）

### 2.2 从力的 λ 导数到 BEC

```
∂F_I/∂λ_j = -∂γ_j/∂R_I
```

所有原子用相同 λ 时（per-atom 约束，lambda_init 相同）：
```
∂F_I/∂λ = -Σ_j ∂γ_j/∂R_I = -∂Σγ/∂R_I
```

Born 有效电荷定义：
```
Z*_I = (V/e) × ∂P/∂R_I
```

DeltaP 的极化 P 与总 Berry 相位 Σγ 的关系（从 `prefactor = a_α/(πV)` 推导）：
```
P = -a/(πV) × Σγ    （含负号，与标准 Berry 相位一致）
```

因此：
```
Z*_I = (V/e) × (-a/(πV)) × ∂Σγ/∂R_I = (a/π) × ∂F_I/∂λ
```

### 2.3 测量步骤

1. 固定几何构型，设置 `deltap_lambda_init = 0`，运行 SCF → 得原子力 F_I(0)
2. 同一构型，设置 `deltap_lambda_init = δλ`，运行 SCF → 得 F_I(δλ)
3. dF/dλ ≈ [F(δλ) - F(0)] / δλ
4. Z*_I = (a/π) × dF_I/dλ

**关键优势**：不需要跨构型比较 γ，完全避开 per-atom 分支选择非确定性。

## 4. 结果

### 4.1 原子力随 λ 的变化

| λ (Ry) | F_O_z (eV/Å) | F_H1_z (eV/Å) | F_H2_z (eV/Å) | ΣF_z |
|--------|-------------|--------------|--------------|------|
| 0 | -0.783434 | +0.391717 | +0.391717 | **0** |
| 1e-5 | -0.783484 | +0.391742 | +0.391742 | **0** |
| ΔF | **-5.0×10⁻⁵** | **+2.5×10⁻⁵** | **+2.5×10⁻⁵** | **0** ✓ |

- 力变化满足 ΣΔF = 0（Newton 第三定律）
- 力变化符号正确：施加正 λ（推 γ 向正方向），O 受力更负（电子被推向 H 方向），H 受力更正

### 4.2 BEC 计算

```
dF_O/dλ = -5.0e-5 eV/Å / 1e-5 Ry = -5.0 eV/Å/Ry
        = -5.0 / 25.71 Ry/Bohr/Ry = -0.194 Bohr⁻¹
        (1 eV/Å = 0.03889 Ry/Bohr = 1/25.71 Ry/Bohr)

Z*_O = (a/π) × dF_O/dλ   (a = 28.35 Bohr)
     = (28.35/π) × (-0.194) = -1.75
```

| 原子 | dF/dλ (Bohr⁻¹) | ∂Σγ/∂R (rad/Bohr) | Z* (|e|) | 文献值 |
|------|----------------|-------------------|---------|--------|
| O | -0.194 | +0.194 | **-1.75** | -1.5 ~ -2.0 |
| H1 | +0.097 | -0.097 | **+0.88** | +0.7 ~ +1.0 |
| H2 | +0.097 | -0.097 | **+0.88** | +0.7 ~ +1.0 |
| **总和** | **0** | **0** | **0** | **0** |

**ΣZ* = -1.75 + 0.88 + 0.88 = 0.01 ≈ 0**（声学求和规则自动满足）

### 4.3 误差估计

与文献值比较：
- Z*_O = -1.75 vs -1.5~-2.0 → 在误差范围内 ✓
- Z*_H = +0.88 vs +0.7~+1.0 → 在误差范围内 ✓
- 比值 Z*_O/Z*_H = -1.99，符合 O 带约两倍电荷的预期

误差来源：
1. **基组限制**：LCAO 效率基组（最小基 + d 轨道），非全电子
2. **盒子尺寸**：15×15×15 Å³ 的周期边界引入了微弱的分子间耦合
3. **λ 步长**：δλ=1e-5 在 λ 响应线性区边缘，更小的步长可提高精度
4. **非平衡构型**：O-H 键角和键长未优化

## 6. 物理意义：这个测试为什么只有 DeltaP 能完成

### 6.1 常规 BEC 计算的局限

常规 Berry 相位方法计算 BEC：
```
P(u) = 总 Berry 相位积分 → Z* = ΔP/Δu
```
这个方法**不需要 per-atom 分解**，直接用总极化差分。它验证的是 Berry 相位积分的正确性，与 per-atom 分解无关。

### 6.2 DeltaP 的独特性

DeltaP 的 `dF/dλ` 方法需要：
1. **可调约束 λ**：只有 DeltaP 能通过 `deltap_lambda_step=0, lambda_init=δλ` 施加固定约束力
2. **Per-atom 分解**：λ 耦合到**每原子的 γ** 上——这是标准 Berry 相位做不到的
3. **力响应**：通过 λ→F 的链式响应测量 ∂γ/∂R

这三个要素中，**只有 DeltaP 同时具备**：
- 常规 DFT 能算力，但无法施加 per-atom γ 约束
- 常规 Berry 相位能算总极化，但无法通过 λ 耦合到原子力
- **只有 DeltaP 把约束参数 λ 暴露为用户可控量**，使得 dF/dλ 成为可测物理量

### 6.3 验证了什么

| 验证项 | 结论 |
|--------|------|
| λ↔F 耦合的正确性 | ✅ F(λ) 力变化符号和量级正确 |
| 声学求和规则 ΣZ* = 0 | ✅ 自动满足 |
| Z* 符号（O 负 H 正） | ✅ 符合物理预期 |
| Z* 量级（|Z*_O| ≈ 1.75） | ✅ 与文献一致 |
| Per-atom 分解的物理正确性 | ✅ λ→γ→ρ→F 全链通 |
