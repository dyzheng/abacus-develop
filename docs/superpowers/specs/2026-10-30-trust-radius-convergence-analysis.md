# 2026-10-30 外层信任域收敛问题：数学形式、物理解释与处理方案

## 0. 现象

LiCl PW/LCAO 的 MBIS 电荷约束（目标 2.0）中，外层 μ 循环慢：
- PW（ecutwfc 50）：信任半径 0.2→0.4→0.8，**85 步收敛**；
- LCAO（ecutwfc 100 网格）：半径**停在 0.2**（零拒绝），100 步仅到 q=2.0216；
- `mixing_beta` 0.4 vs 0.2 无差别（内层 drho 已 ~2e-8）。

## 1. 数学形式

外层约束问题：求 `μ` 使
```
r(μ) = Q(μ) − t = 0 ,   Q: R^n → R^n
J(μ) = ∂Q/∂μ     (响应 Jacobian；稳定约束下负定，令 χ = −J ≻ 0)
```
在第 k 步，用模型 `m_k(Δ) = r_k + J_k Δ`，解**信任域子问题**
```
min_Δ || r_k + J_k Δ ||_∞    s.t.   ||Δ||_2 ≤ Δ_k
```
其解 = Newton 步 `Δ^N = −J_k^{-1} r_k`，若 `||Δ^N|| > Δ_k` 则截断为
`Δ = Δ_k · Δ^N/||Δ^N||`（代码 `mu_solver.cpp:661` 只在超半径时截断）。

预测/实际下降与比值：
```
pred = ||r_k||_∞ − ||r_k + J_k Δ||_∞
ared = ||r_k||_∞ − ||r_{k+1}||_∞
ρ    = ared / pred
```
半径更新（`mu_solver.h:41-46`，`mu_solver.cpp:776,815`）：
```
ρ > 0.5 (eta_good): Δ ← min(2Δ, Δmax=1 Ry)
ρ < 0.1 (eta_bad) : Δ ← Δ/2, 拒绝并回滚 μ
0.1 ≤ ρ ≤ 0.5     : Δ 不变
初始 Δ_0 = max(Δmin, min(step_max, Δmax))   （本用例 = 0.2）
```
**收敛率**：若 `J_k` 准确，ρ≈1、半径增长、Newton 二次收敛；**若 `J_k` 不准**，
ρ 落在 (0.1,0.5] → 半径既不增也不减 → 步长受模型限制、残差线性下降（很慢）。

## 2. 物理解释

- `χ = −J = −∂Q/∂μ` 是**约束响应（磁化率类量）**：单位 μ 能推动多少可观测量。
  LiCl 的 MBIS 盆电荷很"硬"：`χ≈0.04`（实测 Δq≈0.0062 / Δμ=0.15），
  故 **Newton 步 `r/χ ≈ 0.0323/0.041 ≈ 0.79** 很大——需要大 μ 才能挪动 Q。
- 但实测 μ 步只有 ~0.05（远小于半径 0.2），说明**模型 Jacobian `J_m` 高估了 χ**
  （`|J_m|≈0.65`，约为真值 16 倍），于是 `Δμ = −J_m^{-1}r` 被严重缩小。
- `J_m` 由**耦合 Broyden / 对角 secant**从实测 `(Δμ,ΔQ)` 更新。用**冻结 MBIS 权重**
  且内层 SCF 有噪声时，`ΔQ/Δμ` 有偏 → `J_m` 不准 → `pred` 与实际不符 →
  ρ 卡在 (0.1,0.5] → 半径不增长、步长被模型压小。
- **PW 与 LCAO 的差异**正是"模型准确度"的体现：同一物理、不同基组下 `J_m` 的
  估计质量不同（PW 恰好 ρ>0.5 使半径增长并收敛，LCAO 卡在中带）。
- 结论：**信任半径停滞是症状，根因是响应模型 `J_m` 不准（步长被压小）+ 半径
  增长门槛过严**；不是内层 SCF（drho 已 2e-8）、也不是 mixing。

## 3. 处理方案（按推荐优先级）

### 方案 A（最本质）：直接测量 `J`（探针），用 Newton 步
在当前 μ 处对每个分量做固定乘子（k=0）有限差分：
```
J_ij = ( Q_i(μ+δ e_j) − Q_i(μ) ) / δ
```
（即 `calibrate_alm`；LiCl n=1，只需 1 次额外 SCF）。得到准确 `J` 后
```
pred ≈ ared → ρ≈1 → 半径增长 → Newton 二次收敛
```
成本：n_comp 次 SCF/外层步；对 n 小（LiCl=1、Fe2 自旋=2）很划算。

### 方案 B：放宽半径增长门槛 / 放大初始半径
- `ρ>0.25` 即允许增长（而非 0.5），或"残差单调下降即接受并小幅增长"；
- 初始 `constraint_step_max` 取 0.5–1.0（接近 Newton 步 0.79），
  配合拒绝分支防过冲。**注意**：若模型仍把步长压到 0.05，单靠放大半径无效，
  需与 A（准确 J）或 C 配合。

### 方案 C：逐分量 secant（对角 Jacobian）
```
Δμ_i = − r_i / J_ii ,  J_ii 由最近一次 (Δμ_i, ΔQ_i) 估计
```
小 χ 分量自动得到大步；避免全局标量步被其他分量拖累
（代码已有 `constraint_inner_step_scheme jacobi` 路径，需确认对 MBIS 生效）。

### 方案 D：用增广拉格朗日的曲率作模型
ALM 目标 `φ(μ)=E+μr+(k/2)r²`，其 Hessian 已知含 `k`；把 `J_model ≈ −1/k`
（`k≈1/|χ|`，即 `calibrate_alm` 的 k）作为预测响应，使 `pred` 准确 → 半径增长。

### 方案 E：Newton + 线搜索（替代硬信任域）
得到准确 `J` 后取 `Δ=−J^{-1}r`，对 `||r||` 做 Armijo 回溯。没有半径停滞问题，
对模型误差更鲁棒；可与 A 直接配套。

### 方案 F：Broyden 初值/历史改进
用探针 `J` 作为 Broyden 初值（而非单位/对角），并保留跨步历史
（`constraint_trust_carry_jacobian`）；减少早期模型误差，使 ρ 尽快进入 >0.5。

### 方案 G（一致性，非性能）
冻结权重下 `∂Q/∂μ` 只含密度响应、不含 `∂w/∂μ`；若改为外层步**重建权重**，
需把这部分响应计入 `J`，否则模型与 Q 不一致。当前冻结选择对模型是自洽的，
不建议为提速而重建（更慢）。

## 4. 建议组合

1. **A + E**：探针测 `J`（n 小、便宜）→ Newton + 线搜索；最稳健、可迁移。
2. 快速验证：**B**（`constraint_step_max≈0.8`）+ 确认 **C**（逐分量 secant）
   对 MBIS 生效；若仍慢，升级到 A。
3. k 的标定与 **D** 结合（`k≈1/|χ|`）可进一步稳住外层。
