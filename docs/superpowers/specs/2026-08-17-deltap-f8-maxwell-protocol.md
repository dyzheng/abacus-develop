## 1. 主判据：内部 Maxwell 恒等式（不用 efield 对拍）

**推导链**（记账恒等式的直接推论，无场物理近似）：

```
escon = −λ·Γ                      （Route A+ 记账，LCAO 侧 T2/T3 已证）
∂E'/∂λ = −Γ                        （E' = E_KS(ψ*) 对 λ 偏导）
∂σ/∂λ = (1/V)·∂²E'/∂λ∂ε = −(1/V)·∂Γ/∂ε     （σ = (1/V)∂E'/∂ε）
⇒  V·∂σ/∂λ + ∂Γ/∂ε = 0            （恒等式）
```

- **A 侧**（新实现）：H_HK 应力 σ^HK(λ)，FD λ 扫描取斜率 ∂σ_zz/∂λ；
- **B 侧**（零新代码）：FD 应变 → Γ(ε)，取斜率 ∂Γ^HK_zz/∂ε（`compute_gamma_op_hk`
  现有机制，应变变形 + SCF 收敛后测量）。

不用 efield 对拍作**判据**：无 dip_cor 基线陷阱（amp=0 协议）、无 E_eff
换算（×1.6 response 校准不确定性）混入。但 efield 版压电对照
（∂σ/∂λ vs ∂P/∂ε·E）为**必测项**（评审 2026-08-17 签核修正）：内部
Maxwell 恒等是记账推论，PASS 只证明实现正确 + 记账在应变通道一致，
对 17.7× 类场物理失配**零信息量**——"17.7× 是否力路径特有"只能由
efield 外部参照回答。efield 侧沿用 F-2 协议纪律：dip_cor 基线 amp=0、
matched-μ 对照；必测项不设 pass/fail，但数据必须有。

## 4. 判据（预定义，无开放式测量）

```
| V·∂σ_zz/∂λ + ∂Γ_zz/∂ε | / |∂Γ_zz/∂ε|  ≤  5%    ⇒ PASS
```

- ∂σ_zz/∂λ：A 侧三点线性拟合（Ry/Bohr³ 每 Ry；V 用 Ω）。
- ∂Γ_zz/∂ε：B 侧四点线性拟合（rad 每应变）。
- Γ 取 Γ^HK_zz（H_HK 算符观测；总 Γ=Γ^HR+Γ^HK 若 HR 项应变响应
  在记账中抵消则用总 Γ——实现时以 escon 观测口径为准，文档标注）。
- 两侧拟合的相关系数需报告；任一侧无单调响应（|slope| < 噪声 3σ）
  则判据不适用，回查几何/网格设置后重测，不强行判定。

## 7. 评审补充（2026-08-17，执行方自查，两处口径精化）

### 7.1 A/B 两侧的 H_c 构成必须同一开关

判据 `V·∂σ/∂λ = −∂Γ/∂ε` 中的 Γ 必须是**进入 escon 的同一可观测口径**
（escon = −λ·Γ_obs），且 A 侧 σ(λ) 的 λ 依赖必须来自**同一 H_c 构成**：

- 场模式（H_HR off，F-2b 口径）：A 侧跑 `h_deltap_hk_only` 类门控
  （H_HR 关闭，仅 H_HK），B 侧 Γ 取 Γ^HK；两侧 H_HR 必须同为 off，
  否则密度响应的 λ 依赖（HF 已含）与记账 Γ 的构成错位，恒等式被
  记账口径差污染而非实现差污染。
- 全算符模式（H_HR on）：B 侧 Γ 取 Γ^HR+Γ^HK 全量（escon 实测口径），
  A 侧不设门控。实现时在 dated 文档中标注所用开关与 Γ 口径。

### 7.2 "∂E'/∂λ = −Γ" 的口径注释（防误读）

推导链里的 E' 指**扣除 escon 后的物理能量** E_KS(ψ*)（约束态上
Hellmann–Feynman 的直接推论）。报告总能量在记账精确时等于它
（T2/T3 的 escon≡−λΓ 恒等），此时 ∂E'_reported/∂λ ≈ 0（F-7b 实测
线性项 ~0.01 Ry/Ry 量级）——两者不矛盾：前者是物理能量对 λ 的偏导
（=−Γ），后者是记账抵消后的剩余（≈0）。A 侧测量的是**报告应力**
σ_reported(λ)（含密度响应，HF 定理保证其斜率 = −(1/V)∂Γ/∂ε 在记账
精确时成立），因此本判据同时检验两件事：① H_HK 应力实现是
E_HK(ε) 的精确梯度（V-H7 内部 FD）；② 记账恒等在应变通道仍然成立。
若 FAIL，按 §5 分支二分解（实现漏项 vs 记账口径不一致）。
