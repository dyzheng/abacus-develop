## 1. 物理目标与约束变量

目标：约束逐原子 Berry 相位 γ_I（极化的原子级分解）到目标 t_γ。

**γ 的严格定义（测量链，不变）**：沿 gdir 方向的 k-string 上构造 Wilson 环

```
W = Π_j M_j，  M_j 为相邻 k 点 SMO 重叠矩阵
γ_I = Σ_n w_In · θ_n，  θ_n = arg(eig(W))（Hungarian 匹配跨迭代跟踪分支）
w_In = Σ_{lm∈I} |D_{I,lm,n}|²（SMO 投影权重，D_I = ⟨SMO_I|ψ_n⟩）
γ → 偶极：先 2π unwrap，÷自旋因子 2（nspin=1），μ = 换算（F2，验证过 0.9%）
```

**关键事实**：γ 是 k 空间连乘的泛函，**不等于任何已实现哈密顿量算符的期望**。
这一不等性是 Route A+ 之前所有力问题的根源（§4）。

## 2. 约束哈密顿量（LCAO）

```
H_c = H_HR + H_HK

H_HR,μν = Σ_I λ_I · τ_α(I) · Σ_{lm∈I} c_μ(Ilm)·c_ν(Ilm)
  τ_α(I)：原子 I 沿 gdir 的【分数坐标】（taud；B-6 修复，禁用 lat0 单位）
  c_μ(Ilm)：SMO 展开系数（TwoCenterIntegrator::snap）
  λ_I：拉格朗日乘子，Ry

H_HK(k_L) = sym[ (i/2) · S_dk(k_L,k_{j+1}) · C_R · W_eff · C_L† ]
  W_eff[n] = Σ_I λ_I · w_In（沿首条 k-string 的占据带权重）
  S_dk 相位 = exp(2πi(dk·R − dk·τ_bra))，τ_bra 必须分数坐标（相位修复）
  符号约定 +(i/2)·sym，不可翻转（dev log #1）
```

PW 侧：H_c,PW = Σ_I λ_I·P̂_I^onsite（无 τ、无 H_HK），**PW 暂保持 gamma 旧记账**。

## 3. 能量表达式（Route A+ 的核心定义变更）

### 3.1 算符期望观测量 Γ（逐原子）

```
E_c ≡ Tr[ρ·H_c] = Σ_I λ_I · Γ_I

Γ_I = Γ_I^HR + Γ_I^HK
Γ_I^HR = τ_α(I) · ⟨P̂_I⟩，  ⟨P̂_I⟩ = Σ_k w_k Σ_n f_n Σ_{lm∈I} |D_{I,lm,n}(k)|²
Γ_I^HK = −0.5·Im[ Σ_j Σ_p f_p Σ_{p'} w_{I,p'}(j) · T_{pp'}(j) · Π_{p'p} ]
  T = C_L†·S_dk·C_R；Π = C_L†·C_L（Gram）
```

**非正交基教训（T2 轮）**：LCAO 基 C†SC=I 但 C†C≠I，故算符期望必须走
**T·Π 全迹**；对角约定（只取 p=p'）高估 ~18%，escon 与真实耦合错开，
E'(λ) 斜率残留 −13.3 eV/Ry。全迹修正后斜率 −0.013 eV/Ry（T2 判决）。

### 3.2 记账与恒等式

```
escon = −Σ_I λ_I · Γ_I
E'  = E_tot + escon ≡ E_KS(ψ*)     【恒等式，无近似】
```

E' = 约束态的纯 KS 能量：物理上干净（可比较不同构型/约束态），
且使力框架恢复 dspin 结构（§4）。

### 3.3 λ 响应（新旧对比，T2 实测）

```
旧（γ 记账）：∂E'/∂λ_I = Γ_I − γ_I − λ∂γ/∂λ ≈ 224 eV/Ry   （O(1)，力泄漏之源）
新（Γ 记账）：∂E'/∂λ_I = −λ_I·∂Γ_I/∂λ                    （O(λ)，实测 −0.013 eV/Ry）
```

## 4. 力公式（完整推导）

### 4.1 冻结 λ（组①）

```
F_exact = F_std + Pulay(λÔ) + λ·dΓ/dR|full
              └ A1+A2+B，已实现 ┘   └ 残余，O(λ) ┘
A1 = −Σρ·λ_I τ_α ∂(c_μc_ν)/∂R_J        （SMO 基组导数，snap cal_deri=1）
A2 = −λ_J ⟨P̂_J⟩ (L⁻¹)_{αβ}/lat0        （τ 显式导数，Born 电荷型主动力）
B  = −∂E_HK/∂R（全迹版，含 Π 权重、p≠p' 离对角项）
```

### 4.2 约束路径（组②/relax，Γ 激活 dΓ/dR=0）

dspin 恒等式成立（观测量=算符期望）：响应项 ⇔ Pulay 项互换，

```
F_exact(path) = F_std + A1 + A2 + B − λ(∂Γ/∂λ)·dλ*/dR
                                     └ O(λ) 驻点泄漏 ┘
```

**T3 判决（2026-08-05，h2o1 O1-z，生产设置）**：
残差 = −0.0138 eV/Å（修复前 84.8，改善 6100×）；
闭合计算 leak=−λ*·(dΓ/dλ)·Δλ*/2δ = +0.0127~0.0129 ≈ 残差（闭合率 1.07），
残差 ~100% 归因为 O(λ) 驻点泄漏，无未识别项。
严格判据 0.0129 线上未过（超 7%），判据表述为"工作窗 |λ*|≤λ₀ 内残差 ≤X"。

### 4.3 应力（同构）

σ = −(1/Ω)dE'/dε：标准应力模块 + S1（H_HR 对形式，已实现）。
τ 为分数坐标 ⇒ 固定分数应变下 ∂τ/∂ε=0，无 A2 类应力项。
残余 = λ·dΓ/dε（同构 O(λ)）。**H_HK 应力未实现（LIMITATION）。PW 应力未实现。**

## 5. λ 的三级调节机制

```
内层（SCF 每迭代）：残差 = Γ − t_Γ（平滑，无分支介入）
  · 同步模式：单步 GD（λ += step·(Γ−t_Γ)，mixing）
  · 内循环模式：冻密度 BFGS（deltap_inner_nmax>0）
外层（离子步/单点收敛后）：secant 校准代理目标
  t_Γ ← t_Γ + κ·(t_γ − γ_meas)，κ=Δt_Γ/Δγ（首轮 1，clamp [0.3,20]，限幅 1.0 rad）
  实测映射 dγ/dt_Γ ≈ 0.07（弱耦合 → 大极化靶点不可达，见 §8）
冻结协议（FD/生产）：deltap_proxy_target_file + deltap_secant off
```

## 6. E_eff 等效电场（Route A+ 新公式）

```
算符斜坡定义（第一性原理，从 H_HR ramp 势读出）：
  E_eff = λ / (2·a_α)  [a.u.] = λ/(2·a_α) × 51.422 [V/Å]     （无 π！）
焓斜率交叉验证：E_eff = λ·(∂Γ/∂λ)/(∂μ/∂λ)
旧公式 E=−πλ/(2a) 已退役（γ-共轭错配遗留；符号/因子由 V1 efield 对照钉死）
```

## 7. 测量纪律（分支与锚定）

1. **target-aware 分支选择的 γ 报告是靶点跟随的**（deltap_wannier.cpp:1333），
   不能作为任何收敛判据或 FD 可观测量（T4a 教训：λ=0 假收敛）。
2. operator 模式下 γ 只做外循环读数，且必须**连续性锚定**
   （W_prev_/deltap_branch.dat；`deltap_branch_anchor=continuity|target`）。
3. FD 比较用**未均值扣除**的力（FORCE_STRESS.cpp:599 会摊平不守恒项）；
   ΣF=0（平移不变性）单列验收。
4. FD 验收设置：ecutwfc=100 + 显式 ecutrho≥400 + scf_thr=1e-8（LCAO）；
   PW 80–100；归因分析可用低 ecut + 隔离对照。

### 已知限制（LIMITATION）
1. **弱耦合窗口——分两个口径（评审 2026-08-13 要求，引用数字必须带协议标签）**：
   - **可达域（SCF 可收敛口径，T-5' 2026-08-13 实测）**：|Δγ_O| ∈ [−0.004,
     +0.013] rad（λ 内循环预算 0.1 Ry 封顶；H 通道不可用：Δγ_H ≤ 0.001 rad ≈
     噪声级）。0.995/1.005 类靶点不可达；secant 外循环（proxy）对任何非自然
     t_γ 发散，不用于生产。
   - **力精度窗（泄漏预算口径，2026-08-13 反解——生产约束的真正边界）**：
     leak ∝ λ*（T3 锚：残差 0.0138 eV/Å @ λ*=1.09e-3 Ry → 斜率 ~12.7 eV/Å/Ry；
     γ-drive 口径 T3'：0.502 @ λ*_avg=1.05e-2 → 斜率 ~48）。按 0.02 eV/Å 预算
     反解 **|λ*|_max ≈ 0.4–1.6e-3 Ry** → **|ΔG|_max = (dG/dλ)·λ*_max ≈
     1e-5–5e-5 rad（0.01–0.1 mrad）**；评审模型（dλ*/dR=(dG/dR)/(dG/dλ)≈
     1.7/0.028≈60 Ry/Å）更严（~2e-6 rad）。**生产 γ-hold 只允许靶点≈自然值**；
     例：ΔG=0.005 rad → λ*=0.18 Ry → leak≈2.3（T3 线性）–8.6（T3' 线性）eV/Å ≫ 0.02（判据 100–400×）。
   - **响应数字口径对照表（D1/D2 轮定稿，详见 2026-08-12-deltap-ow-vh3-t18.md §1.5）**：

     | 标签 | 协议 | 数值 (rad/Ry) |
     |---|---|---|
     | ow-R5-大尺度 | ow λ 扫描 SCF 收敛，[−0.01,+0.01] 弦斜率 | dγ_O=+0.26（局部 ±0.8–1.4 非单调） |
     | ow-a2-自洽 | ow γ-drive 探针，密度弛豫后 | dγ_O≈+0.06 |
     | ow-D2反推 | E_eff^(ow,O)×dG/dE | dG/dλ≈0.052 |
     | proxy-D1-自洽 | proxy λ 扫描 SCF 收敛 | dG/dλ=+0.028（线性） |
     | 物理上限 1/κ | D2 κ_phys=60.4 Ry/rad²，共轭归一化 | ≈0.017 |

     "T-18 与 proxy 同量级" 仅成立在 **R5-大尺度 vs 旧 proxy 混合** 口径；
     按自洽总 G 口径 ow(0.052) = 1.9× proxy(0.028)，proxy 已贴 1/κ 上限 1.6×。
     密度弛豫屏蔽 80–95%（ow 冻结 0.8–1.4 vs 自洽 0.06–0.26）。
   - **Ô_w 未扩窗（T-18 FAIL）**：按自洽总 G 口径改善 <2×（0.028→0.052），
     远非所需 10×；γ-hold 约束的可达域是"算符-观测量耦合物理强度"问题，不是
     协议选择问题（T3' 0.502 eV/Å 即 Γ-面与 γ-面之间的力差）。
2. **场模式（长程电场近似，F-1/F-2/F-2b 判决）——双行表述**：
   - **能量/响应侧（已实测可用）**：E₀(μ) 与锯齿场 efield 双通道对拍，
     **\|λ\|≤0.007 Ry（\|E\|≲6e-4 a.u.）窗口内偏差 <1e-3 eV**（F-2；
     proxy 与 hk 全算符版同——F-2b 实测 hk 与 proxy E'(λ) 差 ≤34 μeV）。
     极化响应（γ→μ）、偶极矩（1.838 vs 1.855 D）合格。
   - **力侧（实测不可用，F-2b 2026-08-13 判决）**：matched-μ 力偏差
     2.6%@\|λ\|=0.001 → **26%@\|λ\|=0.01**；力/μ 隐含场杠杆比
     **17.7×（hk）/15.7×（proxy）**。**根因重定位**：H_HR（τ·P̂）对总力
     贡献 ≤0.6%（hk vs proxy 总力差 @\|λ\|=0.01 仅 6.1 meV/Å）——F-2
     "τ·P̂ 打在原始布居"归因已证伪；失配内禀于 **H_HK 离散 Berry 联络力
     通道**（B 项 −λ∂Γ^HK/∂R 杠杆 −30.1 eV/Å/Ry，∂Γ^HK(O1)/∂R_z≈+1.17
     rad/Bohr）。**物理本质（评审点破）**：H_HK 能量的 R 依赖走极化通道
     （∂γ/∂R=Born 电荷）与基组几何通道（S_dk/SMO 投影位置导数）双通道，
     真实场力 E·Z* 只允许前者，B 项两者都算——"有力无极化"（T3 与 F-2b
     双命题并存：T3=内部梯度自洽，F-2b=场物理失配，均成立）。
     **relax/力生产需要力级 EFC**（唯一第一性解法：Ô_θ 算符期望即 γ，
     其 R 导数是纯极化通道，Maxwell 一致性白来；目标 L_F=L_μ，验收
     matched-μ 力偏差 <2%）；能量侧 EFC 动机不再成立。可选的半经验补丁
     F_phys=F_DP−λ∂Γ^HK/∂R+E·Z*（Z* 取 efield 通道实测）为
     *empirical correction, not ab-initio*——仅当 ① Z* 在 2–3 个几何验证
     可迁移（小位移下近似常数）② 文档带此标注时才可用于 relax，否则挂起。
     **约束模式封口（评审 2026-08-13）**：F-4 不做（冻密度 γ 响应符号反转
     结构性死亡 + γ-hold 力泄漏 0.5 eV/Å + 场模式无泄漏且有消费者）——
     γ-hold 生产路径维持 proxy 驱动，可达域/力窗见本条目第 1 项。详见
     `2026-08-13-deltap-f2-field-comparison.md`、
     `2026-08-13-deltap-f2b-hk-field-mode.md`。
   - **α_LCAO 基组效应（D2）**：h2o1 LCAO 实测极化率 3.02 Bohr³ = 实验
     9.8 的 31%（紧缩基低估 3.3×，κ_phys=60.4 Ry/rad²）——**所有 LCAO
     极化率类结论（P01/P05 判据）参考值必须按基组重定标，勿以实验 α 判
     LCAO 数值**。E_eff 打印为公式 (b)（πλ/2a），响应校准约 ×1.6（proxy）
     /×3.1（ow O），打印行已带注释，用户换算须读注释。
