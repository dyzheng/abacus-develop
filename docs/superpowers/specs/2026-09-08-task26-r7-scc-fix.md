## 2. 根因（代码级）

  `hamilt2rho_single` 注入 μw 之后取快照、再由 `update_from_charge` 重建（无 μw）——
  于是 vnew = v_phys(ρ_out) − [v_phys(ρ_in)+μw]（含 −μw）。SCC 力核用 vnew×∂ρ_core/∂R 积分，

  只留 O(drho)；力侧 SCC 是单边差、无对消 → 系统性伪力。
