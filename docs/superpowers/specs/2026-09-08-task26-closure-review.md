1. **诚实边界处理是本轮最大亮点**：PW≡LCAO 的"严格同密度 <1e-8"没有硬凑 PASS——
   明确指出需要只读观测口（init_chg=file 会重收敛密度）并登记为开放项；
   DeltaSpin 10× 量级差不粉饰（on-site 投影 vs Becke 是不同观测量），降格为
   "符号+机制"级对标并把量级对等留给 P3/阶段 B 测量。这正是本仓库评审文化的要求。
2. **力矩验证的实际强度高于原设计**：原案是"与 DeltaSpin 直接比 λ"；实际交付改为
   包络恒等式验证（T_ana=−μ* vs 能量 FD，54× 富余）——这是更强的内部自洽证据，
   DeltaSpin 降级为符号交叉验证。判据变更已如实记录，裁定：接受。
3. **扭矩工具缺陷（E' 伪项）是有价值的副产品**：与力 FD 的 raw-E 教训同源，
   证明"记账口径必须逐案推导、不能从力 FD 机械搬运"——建议修复
   run_constraint_torque_fd.sh 并入 A 阶段工具补件。
4. 外推理由（§3.5）成立：机制级 bug、修复作用于共用求值输入、已过两轴覆盖两个极端
   （权重导数最强方向 + 修复变化最大轴）——残余风险被"净力≈0 + 双轴 FD + PW 9/9"
   包围，且外推声明限定包络不作普适声明。
