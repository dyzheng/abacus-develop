> 本文档是 DeltaP 功能"能做什么、不能做什么、边界在哪"的唯一权威说明，
> 面向使用者与评审者。数值结论以本文档为准；主算法文档

---

## 0. 一句话定位

**DeltaP 当前是"小窗口精密约束 + 场模式能量/响应"工具：**
约束模式在自然极化附近的小窗口内（S C F 单点与 Γ-路径力）已验证可用；
场模式（均匀 λ 近似长程电场）的能量与极化响应已验证可用；
**任何 relax/MD、大极化改变靶点、LCAO 多 rank 力路径，当前均不可用。**

## 1. 能力矩阵（按使用场景）

### 1.1 约束模式（deltap_corr=1，给定 γ 靶点）

| 场景 | 状态 | 边界/条件 |
|------|------|-----------|
| LCAO 单点 SCF（串行） | ✅ 可用 | 全部靶点类型（per-atom/total/约束矩阵/掩码/gdir 1-3）验证过 |
| LCAO 多 rank | ✅ 可用（D_I/S_k/HK 三轮修复 + F_HK 力 MPI 化后） | 非方本地块已解锁（656a2a59d）；E' 差 ≤2.5e-5 eV（FP 噪声经 λ 累积） |
| PW 单点/多 rank | ✅ 可用 | KPAR=1 硬限制；**PW 已切 Route A+ operator 记账（L1.1，2026-08-17：escon=−λΓ^PW，Γ^PW=⟨P̂^onsite⟩，λ 驱动保持 γ 残差）**；E'(λ) 平直性 @真 ecut=80 线性项 0.00014 Ry/Ry（F-7b，inner_thr=1e-6 口径）；无 target 文件/约束矩阵接线；total 为假模式 |
| 约束模式力（Γ-路径，小 λ） | ✅ 可用 | T3 判决：残差 0.0138 eV/Å（判据 0.0129 的 1.07×），工作窗见 §2 |
| 约束模式力（γ-hold 路径） | ❌ 不可用 | T3' 实测 0.502 eV/Å（λ² 泄漏）；任何"严格钉 γ 的 relax"都走这条路径 |
| 内循环 λ 优化 | ⚠️ 受限 | 冻密度响应符号反转（−1.28 vs 自洽 +0.03 rad/Ry），冻密度 BFGS 对 γ 结构性失效；同步/SCF 级驱动可用 |
| relax/MD（任何靶点） | ❌ 不可用 | 见 §4-F1：力路径窗口比收敛路径窄得多 |

### 1.2 场模式（均匀 λ ≈ 长程电场）

| 场景 | 状态 | 边界/条件 |
|------|------|-----------|
| 能量/极化响应 | ✅ 可用（窗口内） | E₀(μ) 与锯齿场对拍 <1e-3 eV @ \|λ\|≤0.007 Ry（F-2）；E_eff=πλ/(2a)，实测校准 ×1.6 |
| 场模式力 | ❌ 挂起 | F-2b：力/极化 Maxwell 失配 17.7×（H_HK 能量含非极化几何通道）；第一性解法 = EFC（未立项）；半经验 Z\* 补丁可选（需标注非从头算） |
| 场模式应力 | ❌ 未实现 | H_HK 应力缺失；压电 Maxwell 同族问题待验 |

### 1.3 实验性/不可用

| 场景 | 状态 |
|------|------|
| ow 模式（Ô_w 精确权重算符） | ⚠️ 实验性：SCF/记账可用，**力未实现（F_ow 缺失）**；多 string 网格算符不完整（仅 string-0 覆盖）；应力 WARNING_QUIT |
| KPAR>1 | ❌ 守卫拒绝（k-string 跨全 k 列表） |
| 金属/近简并体系 | ❌ 未验证（分支/本征矢不稳定，理论上需 det 形式 fallback） |

## 2. 定量边界（工作窗）

### 2.1 约束模式

| 边界 | 数值 | 出处 |
|------|------|------|
| Γ-路径力残差 | 0.0138 eV/Å @ λ*≈1e-3 Ry；∝ λ² 增长 | T3 + 闭合率 1.07 |
| γ 可达域（h2o1，λ 预算 0.1 Ry） | O：Δγ∈[−0.004, +0.013] rad；**H：双侧死（±0.001）** | T-5' 窗口测绘 |
| γ-hold 力残差 | 0.502 eV/Å @ λ*≈0.02 Ry | T3'（闭合 96.7%） |
| 传递效率 dγ/dΓ | ≈0.07（自洽）；dγ/dλ≈0.028–0.05 rad/Ry | Q1/D1/D2 |
| γ 物理刚度 κ（h2o1，LCAO 基组） | ≈60 Ry/rad²（α_LCAO=3.02 Bohr³，紧缩基低估实验值 3.3×） | D1/D2 |

**窗口的用法**：小窗口 = 靶点靠近自然极化（界面反场补偿类应用正好落在这里）。
大窗口靶点（|Δγ| 大）当前不可达——主因是体系物理刚度 + 代理传递效率，
**不是 bug**；Ô_w 已实测不能扩大窗口（T-18）。

### 2.2 场模式

| 边界 | 数值 | 出处 |
|------|------|------|
| 能量窗口 | \|λ\|≤0.007 Ry：E₀(μ) 对拍偏差 <1e-3 eV；λ=0.01 时 1.55 meV | F-2 |
| E_eff 换算 | E_eff = πλ/(2a) a.u.（λ Ry，a 该方向周期 Bohr）；response 校准 ×1.6（proxy ΣG 口径） | D2 + F-5 |
| 力偏差 | matched-μ 下 2.6%（λ=0.001）→ 21–26%（λ=0.01） | F-2/F-2b |
| dip_cor 协议 | efield 基线必须 amp=0；力对比必须 no-dip_cor 系列（镜像自能 +3.70 meV 常数） | F-2 协议教训 |

### 2.3 数值/验证设置边界

| 项 | 要求 |
|----|------|
| FD/验收设置 | LCAO：ecutwfc=100 + 显式 ecutrho≥400 + scf_thr=1e-8；PW：ecutwfc 80–100。低 ecut 只可用于隔离对照 |
| 基组 | 紧缩基（DZP 级）极化率低估 ~3×——极化率类结论须按基组定标，勿与实验 α 直接比 |
| MPI | LCAO 4-rank 方阵验证过（E' 差 ≤2.5e-5 eV，FP 噪声经 λ 累积，长轨迹可漂移）；非方网格被守卫拦 |
| 历史数据 | 2026-08-03 前的 λ 值受 B-6 影响需 ×1/L 重标定；之前的 E' 含 λ(Γ−γ) 污染 |

## 4. 失效模式诊断表（用户遇到 X 时）

| 症状 | 原因 | 对策 |
|------|------|------|
| F1: relax 轨迹能量不降/力异常大 | 力路径超出窗口（γ-hold 或大 λ） | 约束模式 relax 当前不支持；只用单点 |
| F2: 多 rank 报 "nrow != ncol" WARNING_QUIT | ~~方阵网格守卫（L2）~~ L2 已解除（656a2a59d），不应再出现 | 若复现 = 回归，报 bug |
| F3: "KPAR>1" WARNING_QUIT | L1 | kpar=1 |
| F4: γ 收敛到靶点但 λ=0 | target-aware 假收敛（L10） | 检查连续性锚是否激活（branch.dat 参考） |
| F5: ow 模式应力为 0 | L6 守卫（应力 WARNING_QUIT 前的旧版本静默缺失） | ow 模式不算应力 |
| F6: 与旧版本数值对不上 | B-6 τ 单位（2026-08-03 前 λ ×1/L 重标定）+ S_k 键修复（2026-08-04 前逐原子 γ 重分配） | 用当前版本重跑基线 |
| F7: 内循环振荡不收敛 | L7（冻密度响应反号） | 用同步/SCF 级驱动（deltap_inner_nmax=0） |
| F8: efield 对拍差常数 | dip_cor 镜像自能 | 基线取 amp=0（F-2 协议） |

## 5. 物理适用域总结

**适合**：
- 绝缘体/分子的极化约束与场响应（已验证：H2O 偶极 0.9%、BN 零刚度发现）；
- 界面/表面反向电场补偿（靶点≈自然极化，正在小窗口内）；
- 极化势能面采样（单点链，无 force 需求时窗口最宽）。

**不适合**：
- 大极化改变（铁电翻转全程、强场响应）——物理刚度 + 传递效率双重封顶；
- 约束 relax/MD（力路径未通）；
- 金属/近简并体系（分支理论未覆盖）。

**生态位备注**：分子/slab 的均匀场需求可先用 ABACUS 锯齿场（efield）满足；
DeltaP 场模式的独特价值在**真正 bulk 周期体系**（锯齿无处可放）——
但该定位的力侧交付以 EFC 为前提（未立项，见
`2026-08-07-deltap-route-a-plus-plus-review-and-plan.md`）。
