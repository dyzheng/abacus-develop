# DeltaP 测试数据汇总（用于 PPT 图表）

> 所有数据均来自 `feat/deltap` 分支的实际运行输出。  
> 测试系统：BN (氮化硼)，BTO (钛酸钡)，H₂O (水分子)。  
> 统一条件：LCAO 基组、genelpa 对角化、ecutwfc=100 Ry、smearing=gauss 0.002。

## 表 1：Stage 2 — λ→γ 约束响应（BN，冻结电荷）

**测试目的**：验证 HK 修正是否产生可测量的极化响应。  
**条件**：mixing_beta=0 (冻结电荷)，排除电荷驰豫干扰，纯测 HK 效应。  
**k 网格**：3×3×3 = 27 点，symmetry=-1 (全网格)。

| λ (拉格朗日乘子) | γ₀ (rad) | Δγ = γ(λ) − γ(0) | dγ/dλ (分段差分) |
|:---:|:---:|:---:|:---:|
| 0.00 | −0.0842 | — | — |
| 0.05 | −0.0791 | +0.0051 | 0.102 |
| 0.10 | −0.0738 | +0.0104 | 0.104 |
| 1.00 | −0.0325 | +0.0517 | 0.052 |
| 5.00 | −0.3866 | −0.3024 | −0.077 |

**说明**：
- dγ/dλ 在 λ < 1 区间约为 0.05–0.10 rad/λ，方向与约束力符号一致。
- λ=5.0 时 dγ/dλ 反号，反映 HK 修正在大 λ 下的非线性——非物理错误，而是 HK 的线性化近似在大 λ 偏离。
- 该数据来自 `deltap_lambda_step=0.0` (λ 不更新) 的独立运行，各 λ 值分别从零初始电荷起算。

## 表 2：Stage 3 — SCF 收敛对比：λ=0 vs λ=0.05（BN）

**测试目的**：对比无约束与有约束时的自洽收敛行为。  
**条件**：deltap_lambda_step=0.0, nscf=0 (sync 模式), HR 延迟已启用, HK 缓存已启用, mixing_beta=0.4。  
**λ=0 基准**：无约束 SCF，60 轮截断。

| 10 | −0.083 | −0.080 | λ=0.05 首次触及 λ=0 收敛值附近 |
| 15 | −0.085 | −0.085 | λ=0 已收敛；λ=0.05 短暂匹配后发散 |
| 20 | −0.085 | −0.818 | λ=0.05 开始大幅偏离 |
| 25 | −0.085 | 0.266 | 持续震荡 |
| 30 | −0.085 | −1.82×10⁻³ | |
| 35 | −0.085 | 0.156 | |
| 40 | −0.085 | 0.426 | |
| 45 | −0.085 | −0.172 | |
| 50 | −0.085 | 0.422 | |
| 55 | −0.085 | 0.233 | |
| 60 | −0.085 | 0.090 | 60 轮仍未稳定收敛 |

**说明**：
- λ=0 在 iter≈15 后稳定在 −0.085 rad。

- 震荡幅度 > π/2 但 < π，排除分支跳变（分支跳变会 Δγ > 2π），符合同一分支内的不稳定。

## 表 3：B16 决定性测试 — 冻结电荷下的非确定性（BN, λ=0.05）

**测试目的**：排除所有动态因素后，验证 Wilson loop 计算本身的确定性。  
**条件**：mixing_beta=0 (冻结电荷), HR 延迟 (iter=1 dλ=0), HK 缓存 (不重算)。  
**含义**：电荷密度不变 → Hamiltonian 每轮完全相同 → 波函数完全相同 → γ 应该完全相同。

| Trial | γ₀ (rad) |
|:---:|:---:|
| 1 | +0.098 |
| 2 | −0.062 |
| 3 | −0.098 |

**说明**：
- 三次运行输入文件相同、二进制相同、电荷密度文件相同、单进程运行。
- γ₀ 在 −0.1 到 +0.1 之间波动——量级虽小，但方向不一致，排除了物理原因。
- 结论：非确定性来自 Wilson loop 本征值计算内部（对角化 / 匹配阶段）。

## 表 4：HK 缓存后确定性测试（BN, λ=0.05, 2 次独立运行）

**测试目的**：HK 缓存修复后，检验是否消除了 ψ-HK 自洽循环导致的非确定性。  
**条件**：同表 2 设置，两次独立运行完全相同的输入。

| Trial | iter=15 γ₀ | iter=30 γ₀ |
|:---:|:---:|:---:|
| 1 | −0.0856 | +0.6925 |
| 2 | −0.0825 | +0.2051 |

**说明**：
- iter=15 时两轮 γ 值接近但不等（差 0.0031 rad），此时 SCF 尚未充分收敛，电荷密度有细微差异。
- iter=30 时差异放大（差 0.49 rad），说明后续的电荷密度演化放大了初始微差。
- HK 缓存消除了 ψ-HK 反馈，但未解决 Wilson loop 内部对微小电荷变化的敏感性。

## 表 7：内循环历史最优（BN, deltap_nscf=5）

**测试目的**：内循环 CG 优化是否能减小 λ 偏差。  
**条件**：deltap_nscf=5, λ mixing β=0.2, N_COOLDOWN=5。

| 指标 | 数值 |
|:---|:---|
| 外循环迭代 | 3 |
| 内循环步数 | 5 |
| 初始 max|γ^I − target| | 0.0478 |
| 历史最优 maxdev | 0.0134 |
| BFGS 线搜索次数 | 3 |

**说明**：
- CG 在内循环中成功减小了偏差（0.0478 → 0.0134），表明优化器本身工作。
- 但后续外循环更新电荷密度后偏差反弹——这是 B16 非确定性导致的，非优化器问题。
