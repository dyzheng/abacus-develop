# 新旧 DeltaP 方案的区别：一份通俗解说（2026-08-13）

> 写给有材料背景、但不熟悉算法细节的读者。
> 目标：讲清楚"基于 Wilson 环特征值的旧方案"和"当前的算符期望方案（Route A+）"
> 到底差在哪、为什么换、换来了什么、没换来什么。
> 全文只有一个核心公式，其余都是图像和数字。

---

## 1. 两套方案共同的东西：怎么"量"极化

两套方案**测量部分完全一样**，先把它说清楚。

周期性体系里，电子的极化不能直接用"平均位置"算（位置算符在周期边界下发散），
标准做法是算 **Berry 相位**：把 k 空间的一条路径切成一串点，把相邻点上
电子波函数的重叠矩阵依次连乘（这串乘积叫 **Wilson 环**），乘积矩阵的
**特征值的辐角**就是 Berry 相位 γ。DeltaP 进一步用 SMO 投影把总 γ 拆成
每个原子的贡献 γ_I。

可以把 γ 理解成"电子云的重心位置"的一种周期性度量。两套方案都靠它读数，
**谁也没改过这条测量链**。

区别在下一步：**测到 γ 之后，怎么用它去"约束"体系。**

## 2. 旧方案：直接拿 γ 当约束变量

想法很直白：要约束 γ，就在哈密顿量里加一个拉格朗日乘子项，
再在能量里记账：

```
哈密顿量加一项：H_c = Σ_I λ_I·（一个局域代理算符）
能量记账：     escon = −Σ_I λ_I·γ_I      ← γ 是 Wilson 环读数
力的计算：     只对 H_c 的算符求导（标准 Pulay 力）
```

问题在于：**哈密顿量里放的是"代理算符"，记账里减的却是"Wilson 环读数"——
这两个东西数值上从来不相等。**

用弹簧打个比方：约束就像用弹簧把 γ 拉到目标值，λ 是弹簧力。
旧方案的账本写的是"弹簧直接拴在 γ 上"，可实际上弹簧拴在**另一根杠杆**上
（代理算符的期望 Γ），这根杠杆和 γ 的联动又弱又不同步。于是：

- **能量账本对不上**：实测 ∂E'/∂λ ≈ 224 eV/Ry（本该接近 0）。
  形象说：约束谷底沿 λ 方向是倾斜的，λ 每动一点，账上就平白多出/少掉
  一大笔能量。
- **力对不上**：弛豫时 λ 必须随结构移动才能钉住 γ，而能量沿 λ 倾斜
  ⇒ 有限差分（FD）测到的力比解析算出的力多出 **84.8 eV/Å**
  （判据是 0.013）——约束一拧紧，力就完全不可信。
- **附带怪象**：为了让 γ 读数"靠近目标"，旧方案把分支选择做成了
  "跟着靶点走"——结果出现 λ=0 也"收敛到目标"的假收敛（T4a 教训）：
  读数被靶点吸住，物理响应被吞掉。

## 3. 新方案（Route A+）：约束"算符自己的观测量"，γ 降级为读数

改动一句话：**弹簧拴在哪根杠杆上，账本和约束就认哪根。**

```
定义 Γ_I = Tr[ρ·(约束算符)]/λ_I   （约束算符的逐原子期望，两条通道：
                                    Γ^HR = τ·⟨P̂⟩，Γ^HK = 全迹 Gram 修正）
能量记账：escon = −Σ_I λ_I·Γ_I     ← 与哈密顿量里的算符严格同一个对象
约束变量：SCF 里 λ 驱动的是 Γ（不再是 γ）
γ 的角色：只作物理读数（算偶极、看靶点），退出 SCF 收敛路径
```

这样做的回报是一个**恒等式**：

```
E' = E_tot + escon ≡ E_KS(ψ*)      （约束态的纯净 KS 能量，无近似）
```

由于记账对象和算符对象严格一致，数学上可以证明（DeltaSpin 定理的同款结构）：
**约束激活时，标准 Pulay 力就是精确力**——不需要任何额外的 escon 力项。
实测效果：

| 检验 | 旧方案 | 新方案（Route A+） |
|------|--------|--------------------|
| E'(λ) 斜率（应≈0） | 224 eV/Ry | **−0.013 eV/Ry**（四个数量级压平） |
| 约束激活 FD 力残差 | 84.8–419 eV/Å | **0.0138 eV/Å**（机制闭合率 1.07） |
| γ 读数假收敛 | 存在（靶点跟随） | 消除（连续性锚定 + 模式门控） |

## 4. 新方案的代价与边界（诚实清单）

Route A+ 不是免费的，它的代价全部来自"Γ 和 γ 不是同一个东西"这个物理事实：

1. **需要一个翻译层**：用户关心 γ，约束旋钮是 Γ，两者之间要靠一个
   外循环（secant 校准代理目标 t_Γ）翻译。翻译层在弱耦合区工作良好，
   在大靶点区会失效（见第 3 条）。
2. **γ 不再直接钉在靶点上**：每个离子步的 γ 由测量确认，外循环修正；
   约束路径的严格含义是"Γ 面"而非"γ 面"。
3. **可控窗口有限（本轮最重要的物理结论）**：
   - 实测 Γ→γ 的传递效率只有 ~7%（dΓ/dλ≈−4.2 vs dγ/dλ≈−0.3 rad/Ry），
     把 γ 推离自然值很远需要巨大的 λ，而力残差 ∝ λ² 增长——
     T3' 实测：γ 直驱路径的力残差 0.502 eV/Å（不可用）；
   - D1/D2 轮进一步查明：**窗口小主要是体系物理刚度**（小盒分子的 γ 被
     极化率锁死，κ≈60 Ry/rad²；LCAO 紧缩基又把极化率低估 3.3 倍），
     不是算符不够好——精确的权重通道算符（Ô_w，T-18）也没能提升响应；
   - 另有结构性死角：H 原子的 Γ 代理在两个 λ 方向上都把 γ 往反方向推
     （"H 死通道"），单侧靶点对该通道不可达。
   - **结论：Route A+ 的合法工作区是"靠近自然极化的小靶点"**——
     恰好覆盖反向电场/界面极化补偿这类真实应用。
4. **E_eff 公式换了**：等效电场改按共轭关系 E_eff = πλ/(2a)（λ 单位 Ry），
   并有实测校准偏差（proxy 模式 ×1.6）随打印注明；旧公式的数值不能直接比。

## 5. 一张图总结

```
旧方案：  靶点 t_γ ──约束──> γ（Wilson 读数）
                记账 −λ·γ ✗ 与算符不符
                结果：能量斜、力错 84.8、读数会被靶点吸住

新方案：  靶点 t_γ ──外循环校准──> 代理目标 t_Γ ──约束──> Γ（算符期望）
                记账 −λ·Γ ✓ 与算符严格一致（E' ≡ E_KS 恒等式）
                γ 只做读数（连续性锚定）
                结果：力残差 0.0138（窗内）；窗口边界由 κ（物理刚度）划定
```

## 6. 后续方向（一句话版）

- **Ô_w（精确权重通道算符）**：已实测——不提升耦合（T-18），
  否决了"换精确算符就能扩大窗口"的设想；
- **EFC/Ô_θ（全精确泛函导数）**：若做，价值在"大靶点下消路径泄漏"
  （∂E/∂λ=γ−t≡0），不是提升响应；是否立项取决于是否有大极化窗口的应用需求；
- **当前可交付**：小窗口内的约束 SCF 与自洽力（Route A+，已过判决），
  工作窗与 LIMITATION 随用户文档发布。
