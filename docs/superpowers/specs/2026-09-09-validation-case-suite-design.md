# 实空间权重约束：真实体系验证算例集设计（离子型 / 过渡金属氧化物 / 电荷转移 / bulk）

> 目的：把验证从 H₂O（玩具体系，共价小分子）扩展到框架的真实应用域。每算例回答一个 H₂O 回答不了的物理问题。
> 原则（承算例重设计 2026-09-09-fd-case-redesign.md）：每个算例必须有**独立参照物**（文献值 / DeltaSpin 对照 / CDFT 文献 / 内部恒等式），不带独立参照的 PASS 不算数；成本按重设计处方（LCAO 优先、dav_subspace、标定网格、release、fixed-μ）。
> 本轮零代码改动、零计算提交。

## 0. 仓库资源摸底（已核实）

| 资源 | 现状 |
|---|---|
| 现成赝势+轨道 | Fe（多套）、Ni、Ti、Pt、Na、Cl、Mg、O、H、Si |
| **现成 TM 氧化物基线** | `tests/17_DS_DFTU/11_PW_DFTU_S2_FeO`（FeO）+ `12_PW_DS_S2_Z`（Fe 基 **DeltaSpin** 用例——自旋约束的直接对照物） |
| 资源缺口 | Au（V6 Au:Si 需外部赝势或换掺杂体系）、Mn、C 的 PBE 赝势（TCNE 类 CT 复合物需要）——**启用前需补库或换体系** |

## 1. 组 I：离子型体系——验证"可达域由体系决定"（R4 的实证检验）

**物理动机**：设计方案 §1.4 的论断——DeltaQ 的正当适用域是**电荷局域、位点可分辨的离子/缺陷体系**；H₂O 的 ±0.3 e 窗口是共价极化刚度造成的，离子体系应展示**显著更宽的线性可达域**。这是"窗口不可跨体系外推"（R4）的正向实证。

### I-1 MgO 或 NaCl 体相（原型离子晶体）
- 体系：MgO rocksalt 原胞/2×2×2（Mg_ONCV_PBE-1.0 + O 赝势在库）；或 NaCl（Na + Cl 在库）；
- 约束：charge on 阳离子片段，delta = ±0.3 / ±0.5 / ±0.8 / ±1.0 e 扫描（H₂O 上限的 3 倍）；
- 判据：① 全点达标无封顶（对照 H₂O 的 κ≈1.7，测离子体系的有效 κ 与线性区宽度）；② sum rule 机器精度；③ Becke 电荷 vs 文献（MgO Hirshfeld/Becke 报道值，~±1.0–1.5 e 带宽——口径核对非精确对拍）；
- 基组/成本：**LCAO 优先**（Mg/O 轨道在库），bulk 小原胞 + 标定网格（ecutwfc=60 起步测噪声）——单次 SCF 预计分钟级；
- 独立参照：文献电荷 + R4 预言（更宽线性区）。

### I-2 Na⁺–Cl⁻ 离子对（"离子液体"的最小可行模型）
- 说明：真·离子液体（EMIM-BF4 熔盐）体系大、无现成赝势组合、需 AIMD 采样——**一期不做**，以离子对/小团簇替代其"分子间电荷转移"内核；
- 体系：NaCl 分子（大盒）或 (NaCl)₂ 小簇；
- 约束：两离子间电荷转移 delta 扫描 + 偶极响应记录（为阶段 C 偶极埋数据）；
- 判据：收敛 + μ–Q 曲线单调性 + 末端电离极限的如实熔断（把 Na⁺ 的电子全推走必然不可达——熔断路径的物理用例）；
- 独立参照：电离能/亲和能的渐近行为（定性）。

## 2. 组 II：过渡金属氧化物——自旋约束本职场景 + DeltaSpin 量级对等（开放项④）

**物理动机**：自旋约束的生产用途是 TM d 电子局域矩控制；同时给出"本框架 μ vs DeltaSpin λ 量级差 ~10×"的正确判决实验——**同一体系、两实现、两种口径**。

### II-1 FeO（首选：现成基线零搭建成本）
- 体系：改造 `tests/17_DS_DFTU/11_PW_DFTU_S2_FeO`（FeO 用例在库）；AFM 构型；
- 约束：spin on Fe 片段，delta = ±0.1 / ±0.3 / ±0.5 μB；
- 判据：① 收敛精度 <1e-4 μB；② **DeltaSpin 对照**：`12_PW_DS_S2_Z`（Fe 基 DeltaSpin 用例）同体系同靶点跑 DeltaSpin，两实现收敛磁矩一致（<0.01 μB），μ 与 λ 的量级差**定量**归因（on-site 投影矩 vs Becke 区域矩的读数差由 V3b 只读观测口在同一密度上直接测出——这是开放项④的正确结案方式）；③ 力矩 FD（选做，LCAO 便宜档）；
- 基组/成本：PW + dav_subspace + 标定网格（FeO 是半导体，小原胞便宜）；DeltaSpin 侧用既有案例设置；
- 独立参照：DeltaSpin（生产级既有实现）+ 文献 FeO 磁矩（~3.3–4 μB 报道带）。

### II-2 NiO（次选，II-1 通过后再议）
- AFM-II 经典考题（Ni_ONCV 在库）；无现成用例需搭建；优先级低——II-1 已覆盖机制。

## 3. 组 III：电荷转移体系——混合约束 + CDFT/Marcus 接口（框架的物理卖点）

**物理动机**：设计方案 §6.4 的卖点——约束功 W=ΣμΔQ 与正反向 μ 差估计 Marcus 重组能，是 CDFT 文献的标准应用（Wu–Van Voorhis 体系）。

### III-1 给体-受体分子对
- 体系：苯-TCNE 或 Na⁺···芳烃（**资源前提：C 的 PBE 赝势/轨道需确认在库，缺口见 §0**）；备选：H₂O 二聚体（零资源门槛，氢键 CT 量级小但机制完整）；
- 约束：v2 混合——给体 charge −q、受体 charge +q（净零 CT 对）± 自旋（若开壳层）；
- 判据：① 双片段同时收敛（A6 混合能力的真实场景复用）；② 正反向（+q/−q）两次约束的 μ 差 → 重组能估计 vs CDFT 文献量级（~0.1–1 eV 带宽，口径级对照）；③ 约束功 W 输出自洽；
- 独立参照：CDFT 文献（Wu–Van Voorhis 重组能数据）；
- 成本：分子大盒但 LCAO 便宜；H₂O 二聚体版本零门槛。

### III-2 界面片段约束（二期候选，一期不建）
- Pt slab + 吸附分子（Pt 在库）：slab/吸附物两片段电荷约束——电化学界面原型；体系大、需 k 点，等 V3/V4 后立项。

## 4. 组 IV：bulk 生产表征（V6 的落地）

- **V6 电荷态扫描**：原方案指定 Au:Si，但 **Au 赝势不在库**——两个选项：(a) 外部引入 Au 赝势（登记资源动作）；(b) 改用库内掺杂体系（Si 空位 / Si:Mg 等，需评估物理等价性）。裁定前不搭建；
- 判据：与原 SMO 趋势一致、口径偏移可解释（原设计方案 V6 的定义）。

## 6. 与既有计划的关系

- 本算例集**不替代** V1/V2 混合力 FD（那是代码路径判决，H₂O LCAO 载体已重设计）；
- II-1 的 DeltaSpin 对照同时结案开放项④；III-1 同时服务阶段 B（混合收敛行为数据）；I-1 是 R4 的判决实验（若离子体系可达域也很窄，则框架的物理适用范围声明要收紧——这是本算例集最重要的单一判决）。
