# 2026-10-30 MBIS 对 Fe/磁性体系的有效性 与 轨道贡献分离

## 0. 直接回答

1. **MBIS 对 Fe 有效吗？** —— 作为**密度/自旋分区**有效（电荷、原子多极、
   空间自旋都是良定义的、基组鲁棒的）；但它给的是**空间盆（basin）量**，
   **不是** onsite 投影矩（XMCD 口径）。具体：
   - 电荷：`q_A = ∫ w_A(r) ρ(r) dr`（可靠）；
   - 空间自旋：`m_A = ∫ w_A(r) [ρ↑−ρ↓](r) dr`（"spin-MBIS"，用同一/单独
     拟合的权重）——Fe 上预计接近 Becke 空间矩（~2.8–3.2 μB），
     **低于** onsite d 投影（~3.7–3.8）。
   - 所以 MBIS **不能替代** DeltaSpin/投影矩去回答"d 壳层磁矩"，但能给一个
     一致的**空间磁矩**。
2. **MBIS 能分离轨道贡献吗？** —— **标准 MBIS 不能**：它是纯实空间、s 型
   pro-density，只给单极/偶极/四极，**不分解 l（s/p/d/f）**。
   但可以**在 MBIS 盆内再做一步 l 投影**：
   ```
   n_{A,l} = ∫ w_A(r) ρ_l(r) dr ,   m_{A,l} = ∫ w_A(r) m_l(r) dr
   ```
   其中 `ρ_l/m_l` 是绕 `R_A` 的 l 投影密度（NAO 或球谐）。
   这样：**MBIS 决定原子间（空间）归属，l 投影决定原子内壳层分解**。
   这是**两步分解**，比现有混合算符更干净。

## 1. 为什么现有混合方案"Fe 行、LiCl 不行"

`A_i = Q_i + Q_c W_i Q_c`，`q_i = Tr[ρ Q_i] + Tr[ρ Q_c W_i Q_c]`。

- **Fe 磁矩**：`q` 主要由 **d 投影** `Tr[ρ Q_i]` 决定，空间互补只占 ~5.6%
  （Fe2：`m_c≈0.21` vs `q≈3.80`）。所以混合方案**近似等于投影矩**，
  在 Fe 上"看起来有效"。
- **LiCl 电荷**：主导的是**空间权重**，而 `W_i` 是固定 Gaussian/Becke
  （Li 半径偏宽）→ `n_tot=3.08 e`；再叠加 Li 4s（弥散）的 `n_T=2.42`
  偏向 Li。结果既不是 MBIS（2.04），也不是 Mulliken（2.48），
  且随基组/target_l 变。**不是电荷的合理口径。**

结论：混合方案在 Fe 上"有效"是**因为那里它退化成投影**；它不是一个通用的
电荷/自旋口径。

## 2. 建议的两步架构（MBIS + l 投影）

### 第一步：MBIS 空间分区（电荷/偶极/ESP）
```
ρ_A^pro = N_A ζ_A³/8π e^{−ζ_A r}
w_A = ρ_A^pro/Σ_B ρ_B^pro
q_A = ∫ w_A ρ ,   m_A = ∫ w_A m        (m = ρ↑−ρ↓)
迭代 N_A=∫w_Aρ, ζ_A=3N_A/∫r w_Aρ
```
得到：**基组鲁棒**的原子电荷、原子偶极 `μ_A=−∫(r−R_A)w_Aρ`、分子偶极
`Σ(q_A R_A+μ_A)`、以及**空间自旋** `m_A`。

### 第二步：MBIS 盆内的 l 投影（轨道贡献）
```
ρ_A(r) = w_A(r) ρ(r)
n_{A,l} = ∫ ρ_A(r) P_l(r−R_A) dr ,  m_{A,l} = ∫ m_A(r) P_l(r−R_A) dr
```
- `P_l` 可用 **球谐投影**（基组无关，推荐）或 **NAO 轨道投影**（与 XMCD 可比）。
- 与现有 `Q_i` 的区别：`Q_i` 把**整个体系**的密度投到原子 i 的 NAO 轨道
  （非局域、跨盆、基组依赖）；这里的 `P_l` 只作用于**已归属给 A 的密度** `ρ_A`
  （局域、无跨原子重复计数、可基组无关）。
- 这一步**不改变** MBIS 的电荷/多极（分区不变），只**分解**原子内壳层。

### 结果
- **电荷/静电**：用 MBIS 第一步（Li⁺≈+0.96，偶极 6.48 D≈实验）。
- **壳层贡献（Fe 的 d、O 的 2p 等）**：用第二步 `n_{A,l}/m_{A,l}`。
- **XMCD/投影矩**：若必须与实验投影口径一致，保留 DeltaSpin 投影（或把
  `P_l` 选成 NAO d 投影），但要知道它是**盆内 d 投影**，不是全空间 d 投影。

## 3. MBIS 对 Fe 的预期行为（待验证）

| 量 | 预计 | 与现有对比 |
|---|---|---|
| MBIS Fe 电荷 | 可靠、基组鲁棒 | 与 Mulliken/Becke 不同属正常 |
| MBIS **空间自旋** `m_A` | ~2.8–3.2 μB（Becke 类） | < onsite 投影 ~3.7–3.8 |
| MBIS 盆内 **d 投影** `m_{A,d}` | 更接近 d 壳层矩（~3.5–3.8） | 与 DeltaSpin 投影可比 |
| MBIS 原子偶极 | 有（Fe 上较小） | 现有方案没有 |

即：**MBIS 本身给空间磁矩；要 d 壳层磁矩，必须加第二步 l 投影**。两者结合
（MBIS 空间 + 盆内 d 投影）很可能既保留 Fe 的 d 信息、又修正 LiCl 的电荷。

## 4. 验证计划（Fe + LiCl）

1. Fe2（nspin=2）输出 `chgs1.cube/chgs2.cube`；
   用 `tools/mbis_prototype.py` 扩展版计算：
   - MBIS 电荷（`ρ↑+ρ↓`）与空间自旋（`ρ↑−ρ↓`）；
   - 与 Becke（~2.8）、Mulliken（~2.4）、onsite 投影（~3.7）对比。
2. 加**盆内 l 投影**（先球谐、再 NAO d）；对比 `m_{A,d}` 与投影矩。
3. LiCl：MBIS + s/p 盆内投影，验证电荷与壳层布居合理。
4. 与 ORCA MBIS（分子）对照电荷/偶极；XMCD/DFT+U 对照 d 矩。

## 5. 注意/风险

- 标准 MBIS 的 s-only pro-density 对**开壳 d 体系**可能拟合不足；可扩展为
  l 依赖 pro-density（非标准），但需验证。
- `l` 投影的**基组/球谐选择**会带入口径依赖；输出必须标注（NAO vs SH）。
- 自旋可用"同一权重作用在自旋密度"或"对自旋密度单独做 MBIS"（spin-MBIS），
  两者都仍是**空间**自旋，不是壳层投影。
- 周期/网格/多极的注意事项同前（`2026-10-30-mbis-alignment-plan.md`）。

## 6. 结论

- **MBIS 对 Fe 有效**（电荷/多极/空间自旋），但**不自动给轨道分辨**；
- **要分离轨道贡献，必须加"MBIS 盆内 l 投影"**（两步法）；
- 现有混合 `Q_i+Q_cWQ_c` 在 Fe 上"有效"是因它退化为投影，在 LiCl 上失败
  是因空间权重/固定半径不合适；**通用方案应是"MBIS 空间 + 盆内 l 投影"**，
  投影矩仅保留给需要 XMCD 口径的场合。
