### 3.1 解析闭合（量化自洽）

E_HK = −0.5·Im(Σ_j Σ_p f_p W_p^{(j)} T_pp^{(j)})，T = C_L†·S_dk·C_R。
整体平移 Δ 下 S_dk（相位 exp(2πi(dk·R − dk·τ_bra))）获得全局相位
e^(−2πi·dk·Δ)：

```
∂E_HK/∂Δ_α = π·dk_α/lat0·Re(Σ_j Σ_p f_p W_p T_pp)
```

实测数据：Re(Σ f W T)（两 link）= 2×(−0.0692) = −0.1384；
`π·0.5/1.8897·(−0.1384) = −0.1150 Ry/Bohr` —— **与 FD 完全一致**。
即：E_HK 的 uniform 敏感性 = loop 相位效应（沿 dk 方向），已被精确定量。

## 5. 相位链缺陷定位：g==0 跳过

`compute_hk_force` 的 ∂S_dk/∂R 核中：

```cpp
const double g = nlm[1 + a][iw0];
if (g == 0.0) continue;   // ← BUG：g=0 时整个 dS_bra（含相位项）被跳过
```

逐对累积打印（hkpair，band 0，z 轴）证明：

- `tacc`（Σ phase·ov·cL*·cR）= 0.7430−0.0905i = T_0 ✓（配对集合一致）；
- `phaseacc`（Σ −2πi·dk/lat0·phase·ov·cL*·cR）= −0.1504−1.2352i =
  −2πi·dk/lat0·T_0 ✓（相位项数学期望）；
- 实际 `Σ_atoms U` = −0.2155−0.2454i ≠ phaseacc —— **相位项缺失**。

缺失来源：自配对（iat=iat1，R=000，d=0 处全部 g=0）与一般 g=0 通道的相位
导数被 `continue` 整体跳过。例：O 自配对 phaseacc = 0.2021−0.9995i，而其对
U 的贡献为 0。

### 5.1 修复

相位项与轨道导数解耦，无条件累积：

```cpp
if (g != 0.0)
{
    U[iat][a*nocc+p] += cb*(phase_sdk*g)*ck;   // bra +g
    U[iat1][a*nocc+p] -= cb*(phase_sdk*g)*ck;  // ket -g
}
// 相位项对每个配对无条件累积（S_dk 相位含 -dk·τ_bra）
U[iat][a*nocc+p] -= cb*(i·2π·dkv[a]/lat0·phase_sdk·ov)*ck;
```

4. E_HK 的 uniform 敏感性被精确量化 = π·dk/lat0·Re(Σ f W T)（两处实验

6. 剩余 FD 残差 = 均值扣除协议项（0.99）+ 缺项 A2/C（2.37）。

### 10.1 修复内容（已实施，deltap_wannier.cpp）

1. `compute_S_dk`（:105-110）：相位 τ 项改用 Direct（分数）坐标：
   `taud0 = ucell.atoms[T0].taud[I0]`，`arg = 2π(dkv·R − dkv·taud0)`。
   原 `get_tau()` 返回 lat0 单位 Cartesian（数值≈Å），与分数步长 dkv
   量纲不匹配，相位放大 L 倍。
2. `compute_hk_force`（:1997-2032）：S_dk 相位同步改 `taud0`。
3. `compute_hk_force` 相位导数因子（:2079/:2085/:2217）：由
   `−2πi·dkv[a]/lat0` 改为 `−2πi·dkv_grad[a]/lat0`，其中
   `dkv_grad = latvec⁻¹·dkv`（`latvec_inv = ucell.latvec.Inverse()`）。
   推导：τ_frac = latvec⁻¹·τ（τ 为 lat0 单位），τ_Bohr = τ·lat0 ⇒
   dτ_frac/dR_Bohr = latvec⁻¹/lat0；正交晶胞下即 −2πi·dkv_α/(L_α·lat0)，
   与用户处方一致。
4. g==0 修复（§5.1）保留不动。

**约定对照（ABACUS 参考实现）**：`unk_overlap_lcao.cpp:529`
`kRn = 2π·(kvec_c[ik_R]·R − dk·tau1)`，其中 `kvec_c = kvec_d·reciprocal_vec`
（2π-free 的 1/lat0 单位）、`R`/`tau1` 为 lat0 单位 ⇒ 数值上等于
`2π·(dk_frac·R_int − dk_frac·τ_frac)` —— 与本修复后的相位完全一致。
参考实现另含一阶位置修正项（`−dk·tpiba·ψrψ`），本代码按注释约定省略
（"Bloch-state overlap (no position correction)"），保持原样。

### 10.3 "15.87× 预言"的两因子分解：真实单位 bug × 数值巧合（机理）

用户预言"∂E_HK/∂Δ 缩小 15.87×（−0.115 → −0.0072）、ΣF_HK,z ≈ +0.007"，
按"相位导数项 ∝ dkv_eff·Re(T)"分解，实测为**两因子**：

- 单位修复改变了 S_dk 的**相位本身**（不只是导数）：O 自配对相位由
  修复前的 `e^(−2πi·0.5·7.9365) ≈ +0.980−0.199i`（τ_lat0·dk≈整数，
  近实正数，**几何巧合**）变为修复后的 `e^(−2πi·0.5·0.5) = −i`。
- 结果：`Re(T_00)` 由 +0.743 塌缩为 **−0.0222**（Im(T)→−0.999，
  S_dk 变为虚数主导），link 能量 `e_link` 的 Re 由 −0.0692 → +0.00128。
- 相位导数项 ∝ `dkv_eff·Re(T)`：修复前 0.5×0.743=0.3715，修复后
  0.0315×(−0.0222)=−0.00070 —— 收缩 **~530× = 15.87×（dkv 单位修复，
  本轮数据确认 dkv_eff 恰按 L 收缩）× 33×（Re(T) 塌缩，O 恰在 τ_lat0≈8
  处的几何巧合）**，符号翻转。
- 实测：ΣF_HK,z 由 +0.1147 → **−1.4e-4 ≈ 0**：单位修复后 E_HK 的解析力
  在冻结 C 下**已是平移不变的**（轨道部分逐对相消、相位部分 ∝ Re(T)≈0）。
- "15.5× ≈ 15.87"的精确数值吻合确有巧合成分：修复前 FD −0.115 被 O 块
  相位导数主导（Re(T)≈0.74≈1，O 恰在 τ_lat0≈8≈整数处，旧相位≡1），
  于是 FD ≈ 相位导数"名义值"，与 −∂escon/∂Δ 的比值恰好接近 L。

**结论**：B-6 是必须修的量纲 bug，dkv 单位因子按 L=15.87 精确收缩已由
本轮数据证实（用户判定正确）；"15.5×≈15.87"的数值吻合是**单位 bug 的
真实放大 × O 几何巧合**叠加。"ΣF_HK,z ≈ +0.007 ≈ C"的定量预言未复现
（实测 ≈ 0），因为 Re(T) 塌缩是修复相位本身的必然结果，不改变"单位
修复正确、E_HK 恢复平移不变"的结论。E_HK 量级大变（+2.6e-3 → −8.6e-2

1. `∂(TrρH_HR)/∂Δ` 与 `∂escon/∂Δ` **同号**（−2.93e-2 vs −3.70e-3，
  均使 E' 随 +Δ 下降）——"−E·P 对偶补偿"（λτ 项与 escon 相消）的前提
  是 **H_HR 是 γ 的精确算符**；实测 H_HR 的原点敏感性（−2.93e-2，
  即 A2 均匀内容）比真 γ（经 escon，−3.7e-3）**大 8.0×** ——这不是
  "预言未复现"，而是**指南 O5（H_HR 代理算符与 γ 算符的差距）的定量
  测量**：H_HR = ΣλτP̂ 的 τ·P̂ 是位置型代理，与 γ（Berry 相位）的
  精确生成元相差约 8×（本算例，**B-6 前 lat0 τ 约定**）。B-6 修复后
  （已验证，见 2026-08-03-deltap-b6-tau-unit-fix.md）：同步模式 λ 单步
  冻结**不重收敛**，H_HR = λ·τ_frac·P̂ 精确缩小 L 倍，均匀分解变为
  A2=+1.85e-3 / C=+3.70e-3（比值 0.5×，仍同号相加）——稳健结论是
  **无 −E·P 相消**，O5 的最终定量以 D-D 轮逐原子 FD 为准。A2 的解析式
  −λ_J⟨P̂_J⟩(L⁻¹)_{αβ} 是代理算符自己的力（逐原子 B-6 后仍为
  −λ⟨P̂⟩/a≈0.08 eV/Å 量级），实现后若 O1-z 残差闭合，说明差距集中在
  C 项；若不闭合，差距在代理算符本身（H_c 形式重构，O5 完整路径）。
2. **B-6 后的均匀预算（已验证）**：A2 均匀 = **+1.85e-3 Ry/Bohr**
  （H_HR 缩小 L 倍后 ∂E_H_HR/∂Δ = −1.85e-3；同步模式 λ 不重收敛），
  C 均匀 = **+3.70e-3 Ry/Bohr**（escon 不变，λ/γ 均不变）——二者同号
  相加，不是符号相消（1 的推论）；B-6 前 lat0 τ 的 +2.93e-2 为旧约定
  值。内循环 BFGS 模式 λ 预期重收敛 ×L（算符不变），未验证（D2 缺口）。
3. **A2 的逐原子部分不是均匀项**：每原子权重 −λ_I·⟨P̂_I⟩ 不同，
  E' 均匀分量的均值扣除（FORCE_STRESS:595-601）**掩不住逐原子 A2**——
  这正是 A2 必须实现的原因（relax 中原子将感受到约束的逐原子位置力）。
