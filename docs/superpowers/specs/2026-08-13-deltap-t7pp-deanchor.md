### 3.4 决定性测量：冻密度响应为负，与靶点方向相反

trial 0（仅 O1 λ≠0，单分量孤立测量，两臂独立一致）：
- jacobi：Δλ_O1=+0.0025 → Δγ_O1 = −0.0032 → **dγ_O/dλ_O = −1.28 rad/Ry**
- cg：Δλ_O1=−0.0025 → Δγ_O1 = +0.0032 → dγ_O/dλ_O = −1.28 rad/Ry

**冻密度 γ(λ) 响应为负**（优化器假设的正响应方向是错的）。本几何 SCF 级
净响应同为负（λ_O1=−3.86e-3 → γ +0.0024 ≈ −0.62 rad/Ry）；对照 T-18 几何
自洽 +0.059——**γ 对 λ·θ·P̂ 的响应符号跨几何不稳定**。

交叉耦合：trial 0 后 H1 残差 = −0.0018（与 O1 残差同量级）——λ_O1 驱动
同时推开 H 的 γ，**非对角响应 ≈ 对角响应**，3×3 强耦合。

## 4. 分析

1. **解锚机制验证**（本轮价值）：入口冻结后报告 = raw 精确跟随，T-7' 的
   "残差常数化"根因（连续性锚钉死）被消除；检查点 1/2 全过。锚定三形态
   （target-aware 假收敛 / 连续性锚吞响应 / 冻结 shift 正确）在 ow 模式
   得到完整闭环验证。
2. **收敛失败的物理层根因**：γ 对局部算符 λ·θ·P̂ 的冻密度响应为负且与
   自洽/其它几何符号不一致（弱 + 方向不稳定，T-18 评审的
   "+0.5@−0.01 vs −0.38@−0.021"在此几何以更干净的数据重现）；
   叠加强交叉耦合（非对角≈对角），scalar-CG 翻号、对角 Jacobian 2-循环，
   两者都结构性不可收敛。**这不是记账/测量通道问题（已修），是算符控制
   权限问题**——T-6' 节开放问题正式裁定：γ-drive 冻密度内循环不可行。
3. cg 臂 SCF 级半达成（2.69e-3）说明自洽循环下 γ 可被驱动，但 λ* 由冻
   密度内循环产出（符号/量级均不可靠），结果是半吊子且不可控——不能
   作为生产路径。
