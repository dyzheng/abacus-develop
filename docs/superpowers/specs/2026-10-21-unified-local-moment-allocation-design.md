# 统一局域磁矩分配（正交目标轨道 + 互补子空间空间分配）：设计文档

**日期**：2026-10-21
**状态**：设计（未实现）
**定位**：在"实空间分区（Becke/Hirshfeld）"与"原子轨道投影（DeltaSpin）"之间建立一个**可调插值**的分配算符族；保留轨道含义，同时使每原子（电荷/自旋）总和严格等于全局量。本文给出公式、约束算符、能量/力/应力修正项、实现路径与风险清单。

---

## 0. 设计目标与非目标

### 0.1 目标

1. **精确可加**：`Σ_i n_i = N`（电子数）、`Σ_i m_i = M_tot`（总自旋磁矩），对任意电子态成立（不靠约束"凑"出来）。
2. **保留轨道含义**：同时输出"目标轨道子空间"的读数 `m_i^T`、`n_i^T`（如 TM 的 d、稀土的 f、配体空穴的 O 2p），以及"互补子空间"的逐原子分配 `m_i^c`、`n_i^c`。
3. **正性（电子数）**：每个 `n_i ≥ 0`；自旋分量可正可负（物理上允许反平行）。
4. **可平滑求导**：对原子位置、应变可微（在所选权重后端光滑时），力/应力可由解析式给出并接受 FD 校验。
5. **可调**：目标轨道集为空 ⇒ 退化为纯空间划分；目标轨道集完备 ⇒ 退化为正交轨道（Löwdin 型）划分；中间即为"轨道 + 空间"混合。

### 0.2 非目标

- 不解决**轨道磁矩**（`m_orb` 来自电流密度，需独立的周期轨道磁化理论）；本设计的 `m` 一律指**自旋磁矩**。
- 不声称目标轨道集的选择是唯一的；它由化学问题决定，必须随结果报告。
- 不声称构造本身是文献首创；本文只做工程化设计与风险分析。

## 1. 约定与符号

| 符号 | 含义 | 单位 |
|---|---|---|
| `ρ̂ = Σ_n f_n |ψ_n⟩⟨ψ_n|` | 电子密度算符（含占据数与 k 权重），每晶胞归一化 | — |
| `ν(r) = n↑(r) − n↓(r)` | 共线自旋极化密度 | 1/Bohr³ |
| `m(r) = μ_B ν(r)` | 自旋磁矩密度 | μ_B/Bohr³ |
| `M_tot = μ_B Tr(ρ̂ σ_z)` | 每晶胞总自旋磁矩 | μ_B |
| `w_i(r) ≥ 0, Σ_i w_i(r) = 1` | 空间权重（Becke 归一化或周期 Hirshfeld） | 无量纲 |
| `Ŵ_i` | 乘以 `w_i(r)` 的乘法算符 | — |
| `{|φ_ia⟩}`, `a=1..n_i` | 原子 i 的**正交归一目标轨道**（如 5 个 d） | — |
| `Q̂_i = Σ_a |φ_ia⟩⟨φ_ia|` | 原子 i 的目标轨道投影 | — |
| `P̂ ≡ Q̂_d = Σ_i Q̂_i` | 全部目标轨道投影 | — |
| `Q̂_c = Î − P̂` | 互补子空间投影 | — |
| `Â_i = Q̂_i + Q̂_c Ŵ_i Q̂_c` | **统一分配算符** | — |
| `λ_i` | 拉格朗日乘子（自旋：Ry/μ_B；电荷：Ry/e） | — |
| `s_i, t_i` | 无量纲自旋读数/目标；电荷用 `n_i, t_i^c`（e） | — |

**符号约定（本设计统一，避免符号漂移）**：

```
E_c[ρ] = E_KS[ρ] + Σ_i λ_i (s_i − t_i)                       （拉格朗日泛函）
ΔĤ     = Σ_i λ_i Â_i σ_z                                      （自旋；电荷时 σ_z→I）
⇒ ∂E_*/∂t_i = −λ_i ，磁广义力 f_i^mag = −∂E_*/∂m_i = λ_i/μ_B
```

（注：若软件内部采用 `E − Σλ(M−Mt)` 并配 `+λσ`，则其 λ 与本设计相差一个符号；比较时必须用能量对目标的 FD 判定，不能只看符号。）

## 2. 分配算符与基本性质

### 2.1 定义与恒等式

```
Â_i = Q̂_i + Q̂_c Ŵ_i Q̂_c                                                   (2.1)
```

利用 `Q̂_c² = Q̂_c`、`Q̂_c P̂ = 0`、`Σ_i Ŵ_i = Î`：

```
Σ_i Â_i = P̂ + Q̂_c (Σ_i Ŵ_i) Q̂_c = P̂ + Q̂_c = Î                            (2.2)
```

即分配算符构成**单位分解**（对算符空间精确，与电子态无关）。

**低秩展开**（实现的核心）：

```
Â_i = Q̂_i + Ŵ_i − P̂Ŵ_i − Ŵ_iP̂ + P̂Ŵ_iP̂                                  (2.3)
```

因此约束势可以写成"局域势 + 低秩投影修正"：

```
ΔĤ = σ [ V̂ − P̂V̂ − V̂P̂ + P̂V̂P̂ + Σ_i λ_i Q̂_i ] ,   V̂ ≡ Σ_i λ_i Ŵ_i      (2.4)
```

- `V̂` 是现有 Becke 注入的局域势（逐自旋通道 ±）；
- 修正项都通过 `P̂ = Σ_i Q̂_i` 作用，**秩 ≤ R ≡ Σ_i n_i**（如 5×磁性原子数），不是一般非局域算符。

### 2.2 三条性质

1. **正性（电子数）**：对任意 `|v⟩`，
   `⟨v|Â_i|v⟩ = Σ_a |⟨φ_ia|v⟩|² + ∫ w_i(r) |(Q̂_c v)(r)|² dr ≥ 0`。
   自旋分配 `Tr(ρσÂ_i)` 不要求正（反平行/非共线允许）。
2. **可加性**：`n_i = Tr(ρ̂ Â_i)` ⇒ `Σ_i n_i = N`；`m_i = μ_B Tr(ρ̂ Â_i σ_z)` ⇒ `Σ_i m_i = M_tot`。
3. **POVM 而非投影**：`Â_i ≥ 0`、`Σ_i Â_i = Î`，但 `Â_i² ≠ Â_i` 且 `Â_iÂ_j ≠ 0`。
   因此逐原子读数**可加但非独立**（类似 POVM）；跨原子协方差无定义，不应当作"正交可观测量"。

### 2.3 与两种极限的关系（插值族）

| 目标轨道集 | `Q̂_c` | `Â_i` | 退化结果 |
|---|---|---|---|
| 空集 `Q̂_d = 0` | `Î` | `Ŵ_i` | **纯空间划分**（Becke/Hirshfeld） |
| 全部局域轨道（基组空间内） | `0` | `Q̂_i` | **正交轨道划分**（Löwdin 型） |
| 部分（如 d/f/活性空间） | `Î−P̂` | `Q̂_i + Q̂_cŴ_iQ̂_c` | **混合** |

这条插值性质是本设计的核心：**"空间 ↔ 轨道"不是二选一，而是由"目标轨道集的大小"连续控制**；代价是非局域性随目标集增大而增加（但始终是低秩的）。

### 2.4 读数分解

```
n_i^T = Tr(ρ̂ Q̂_i) ,           m_i^T = μ_B Tr(ρ̂ Q̂_i σ_z)          （目标轨道读数）
n_i^c = Tr(ρ̂ Q̂_c Ŵ_i Q̂_c) ,   m_i^c = μ_B Tr(ρ̂ Q̂_c Ŵ_i Q̂_c σ_z)  （互补通道）
n_i   = n_i^T + n_i^c ,        m_i   = m_i^T + m_i^c                （完整分配）
```

- `n_i^c = ∫ w_i(r) n_c(r) dr`，其中 `n_c(r) = ⟨r|Q̂_c ρ̂ Q̂_c|r⟩ = Σ_n f_n |ψ_n(r) − Σ_a φ_a(r)⟨φ_a|ψ_n⟩|²`。
- **名称纪律**：`n_c(r)` 是"互补投影态的密度"，**不是** `ρ − ρ_T`；`m_i^c` 也**不是**纯间隙磁矩。`m_i^c` 可能含原子附近的其他轨道成分。
- `m_i`（完整分配）一般**不等于**纯空间划分的 `m_i^spatial`，两套规则不同，不能混称。

## 3. 目标轨道集的构造

### 3.1 构造步骤

1. **取初始目标轨道**：`|α_a⟩` 为所选角动量通道的原子局域轨道（NAO 或赝势 onsite projector），位于原子 `i`，`a = 1..n_i`（如 `l=2` 的 5 个分量）。目标集按化学问题选取（§3.3）。
2. **小空间正交化**：`S_ab = ⟨α_a|α_b⟩` 是 **R×R**（R = Σn_i，典型几十到几百）的矩阵；`S = U s U†`；
   `|φ_a⟩ = Σ_b |α_b⟩ (S^{-1/2})_{ba}`。**正交化只在目标子空间内进行，不涉及全基组**——这是本设计可实施的关键。
3. **构造投影**：`Q̂_i = Σ_{a∈i}|φ_a⟩⟨φ_a|`；`P̂ = Σ Q̂_i`；`Q̂_c = Î − P̂`。
4. **周期性/几何一致性**：目标轨道随原子位置移动；每个几何重新正交化。若 `S` 近奇异（近线性依赖），按秩截断并记录（见 §7 风险 R3）。

### 3.2 实现口径

| 基组 | 初始 `α` | `⟨α_a|α_b⟩` | `⟨α_a|ψ⟩` | 备注 |
|---|---|---|---|---|
| LCAO | NAO 轨道文件中的选定通道 | 现有重叠矩阵 `S` 的子块（R×R） | 现有投影 | 最省力 |
| PW | 赝势 onsite projector `α_lm` | 需新增 projector–projector 重叠（两中心或实空间积分） | 现有 becp | 需要一项小积分实现 |
| Wannier | 占据流形的 d 型 Wannier | 正交（`S=I`） | 现有 Wannier 接口 | 正交性天然；几何依赖，需冻结近似（§7 R4） |

### 3.3 目标集选择（必须随结果报告）

| 目的 | 建议目标集 | 说明 |
|---|---|---|
| TM 自旋矩 / XMCD | TM `d`（+ 可选 `s/p`） | XMCD 为元素/壳层分辨，`m_i^T` 与之同类 |
| 稀土 | `4f` | 轨道矩需另开 SOC（本设计不覆盖） |
| 2p 磁体/缺陷 | `p` | 通道按体系选择 |
| 电荷 / 氧化态 | TM `d` + 配体 `p`（pd 活性空间）或空集 | 空集退化为空间划分；d-only 不适合净电荷 |
| 配体空穴（NiO、LiNiO₂） | Ni `d` + O `2p` | 让活性空间覆盖共价物理，`m^c` 变小 |

**注意**：`n_i^T`/`m_i^T` 是"该子空间的读数"，**不是**净电荷/总矩；`n_i`/`m_i` 才是完整分配。三者同时报告。

## 4. 能量项

```
E_c = E_KS + Σ_i λ_i (s_i − t_i)                                          (4.1)
e_con = Σ_i λ_i (s_i − t_i)                                              (4.2)
```

- 自旋：`s_i = Tr(ρ̂ Â_i σ_z)`（无量纲，`m_i/μ_B`），`t_i` 无量纲目标；
- 电荷：`s_i = Tr(ρ̂ Â_i)`（e），`t_i^c` 为电子数目标，`λ_i` 用 Ry/e；
- 混合：两项并存，`e_con = Σ_i λ_i^s(s_i−t_i) + Σ_i λ_i^c(n_i−t_i^c)`。

**ALM（增量罚函数）扩展**：

```
E_ALM = E_KS + Σ_i [ λ_i(s_i−t_i) + (k_i/2)(s_i−t_i)² ]                   (4.3)
ΔĤ    = Σ_i (λ_i + k_i(s_i−t_i)) Â_i σ_z                                 (4.4)
λ_i^eff = λ_i + k_i(s_i−t_i)          （报告的物理乘子/恒电势标签）        (4.5)
```

- 罚项使 `s_i` 在 SCF 内连续跟踪目标；外层 `λ ← λ + k(s−t)` 收缩（沿用既有的信赖域/Broyden 调度）。
- **力/应力只在收敛点取**（`s≈t`），此时 ALM 的密度依赖项按包络定理消失；未收敛时必须给出残差警告（沿用现有 `res > thr` 警告）。

## 5. 约束算符与实现算法

### 5.1 本征方程的改变

```
Ĥ_c = Ĥ_KS + ΔĤ ,   ΔĤ = Σ_i λ_i Â_i σ_z = σ_z V̂_eff                  (5.1)
V̂_eff = V̂ − P̂V̂ − V̂P̂ + P̂V̂P̂ + Σ_i λ_i Q̂_i ,   V̂ = Σ_i λ_i Ŵ_i        (5.2)
```

电荷通道把 `σ_z` 换成 `I_σ`（两自旋通道同加）；混合时 `ΔĤ = Σ(λ_i^c Â_i ⊗ I + λ_i^s Â_i σ_z)`，两项共用同一 `Â_i`，在自旋空间对易。

### 5.2 作用到波函数的算法（每个 band，每 SCF 迭代）

输入：`ψ`；预计算量（每几何一次）：`φ_a`、`{m_ba = ⟨φ_b|V̂|φ_a⟩}`（R×R）、`{V̂φ_a}`（R 个局域乘积）。

```
1.  o_a  = ⟨φ_a|ψ⟩                                   # R 个重叠（becp/AO 系数）
2.  u    = V̂ψ                                        # 局域乘，O(nrxx)
3.  b_a  = ⟨φ_a|u⟩ = ⟨φ_a|V̂|ψ⟩                      # R 个局域积分
4.  Pu   = Σ_a b_a φ_a                               # P̂V̂ψ
5.  V Pu = Σ_a o_a (V̂φ_a)                           # V̂P̂ψ
6.  PV Pu= Σ_b (Σ_a m_ba o_a) φ_b                    # P̂V̂P̂ψ，R² 小矩阵
7.  Δψ   = u − Pu − V Pu + PV Pu + Σ_a λ_{i(a)} o_a φ_a
```

复杂度：`O(R·nrxx + R²)`/band/迭代（R 为几十量级）；`V̂φ_a` 与 `m_ba` 每几何一次。
- LCAO：`φ_a` 为 AO 子块，`V̂` 为局域势矩阵，`V̂φ_a` 为矩阵–向量乘，`o_a` 为系数投影；规模更小。
- PW：`φ_a` 为 onsite projector，`V̂φ_a` 在网格上乘；`m_ba` 需 projector–projector 重叠（§3.2 的新增项）。

### 5.3 观测（无约束时也可用，作后处理）

```
n_i^T = Σ_{a∈i} Σ_n f_n |⟨φ_a|ψ_n⟩|² ,   m_i^T = μ_B Σ_{a∈i} Σ_n f_n s_n |⟨φ_a|ψ_n⟩|²
n_c(r) = Σ_n f_n |ψ_n(r) − Σ_a φ_a(r)⟨φ_a|ψ_n⟩|²
m_i^c = μ_B ∫ w_i(r) [n_c↑(r) − n_c↓(r)] dr
n_i = n_i^T + n_i^c ,   m_i = m_i^T + m_i^c
```

审计：`Σ_i n_i = N`、`Σ_i m_i = M_tot`、`Σ_i Â_i = Î`（矩阵）、`min eig(Â_i) ≥ 0`。

## 6. 力与应力

### 6.1 约束力（一般式）

在约束极小点，`Ψ` 使 `E_c` 驻定，故

```
F_J^con = −dE_c/dR_J = −Σ_i λ_i Tr( ρ̂ σ ∂Â_i/∂R_J )                       (6.1)
```

一般分解（`∂P̂ = Σ_j ∂Q̂_j`，`∂Q̂_c = −∂P̂`）：

```
∂Â_i = ∂Q̂_i + ∂Ŵ_i − (∂P̂)Ŵ_i − P̂∂Ŵ_i − ∂Ŵ_iP̂ − Ŵ_i∂P̂
       + (∂P̂)Ŵ_iP̂ + P̂∂Ŵ_iP̂ + P̂Ŵ_i(∂P̂)                                (6.2)
```

- `∂Ŵ_i`：现有空间权重导数核（Becke 已有；Hirshfeld 用商法则 `∂w_i = (∂q_i − w_i Σ_j ∂q_j)/Σ_j q_j`）。
- `∂Q̂_i`：正交化目标轨道的几何导数（`∂S^{-1/2}`，见附录 B 型公式）；这是"轨道旋转"贡献。
- `∂P̂` 项成对出现，保证 `Σ_i ∂Â_i = 0`（可作为实现自检）。

**（6.1）只是显式几何导数项。** 完整力必须与现有力机制组合，而不是替换：

- LCAO（原子中心基组）：波函数系数随基函数移动产生 Pulay 项，按现有 KS-Pulay 机制加入；
- PW（固定平面波基）：无基组 Pulay 项，但目标轨道（onsite projector）随原子移动，其导数必须包含在 `∂Q̂_i` 内（与现有非局域赝势力的 projector 导数同一类）；
- 局域部分 `V̂` 的力沿用现有约束框架的 `μw`-Pulay 修正。

### 6.2 冻结目标轨道近似（第一阶段实现）

若在一个几何内把正交化目标轨道视为固定（略去 `∂Q̂`），则

```
∂Â_i |_frozen = Q̂_c ∂Ŵ_i Q̂_c
⇒ F_J^con ≈ −Σ_i λ_i Tr( ρ̂ σ Q̂_c ∂Ŵ_i/∂R_J Q̂_c )
           = −Σ_i λ_i ∫ [ν_c(r)] (∂w_i/∂R_J) dr                       (6.3)
```

即**互补投影自旋密度 `ν_c` 乘权重导数**——与现有 Becke 力核同构，只是把 `ν` 换成 `ν_c`。
- 优点：第一阶段实现几乎复用现有力核；FD 可立即验证。
- 代价：略去轨道旋转项；**必须用 FD 量化其误差**，超过容差则进入 §6.1 完整式。
- 目标随几何移动（delta 模式）时，再加 moving-target 项：

```
F_J^{moving} = F_J^{fixed} + Σ_i Σ_β λ_{iβ} ∂t_{iβ}/∂R_{Jα}              (6.4)
```

### 6.3 应力（一般式）

```
σ_αβ^con = −(1/Ω) Σ_i λ_i Tr( ρ̂ σ ∂Â_i/∂ε_αβ )                          (6.5)
```

按 (6.2) 展开，逐项对应：

1. `∂Ŵ_i/∂ε`：权重对程度的显式导数（分数坐标权重需含度规项；Hirshfeld 周期求和需含镜像项）；
2. `∂Q̂_i/∂ε`：目标轨道/正交化对程度的导数（冻结近似下为 0）；
3. `P̂` 交叉项：与 (6.2) 同结构；
4. moving-target（若目标随应变重算）：`+ (1/Ω) Σ λ ∂t/∂ε`；
5. 体积/归一化项：`s_i` 是每胞电子数，按固定分数坐标定义时应与 KS 应力口径一致。

符号约定以代码现有 KS 应力为准；**最终由应变 FD 判定**（见 §8）。

## 7. 风险点与对策

| # | 风险 | 影响 | 对策 / 验证 |
|---|---|---|---|
| **R1** | **正交化混合**：`S^{-1/2}` 使"原子 i 的 d 轨道"泄漏到邻原子，`m_i^T` 不再严格局域 | 化学解释变弱；与 DeltaSpin 原始读数不同（必须声明） | 报告目标轨道空间展宽/中心偏移；检查远处原子扰动的响应；必要时改用 Wannier 目标轨道 |
| **R2** | **POVM 非正交**：`Â_iÂ_j ≠ 0`；逐原子读数可加但非独立 | 不能把协方差/涨落简单相加 | 文档与输出中明确"可加≠独立"；只做求和与逐项报告 |

| **R7** | **覆盖失败**（大真空/孔洞）：有限支撑权重在某点全为零 | 单位分解失效 | 不靠分母加 ε 掩盖；显式"余量通道"（原子 + 余量 = 全局）；覆盖审计 |

| **R11** | **赝势/PAW 密度口径**：局域读数用赝密度 | 与全电子/实验的口径差 | 明确使用与 KS 能量一致的密度；NLCC/增广项单列；与全电子重构对照 |
| **R12** | **轨道矩缺失**：本设计只覆盖自旋 | 与中子/磁强计的"总矩"比较不完整 | `m_orb` 独立处理（周期轨道磁化理论/Wannier 电流）；报告时区分自旋与总矩 |

## 附录 A：为什么"精确可加"不违反"逐原子值不可任意改"的代数事实

若要求每个新原子值都与原始投影 `m_i^P` **完全相同**，则只有 `Σ_i m_i^P = M_tot` 时才能同时满足逐原子求和；否则必须引入差额 `ΔM`（显式通道）或改变局域定义（正交化）。本设计选择后者：`m_i^T` 是**重新定义**的正交目标轨道读数，`m_i^c` 是显式互补通道，二者相加精确等于 `M_tot`。若需保留原始 DeltaSpin 读数，应走"`m_i^P` + 显式 `ΔM`"路线（不做正交化），两条路线的数值不应混用。

## 附录 B：正交化与导数的关键式

```
S_ab = ⟨α_a|α_b⟩ ,  S = U s U† ,  |φ_a⟩ = Σ_b |α_b⟩ (S^{-1/2})_{ba}
∂(S^{-1/2}) = −∫_0^∞ e^{−t S^{1/2}} (∂S) e^{−t S^{1/2}} dt   （实用：S 的 R×R 谱分解 + Fréchet 导数）
∂Q̂_i = Σ_{a∈i} ( |∂φ_a⟩⟨φ_a| + |φ_a⟩⟨∂φ_a| )
```

R×R 规模使该导数成本可接受；`S` 近奇异时需秩截断的连续化（风险 R3）。
