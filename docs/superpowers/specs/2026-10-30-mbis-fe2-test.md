# 2026-10-30 Fe2 MBIS 测试：电荷/自旋四口径对比

## 0. 结论

Γ-only、LCAO、Fe2 自由态（同一密度）上：

| 口径 | Fe1 自旋 (μB) | 说明 |
|---|---:|---|
| **MBIS 空间自旋** | **+2.647** | `Σ_ir w_A(r) (ρ↑−ρ↓)`，ζ=1.08 |
| Becke 空间矩 | +2.285 | 报告 `m_tot` |
| onsite **d 投影** `m_T` | +2.985 | `target_l=2` 的轨道投影 |
| Mulliken | +3.082 | 轨道布居 |

- **MBIS 对 Fe 有效**：电荷对称（16.00/16.00，中性 Fe），空间自旋 ±2.65，
  自洽收敛（ΣN=32、Σm≈0）。
- MBIS 自旋落在 **Becke(2.29) 与 d 投影(2.99) 之间、更靠近投影**——因为
  MBIS 把 Fe 的 pro-density 优化到较紧凑（ζ=1.08），比固定半径的 Becke
  抓住更多局域 d 自旋；但它仍是**空间盆量**，不等于纯 d 投影。
- Mulliken(3.08) 高于 d 投影(2.99)，是基组依赖的轨道布居。

## 1. 设置

- 用例：`tests/constraint_s5_parity/fe2_bcc_alloc` 改为 **LCAO**
  （`basis_type lcao`、`genelpa`、`gamma_only 1`、`nspin 2`、`constraint` 用
  delta=0 空操作以打印 ALLOC、`constraint_alloc_target_l=2`、`out_chg 1 6`、
  `out_mul 1`）。Γ-only；ETOT=-6787.961875，CONVERGED。
- 密度：`OUT.*/chgs1.cube`、`chgs2.cube`（30³ 体素，bcc 常规胞，非对角体素）。
- 工具：`tools/mbis_prototype.py`（本轮修正：**一般体素矩阵坐标**、**周期镜像**、
  **同种原子对称化**）。

## 2. 关键：周期胞下的 MBIS 需要额外处理

- 直接对 bcc 常规胞 cube 跑朴素 MBIS → **对称性破缺**：
  `N_Fe=22.65/9.35`、ζ 极度弥散、自旋≈0（坐标/镜像不对）。
- 修正坐标（非对角体素）后仍不对称（17.8/14.2）——常规胞不是原胞，
  两 Fe 在常规周期下不等价，且 Slater 尾部需更多镜像。
- 最终：**镜像 ±2 层 + 同种原子对称化**（平均 N,ζ）→
  `N_Fe=16.000/16.000`、ζ=1.078、自旋 ±2.647（对称）。
- **原子偶极在周期小胞里不可用**（规范依赖，数值巨大）；LiCl 分子（大盒、
  居中）已用偶极对实验验证，见 `2026-10-30-mbis-prototype-licl-comparison.md`。

## 3. 分析

1. **电荷**：MBIS 给出中性 Fe（16/16），合理；Becke/投影/Mulliken 的电荷口径
   各不相同（另有 LiCl 对比）。
2. **自旋排序**：`Becke 2.29 < MBIS 2.65 < d投影 2.99 < Mulliken 3.08`。
   - MBIS 比 Becke 高，是因为 pro-density 宽度被优化（Fe 更紧凑）；
   - MBIS 仍低于 d 投影，因为空间盆包含原子间/非 d 分量；
   - Mulliken 高于 d 投影，是轨道布居的基组效应。
3. **MBIS 是空间 AIM，不是壳层投影**：要"分离轨道贡献（d）"，必须在
   MBIS 盆内再做 l 投影（`m_{A,d}=∫w_A m_d`），本轮尚未实现（需 NAO 或
   球谐投影），属下一步。

## 4. 限制/注意

- Fe2 cube 仅 **30³**（0.273 Bohr），积分较粗；数值为指示性，非高精度。
- 周期小胞的 MBIS 需镜像+对称化；生产实现应直接做**原胞**或按晶体对称性
  求和，避免常规胞的等价性丢失。
- 原子偶极在周期胞内不作数（用分子/大盒或 Berry 相位）。
- 尚未做盆内 l 投影；"MBIS 是否复现 d 矩"需补齐后再判。
