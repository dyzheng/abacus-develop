### 3.2 逐项判定

1. **自旋反假收敛（PW delta=0，集成级）**：audit q=4.32e-6 = 自然磁矩、t=4.32e-6、
   μ=0、res=0、e_con=0，**1 个外步 CONVERGED**，E=-466.9510093819987 eV。
   无假收敛到非自然靶点。**PASS**。
2. **LCAO 4-rank 单腿（R0，fixed-μ absolute t\*）**：np1 vs np4 FINAL_ETOT
   -466.2070054188878 vs -466.2070054151704（差 3.7e-12 eV）；audit q/t/mu 逐位一致；
   三原子 9 个力分量一致到打印精度（最大差 ~2e-10 eV/Å，H1-x 2e-10）。**PASS**。
3. **PW≡LCAO 对拍（3 原子分划，δ=[-0.1,+0.05,+0.05]，delta 模式，R7）**：
   - 两基组均 CONVERGED（res <1e-4），partition-of-unity maxdev=2.220446049e-16（两基组）；
   - LCAO M3b 运行时审计：max |Tr[W.DM] - ∫wρ| = 2.54e-8 e（=SCF 残差地板级，逐 α 口径
     一致性证据；矩阵路径=网格路径）；
   - 收敛端点（q/t/mu 逐片段）如实测量：

   | 片段 | PW q / t / μ | LCAO q / t / μ | Δt（基组分划差） |
   |---|---|---|---|
   | c0 O | 6.278818342 / 6.278779656 / +0.0900529 | 6.305513257 / 6.30555988 / +0.1033641 | 0.02678 e |
   | c1 H1 | 0.8605905203 / 0.8606098715 / -0.0900522 | 0.8472433718 / 0.8472200601 / -0.1033641 | -0.01339 e |
   | c2 H2 | 0.8605911374 / 0.8606104727 / -0.0900535 | 0.8472433713 / 0.8472200602 / -0.1033641 | -0.01339 e |

   - **裁定与诚实边界**：严格"同一密度下跨基组 Q_α<1e-8"需要**不重收敛密度的只读观测口**
     （PW 导 cube → LCAO 只读 ∫wρ，不动 SCF）——现有 init_chg=file 会重收敛密度

     读数差 0.013-0.027 e / μ 差 ~15% 归因于**基组自由密度差**（NAO 基组不完整性），
     非算符/读数不一致——读数-注入同算符由构造保证且两基组共用同一 M2 代码路径，
     LCAO 侧 M3b 2.5e-8 实证到残差地板。PW≡LCAO 的**口径不变量**证据链闭合：
     同约束态 FD 双基组分别 PASS + 读数算符构造相同 + 自旋单约束 μ 双基组差 <1%
     （PW -0.0719307 vs LCAO -0.07234，见 §3.4）。**判定：算子口径 PASS；严格同密度
     逐位 <1e-8 跨基组读数登记为开放项**（需只读观测口，列入 A 阶段工具补件候选，

### 3.4 力矩 FD（R7，DM=0.01 μB，raw-E 口径）

- base（delta +0.1 μB）：m\*=0.1000021944 μB、μ\*=-0.07193070771 Ry/μB、
  E0=-466.9020964628797 eV（CONVERGED，5 外步）。
- 腿（absolute m\*±0.01，从 base 密度重启，np4）：
  - hi m=0.1100021944：E=-466.8918210078962，μ=-0.07914777508，4 外步 CONVERGED；
  - lo m=0.0900021944：E=-466.9113921325595，μ=-0.06469447139，3 外步 CONVERGED。
- **观测口径（承力 FD 归因教训）**：用 raw FINAL_ETOT 作 FD 可观测量（E_tot 收敛时
  e_con≈0，即约束基态能量 L\*(t)；包络 dL\*/dt=-μ(t)）。repo 工具
  run_constraint_torque_fd.sh 的 E'=E-μ·t 修正在这里重犯了力归因已排除的
  μ·(dμ 项) 伪项——登记为**工具缺陷**（与 force 脚本头注同理），本判决用 raw-E。
  - μ(m_t) 三点线性：-0.06469 / -0.07193 / -0.07915，dμ/dm=-0.7227 Ry/μB²；
  - dE_raw/dm（lo→hi 中心差）= (Ehi-Elo)/0.02 = **T_FD=0.97855623 eV/μB**；
  - T_ana = -μ\* × 13.605693 = 0.97866713 eV/μB；
  - **|d| = 0.00011089 ≪ 0.006 → PASS（富余 ~54×）**；
  - 对照：若用 E' 口径则 T_FD'=2.9403（FAIL 1.96）——证明 E' 修正为伪项，证据同上。
- **DeltaSpin 参照（同体系同靶点：H₂O PW nspin=2、O 磁矩 0.1 μB）**：
  遗留 DeltaSpin 冒烟档（ecutwfc=20/ecutrho=80，np4）收敛后打印
  after-optimization spin O=0.1000004 μB、lambda_O ≈ -10.5..-10.8 eV/μB：
  - **符号交叉验证**：框架 μ（-0.07193 Ry/μB = -0.9787 eV/μB）与 DeltaSpin λ 同为负
    ——正 delta 磁矩 → 负乘子，μ=-λ 符号关系成立；
  - **量级差 ~10× 归因**：DeltaSpin PW 原子磁矩为 on-site 投影算符（cal_mi_pw，
    且未约束 H 也显示 ~0.11 μB 串扰），本框架为 Becke 区域 ∫w(ρ↑-ρ↓)——非同一可观测
    算符；另冒烟档 drho~1e-2 未完全收敛电荷。故 DeltaSpin 对标取"符号+机制"级，
    量级对等不属判据（记录为 P3/阶段 B 测量项）。

### 3.5 未覆盖 LCAO 轴的外推理由

LCAO 余 7 轴未跑 FD（批复批准不强制全量）：PW 已 18 腿全轴 PASS（同协议同体系）；
LCAO 根因为**机制级 bug**（μw 在 v_eff 重建时被抹，属势生命周期问题），修复在代码层
一次性作用于所有原子/轴共用的 `cal_pulay_fs`（fvl_dphi）求值输入，无逐轴特定项。
已过 FD 的两条 LCAO 轴覆盖两个极端：O-z=权重导数最强方向、H1-x=修复后解析力变化
最大轴（Δ~-2.2 eV/Å）。其余轴残余风险同源、被"净力≈0（逐轴求和）+ 双轴 FD +
PW 同协议 9/9"包围；外推仅限同体系同协议包络，不作普适声明。

### 3.6 力能力声明（限定包络，用户手册 §5 改写依据）

约束态解析力在以下**已验证包络**内可用（小窗验收）：
- H₂O 类小分子；PW 与 LCAO 双基组；R7 网格（ecutwfc=100/ecutrho=400/scf_thr=1e-8）；
- |μ| ≤ 0.5 Ry、约束残差 <1e-4 e（μB）的收敛约束态；
- 力分量与 FD 一致到 <0.013 eV/Å（实测富余 35-58×）。
包络外（大体系/偶极/应力/大 μ/松收敛/未过 FD 的轴组合）维持"未验收"，
任何新注入点（应力、偶极）必须过"注入势在力求值时刻是否存活"检查。
