# 2026-10-30 为什么 LiCl 没有破缺、Fe2 有：回到 MBIS 公式

## 0. 结论

- **LiCl 不是"没出问题"，而是它不存在"可破缺的对称性"**：两原子是**不同物种**（Li、Cl），
  精确 MBIS 解本来就**不对称**（Li 2.04 / Cl 7.96），这是**正确**的，不是问题。
- **Fe2 的破缺是"等价原子的伪对称破缺"**：两个 Fe **同种且应等价**（bcc 体心平移），
  但**小周期胞 + 图像求和不全/图像格不对**使 KL 迭代落到**破缺不动点**（0.075/7.92）。
- **不是"金属 vs 绝缘体"的问题**：MBIS 权重只由**电荷密度的几何（原子位置、N、ζ、镜像）**
  决定。金属性只影响**密度的弥散/噪声**（可放大破缺），**不是根因**。

## 1. MBIS 公式回顾（权重与密度无关的"几何"部分）

```
ρ_A^pro(r) = N_A ζ_A³/(8π) e^{−ζ_A|r−R_A|}   (+ 周期镜像求和)
w_A(r)     = ρ_A^pro(r) / Σ_B ρ_B^pro(r)
KL 更新:    N_A = ∫w_A ρ ,  ζ_A = 3N_A / ∫r w_A ρ
```
- **权重 `w_A` 只依赖 pro-density**（原子位置、`N_A,ζ_A`、镜像），**不依赖电子结构**；
  密度 `ρ` 只在 KL 的**积分**里出现。
- 因此 LiCl/Fe2 的差异**不可能**仅由"金属/绝缘"解释，而是**几何/周期性/对称性**。

## 2. LiCl：两原子不等价 → 精确解本就不对称

- LiCl 是 Li + Cl，**不同物种、不同 Zval/ζ/半径**；精确 MBIS 分区**必然不对称**
  （Li 盆 ≈2.04 e、Cl 盆 ≈7.96 e）。这是 MBIS 的**正确结果**。
- 盒子 15 Å（28 Bohr）、原子在中心 → **周期镜像尾巴可忽略**（`images=0` 就足够精确）。
- 没有"两个等价原子"，所以**不存在**可被迭代破缺的对称性 → 无需 symmetrize。

## 3. Fe2：两原子等价，但数值上被"破缺"

- 两个 Fe **同种**，且由 **bcc 体心平移** `(a/2)(1,1,1)` 相联系 → 精确解应满足
  `N_Fe1=N_Fe2`、`M_Fe1=−M_Fe2`（AFM）。
- 但：
  1. **胞很小**（a≈8.19 Bohr），原子位于**角点/体心**（边界）→ pro-density 尾巴在边界不可忽略，
     **周期镜像必须算**；
  2. 常规胞的**图像格是立方格**，**不含体心平移** → 角点原子与体心原子的**镜像求和不等价**；
  3. KL 是非线性迭代，初始对称（两 Fe 都 `N=Zval, ζ=1`），但上述**微小数值不对称被放大**
     → 收敛到**对称破缺不动点**（0.075/7.92）。
- 这是**迭代的伪对称破缺**（exact 解对称，数值迭代/镜像破坏了它），不是物理破缺。

## 4. 是"金属"的问题吗？

- **根因是几何/周期/对称性**，与金属性无直接关系：
  - 把一个**分子/绝缘体**的**两个等价原子**放进**小周期胞且镜像不全**，同样会破缺；
  - 把一个**金属**放进**大盒/正确图像格**（原胞平移），不会破缺。
- **金属性/磁性的次要影响**：
  - 金属密度更**弥散/振荡**，SCF 与 KL 的噪声更大，可能**促成/放大**破缺；
  - Fe 是**磁性**的，但 MBIS 权重用的是**电荷** `ρ=ρ↑+ρ↓`；自旋只进入观测量 `M_A=∫w_A m`。
  - 所以"金属"不是根因，最多是**加剧因素**。

## 5. 因此"修复"该针对什么

- **不是**给金属加特判；而是针对**等价原子的周期图像/对称性**：
  1. **原胞**（bcc 1 原子）或**原胞平移格**镜像求和 → 迭代天然对称（最本质）；
  2. **空间群等价轨道投影**（`isym_rotiat_`，需 `symmetry` 开）；
  3. 现用的"同种原子平均"是 (2) 在 `symmetry 0` 时的**粗糙代替**，仅当该物种全部等价时正确
     → 必须 opt-in。
- LiCl 无需任何处理（不等价原子，大盒）；Fe2 需要上述之一。

## 6. 一句话

**LiCl 是"不同原子、本就不对称"（正确）；Fe2 是"等价原子在小周期胞/错误图像格下的伪破缺"。
这是几何与周期性问题，不是金属问题；金属性至多放大噪声，不是根因。**
