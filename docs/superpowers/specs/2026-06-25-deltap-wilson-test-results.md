## 关键发现

### 1. Ba平滑性显著改善 ✓

Wilson loop的Ba平滑性比值=1.12（接近1），远优于：
- berry_phase: 0.79
- Berry connection(旧): 未测试但之前为16×

**精确O消除了规范固定问题**——Ba的P值在±0.01 Bohr位移下平滑变化。

### 2. Ti仍有SVD不连续问题 ✗

Ti的P值在Ti+和Ti-之间跳变（4.55e-3 vs -3.7e-5，比值0.01）。原因：

**SVD奇异值交叉**：当Ti位移时，D_I矩阵的奇异值可能交叉（σ_i ≈ σ_j），导致极分解U=WV†不连续。Ti的d电子使奇异值谱密集，容易交叉。

### 3. 分支跟踪需跨SCF持久化

当前W_prev_是内存变量，每次ABACUS运行重置。跨独立SCF运行时，arg()在不同分支上，需要：
- 将W_prev_写入文件（deltap_branch.dat）
- 或用berry_phase P确定正确分支（但仅对总P有效，非per-atom）

### 4. SMO不完备性

Wannier P ≈ berry_phase P × (SMO完备度)。对BaTiO3，SMO完备度约6%（P_wannier/P_berry ≈ 0.06）。这意味着：
- 绝对Z*值偏大（差分放大了不完备性的结构依赖）
- 但如果完备度对结构不敏感，相对Z*（比值）仍有意义

## 改进方向

### 短期（修复当前问题）

1. **持久化分支跟踪**：将W^I复数写入`deltap_branch.dat`，跨SCF运行读取
2. **SVD连续性**：在奇异值交叉时，用前一个结构的U作为初猜，通过连续变形跟踪U

### 中期（提高精度）

3. **增大SMO完备度**：增大rm或增加ζ函数数量，使SMO更完备
4. **添加ionic贡献**：Wannier P只含电子部分，Z* = Z_formal + Z*_electronic

### 长期（根本解决）

5. **解析SVD导数**：用一阶微扰论跟踪奇异向量在交叉点的连续变形
6. **精确Wilson loop + 完备SMO**：当SMO完备度>90%时，绝对Z*应接近文献值

精确Wilson loop **部分解决了平滑性问题**：
- ✓ 消除了规范固定敏感性（Ba平滑性1.12）

- ✗ SMO不完备导致绝对Z*偏差
