# 2026-10-30 真实 cube 稳定性：LiCl 稳定；Fe2 的"破缺"是 STRU 0.51 导致的非等价

## 0. 结果

| 体系 | cosets | ρ(∂F/∂p) | ‖J‖₂ | 结论 |
|---|---|---|---|---|
| LiCl (nspin=1) | 1 | **0.2953** | 0.484 | **稳定/收缩**；N_Li=2.04466, N_Cl=7.95537（与 Python 一致） |
| Fe2 bcc | **1** | 0.27 | 0.93 | 两 Fe **不等价**（见下），不对称是**输入使然** |

- LiCl：`ρ<1` ⇒ Picard 稳定；Picard 与 Newton 同解（D=1.541997）。
- Fe2：`cosets=1` ⇒ `detect_cosets` **未**找到体心平移。

## 1. 根因（重要）

Fe2 的 `STRU`：
```
LATTICE_CONSTANT 8.190
LATTICE_VECTORS  1.00 0.50 0.50 / 0.50 1.00 0.50 / 0.50 0.50 1.00
ATOMIC_POSITIONS Direct
0.00 0.00 0.00
0.51 0.51 0.51      <-- 不是理想体心 0.50 !
```
- 体心应为 `(0.50,0.50,0.50)`；用的是 **`0.51`** ⇒ 两 Fe 相差 `0.01` 分数坐标
  （≈0.16 Å），**本来就不是平移等价的**。
- 因此 `detect_cosets` 正确返回 **1**（无体心平移），MBIS 给出强不对称
  （~0.48/31.52 或 19/13）是**该输入的物理结果**，**不是算法 bug**。
- **注意**：早期"Fe2 16/16 对称"来自**理想 `0.50`** 的另一个 cube；本 cube 是 `0.51`。

## 2. 本轮修复

- **段错误**：`newton_fp` 中 `solve_lin` 失败时 `dx` 未分配即 `dx[i]=-G[i]`（越界）。
  已加守卫（失败时 `dx.assign(n,0)` 走梯度步）。
- `image_translations` 简化为**周期平移群协集**求和（`return detect_cosets(...)`）：
  对一个**胞周期**的 pro，再叠加晶格平移会**重复计数**（且把 D 整体缩放），
  协集群本身即精确的群和。LiCl 不变（cosets={0}）。

## 3. 结论

- **通用性验证**：LiCl（真实、非对称晶胞）上 `ρ=0.295<1`、N 与独立 Python 一致 ⇒
  算法在其探测到的平移群内正确、稳定。
- Fe2 需用 **`0.50`** 的 STRU 重新生成 cube 才能验证 bcc 等价原子落在对称稳定不动点。
