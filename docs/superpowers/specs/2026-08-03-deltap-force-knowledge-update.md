# 第 1 部分：名词解释（按理解顺序）

## 1.1 物理对象

**Berry 相位 γ（读作 gamma）**
电子波函数沿 k 空间一条闭合路径走一圈累积的几何相位，单位是弧度（rad）。
它与材料的电极化直接相关（极化 ≈ 电子 Berry 相位 + 离子位置项）。
DeltaP 要约束的就是每个原子上的 γ_I。

**Wilson loop（威尔逊环）**
计算 γ 的数值工具：把 k 空间路径离散成一串 k 点（叫 k-string），
相邻 k 点波函数做重叠矩阵 M_j，全部连乘 W = M₁·M₂·…·M_n，
γ = W 的本征值的辐角。因为连乘是矩阵积，γ 只能确定到 ±2π 的整数倍——
这就是"分支"问题（见 1.4）。

**SMO 投影 / 投影算符 P̂_I**
SMO = Smooth Molecular Orbital，一套平滑的原子轨道。
P̂_I = 把波函数投影到原子 I 的轨道上的算符。⟨P̂_I⟩ 大致表示
"电子在原子 I 上的权重"。它是 γ_I 的**实空间近似**——γ_I 精确值
必须算 Wilson loop，但把约束写进哈密顿量时需要一个局域算符，就用 P̂_I 代理。

**λ（拉格朗日乘子，读作 lambda）**
约束的强度，单位 Ry。物理图像：λ 是 γ 的"共轭力"——就像用弹簧把 γ
拉到目标值，λ 是弹簧力。λ 越大，γ 被推得越狠。λ 的数值由程序在 SCF
过程中自动调整（两种调整模式见 1.3）。

**escon（约束能量修正）**
记账项：escon = −Σ λ_I·γ_I（单位 Ry）。
程序报告的总能量是 E' = E_tot + escon。**为什么需要它**：
E_tot 的能带能量里包含约束算符的贡献（电子被约束推高了能量），
escon 把它减掉，使 E' 近似等于"没有约束时的物理能量"。
这与 DFT+U、DeltaSpin 的记账方式完全同构。

## 1.2 哈密顿量中的约束项 H_c

约束通过往哈密顿量里加一项 H_c 实现（电子感受到一个推动 γ 的势）。
DeltaP 的 H_c 有**两个部分**：

**H_HR（实空间部分）**
H_HR = Σ_I λ_I · τ_α(I) · P̂_I。
- τ_α(I) = 原子 I 沿约束方向（gdir）的**分数坐标**（0~1 之间，无量纲）。
- 物理图像：这模仿"电场 × 位置"的耦合（电场焓 −E·P 里的 E·R 项）。
- ⚠️ 历史 bug（B-6）：代码曾误用"lat0 单位坐标"（数值≈Å），比分数坐标大
  ~16 倍（等于晶胞尺寸），导致约束强度放大 16 倍。**已修复**。

**H_HK（k 空间部分）**
H_HK = 沿 k-string 构造的 Berry 联络修正矩阵。
物理图像：H_HR 只是 γ 的粗糙代理，H_HK 是更贴近 γ 真实定义
（Wilson loop）的修正项，主要在"内循环"模式起作用。
E_HK = Tr(ρ·H_HK) 是它贡献的能量。

**E_H_HR = Tr(ρ·H_HR)** = Σ_I λ_I·τ_α(I)·⟨P̂_I⟩，H_HR 贡献的能量。

## 1.3 λ 的两种调整模式

**同步模式（synchronous，deltap_inner_nmax=0）**
每个 SCF 迭代末：测一次 γ，按梯度下降把 λ 调一小步
（λ += step·(γ−target)），下一步 SCF 用新 λ。λ 和电荷密度一起慢慢收敛。
问题：SCF 收敛时 λ 只走了有限步，**通常没真正到达"γ=target"**。

**内循环模式（inner loop，deltap_inner_nmax>0）**
当电荷密度基本收敛后：冻结密度，在固定电子结构下用 BFGS 优化 λ，
直到 γ 精确达到 target，然后继续。λ 收敛更精确，但目前有稳定性问题
（见 §3-D8）。

## 1.4 分支（branch）与分支翻转

γ 只能确定到 mod 2π。程序用 Hungarian 匹配算法跨迭代跟踪"哪个本征值
对应哪一条分支"。当两条分支靠得太近或物理变化跨过 ±π 边界时，
匹配结果可能突然交换——**分支翻转**。表现为 γ 突然跳变 ±2π 量级，
λ 跟着跳，能量出现折点（不可微）。这是 FD 测试的主要噪声源之一。

## 1.5 力求解的核心概念

**Hellmann-Feynman（HF）定理 / Pulay 力**
对总能量的严格求力：F = −dE/dR。当基组随原子移动（LCAO 数值轨道
就是），除了 HF 项（电子对势的直接响应）外，还有 **Pulay 项**
（基函数本身随位置变化的导数）。DeltaP 的约束力 = 约束算符 H_c 的
Pulay 项 + escon 记账项的导数。

**原点敏感性 / 平移不变性（本专项最关键的概念）**
物理要求：把**所有原子整体平移**任意距离，总能量和每个原子受的力
**必须不变**（空间是均匀的）。等价地，**所有原子受力之和必须为零**
（牛顿第三定律）。
- 检验方法：全体原子同移 ±δ，对能量做差分，结果应为 0；
  或直接把各原子力求和，应为 0。
- DeltaP 的特殊性：Berry 相位 γ 在整体平移下**会变化**
  （极化的原点依赖性），所以 escon 随平移变化；要让总能量 E' 不变，
  H_c 的能量必须跟着变、且两者**恰好抵消**。抵消不掉 = 模型有缺陷。
- 实测：H_HR 随平移的变化量比 escon 大 ~8 倍，抵消不掉——
  这就是"代理算符差距"（见 §3-D1）。

**均值扣除（FORCE_STRESS.cpp:599 的机制）**
ABACUS 在打印总力前，自动把"所有原子受力的平均值"从每个原子上减掉，
强制合力为零（除非开启 efield/gate）。
**副作用**：如果某个力项本身不守恒（合力≠0，是 bug），这个机制会把
错误平均摊到每个原子上，把 bug 藏成一个"所有原子同方向的均匀偏移"——
T7-c 曾为这个假象排查了半天。
**纪律**：FD 验证时必须用扣除前的力；平移不变性（合力=0）单列验收。

**约束激活 / 驻点（stationary point）**
"约束激活" = γ 真的到达了 target（γ≈t）。
"λ 处于驻点" = 再调 λ 能量也不变（∂E'/∂λ = −(γ−t) = 0）。两者等价。
**dspin 定理**：只有 λ 在驻点时，"只算 Pulay 项的力"才是精确的——
这是 DeltaSpin 力求解正确的数学基础，也是 DeltaP 组② 判决的前提。
同步模式的单步梯度下降**不满足**这个前提（见 §3-D4）。

**FD 验证（有限差分，finite difference）**
把原子 J 沿方向 α 挪 ±δ，用能量差除以 2δ 得到"数值力"：
F_FD = −[E'(R+δ) − E'(R−δ)] / 2δ。
与程序解析算的力对比，差值 < 判据（0.0129 eV/Å）才算通过。
这是力正确性的金标准。

**组① / 组②（FD 实验的两种协议）**
- 组①：位移后 **λ 冻结**不动。测量的是"固定约束强度下"的力。
  理论上此时还差 C 项和响应项 R（见 §3-D9），不严格闭合。
- 组②：位移后 **λ 重新调整到 γ 回到 target**。这模拟 relax 的真实
  受力（每步结构弛豫 λ 都会重调）。**这是 relax 可用性的判决实验。**

**egg-box 噪声（FFT 网格噪声）**
电荷密度、Hartree/XC 势在 FFT 网格上表示。原子相对网格点移动时，
能量有周期性微小起伏（像鸡蛋盒），产生虚假力。网格越细噪声越小。
量级经验：ecutwfc=50（密度网格 200 Ry）时噪声 ~0.006 eV/Å，
已达 FD 判据（0.0129 eV/Å）的一半——**所以验收必须 ecutwfc=100**
（密度网格显式 ecutrho≥400）。

**A1 / A2 / B / C / R（力分解的五项，全文通用代号）**
| 代号 | 内容 | 物理意义 |
|------|------|----------|
| A1 | −Σρ·λτ·∂(c_μc_ν)/∂R | H_HR 中轨道系数的 Pulay 导数 |
| A2 | −λ_J⟨P̂_J⟩(L⁻¹)_{αβ} | H_HR 中 τ（位置权重）的导数——"Born 电荷型"主动力 |
| B | −Σρ(k) ∂H_HK/∂R | H_HK 的 Pulay 导数 |
| C | +λ·∂γ/∂R（波函数不变） | escon 记账项的显式导数 |
| R | +λ·(δγ/δψ)(dψ/dR) | escon 经波函数响应的导数（耦合微扰量级） |

**锚点（anchor）**
回归基准：一组测试用例在固定设置下的标准输出（能量、λ/γ 轨迹、
分支文件），改动代码后重跑对比，防止数值漂移。

# 第 2 部分：力求解的完整公式

```
F_J = F_KS  +  A1  +  A2  +  B  +  C  +  R
      │        │     │     │     │    └ 未实现（论证：约束激活时与 C 相消）
      │        │     │     │     └────── 未实现（同上；只影响冻结 λ 场景）
      │        │     │     └──────────── ✅ 已实现+验证（T7-c B-7）
      │        │     └────────────────── ✅ 已实现+验证（T7-c A2，4ppm）
      │        └──────────────────────── ✅ 已实现+验证（模板与 DeltaSpin 一致）
      └───────────────────────────────── ABACUS 标准力（本来就有）
```

**dspin 定理（为什么后两项可以不做）**：
relax 时每步 λ 都重调到 γ≈target（约束激活），此时 dγ/dR=0，
C 和 R 大小相等符号相反、严格相消 → **只需 A1+A2+B 就是精确力**。
前提：λ 必须真正调到驻点——这是当前唯一未验证的环节（组② 判决）。

# 第 3 部分：九大难点详解

## D-1 观测量与算符的二元性【根源性难点 · 现状：接受 + 兜底方案】

**问题**：程序里有三个互不相等的"约束相关量"：
1. γ（Wilson loop 算的，escon 记账用它）；
2. H_HR（实空间代理算符，进哈密顿量产生力）；
3. H_HK（k 空间修正，进哈密顿量产生力）。

DeltaSpin 里这三个是同一个对象（M = Tr[ρ·Ô]，Ô 就是哈密顿量里的算符），
所以能量记账严格相消。DeltaP 里三者不等，相消关系不成立。

**实测定量**（总 E' 均匀平移 FD）：平移时 H_HR 能量变化是 escon 变化的
~8 倍，且同号——不抵消。这意味着 E' 整体随坐标原点有线性倾斜
（−3.25e-2 Ry/Bohr），物理上不应该。

**影响与对策**：
- 对 relax：均值扣除消去这个均匀倾斜，逐原子的力差不受影响 → 可用；
- 对精度上限：这是"用代理算符近似 γ"的固有误差。若组② 判决发现
  残差超判据 → 触发预案 O5（重构 H_c 的算符形式）。
- **状态：已定量、已接受、有兜底。**

## D-2 τ 坐标单位 bug（B-6）【✅ 已解决】

**问题**：代码把"lat0 单位坐标"（数值≈Å，如 8.0）当"分数坐标"
（0~1，如 0.5）用，约束强度放大 = 晶胞尺寸 L 倍（测试体系 15.87 倍）。
**两处病灶**：H_HR 的 τ；k 空间 S_dk 的相位。
**怎么发现的**：平移实验中 E_HK 变化与 escon 变化失配 15.5 倍 ≈ L=15.87
（精确吻合含巧合成分，但机制为真）。
**修复验证**：E_H_HR 精确缩小 15.90 倍（理论 15.87，吻合 0.15%）；
修复后 E_HK 恢复平移不变（合力 0.1147 → 0.0001）。
**连带影响**：所有历史 λ 数值的物理强度解读都要除以 L；
E=−πλ/(2a) 公式只在修复后成立；λ≠0 的测试锚点已重建。

## D-3 H_HK 的构造与解析力（B-7）【✅ 已解决】

**问题**：H_HK 的力需要对其构造链（重叠矩阵导数 + 相位导数）逐项求导。
初版代码有个隐蔽 bug：`if (g == 0) continue` 把轨道导数为零的配对的
**相位导数也一起跳过了**（两类导数本应独立累积）——自配对（s 轨道等）
的相位贡献全部丢失。
**验证方法（双闭合，值得作为范式）**：
1. 单原子 FD：E_HK 差分 +2.86 eV/Å ↔ 解析力 +2.97 ✓；
2. 均匀平移 FD：−0.115 Ry/Bohr ↔ 解析合力 +0.1147 ✓。
教训：只做单点验证可能靠巧合通过，必须两个独立闭合。

## D-4 dspin 定理前提 vs 同步模式协议【组② 残差的真相 · ⏳ 待驻点判决】

**问题**：组② FD 实验（位移后重调 λ）残差 0.02–0.32 eV/Å，一度以为
是力实现错误。定量分解后发现：同步模式的 λ(R)=0.001·(γ(R)−t) 是几何的
函数，E' 对 λ 又极敏感（dE'/dλ≈405 eV/Ry）——残差**全部**来自
"λ 随几何变化"这个协议效应，不是力的错误。
**结论**：要判决"A1+A2+B 是否精确"，必须让 λ 真正收敛到驻点。
**方案（已确定，待执行）**：脚本级驻点协议——每个位移几何反复
"SCF→测 γ→调 λ"直到 |γ−t|<1e-3，再做 FD。绕开内循环的稳定性问题。

## D-5 分支离散性【协议已修 · 风险已控】

**问题**：γ mod 2π 的分支跟踪在简并/跨界时翻转，能量出现折点，
FD 直接失效。早期组② 失败的主因是 target=(0,0,0) 离 γ*≈(−5.5,−3.6,−3.6)
太远（约束从未激活，分支乱跳）。
**对策**：FD 的 target 取 γ*(base)（约束激活）；分支翻转次数纳入锚点监控。
**遗留现实**：B-6 修复后约束驱动弱 16 倍，同步模式下 γ 常到不了 target
（5/9 用例末态 |γ−t|≈2.6–5.8）——这是物理预期，λ 步长重标定归 F1 备忘录。

## D-6 均值扣除的掩盖效应【纪律已立】

见名词解释 1.5。核心教训：**任何力求和不为零的现象都是一等线索**，
均值扣除会把它伪装成均匀偏移。FD 验证一律用未扣除的力。

## D-7 FD 噪声预算【协议已立 · 锚点已就位】

判据 0.0129 eV/Å 对应能量噪声须 < 6.8e-5 eV。各噪声源：
- ecutwfc=50 的 egg-box ≈ 0.006 eV/Å（判据一半，**不可用于验收**）；
- scf_thr=1e-7 ≈ 0.0003 eV/Å（可接受，验收用 1e-8）；
- δ 线性度（±δ vs ±2δ 斜率一致性）排除分支折点。
**协议**：归因分析可用低精度 + 隔离对照（噪声相消）；
**正式验收必须 ecutwfc=100 / ecutrho≥400 / scf_thr=1e-8**（锚点已按此重建）。

## D-8 内循环 SCF 极限环【❌ 未解决 · relax 生产化阻塞】

**症状**（BN，ecutwfc=100）：电荷密度残差在 6e-4–1e-3 之间持续振荡不收敛；
1 进程与 4 进程结果不同。
**疑似机理**：密度残差正好骑在 λ 更新的触发阈值（1e-3）上——
"触发 λ 更新 → 扰动使残差升高 → 退出 → 再触发"的磁滞振荡。
1v4 进程差异可能是振荡的混沌敏感（对初值微扰放大），不一定是 MPI bug。
**下一步（界定实验，先于动刀）**：
1. 范围界定：h2o1 是否也振荡？（此前 test_stru_target 内循环曾通过——什么变了？）
2. 混沌鉴别：单进程加微小初值扰动，若同样发散 → 是混沌不是 MPI；
3. 机理确认：检查内循环触发标志的复位时机（是否每次过阈值都重触发）。

## D-9 C 项与响应项 R【已论证：relax 不需要 · 暂缓实现】

组①（冻结 λ）FD 残差 +0.615 eV/Å ≈ C + R，与理论预期一致。
- C 的实现成本 ~300 行（Wilson 环本征相位求导 + 分支跟踪）；
- 即使做了 C，组① 还差 R（耦合微扰量级），仍不严格闭合；
- relax（约束激活）场景 C+R 相消，**不需要**。
**决策**：暂缓。若未来需要"冻结 λ 下扫描能量地形的力"，先做一次
FD-of-γ 实验（差分直接测 dγ/dR 全量）界定 R 的大小，再决定是否实现 C。
