# DFT+U 与统一约束框架的算法冲突评估

> 依据：本轮三项交付（1c1199987 审计仪器 / 04f6b8482 边界文档 / 0273636b0 MgO 远侧）+ II-1 系列实测 + 代码核实（constraint_loop.cpp:437 仪器、ee7ac0b4c 守卫）。
> 问题：涉及 DFT+U 时，统一约束框架有没有算法上的冲突？
> 结论先行：**无正确性层面的算法冲突，但存在三层真实张力——最实质的一层（观测量口径错配）已被本轮数据定量证实；另有一个被 C-29 揭示的健壮性缺口（非 U 特有但同族）。**

## 1. 哈密顿共存：无冲突（已实证）

两条势通道在哈密顿量中独立相加：DFT+U 走 on-site 投影算符（占据依赖非局域势），约束走 veff 网格（μw）。FeO II-1a 共存 PASS 已实证。冻结权重 + μ 仅外环更新 → 约束侧无 T-17 活算符极限环风险；U 的占据矩阵更新是其自身标准机制，与冻结约束势不构成互相激励的振荡。**结构与自洽两个层面均无冲突。**

## 2. 观测量口径错配：核心张力（模型层，非 bug）

- 约束的共轭观测量是 **Becke 加权矩**；U 校正的目标是 **on-site d 占据**。体系存在一条**廉价通道**：只重排 basin 尾部/间隙磁化即可满足约束，完全绕过 U 所针对的 d 关联。
- 本轮数据定量证实（II-1b）：良态 δ=+0.1 μB 点 d 矩只跟随 **74%**；换态点**反向脱钩**（Becke −1.28 μB vs d 矩 −0.20 μB）。
- 定性：这是 CDFT 的固有性质——μ 严格共轭于**所选**观测量，框架没有算错任何东西；错配的是用户预期（"约束 TM 自旋" ≠ "控制 U 针对的 d 矩"）。
- 深层张力（评审立场）：on-site 投影矩贴近 d 矩恰恰**基组相关**（PW 赝势 β 投影器 vs LCAO NAO 投影器口径不同）——当初换实空间权重消灭的口径分裂会随 on-site 权重回归。因此处置链必须是：
  (i) 透明化（审计行 `onsite=` 同点对照，**已落地** 1c1199987）；
  (ii) 定量研究（Fe 半径敏感性，4b 待锚点）；
  (iii) 边界声明（L14 **已落地**）；
  (iv) on-site 权重类型**只能作为阶段 C 的明示权衡**（用户显式选择"放弃基组无关换 d 局域"），不得静默引入。

## 3. 多解地貌放大：工作流冲突（已部分处置）

U 的亚稳占据态 × 约束推力 → 分支翻转概率显著高于无 U 体系（FeO 实测双解、换态）。处置：BRANCH_FLIP 守卫已落地（ee7ac0b4c），L15 如实登记两条盲区：① 只抓能量向下的换态；② **只在 SCF 收敛点判**——固定 μ 极限环（不收敛点）守卫无从介入。盲区②与 §4 相连。

## 4. C-29 揭示的健壮性缺口（非 U 特有，但与远侧扫描同族）

- 事实：Mg³⁺ 远侧 δ=−2.0 e，外步 56 的约束 SCF 在 scf_nmax=800 内不收敛，**非收敛收尾路径堆破坏**（free(): invalid next size）并挂死；父提交二进制逐位复现 = 预存在 bug。
- 两层含义：(a) C-29 是内存 bug，需 ASAN/gdb 专项定位（同意列为最高优先级）；(b) **更一般的设计缺口**：外环熔断的前提是"每个外步都拿到一个收敛的 SCF"——μ 顶限熔断在本体系**实际不可达**（SCF 先崩）。即使 C-29 修好，也必须补一条"**SCF 不收敛 → 判 UNREACHABLE/降级**"的路径（这正是 L15 盲区②的解法），否则任何远侧扫描都有挂死风险。
- 运行纪律（mpirun 必裹 timeout）同意并应写进扫描脚本默认。

## 5. 裁定与建议顺序

| 序 | 项 | 依据 |
|---|---|---|
| 1 | **C-29 专项定位**（ASAN/gdb） | 生产邻近路径上的崩溃 bug，阻塞远侧扫描 |
| 2 | **"SCF 不收敛→熔断/降级"路径**（连同 L15 盲区②） | 熔断可达性设计缺口，比 C-29 更一般 |
| 3 | 4b 半径敏感性（与 II-1 重锚定合批） | 定量 §2 错配幅度 |
| 4 | FeO S4/S5 继续暂缓；I-1 判决不受影响（同意） | 报告判定正确 |

**总答**：DFT+U 与统一约束框架**没有算法正确性冲突**——共存与自洽均已实证；真正的冲突在**观测量语义层**（约束控制加权矩而非 U 针对的 d 矩），它是 CDFT 观测量选择的固有权衡，已通过 L14 文档 + `onsite=` 仪器正确处置，终极解法（on-site 权重）必须留阶段 C 明示权衡。当前最紧的是 C-29 与"SCF 不收敛熔断"缺口。
