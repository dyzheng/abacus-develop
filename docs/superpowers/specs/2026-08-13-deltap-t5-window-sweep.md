## 1. 结论先行

- **0.995/1.005 双向靶点均不可达**（O 差 ~2×、H 差 ~20×）。量化可达域：
  - **O 通道**：Δγ_O ∈ **[−0.004, +0.013] rad**（λ∈[−0.1,+0.1]，内循环预算
    封顶 0.1 Ry）；0.995 侧（γ 向 0）比 1.005 侧宽 ~3×（+0.013 vs −0.004），
    但都达不到 0.995 靶（需 +0.0276）；
  - **H 通道**：Δγ_H ∈ **[−0.0003, +0.0012] rad ≈ 噪声级**——双侧均死，
    T-2"γ_H>自然不可达"实为"双侧都不可达"（Γ_H U 形退化 + γ_H 响应 ~0）；
  - 约束松弛（Γ→t_Γ）在 |t_Γ−Γ_nat| ≳ 0.1 处失效：λ 预算耗尽后
    |Γ−t_Γ| 残差 0.08–0.55（判据 1e-3 的 100–500×）。
- **secant 外循环在两侧均发散**（t0995/t1005）：pass-2 κ 符号翻转/超调
  （−16.5/−7.1 与 +13.5/−3.7），t_Γ 崩溃到自然以下（6.75→6.24），
  pass-3 内循环 λ_O=+0.097~+0.106（预算外）→ SCF 不收敛。与 T-2（0.98 靶）
  同族失败——**secant 机制在 proxy 模式下对任何非自然靶点均不稳定**。
- **改用冻结 t_Γ 协议**（T3 式：`deltap_proxy_target_file` + secant off +
  内循环）测得上述干净数据（12 点全部 SCF 收敛）。
- 对 LIMITATION 的更新：合法工作窗 |Δγ| ≲ 0.01 rad/原子（O），H 通道不可用；
  Ô_w（T-18 FAIL）未能扩窗——两条独立路径（secant 外循环 / Ô_w 换算符）
  都已实证关闭，**γ-hold 类约束在当前算符-记账框架下无可用工作区**。

## 5. 分析

1. **H 通道死**：λ_H=±0.1（预算上限）下 Γ_H 仅 1.977→1.94/2.04（U 形底，
   dΓ_H/dλ≈−0.35 弱），γ_H 仅 ±0.001 rad（dγ_H/dλ≈±0.01）——"Γ 旋钮对
   H 的 γ 无控制力"（T-2 第三层）被独立协议定量证实；**双侧都不可达**，
   "单侧可达域"不存在。
2. **O 通道窄且不对称**：自洽 dΓ_O/dλ≈−1.2（λ=+0.1 时 ΔΓ=−0.12；λ=−0.1 时
   ΔΓ=+0.25——U 形在 O 上也出现），γ_O 可达 +0.013（0.995 侧）/−0.004
   （1.005 侧）；0.995 靶（+0.0276）差 ~2×。
3. **λ 预算封顶 0.1 Ry**（内循环 BFGS 步长 ~0.005×20 步）是当前机制的硬约束；
   超预算（secant 崩溃路径 λ=0.1+）SCF 不收敛（T-2：λ=−0.865 失控同族）。
4. **约束松弛失效**：|t_Γ−Γ_nat|≳0.1 时内循环无法满足 Γ→t_Γ（残差
   0.08–0.55）——可达域边界由"Γ 自洽响应弱 + λ 预算"双重决定，与 t_γ 定义
   无关。
5. **T-5' 与 T-18 交叉印证**：ow 模式 dγ/dλ≈0.26（T-18）与 proxy 模式
   γ 可达域 ±0.01（T-5'）一致指向——γ↔算符耦合的物理强度就是 ~0.1 rad/Ry
   量级，换算符（Ô_w）未改变值域（T-18 已判 FAIL）。两条独立路径关闭后，
   **γ-hold 约束在现框架下无可达工作区**（除自然点附近 ≤0.01 rad）。

## 6. 对 LIMITATION 文档的更新（写入 08-05 主算法文档 §8）

1. 弱耦合窗口量化：合法工作窗 |Δγ| ≲ 0.01 rad/原子（O 实测，λ 预算 0.1 Ry）；
   H 通道不可用（Δγ_H ≤ 0.001 rad）；0.995/1.005 类靶点不可达（O 差 2×、
   H 差 20×）。
2. secant 外循环（proxy 模式）：对任何非自然 t_γ 发散（κ=1 首轮方向错误 +
   修正 κ 超调 + λ 预算耗尽），不用于生产。
3. Ô_w 未扩窗（T-18 FAIL）：换算符路线对 γ 值域的改善 <2×，远非所需 10×；
   γ-hold 约束的可达域问题不再是"协议选择"而是"算符-观测量耦合物理强度"。
