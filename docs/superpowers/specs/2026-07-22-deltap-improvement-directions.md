# DeltaP 算法改进方向分析

**日期**: 2026-07-22
**基于**: 完整开发历程——分支选择修复、BN/H2O PES、BEC结构性局限、total约束模式

---

## 背景总结

经过本次开发循环，DeltaP 算法框架已确认的能力和局限：

| 已验证的能力 | 已确认的局限 |
|-------------|-------------|
| ✅ Per-atom γ 约束（H2O 刚度可测） | ✗ BEC 不可靠（per-atom 分解的结构性代价） |
| ✅ Total 模式约束 Σγ | ✗ λ 在零刚度体系（BN）中淹没于噪声 |
| ✅ 全局分支选择消除了 per-string 非确定性 | ✗ arg(zeta) 模 2π 截断破坏跨构型相位 |
| ✅ H2O per-atom→total 弛豫因子 4× 测量 | ✗ 单原子约束无法直接对比实验极化率 |

---

## 改进方向 1：直接总 Berry 相位模式

**问题**：当前代码必须经过 per-atom 分解才能得到 γ 值。arg(zeta_scalar) 直接输出存在 2π 截断，跨构型不可靠。

**方案**：新增 `deltap_direct_bp = true` 模式。在此模式下，跳过 per-atom 分解（不计算 w_In, gamma_I_per_atom, Steps 1-3），直接输出每条 k-string 的持续跟踪总 Berry 相位。关键设计：

- 对每条 k-string，追踪 zeta_scalar 的**累积相位**（非 arg 截断）：Γ_string = unwrap(arg(zeta_1), arg(zeta_2), ..., arg(zeta_N))
- 跨 string 平均得到总 Γ
- 此值不经过 per-atom 分解，无 rescaling 引用漂移
- 直接用于 BEC：Z* = (a/π) × dΓ/du

**复杂度**: ~100 行新代码，复用现有 k-string 循环  
**验证方式**: 标准 BN BEC 测试，与文献 ±2.7 对比  
**风险**: 跨 string 的 unwrapping 引用仍需小心处理（string 间的 2π 跳变）  
**收益**: 补上 DeltaP 不支持 BEC 的关键缺口

---

## 改进方向 2：通用线性约束矩阵

**问题**：当前只支持两种约束模式——per_atom（单位矩阵）和 total（全 1 向量）。物理上有意义的约束模式远不止这两种。

**方案**：新增 `deltap_constraint_matrix` 参数，接受一个矩阵文件或内联定义：

```
deltap_constraint_mode  matrix
deltap_constraint_matrix  constraint.mat
```

`constraint.mat` 格式：
```
n_constraints  n_atoms
C_11  C_12  ...  C_1n    target_1
C_21  C_22  ...  C_2n    target_2
...
```

每行定义一个线性约束：Σ_j C_ij · γ_j = target_i。

**示例应用**：

| 约束矩阵 | 物理含义 |
|---------|---------|
| `[1, -1, 0, 0, 0]` | 原子 1↔2 的 γ 差值（电荷转移约束） |
| `[w_1, w_2, ..., w_n]` | 加权总极化（不同原子不同贡献） |
| `[1,1,0], [0,0,1]` | 部分原子总约束 + 单原子约束 |

**需要的代码改动**：
- 分支选择：从 per-atom 搜索改为约束空间的联合搜索（贪心顺序 + K=5 穷举）
- λ 更新：dλ_α/dt ∝ C·γ - target（已在 total 模式中验证可行）
- HK 修正：w_eff[n] = Σ_α λ_α · (Σ_i C_αi · w_In[n][i])

**复杂度**: ~150 行新代码  
**验证方式**: 再现 H2O per-atom 和 total 结果（单位矩阵和全 1 向量是其特例）  
**收益**: 可测量原子间电荷转移刚度、Born 有效电荷（通过约束差分的等效方式）

## 改进方向 3：自适应约束强度

**问题**：deltap_lambda_step 和 deltap_lambda_mixing 是固定值。BN（零刚度）的 λ 在噪声地板，而理论上的铁电体可能 λ 过大导致不收敛。

**方案**：Phase 1 收敛后，用**自动微扰法**估计系统刚度，据此设定 step 和 mixing：

1. Phase 1 结束时记录 γ_i 和 E
2. 施加微小试探 λ_trial = (ε, ε, ..., ε)
3. 一次 SCF 迭代 → 测量 Δγ/Δλ → 估计刚度 k_i ≈ Δλ_i/Δγ_i
4. 设置 step_i = α / k_i（使 λ 更新步长与系统刚度匹配）
5. 对 k_i ≈ 0 的原子（BN 类），自动切换为"仅分支锚定"模式

**替代方案**（更简单）：多点采样 + 线性回归。用 3 个 λ 值（0, λ_small, λ_large），分别做一次约束 SCF，测量 γ(λ) 斜率 → k。

**复杂度**: ~80 行新代码  
**验证方式**: BN 自动检测 k≈0 并跳过约束；H2O 自动设定合理 step  
**收益**: 消除手工调参，使 DeltaP 对任意体系"开箱即用"

## 改进方向 4：多靶标自动 PES 扫描器

**问题**：当前 PES 扫描需手动生成 9 个目录、9 个 target.dat、手动分析。H2O PES 就是这样做的。

**方案**：新增 `deltap_pes_scan` 参数，自动驱动多靶标 PES 扫描：

```
deltap_pes_scan  true
deltap_pes_center  γ1 γ2 ... γN     # 基态靶标
deltap_pes_step    0.1              # Δ 步长
deltap_pes_directions  axis diag    # 扫描方向：axis（仅轴）、full（含对角线）
deltap_pes_natoms 2                 # 参与扫描的原子数（前 N 个）
```

运行时：
1. 用 center 做一次 SCF → 获得基态能量 E_0 和 λ_0
2. 自动生成 9 个（或 2N+1 个）靶标
3. 在每个靶标做 SCF → 记录 E, λ, γ_actual
4. 拟合 Hessian、输出 λ-γ 响应、导出极化率

**输出文件**：`deltap_pes_results.csv` 和 `deltap_pes_summary.txt`

**复杂度**: ~200 行新代码（主要在 esolver 层）  
**验证方式**: 重现 BN 和 H2O 的已有 PES 结果  
**收益**: 将 PES 扫描从"手工流程"变成"一键运行"，大幅降低使用门槛

## 改进方向 5：λ→物理观测量自动转换

**问题**：λ（μRy/rad）不能直接对比实验。用户需要手动换算到有效电场 E_eff、极化率 α、介电常数 ε_∞。转换公式分散在不同文档中，容易出错。

**方案**：在输出中自动计算并打印物理观测量：

```
[DeltaP-Physics] 
  Σγ = -12.726 rad
  λ_total = 2140 μRy/rad²
  E_eff = -λ × 2π/a = 1.39e-3 V/Å
  χ = (a²/(4π²V)) × (δΣγ/λ) = 0.279
  ε_∞ = 1 + 4πχ = 4.5
  α = (a/(2π))² / k = 9511 a.u.
```

需要的输入参数（新增）：
```
deltap_lattice_a  6.831    # 极化方向的晶格常数 (Bohr)，默认为自动检测
deltap_cell_volume 637.6   # 晶胞体积 (Bohr³)，默认为自动检测
```

**复杂度**: ~50 行新代码（纯后处理）  
**验证方式**: BN 输出 ε_∞ ≈ 4.5（当 λ 大于噪声地板时）  
**收益**: 输出直接可对比实验，无需手工换算

## 改进方向 6：分支状态持久化与跨构型锁定

**问题**：BEC 测试中，同一构型的分支选择是确定性的，但不同构型可能选到不同周期像。如果分支选择方案能跨构型锁定，BEC 也许可行。

**方案**：将当前构型的分支选择状态（每个 atom 的 k-best vector，zeta rescaling 的 scale 因子，prev_gamma）保存到 `deltap_branch_lock.dat`。下一构型加载此文件，**跳过全局搜索**，直接复用锁定的分支参数。

**与 BEC 局限文档的对比**：文档认为跨构型锁定"不可行"。这里提供一个**有限但有效的折衷**：

- 只在满足条件时锁定：|γ_raw(new) - γ_raw(ref)| < π × min(w_norm)（即 raw γ 在同一分支周期内）
- 如果 raw γ 超出周期 → 回退到正常的全局搜索
- 对 BEC 测试，位移 δu 足够小时，raw γ 变化在周期范围内 → 锁定有效

**复杂度**: ~120 行新代码  
**验证方式**: δu=0.01 Bohr BEC 测试，锁定后 Z* 应与文献一致  
**风险**: 对 δu 有上限要求，不如方向 1（直接 BP 模式）可靠  
**收益**: 保留 per-atom 信息的同时获得可靠的 BEC

## 方向对比总结

| # | 方向 | 复杂度 | 收益 | 风险 | 推荐优先级 |
|---|------|--------|------|------|----------|
| 1 | 直接总 BP 模式 | 中 | **高** — 补上 BEC 缺口 | 低 | ⭐⭐⭐ |
| 2 | 通用线性约束 | 中 | **高** — 测量新物理量 | 中 | ⭐⭐⭐ |
| 3 | 自适应约束强度 | 低 | 中 — 改善易用性 | 低 | ⭐⭐ |
| 4 | 自动 PES 扫描器 | 中 | 中 — 降低使用门槛 | 低 | ⭐⭐ |
| 5 | λ→物理量自动转换 | 低 | 中 — 输出可对比实验 | 低 | ⭐⭐ |
| 6 | 分支跨构型锁定 | 中 | **高** — 可能解锁 BEC | **高** | ⭐ |

**推荐路线**：
- **方向 1 + 5** 组合：直接 BP 模式 + 自动物理量转换 → 完整闭合 BEC 和介电常数验证
- **方向 2** 独立：通用线性约束 → 打开全新的物理测量维度
- **方向 3 + 4** 可选：改善工具链成熟度
- **方向 6** 不推荐：方向 1 是 BEC 的更可靠方案
