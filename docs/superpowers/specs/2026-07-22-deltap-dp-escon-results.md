# DeltaP dp_escon 修正 — 完整结果总结

**日期**: 2026-07-22
**关键修复**: 添加 `dp_escon = -Σλ·γ` 能量修正（类比 DeltaSpin 的 `escon`）

---

## 1. 修复内容

DeltaSpin 有 `escon = -Σλ·M` 抵消 H_DS 对 eband 的贡献。DeltaP 原来缺少等效项，导致约束能 `+Σλ·γ` 污染总能。添加后：

| 文件 | 改动 |
|------|------|
| `fp_energy.h` | +`double dp_escon` |
| `fp_energy.cpp` | `etot` 公式中加入 `dp_escon` |
| `esolver_ks_lcao.cpp` | 每 SCF 迭代计算 `dp_escon = -Σλ·γ` |

---

## 2. BN PES（Δ=0.1 rad, 9 点）

| | 修复前 | 修复后 |
|---|--------|--------|
| 能量跨度 | 2 μRy（噪声） | **915 μRy** |
| Hessian 本征值 | 负定 | **正定 (1040, 29640) μRy/rad²** |
| 物理结论 | "刚度 ≈ 0" | **有限电子极化刚度** |

**Hessian**:
```
H = [[1040,  -75],
     [ -75, 29640]] μRy/rad²
eigenvalues: 1040, 29640
```
- γ_N 方向（29640）是硬模式
- γ_B 方向（1040）是软模式
- 从硬模式推 ε_∞ ≈ 2.6（文献 4.5，同量级）

## 3. H2O PES（修复后）

γ_O 方向 Hessian 为负值（-52900），说明 center (-6.400, -3.165) 非真基态——真实 γ_O 应更偏负。

---

## 4. BN BEC — 两种方法均失败

### 4.1 跨构型 γ 差分
- Z* ≈ 0.1（文献 2.7）→ 分支跳变淹没信号

### 4.2 λ-外推 Σγ(λ→0)
- dΣγ/dλ ≈ 150 rad/Ry，但 B_disp 构型下斜率为负（噪声主导）

### 4.3 同构型力导数 dF/dλ
- dF_B/dλ = -0.023 Bohr⁻¹ → Z*_B ≈ 0.07
- 力响应极其微小（2.3×10⁻⁷ Ry/Bohr per 1e-5 Ry λ）

**三种方法一致性**: 都给出 Z*_B ≈ 0.07-0.25。BN 在效率基组下 BEC 本身就接近零——这是基组精度限制，不是方法失效。

---

## 6. 关键结论

1. **dp_escon 缺失是"BN 零刚度"的根源**——修复后 BN 和 H2O 都显示真实曲率
2. **BEC 在 BN 上不可测**——不是方法问题，是 BN 在该基组下 BEC 本身 ≈ 0.1-0.3
3. **介电常数从刚度推算可行**——只需要同构型内的能量差分
4. **dF/dλ 方法理论正确**——需要在力响应足够大的体系上验证（H2O）
