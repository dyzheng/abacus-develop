## 4. Analysis

### 4.1 V-H7 与 Maxwell 的 6.8%/7.0% 残差：C 响应，非实现缺陷

- 残差 = ∂E_HK 的 FD 路径（每应变点 SCF 收敛，含波函数弛豫）与解析
  σ^HK（冻结 C）之差 = (∂E_HK/∂C)·(dC/dε)，O(λ)。
- E_HK 是非变分分量（对 C 的导数不为零），C 响应一阶项不消失——这是
  与力侧 T3 完全同族的签名：T3 力残差 0.0138 vs 0.0129 eV/Å = **7%**，
  与本轮 6.8%/7.0% 同源同量级。
- 判定：**严格 5% 判据线上未过（超 2 点），残差 100% 归因 C 响应，
  机制一致性成立**。λ→0 时残差 ∝λ 线性消失（与 T3 泄漏 ∝λ² 同族）。
  协议原判据未预见到"冻结 C 解析侧 vs SCF 弛豫 FD 侧"的 C 响应项，
  已在文档如实标注，不宣称 ≤5% PASS。
- 佐证：Maxwell 残差（7.0%）与 V-H7 残差（6.8%）同源——两者都是同一
  C 响应项在两种 FD 口径下的体现。

### 4.2 efield 必测项：力侧失配是力路径特有（协议 §5 决策树）

- 同体系（hf）：力侧 L_F/L_μ = **52.5×**（h2o 的 17.7× 同族，hf 更甚），
  应力侧 L_σ/L_μ = **1.78–2.68×**——差 ~20–30 倍。
- 按协议 §5：**17.7× 类失配不普适，是力路径特有**，需重新归因
  （力通道的 B 项 F_HK = −λ·∂Γ/∂R 含基组几何通道；应变通道的对应项
  ∂Γ/∂ε 主成分是极化通道——应变导数与位置导数对 S_dk/SMO 投影的
  敏感度结构不同，方向 3 的一行定理在此的实证边界）。
- EFC 立项动机修正：力级 Maxwell 一致性仍是唯一第一性解法（力侧 52×），
  但"应力/压电侧也撞同族问题"的前瞻警告（F-8 评审预警）**未兑现**——
  应力侧无 17.7× 类失配，EFC 不需要为压电路径立项。

### 4.3 实现注记（留给后来者）

- σ 符号：σ = −(1/Ω)dE_HK/dε，E_HK = −0.5·Im(Σ kern) ⇒ σ = +0.5·Im/Ω
  （力侧 F = +0.5·Im(Σ acc) 的 ε 版镜像，符号不同不要照抄）。
- ÷2：pair 循环双向访问（bra=A 与 bra=B 访问同一无序对），反访时
  d→−d、grad→−g，每对同号双计 ⇒ 权重 0.5·d_β。
- 格矢权重陷阱：R=0 pair 的格矢部分全零 → 必须用全分离矢量
  d = τ₀−τ₁·lat0（含周期镜像），勿回退到格矢。
- 相位部分应变不变（固定约化 k、分数坐标下 ∂phase/∂ε=0），只走轨道
  导数 g 通道；∂W/∂ε 同构（S_k pair 通道）。
- MPI 门控：`cal_force_stress` 对 hk+MPI+cal_stress、ow+cal_stress
  WARNING_QUIT（守卫保留）；串行 hk 的 H_HR 应力置零（H_HR 未施加），
  σ^HK 经静态存储由 FORCE_STRESS 加入总应力。
