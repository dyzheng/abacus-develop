## 0. 摘要

| | 算法 A：Becke 分区（约束框架） | 算法 B：DeltaSpin 投影 |
|---|---|---|
| 可观测量 | `m_a = ∫ w_a(r)·[ρ↑−ρ↓](r) dr` | `M_I = Tr[P_I·ρ_diff]`，`P_I` 为原子轨道投影算符 |
| 局域化方式 | **实空间**：Becke 胞权重 | **希尔伯特空间**：指定的 `l,m` 通道 |
| 求和规则 | `Σ_a m_a ≡ M_tot`（**机器精度**，同一网格同一积分） | `Σ_I M_I ≠ M_tot`（投影截断，近似） |
| 局域值的物理含义 | 无化学意义（分区人为；实测展宽 0.77 e 量级） | 轨道投影矩，可与 DFT+U/实验局域矩对照 |

| 解析力 | `−∫[ρ↑−ρ↓]·μ∇w` + Pulay 项；FD 验证 54–369× 富余 | 需投影算符导数项；本仓库未做同级 FD 验证 |
| 基组 | PW/LCAO **共用同一实现**、同口径 | LCAO 走密度矩阵、PW 走 onsite projector，两套实现 |
| 已知失效模式 | APNS 赝势下 LiNiO₂ 自旋三点翻磁分支；TM 体系与 `d` 通道矩脱钩 | 迹公式实现陷阱（邻域截断）；投影求和规则近似 |

## 1. 算法 A：Becke 实空间权重分区

### 1.1 权重构造

对格点 `r` 与原子 `I`（位置 `R_I`，分区半径 `R_I^cov`）：

```
r_I   = |r − R_I|                        （周期体系取最小镜像）
R_IJ  = |R_I−R_J|
μ_IJ  = (|r−R_I| − |r−R_J|)/|R_I−R_J|  ∈ [−1, 1]          （Becke 1988）
p(x)  = 0.5·x·(3 − x²)
s(μ)  = 0.5·(1 − p(p(p(μ))))             （三阶迭代多项式，3 次迭代）
p_I(r) = Π_{J≠I} s(μ_IJ(r))
w_I(r) = p_I(r) / Σ_J p_J(r)             （显式归一化）
```

**异核尺寸修正**（`source/source_base/module_grid/partition.h`，`w_becke_adjusted`）：

```
χ_IJ = R_I^cov / R_J^cov
u_IJ = (χ_IJ − 1) / (χ_IJ + 1)
a_IJ = clip( u_IJ / (u_IJ² − 1), −0.5, +0.5 )
μ'_IJ = μ_IJ + a_IJ·(1 − μ_IJ²)          （等半径时 a=0，退化为标准 Becke）
```

`w_I` 用 `μ'` 替代 `μ`。半径取 `ModuleBase::CovalentRadius`（Angstrom→Bohr）。

**单位分解**：`s(μ) + s(−μ) = 1` 只给出成对恒等式，不能直接推出多中心
`Σ_I p_I = 1`；显式归一化 `w_I = p_I / Σ_J p_J` 才把它变成单位分解。反例：三个等半径、
等距中心（等边三角形中心）处每个 `s(μ_IJ) = 1/2`，故未归一化的
`Σ_I p_I = 3 × (1/2)² = 3/4`，而归一化后 `Σ_I w_I = 1`。`WeightGrid::build()`
（`source/source_estate/module_constraint/weight_grid.cpp`）调用已显式归一化的
`w_becke_adjusted()`，并对每个格点校验 `Σ_I w_I(g) = 1`、做全局 MPI 归约，得到审计量
`maxdev = max_g |Σ_I w_I(g) − 1|`（实测为 0）。

**片段权重**：片段 `a` 是任意原子子集，`w_a = Σ_{I∈a} w_I`
（`WeightGrid::set_constraint_atoms`）。注意这是逐原子求和：片段**重叠**会双重计数。

### 1.2 局域磁矩可观测量

```
m_a = Σ_g w_a(g) · [ρ↑(g) − ρ↓(g)] · dV,      dV = Ω/nxyz
```

- 通道符号由 `build_channel_profile(Spin)` 固定：`read_up = +1`、`read_dn = −1`
  （`module_constraint/constraint_io.h`）。
- 积分在 FFT 密度网格上完成，跨 MPI 池归约（`constraint_observe.cpp`）。
- 自旋矩约束要求 `nspin = 2`（配置期守卫）；`nspin = 4` 不支持。

### 1.3 约束势与能量

```
v_↑(r) += μ_a · w_a(r)
v_↓(r) −= μ_a · w_a(r)                    （分离注入，与 DeltaSpin 的 σ_z 结构同构）
E' = E_KS + Σ_a μ_a · (m_a − t_a)
```

- 增量罚函数模式（ALM）下再叠加 `Σ_a (k_a/2)(m_a − t_a)²`，约束势用
  `μ_eff,a = μ_a + k_a(m_a − t_a)` 每 SCF 迭代连续更新。
- 参考相先跑 `μ = 0` 得到自然矩 `m_ref`；增量模式 `t = m_ref + δ`，绝对模式 `t` 来自目标文件。
- 能量修正进总能量（`f_en.cc_escon`），每次外层更新输出审计行
  `CONSTRAINT_AUDIT ... q= t= res= mu=`。

### 1.4 力

```
F_con,J = −∫ [ρ↑−ρ↓](r) · Σ_a μ_a · ∂w_a(r)/∂R_J dr   + Pulay 项
```

- 核实现：`module_constraint/constraint_deriv.cpp`（调用点 `constraint_loop.cpp` 的
  `compute_force`）。
- 平面波需要 `μw`-Pulay（SCC）修正，LCAO 需要非正交基 Pulay 修正；两处均已实现并经位移
  有限差分验证（不含该修正时，PW 一侧的 9 个位移轴中有 5 轴误差达 1.69–3.36 eV/Å，补上后
  9/9 通过；固定乘子平移不变性校验中残余 z 力由 +7.078 eV/Å 回到打印精度）。

### 1.5 求和一致性（严格）

设片段集合 `{a}` 构成原子集合的一个**划分**（两两不相交、并集为全部原子）：

```
Σ_a m_a = Σ_g (Σ_a w_a(g))·[ρ↑−ρ↓](g)·dV = Σ_g [ρ↑−ρ↓](g)·dV = M_tot
```

右侧 `M_tot` 在 `source/source_estate/magnetism.cpp` 中就是**同一网格上的同一离散积分**
（`tot_mag = Σ_ir (ρ↑−ρ↓)·Ω/nxyz`，同一 pool 归约），因此：

> **`Σ_a m_a = M_tot` 成立到机器精度**，不引入任何近似。

**电荷通道同理**：`Σ_a q_a = ∫ρ dV`；与输入电子数 `nelec` 的相等只到 SCF 密度归一化精度
（LiCl 15 Å 盒、APNS Li/Cl 赝势、100/400 Ry、Γ 点、`scf_thr = 1e-8` 的收敛密度上，
独立后处理积分得 `Σq − nelec = 5.3×10⁻¹⁵`）。

**实现现状（重要前提）**
- 求和等式的前提是片段**恰好覆盖全部原子且不重叠**。默认"每原子一个约束"满足；用户自定义
  片段不满足时求和规则失效。
- 代码目前只对**完全相同的 `(kind, atoms)` 重复项**发 warning
  （`constraint_io.cpp`，提示可观测量近似共线），**没有**片段覆盖/重叠守卫，也**没有**运行时
  把 `Σm` 与 `tot_mag` 对账。
- 审计行固定打印 `total_charge`（=ΣQ）与 `nelec`（电子数，`constraint_accounting.cpp`）：
  电荷场景下二者可人工对账但无断言；**自旋场景下二者量纲不同（Σm vs 电子数），全局
  `tot_mag` 既未打印也未对账**。
- `total_charge` 的语义是"各约束读数之和"，不是体系总电荷/总磁矩：单片段约束时它等于该片段
  的读数（例：LiCl 仅约束 Li 时 `total_charge = 3.0959 e`，而 `nelec = 10`）。
- 补齐上述缺口是低成本改进：审计时对 `|Σq − nelec|`、`|Σm − tot_mag|` 做断言，配置期对
  片段覆盖/重叠发 warning。

### 1.6 分区敏感性（实测）

测试设置：LiCl 离子对，Li (7.5,7.5,7.5) Å、Cl (7.5,7.5,9.52) Å，15³ Å 真空盒，Γ 点，
`ecutwfc/ecutrho = 100/400 Ry`，ONCV PBE 赝势（Li 3e、Cl 7e），`scf_thr = 1e-8`；
**同一份收敛密度**、同一套 Becke 多项式，仅改协价半径后独立重积分：

| 分区半径 (Li/Cl, Å) | q_Li (e) | max\|Σw−1\| |
|---|---:|---:|
| 1.30 / 1.00（默认） | 3.095916 | 0 |
| 1.45 / 1.00 | 3.263257 | 0 |
| 1.10 / 1.00 | 2.870657 | 0 |
| 1.00 / 1.00（等半径） | 2.757506 | 0 |
| 1.00 / 1.30（互换） | 2.497145 | 0 |

结论：**归一化与求和规则与分区无关**（`maxdev ≡ 0`），但**绝对片段读数随分区变化**
（本例展宽 0.77 e）。因此算法 A 的绝对局域值只能作为同口径下的相对量/导数使用；物理电荷转移
应由总密度给出的偶极矩读取（同一密度下 LiCl 分子偶极 6.87 D，对应点电荷口径电荷转移 0.71 e）。

## 2. 算法 B：DeltaSpin 原子轨道投影

### 2.1 投影算符与可观测量

```
P_I = Σ_{lm∈原子I} |α_lm(I)⟩⟨α_lm(I)|       （选定角动量通道，例如 d）
M_I = Tr[ P_I · ρ_diff ] = Σ_{k,ib∈occ} f_{k,ib} Σ_{lm} |⟨α_lm(I)|ψ_{k,ib}⟩|²   （旋分）
```

- `nspin=2`（共线）：只约束 `M_I^z`，自旋差密度 `ρ_diff = ρ↑ − ρ↓`。
- `nspin=4`（非共线）：`M_I = (M_x, M_y, M_z)`，由 Pauli 矩阵迹提取。
- `α_lm(I)` 是原子 `I` 的局域轨道（NAO），**只含所选 `l,m` 通道**，不含该原子其它通道、
  也不含间隙或其它原子贡献。

### 2.2 约束泛函与 λ 优化

```
E'[ρ] = E[ρ] − Σ_I λ_I · (M_I − M_I^target)
H_delta(原子 I) = λ_I^z · σ_z                 （nspin=2，对角 ±λ）
H_delta(原子 I) = λ_I · σ                     （nspin=4，含自旋翻转项）
```

λ 的求解（`module_deltaspin/lambda_loop.cpp`）：

1. 由当前波函数计算 `M_I`；
2. 残差 `Δ_I = M_I − M_I^target`；
3. 构造搜索方向（最速下降 / Polak-Ribiere CG / BFGS，`sc_lambda_strategy`）；
4. 步长 `alpha_trial` 自适应，线性插值选最优 α；
5. `λ += α·direction`，带 λ 修正的 Hamiltonian 重新求解（PW 用子空间对角化加速）；
6. 直到 `RMS(Δ) < sc_thr`（自适应阈值）、梯度衰减 `max|dM/dλ| < decay_grad` 或达到
   `nsc`（最少 `nsc_min`）。

**稳定化机制**：子空间加速、`sc_scf_thr_mode = immediate|threshold|off`、共线模式下的
`direction_only` 两阶段策略（先约束幅值、再放开方向）、梯度衰减早退。

### 2.3 两条基组路径

| 路径 | 实现 |
|---|---|
| LCAO | `DeltaSpin` 算子（`source_lcao/module_operator_lcao/dspin_lcao.h`）对密度矩阵做 `cal_moment(dmr, constrain)`；`nspin=2` 时先取 `dmr = rho_up − rho_dn` |
| PW | `OnsiteProjector` 先算 `becp = ⟨α_lm|ψ⟩`，再由 Pauli 迹组装 `M_I`（`cal_mw.cpp`） |

两条路径是**两套独立的投影实现**（PW 用 onsite projector，LCAO 用 NAO 投影），这与算法 A
的"PW/LCAO 共用同一个 `WeightGrid`"形成对照。

### 2.4 求和一致性（近似）

**数学上**：`Σ_I P_I ≠ 1`。原因三重——通道截断（只含选定 `l,m`）、NAO 非正交
（需对偶基/正交化）、子空间不完备。因此

```
Σ_I M_I ≠ M_tot            （一般情形；仅当所选通道恰好承载全部磁矩时近似成立）
```

偏差随基组、所选通道、体系而定，**不能**像算法 A 那样给出精确等式。这决定了算法 B 不适合
作为"精确总量守恒"方法（如巨正则/恒电势热力学积分）的底层坐标。

### 2.5 实现等价性陷阱（同一可观测量的两种写法）

"逐带迹公式" `M_I^trace = Σ_{k,ib} f·⟨ψ_{k,ib}|P_I|ψ_{k,ib}⟩` 与"密度矩阵路径"
`M_I^DMR = Tr(P_I·DMR)` 在完备求和下数学等价；但迹公式的实现依赖 `cal_PI_sub` 的**邻域
截断**（`onsite_radius`），而密度矩阵路径使用的是全空间密度矩阵，具有补偿。

**实测（BCC Fe，两个原子的共线计算）**：

| 原子 | 全对角化 | 密度矩阵路径 | 逐带迹公式 | \|Full−DMR\| | \|Full−Trace\| |
|---|---:|---:|---:|---:|---:|
| 0（Mz ≈ +1.85） | +1.8485 | +1.8485 | +1.8642 | 3.5×10⁻¹⁴ | 0.016 |
| 1（Mz ≈ −2.80） | −2.7951 | −2.7951 | **+1.8650** | 1.1×10⁻¹³ | **4.660** |

结论：密度矩阵路径与全对角化一致到 10⁻¹³；迹公式在邻域截断下**丧失原子分辨能力**
（原子 1 符号反转、偏差 4.66 μB）。实现上应固定使用密度矩阵路径（并保留梯度饱和时回退到
全对角化的机制）；若必须修正迹公式，需引入 Löwdin 正交化或对偶基（`S^{-1/2}`，一次性
O(N³) 代价）。

## 3. 优缺点对照

### 3.1 总表

| 维度 | 算法 A（Becke 分区） | 算法 B（DeltaSpin 投影） |
|---|---|---|
| **求和规则** | ✅ 精确（单位分解 ⇒ 机器精度） | ⚠️ 近似（投影截断，基组相关） |
| **局域值的化学/物理意义** | ❌ 人为分区，绝对值不可跨方法比 | ✅ 轨道投影矩，可与 DFT+U/实验对照 |
| **"控制什么"** | 空间区域内的净磁化 | 指定 `l,m` 通道的占据差 |
| **基组一致性** | ✅ PW 与 LCAO 同一实现、同口径 | ⚠️ 两套独立实现（onsite projector vs 密度矩阵） |
| **约束势性质** | ✅ 实空间光滑局域势 | ⚠️ 非局域轨道投影修正 |
| **解析力** | ✅ 明确（∇w + Pulay），FD 已验证 | ⚠️ 需投影导数项，本仓库未做同类 FD 验证 |
| **任意片段/多原子组合** | ✅ 任意原子子集（注意需构成划分） | ⚠️ 原生按原子；片段需自行组合投影 |
| **非共线磁矩方向约束** | ❌ 仅 nspin=2 | ✅ 原生支持（`direction_only`、Pauli 全分量） |
| **强关联 d 电子局域化** | ⚠️ 依赖空间胞形状，可能把配体/间隙算入原子 | ✅ 直接落在 `d` 通道 |
| **分支/多解稳定性** | ⚠️ 有实测翻分支；已工程化缓解（锚定/信赖域/ALM） | ⚠️ 同样存在换态风险；有两阶段/子空间加速等稳定化 |
| **口径漂移来源** | 分区半径 + 网格 | 所选通道/截断半径/基组 + 迹 vs 密度矩阵路径 |
| **求和规则的配置门槛** | 用户必须把片段配成划分（代码未强制） | 数学上无法精确（与配置无关） |

### 3.2 逐项说明

**算法 A 相对 B 的优势**

1. **精确求和规则**：对划分片段，`Σm = M_tot`、`Σq = nelec` 是恒等式而非近似——恒电势/巨正则
   系综、热力学积分要求的总量守恒天然成立。
2. **基组无关**：同一个 `WeightGrid` 同时服务观测、注入与力核，不存在两套投影实现之间的口径差。
3. **局域势 ⇒ 力便宜且可验证**：`v = ±μw` 是实空间势，解析力与位移有限差分对拍有 54–369 倍
   富余（见 §4.2）。
4. **连续可微**：`w` 是几何的光滑函数；配合信赖域外层与 ALM 单层反馈，约束动力学可做得连续
   平稳（见 §4.2 的 ALM 自旋集成：0 次磁分支拒绝）。
5. **任意片段**：电极/电解液、离子对等"区域"约束是原生操作。

**算法 A 相对 B 的劣势**

1. **局域值无物理意义**：同一密度换 Becke 半径，Li 片段电荷在 2.50–3.26 e 间变化（§1.6）；
   磁矩同理存在未定量的分区依赖。绝对值不能与实验/其它代码混比。
2. **不控制"化学上的 d 矩"**：TM 体系里 Becke 矩是空间积分，混入配体/间隙、漏掉胞外尾部。
   实测（FeO，δ = +0.1 μB）：与 DFT+U 占据迹给出的 d 矩**同向但只有 74% 幅值**；在另一个
   多解（塌陷）点上两者**反向脱钩**。因此算法 A 的 TM 自旋约束结果只能按"Becke 加权矩"口径
   报告，不得表述为"d 矩控制"。
3. **求和规则的配置前提**：片段未构成划分时静默失效（无覆盖/重叠守卫、无运行时对账）。
4. **几何依赖**：`w(r)` 随离子位置变化，增量目标随几何漂移（约束 MD 中实测 `t` 随键长在
   3.19–3.44 e 间移动）。
5. **势在空间铺开**：μ 作用于整个 Becke 胞而非特定通道，会整体极化片段（约束增强时观察到
   胞内组分份额迁移：Li 胞内 Cl 密度份额上升）。
6. **无共线→非共线扩展**：当前仅 `nspin=2`。

**算法 B 相对 A 的优势**

1. **化学可解释**：`M_I` 是原子轨道通道的占据差，与 DFT+U 局域矩、XMCD、晶体场图像直接对话。
2. **直接控制强关联通道**：约束 `d` 电子而非"原子周围一片空间"，适合 Ni/Fe/Mn 氧化物。
3. **非共线原生支持**：`direction_only`、Pauli 全分量、两阶段策略。
4. **成熟的 λ 优化器**：BFGS/CG + 子空间加速 + 自适应阈值，参数体系完整。

**算法 B 相对 A 的劣势**

1. **求和规则近似**：`Σ_I P_I ≠ 1`，总量不守恒（基组/截断相关），不宜作为精确总量方法的底层坐标。
2. **基组依赖与双实现**：LCAO/PW 两套投影，口径一致性需额外对拍；NAO 不完备性进入结果。
3. **非局域约束 ⇒ 力的复杂性**：投影算符依赖波函数/基组，力的解析导数项更重，本仓库未做与
   算法 A 同等级的 FD 闭合。
4. **实现陷阱已实测**：迹公式与密度矩阵路径在邻域截断下差 4.66 μB（§2.5），必须固定推荐路径。
5. **约束观测量不含间隙/配体**：未约束原子会吸收"总磁矩误差"，约束越紧、剩余原子的负担越重。

### 3.3 选型建议

| 需求 | 推荐 |
|---|---|
| 恒电势/巨正则、热力学积分、需要总量精确守恒 | **算法 A**（Becke；片段须配成划分） |
| 需要与实验/DFT+U 的"原子局域矩"直接对照、约束 d 电子、非共线方向 | **算法 B**（DeltaSpin） |
| TM 氧化物"控制 d 矩" | 算法 B；若用算法 A，结果只能按"Becke 加权矩"口径报告 |
| 同时要"精确热力学坐标"与"化学可读读数" | 算法 A 做约束 + 并列输出 on-site 迹差矩（DFT+U 占据迹）或 DeltaSpin 矩做对照 |
| 电荷（非磁）局域约束 | 算法 A 独有；DeltaSpin 不含电荷通道 |

## 4. 测试结果

### 4.1 头对头：同一体系、同一靶点（H₂O，O 自旋 +0.1 μB）

测试设置：H₂O 分子，LCAO 基组，8 价电子，`nspin=2`，`ecutwfc/ecutrho = 20/80 Ry`，
Γ 点（`gamma_only`），`scf_thr = 1e-7`，无对称性；对 O 原子施加 +0.1 μB 的局域矩约束。

| 方法 | 乘子数值 | 单位换算 |
|---|---|---|
| 算法 A（Becke 自旋约束） | `μ_O = −0.07193070771 Ry` | **−0.9787 eV/μB** |

## 5. 结论

1. **求和一致性**：算法 A 在"片段构成划分"前提下给出**机器精度**的局域求和 = 全局总量（自旋
   通道与 `tot_mag` 是同一网格积分，尤其干净）；算法 B 的投影算符不构成单位分解，求和规则只能
   近似。**算法 A 目前不强制划分**（无覆盖/重叠守卫、无运行时 `Σm↔tot_mag` 对账），这是最值得
   补的低成本缺口。
2. **物理含义**：算法 B 的局域矩是"化学上可读的轨道投影矩"，算法 A 的局域矩是"人为空间区域的
   净磁化"。需要"d 矩控制"或与实验/DFT+U 对照时用 B；需要精确总量/恒电势语义时用 A。
3. **工程可靠性**：算法 A 的力/力矩与求和规则已有位移有限差分与机器精度级验证，且磁分支锚定与
   ALM 单层反馈把稳定性与效率做成了工程保障（自旋 ALM 集成：90 步、0 次拒绝）；算法 B 的 λ 循环
   成熟，但存在实现路径陷阱（迹 vs 密度矩阵）与基组双实现问题。
4. **组合使用**：以 A 作为约束/热力学坐标（精确守恒、力干净），并列输出 on-site 迹差矩或 B 的
   投影矩作为物理读数，是目前最稳妥的口径组合；TM 体系不得把 A 的结果表述为"d 矩控制"。
