- 日期：2026-08-17
- 前置：Stage 4.1 锚点重建 #3（`34e985894`）；评审批准 4.2：
  "三体系驻点 FD 全矩阵 + ⟨η⟩ 关联检查（CO ⟨η⟩=1.67% 是否预测力残差偏大——
  该诊断价值的首次兑现检验）"。
- 范围：T3 协议扩展（t_Γ*=自然 Γ 冻结 → 位移腿内循环 λ 重收敛 → FD 力 vs
  解析力）在 hf/co/h2o_asym 三体系上的全矩阵验收。

## 1. 测试计划

1. 每体系：Step 0 自然跑（λ 冻结 0）提取自然 Γ → 冻结 t_Γ*；Step 1
   逐原子 x/y/z ±δ 位移腿，内循环以 `deltap_proxy_target_file=t_gamma_star.dat`
   重收敛 λ（`deltap_secant off`、`deltap_inner_nmax 20`、
   `deltap_conv_thr 1e-3`、`deltap_inner_thr 1e-3`）；Step 2 中心差
   F_FD = −(E₊−E₋)/2δ 对比自然几何解析力（TOTAL-FORCE，λ=0）。
2. 判据：|F_FD − F_ana| < 5e-4 Ry/Bohr = **0.0128555 eV/Å**（与 T3 同）。
3. ⟨η⟩ 关联检查：记录各体系 base 自然跑的 `[DeltaP L1] <eta>`，对照最大
   力残差——检验 CO ⟨η⟩=1.67% 是否预测残差偏大。

  各位移腿内循环 λ* 收敛在 ~1e-3–2e-2 Ry（例：hf atom0 z± λ*≈±2.3e-2、

  ~3e-3–7e-3 与 T3 的 0.0138（λ*≈1e-3）同族同量级（此处 |λ*| 略大但
  位移腿 dλ*/dR 更小）。⟨η⟩ 诊断在本协议（驻点 FD）层面不预测力残差
  偏大——如实记录为阴性，不据此下任何因果结论。
- **诚实标注 |Γ−t_Γ*| 收敛**：位移腿内循环最终 |Γ−t_Γ*|∞ ≈ 1.7–2.7e-3，
  略高于名义 1e-3（内循环在 inner_nmax=20 触顶平台，λ 连续三轮不变）。
  残差仍以 1.95× 裕度通过；该余量与 T3/T3' 同族的 O(λ) 泄漏项一致，不
  构成未解释项。

## 4. 分析

- **T3 协议在 4.2 全矩阵上成立**：驻点（Γ-约束面）FD 力 = 解析力的
  数学自洽在 hf/co/h2o_asym 三体系（含非对称 h2o_asym 全 9 分量）全部
  复现，最大残差 0.0066 eV/Å ≪ 0.0129 判据。这与 T3 PASS（数学自洽）
  / T3' FAIL（物理路径 γ-hold 不可用）的分层表述一致——4.2 测的是
  Γ-约束面（内部自洽），不改变物理路径结论。
- 残差结构：x/y 平移对称分量 ~1e-7–1e-5（数值噪声级），z（链轴）与
  h2o_asym 原子位移分量 ~3e-3–7e-3（O(λ) 响应族）——与 T3 力侧闭合率
  1.07 的归因结构一致，无新未解释项。
- 运行注意：h2o_asym 3 原子 9 腿全矩阵 ~1.5 h（单任务串行，每腿
  5–10 min）；hf/co ~25 min。脚本天然串行、一次一任务，符合
  "严禁并行启动测试"纪律。
