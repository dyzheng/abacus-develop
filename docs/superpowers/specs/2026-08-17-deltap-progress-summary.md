## 1. 功能定位与一句话现状

DeltaP 在 DFT SCF 中引入逐原子的 Berry 相位（γ）约束拉格朗日乘子 λ，
两种用法：**约束模式**（给定 γ 靶点，钉极化分布）与**场模式**（均匀 λ，
近似长程电场，目标场景是真正 bulk 周期体系——锯齿场无处可放的地方）。

**一句话现状**：约束模式已封口（小窗口 SCF 单点 + Γ 路径力可用，relax/MD 不可用）；
场模式能量/极化响应已验证（|λ|≤0.007 Ry 窗口），力侧因 H_HK 内禀几何通道
挂起（第一性解法 = EFC，未立项）；机器层（LCAO/PW、串行/MPI、记账/力/诊断）
已基本闭环；下一棒是 F-8 应力（协议已签核）→ Stage 4 正式验收。

## 2. 算法核心：Route A+

### 2.1 记账恒等式（一切验证的地基）

约束哈密顿量 H = H_KS + H_c，H_c = Σ_I λ_I·Ô_I（Ô 为逐原子 θ 算符）。
Route A+ 定义记账修正 **escon = −Σ_I λ_I·Γ_I**，其中
**Γ_I = ⟨Ô_I⟩ = 算符期望的全 Gram 迹**（LCAO；PW 侧 Γ^PW_I = ⟨P̂_I^onsite⟩，
becp 期望）。由 Hellmann–Feynman：

```
∂E_KS(ψ*)/∂λ = ⟨∂H/∂λ⟩ = ⟨Ô⟩ = Γ
⇒ E' ≡ E_KS(ψ*) + escon 对 λ 平直（恒等式，非近似）
```

**意义**：E' 平直性是"记账正确 + 实现正确"的零成本探针——任何 H_c 施加与
记账的不一致都会立刻表现为 E'(λ) 倾斜。全部 MPI 修复、PW 记账切换均以
该恒等式为验收锚。

### 2.2 力项分解（LCAO）

```
F = F_std + A1 + A2 + B
```

- **A1**：Ô 算符的 Pulay 项（基组/重叠导数）；
- **A2**：密度响应经 λ 约束反作用的间接项；
- **B = F_HK**：H_HK（k 空间 θ 算符部分）的显式力，含相位定理导数与
  C 矩阵响应。

T3 实测证明：**所实现的力 = Γ-约束面上 E' 的精确梯度**（数学自洽）。

### 2.3 两条路径的分野（全项目最重要的物理结论之一）

| 路径 | 含义 | 力残差 | 裁定 |
|------|------|--------|------|
| Γ-hold（λ 冻结在约束面上测力） | 数学约束面的梯度 | **0.0138 eV/Å**（T3，判据 0.0129 的 1.07×，闭合率 1.07） | ✅ 小窗口可用 |
| γ-hold（严格钉住物理 γ 靶点的 relax 路径） | 生产 relax 的真实路径 | **0.502 eV/Å**（T3'，判据 25×，闭合率 0.97） | ❌ 结构性不可用 |

γ-hold 泄漏 ∝ λ²：约束面（Γ=常数）与物理面（γ=常数）不重合，0.502 eV/Å
即两面力差。**"T3 PASS = 数学自洽 / T3' FAIL = 物理不可用"双句定稿**，
约束模式因此封口：proxy 驱动 + LIMITATION，F-4（γ-hold 自洽驱动）评审裁定不做。

### 2.4 锚定与分支纪律

γ 是多值（mod 2π）分支量，历史上两次事故确立三条铁律：
1. 任何判据/FD 必须用**连续性锚定**读数，target-aware 报告是靶点跟随的、
   不能作判据（否则出现"γ 收敛到靶点但 λ=0"的假收敛）；
2. 响应测量期间 branch shift 必须冻结；
3. 锚定三形态（连续性锚 / target-aware / 算符观测）各自口径需在文档标注。

## 3. 关键技术点详述

### 3.1 弱耦合窗口 = 物理刚度，不是 bug

- 传递链：dΓ/dλ ≈ −4.2（算符期望对 λ 敏感），dγ/dλ ≈ 0.028–0.05 rad/Ry
  （自洽），**传递效率 dγ/dΓ ≈ 0.07**——λ 的绝大部分被密度响应吸收；
- γ 物理刚度 **κ ≈ 60.4 Ry/rad²**（h2o1，D1/D2 实测）；
- 基组效应：α_LCAO = 3.02 Bohr³ vs 实验 9.8（紧缩 DZP 基低估 3.3×）——
  极化率类结论须按基组定标；
- **H 原子方向性死通道**（T-2/T-5' 实测，双侧 ±0.001 rad ≈ 噪声级）。

### 3.2 场模式（均匀 λ ≈ 长程电场）

- **E_eff 换算**：E_eff = π·λ/(2·a_α)（λ 单位 Ry，a_α 为该方向周期，Bohr；
  结果 a.u.），response 校准实测 ×1.6（proxy ΣG 口径）；
- **能量侧已验证**（F-2）：E₀(μ) 与锯齿场对拍，|λ|≤0.007 Ry 内偏差
  <1e-3 eV（λ=0.01 时 1.55 meV）；
- **力侧挂起**（F-2/F-2b）：matched-μ 下力偏差 2.6%（λ=0.001）→ 21–26%
  （λ=0.01），力/极化 Maxwell 杠杆失配 **17.7×**；F-2b 证伪 H_HR 归因
  （≤0.6%），失配**内禀于 H_HK 的 R 依赖含非极化几何通道**——
  实现的 B 项是所实现能量的正确梯度（T3 自洽）但场物理错误。
  **EFC（Ô_θ 全阶化）是力级 Maxwell 一致性的唯一第一性解法**；
  半经验 Z\* 补丁（λ·(L_μ·Z\*−L_F)）可选但须标注 empirical +
  Z\* 多几何可迁移性验证；
- **协议纪律**（F-2 教训）：efield 基线必须 amp=0；力对比用 no-dip_cor 系列
  （dip_cor 镜像自能 +3.70 meV 常数污染）。

### 3.3 MPI 修复链（三轮 + 顺带一役）

| 轮 | 对象 | 根因 | 修法 | 验收 |
|----|------|------|------|------|
| 1（f49f9fcae） | D_I/S_k | 带槽位/键索引混带 | 本地列→全局带映射 | hf 4-rank raw γ 六位一致 |
| 2 = F-6（217e8888f） | H_HK（compute_hk_correction） | ① psi 带索引按全局 nocc_use 遍历本地带（部分和/越读）；② H_sym 行列都用本地行轨道——**nrow==ncol 只是计数巧合**，rank(p,q) p≠q 时行/列轨道是两组（hf 4-rank E' 差 2.33 eV 量化后果） | pzgemm 分布式 GEMM：SC=S_dk·C_R → F=(i/2)w_eff·SC → H_sym=0.5(F·C_L†+C_L·F†)；Γ^HK 迹走 A' 族均匀计数 Allreduce | 串行 A/B 逐字节（FINAL_ETOT −481.6964709588435 eV 一致）；hf/co 4-rank ΔE' 2.7e-6/2.5e-5 eV（FP 求和顺序经 λ 累积，非可消除偏差） |
| 3 = 3.2/3.3（656a2a59d） | F_HK 力 + 非方本地块 | 同上设施延伸；**顺带修掉 F-6 隐藏的 Allgatherv complex 计数 ×2 bug**（h2o_asym Γ 22% 偏差根因——奇数轨道用例"恰好会失败"的回报） | 行组 gather 全带对 Allreduce | h2o1/h2o_asym 4-rank 与 2-rank 逐位一致、co（NBANDS=15）一致、smoke 4/4 |

硬约束纪律：任何 MPI 路径改动，串行 A/B 必须逐字节一致。

### 3.4 PW Γ 记账与 escon 测量伪影（F-7/F-7b）

- L1.1 切换：PW escon 从旧 γ 记账（E' 斜率 ~109 eV/Ry，严重污染）切到
  operator 记账 Γ^PW=⟨P̂^onsite⟩（**λ 驱动保持 γ 残差不变，只换记账**），
  改善 ~600×；
- F-7b 证伪"结构性失配"假说（残余 0.187 eV/Ry 的归因链）：
  ① **判据选错**——dE_band/dλ = +14.17 vs ΣΓ = 7.94 的 6.23 缺口 = 密度
  响应（E_band 对 λ 非变分，HF 只适用于总能量）；能量分量闭合
  +0.19 ≈ 实测 +0.179 eV/Ry，100% 归因；
  ② **escon 一次性测量伪影**——PW 同步两相模式只在首个
  drho<deltap_inner_thr 迭代测一次 Γ，默认 1e-3 时测量在 drho≈7e-4 的
  部分收敛态；inner_thr=1e-6 下线性项塌缩 100× 至 +0.00014 Ry/Ry，
  且**符号随 ecut 反转**（−0.0214@80 / +0.0131@40）——算符失配不可能
  产生的特征；
  ③ 过程发现：原"ecut=80"扫描实为 ecut=40（scan.py 嵌套 if bug，
  npwx 97373 vs 275340）；
- 终验收（真 ecut=80 + inner_thr=1e-6）：escon≡−λΣΓ 恒等 7/7，
  E'(λ) 三窗口中心差全部 ≤0.0002 Ry/Ry。**L1.1 条件解除，F-7 完全 PASS**；
- 新增 L11：escon 精度判据须 inner_thr≤1e-6（遗留 Q：测量时机能否
  移代码到收敛末迭代，待成本评估）。

### 3.5 内循环与算符轨道（否定性结论，同样重要）

- **T-7'' 冻密度内循环对 γ 结构性失效**：冻密度响应 dγ/dλ = −1.28 vs
  自洽 +0.03 rad/Ry——**符号反转**。冻密度 BFGS 驱动 γ 不可能收敛；
  内循环仅 proxy/Γ 驱动可用，生产用同步/SCF 级驱动；
- **T-18 Ô_w（精确权重算符）判决 FAIL**：dγ/dλ ≈ 0.26 vs 预言 ≥3，
  差 ~10×，且 γ(λ) 非单调——**Ô_w 不提升响应、不扩大窗口**；
- **Ô_θ/EFC 全阶化**：挂起，唯一剩余动机 = 场模式力级 Maxwell 一致性
  （F-2b 前置）；Route W（k 局域位置中心约束）= 解除 KPAR=1 的候选，
  预研级。

### 3.6 诊断输出（F-7，L1.2/L1.3）

- **⟨η⟩ 完备性**：per-k per-band raw SMO 投影泄漏，SCF 收敛时打印。
  H2O ≈ 0（<1% ✓）；CO 1.67%（单带 max 8.4%）——机制非恒零、有判别力；
  1% 为启发式阈值，CO 越线项已写入 Stage 4.2 关联检查；
- **spread_I**：per-string 加权 θ 散布（公式提取至 deltap_common）。
  H2O (0.112, 0.121, 0.121) rad、CO (0.257, 0.197) rad——string 局域性
  良好（≪π）；均匀 θ spread=0 单测 4/4。

## 4. 测试点详述（判决性实验全录）

### 4.1 T0：escon 双口径恒等
**目的**：记账恒等式 escon≡−⟨H_c⟩ 的逐点验证。**结果**：双口径 12 位一致。
**意义**：Route A+ 的地基实验，此后一切 E' 平直性判据的前提。

### 4.2 T2：E'(λ) 平直性
**设置**：λ 扫描，测报告能量 E'。**结果**：斜率 **−0.013 eV/Ry**（LCAO）。
**意义**：E'≡E_KS(ψ*) 恒等式成立；此后成为所有 MPI/记账改动的回归锚
（F-1 场模式基线逐点复现该值）。

### 4.3 T3 / T3'：力的双路径判决（本项目的分水岭实验）
**设置**：驻点几何，FD 位移对照解析力，高精度档（ecutwfc=100/ecutrho=400/
scf_thr=1e-8）。**结果**：Γ-hold **0.0138 eV/Å**（判据 0.0129 的 1.07×，
闭合率 1.07）；γ-hold **0.502 eV/Å**（25×，闭合率 0.97，λ² 泄漏）。
**意义**：确立"数学自洽 ≠ 物理可用"，约束模式封口；演示了"PASS/FAIL 双
句定稿"的判据纪律。

### 4.4 T-5'：γ 可达域窗口测绘
**设置**：h2o1，λ 内循环预算 0.1 Ry 封顶，secant 外循环。**结果**：
O 通道 Δγ∈[−0.004, +0.013] rad；**H 通道双侧死**（±0.001 rad ≈ 噪声）；
0.995/1.005 类靶点不可达；secant 外循环（proxy）对非自然 t_γ 发散。
**意义**：把"弱耦合窗口"从印象变成定量边界；小窗口=界面反场补偿类应用
正好落入的区间。

### 4.5 D1/D2：物理刚度与极化率定标
**结果**：κ ≈ 60.4 Ry/rad²（h2o1）；α_LCAO = 3.02 vs 实验 9.8 Bohr³；
E_eff = πλ/(2a) 公式 + ×1.6 response 校准。**意义**：窗口的物理归因
（体系刚度 + 基组效应），排除"实现缺陷"方向的无谓搜寻。

### 4.6 T-18：Ô_w 响应判决（否定性）
**预言**：Ô_w 精确权重应使 dγ/dλ ≥ 3。**实测**：≈0.26（差 ~10×）且
γ(λ) 非单调。**意义**：关掉"换算符扩大窗口"的技术路线，节省后续投入；
演示"预言先行、偏离即停"的评审纪律。

### 4.7 T-7' / T-7''：内循环 Jacobian
**结果**：单元层 ✅（componentwise BFGS 反号系统 1 步 vs 60 步）；
集成层 ❌（驱动观测量被锚钉死）；解锚机制 ✅ / 冻密度收敛 ❌（符号反转
−1.28）。**意义**：内循环能力边界钉死——仅 proxy/Γ 驱动可用。

### 4.8 F-1 / F-2 / F-2b：场模式三步判决
- **F-1**：均匀 λ 冒烟，E'(λ) 平直性复跑 PASS（−0.013 eV/Ry，T2 逐点复现）；
- **F-2**：锯齿场对拍。能量侧 PASS（|λ|≤0.007 内 <1e-3 eV）/ 力侧 FAIL
  （21%，杠杆 15.6×）；残差 100% 闭合（纯测量，无未解释项）；
  dip_cor 协议教训（基线 amp=0）；
- **F-2b**：HK-only 对拍证伪 H_HR 归因（≤0.6%），失配重定位到 H_HK 力
  通道（17.7×），双命题并存（实现的力自洽 ∧ 场物理错误），EFC 重定位
  为唯一第一性解法。

### 4.9 MPI 验收矩阵
- **deltap_mpi_smoke 4/4**：PW 2-rank / BN 4-rank / CO NBANDS=15（奇数带）/
  BN inner-loop——每轮回归必跑；
- **fd_force 套件**（h2o1/hf/co/h2o_asym + run_fd.sh 双组协议）：
  h2o_asym（奇数轨道、非对称）是"恰好会失败"的设计——它先后抓住
  nrow!=ncol 守卫触发与 Allgatherv ×2 bug（Γ 22% 偏差）；
- **串行 A/B 逐字节**：FINAL_ETOT −481.6964709588435 eV、DeltaP 行/GE
  能量列 md5/TOTAL-FORCE 全一致——MPI 改动的硬约束。

### 4.10 F-7 / F-7b：PW 记账与伪影归因
见 §3.4。要点：ecut=20 验收被评审打回（判据 LCAO 100 / PW ≥80）→
复测升级为判决链（判据选错 + 测量伪影 + scan.py bug 三重发现）→
终验收 ≤0.0002 Ry/Ry。**演示了"验收精度档不足时复测优先于继续开发"的
评审裁定流程。**

### 4.11 锚点套件（三次重建）
operator 路径可观测锚点（γ/Γ/E' 基线快照），每次记账/约定变更后重建：
#2 于 178f09710（ecutwfc=100，12 用例）；**#3 计划在 F-8 后进行**
（PW Γ 记账已改变 PW 侧数值，先重建会白做），届时纳入 PW Γ 用例。

### 4.12 FD 协议纪律（全部测试共用）
- 高精度档：LCAO ecutwfc=100 + 显式 ecutrho≥400 + scf_thr=1e-8；
  PW ecutwfc≥80；低精度档仅可用于隔离对照且必须标注；
- 历史数据重标定：2026-08-03 前 λ 值受 B-6 影响（×1/L）；
  2026-08-04 前逐原子 γ 受 S_k 键修复影响（重分配）；
- 判据先定、测量后做；PASS 须注明独立参照物；偏离预言即停。
