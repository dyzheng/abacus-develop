## 一、总体结论（先行）

**方向正确，值得尝试——但必须按"分期 + 判决性实验先行"的方式做，且需修正方案中三处与历史实测冲突的表述。**

方案的核心结构选择（实空间权重 × 密度通道、约束势注入 veff、观测量与注入算符同一、冻结权重、熔断机制）恰好逐一命中 DeltaP 项目用数月踩坑换来的正确设计原则；其推荐终态（Hirshfeld/Becke 网格权重）在本仓库历史中是**未探索的空白区**——无既有否定结论。同时，方案的 toy model 验证只覆盖了最浅的两条验收标准（C1/C2），真正翻车的历史高发区（力、SCF 耦合、口径一致性、假收敛）全部尚未触及。

## 二、与仓库记录吻合的点（可行性支撑）

### S1. 病灶诊断与仓库独立记录一致
方案称 SMO 简单投影"不是单位分解、交叠密度被重复分账"。本仓库 2026-07-11 SMO 投影评估独立确认：H₂O 实测投影权重 raw_sum=5.91、tilde_sum=18.35（应为 O(1)），Σ_I w_In ≠ 1，且数值 S^{-1} 误差达 24%（S·Sinv 最大误差 0.237）。方案的"交叠密度无分账规则"表述是对同一病灶的更精确刻画。DeltaP 侧另有 ⟨η⟩=max(0,1−Σ_I w_In) 完备性指标的长期量化（H₂O 0%、CO 1.67%）。

### S2. "观测量 = 注入算符"是本项目最惨痛教训指向的正确结构
DeltaP 旧方案（escon=−λ·γ，γ 为非算符 Wilson 相位）因记账观测量 ≠ 哈密顿量算符期望，驻点 FD 力残差 **84.8–419 eV/Å**（判据 0.0129，超 6600–32000 倍）；Route A+ 把驱动/记账统一到算符期望 Γ 后降至 **0.0138 eV/Å**（6100× 改善，T3 PASS，三体系 21/21 腿）。方案的 V_con=Σ_α μ_α w_α(r) 注入 veff、读数 Q_α=∫w_α d_α 用同一 w——**天然满足 dspin 恒等式三条件**（观测量=H_c 算符期望、记账恒等相消、驻点），这是方案最强的结构性优势，且其反面已被历史定量验证。

### S3. 冻结权重避开了"活算符极限环"实录
ow 模式实测：注入算符随当前 ψ 重建 → 双自洽解间周期 2 往返、150 iter 极限环；冻结算符核后全窗 7 点 λ 扫描 26–41 iter 全部收敛（T-17）。方案的 Becke（纯几何）与固定 promolecule Hirshfeld 均为冻结权重，μ 只在外环更新——结构上正确。方案 §3.2.2 明确排除 Hirshfeld-I（权重依赖密度 → 非线性），这一排除与 T-17 教训完全吻合，**实施时必须坚持，不得中途引入密度依赖权重**。

### S4. PW/LCAO 口径统一动机真实存在
记录在案的分裂：LCAO 走 SMO/Löwdin 投影（pre_hr），PW 走赝势 beta 投影（OnsiteProjector/becp）；λ 环行为不同（PW 无内循环）；无 target 语义分裂（LCAO 自由跑 vs PW 约束 γ→0）。网格权重读数确实从根上消除此分裂。

### S5. 熔断与工程护栏有先例
方案 μ_max 熔断与历史机制同族且已被证明必要：λ 预算封顶 0.1 Ry/外环步、secant κ clamp [0.3,20]、单步限幅、连续 2 步发散 κ 减半 + WARNING。

### S6. 代码骨架可承载
源码核实：`spin_constrain` 外环（BFGS/PR-CG lambda_loop）、`DeltapScfSolver::Backend` 回调注入抽象（set_lambda/compute_gamma 等 10 回调）、escon 记账路径、stationary4 驻点 FD 验收协议（δ=0.005 Bohr、判据 0.0129 eV/Å）均现成可复用；PW 侧力核有双用先例（cal_force_onsite_dspin 同时服务 dspin/deltap）。

## 三、风险点充分披露（按严重度排序）

### R1【事实核查】两个关键激励数字在仓库内查无出处
方案引用的"μ→−1244 Ry"与"H₂O ΣN_I≈11.48 vs 8"在本仓库全部文档与源码中无匹配（全库 grep 无 1244/11.48）；仓库中亦**不存在 DeltaQ 实现**（仅有 DeltaSpin 与 DeltaP），方案所称"原文档"不在本仓库。诊断方向不受影响（S1 已独立确认病灶），但评审时应要求方案作者给出这两个数字的可复现算例，否则方案 §3.4 的 μ_max=5 Ry 熔断阈值与 §6.2 的"μ 量级诊断表"（0.01–0.1 Ry 正常区）缺乏本仓库内的定标依据。

### R2【SCF/外环】secant 对非自然靶点发散有明确实录，方案护栏不足
历史：外层 secant 驱动非自然靶点时 κ 翻号振荡（+12.3→−20→+10）、T-5' λ 顶到预算上限后 SCF 不收敛、T-4a' 外循环失控 λ 跑到 (−0.865,+1.34,+1.34) Ry 并破坏 SCF；同步梯度下降永不收敛（γ 反弹 ±3–5 rad）。方案 §3.4 的 secant 仅有 |Δμ|≤0.05 Ry 步长截断，**缺少 κ（斜率估计）限幅与翻号检测**——这是对照历史教训的具体缺口，必须补。另建议熔断判据采用"μ 顶限 + 残差平台"联合信号（历史操作性格式），而非仅看 |μ|。

### R3【多约束】全 Broyden 收益存疑，且存在"死通道"风险
实测 H₂O 约束 Hessian = [[18380,−25],[−25,−1720]] μRy/rad²，非对角元仅为对角元 ~0.1%，本征矢纯度 99.9%——方案"J 主对角占优"假设与实测一致，但也意味着**全 Broyden 相对逐分量（对角）secant 无实质收益**，反而在噪声下增加 Jacobian 估计病态风险（冻密度对角 Jacobian 已实测出现 2-循环极限环）。更重要：H 通道实测刚度在噪声地板以下、Γ_H(λ_H) 呈 U 形非单调（"死通道"，双侧不可达）——电荷约束场景同样可能出现软/硬通道混合（如对 H 这类小权重区电荷响应弱）。**建议一期只用逐分量 secant，Broyden 降级为二期选项。**

### R4【物理上限】换权重移除的是"假饱和"，物理可达域仍由体系刚度封顶
DeltaP 最核心翻案：Ô_w 精确算符**不提升**约束耦合（T-18 否决"换算符可扩大窗口"叙事）；窗口由体系物理刚度 κ 决定（h2o1 κ≈60 Ry/rad²，BN κ≈0 差 6 个量级），且**不可跨体系外推**。方案的 C2"无饱和"仅对算符层面成立；Hirshfeld 电荷的物理可达域（受 Hartree 屏蔽限制）未经测量，方案第六部分"μ 0.01–0.1 Ry 正常区"的量级表必须逐体系标定，不能作为普适判据写入用户文档。

### R5【偶极对偶】V4 是历史上最高危的验证类型
方案主张"偶极约束与外电场互为 Lagrange 对偶，两法 ρ(r)、E 曲线一致"（V4）。仓库实测：约束模式内场刚度 vs efield 物理响应差 **~250×**（自洽屏蔽 10–30× × SMO 覆盖间隙 × on-site 不敏感）；efield 对拍有协议陷阱（dip_cor 镜像自能 +3.70 meV 常数、基线必须 amp=0）；"10 Bohr 盒子淬火是所有极化率结果的共同下限"（efield+FD 也偏低 68%）。数学对偶成立，但**数值交叉验证的通过标准必须细化**（窗口、精度、协议），否则 V4 要么假 PASS 要么假 FAIL。历史另有一次 raw/branched 口径混用导致 28% 极化率偏差的事故（T-12）。

### R6【力与应力】力的显式项推导可信，但应力"无贡献"说法过于乐观
- 力：方案第五部分包络定理推导与 dspin 恒等式三条件同构，可信度较高；其正确性前提（外环收敛、驻点）有现成 stationary4 FD 协议可验收（21/21 腿先例）。历史已知近似隙：冻结-C 类残余 ~7%（T3 闭合率 1.07）——方案力精度预期应按"残差 ∝ μ²"而非机器精度管理。
- 应力：方案 §5.4"权重随原子刚性移动 → 应力无显式贡献"**存疑**——应变下 w(r) 作为实空间函数随形变（r−R_I 被应变变换），且 virial 构造 S1=(1/Ω)Σ F·R 意味着有力项就有对应应力通道；历史 F-8 显示应力侧有独立坑（符号陷阱、pair 双向 ÷2、Maxwell 闭合 6.8–7.0%）。方案验证矩阵 V1–V7 **完全没有应力验收**，一期若声明支持周期体系应力则必须补应力 FD 测试，否则应明确标注"应力未验收"。

### R7【数值】egg-box 与网格精度的历史处方未纳入方案
方案 §3.7 称"复用现有密度网格即可，无需加细"——对能量读数成立，对力的 FD 验收**不成立**：历史实测 ecutwfc=50 时 egg-box 噪声已达力判据一半（~0.006 eV/Å），验收处方为 ecutwfc=100 + 显式 ecutrho≥400 + scf_thr=1e-8。权重、读数、力三者都在网格上，此风险比 DeltaP 双倍相关。方案 V5（力 <1e-4 Ha/Bohr）若不写网格前提必然假 FAIL。

### R8【工程量】veff 注入是全新接线而非"改造"
源码核实：现有 dspin/deltap 约束全部走哈密顿矩阵（LCAO HR）或非局域投影算符（PW），**没有任何 veff 通道先例**。方案 §3.6 的两条路径（PW veff 网格、LCAO 网格积分矩阵元）中，PW 侧相对直接（efield 模块有先例），LCAO 侧网格积分组装 H 矩阵元是新通道（XC 路径可借但约束势的并行/力一致性需重新过）。方案附录 B"迁移清单"的工程量应按"新建通道"而非"改造"估算。

### R9【验收纪律】toy model 只覆盖 C1/C2，历史翻车全部发生在 C3–C6 层
历史假通过高发模式：gdir=3 默认配置恰好自洽掩盖方向错配 bug；λ=0"收敛到靶点"的分支锚定假收敛（T4a）；串行/方阵网格/单 string 恰好隐身多个 MPI bug；记账恒等式在同一错误下自洽闭合（T2 测不出）。方案 toy model 验证了 sum rule 与饱和（C1/C2），这必要但远远不够。验收矩阵必须增加三条历史纪律：(a) **反假收敛检验**——μ=0 自由跑不得收敛到任何非自然靶点；(b) MPI 多 rank 一致性（含非方进程网格）；(c) 非默认配置（多约束混合、片段+原子混合、自旋+电荷同开）。

### R10【次要】方案对备选路线的评估偏低/偏高各一处
- 路线 A（全基 Löwdin）被评为"最小改动解"，但仓库实测现有 SMO 代码的数值 S^{-1} 误差达 24%（条件数仅 21 的矩阵），路线 A 在现有代码里还有未诊断的数值精度坑，"改造量小"的判断偏乐观；
- 罚函数模式（§3.3）在 DeltaP 历史上**从未实现/测试**（仅口头 Plan B），方案"SCF 鲁棒"的表述无数据支撑，应标注为待验证假设而非优势。

### R11【范围】第七部分输出规范是 scope 蔓延
权重投影 DOS、逐带分解、硬度矩阵输出、JSON/YAML 契约均为新开发，与"最小修复"目标冲突。建议一期只保留：残差、sum rule 审计行、收敛元数据三项；其余全部二期。

### R12【用户面】输入语义变更是事故高发区
DeltaSpin 历史：direction_only 使 λ 数学归零、"off" 模式 M_z≠target 等语义陷阱。方案将 tc 从"SZV 投影电荷"改为"Hirshfeld/Becke 电荷"（绝对值量级从 ~e 降到 ~0.2 e），除文档化外建议加**守卫**：absolute 模式打印显式 WARNING（口径已变、推荐 delta 模式），避免老输入文件静默产生错误物理。

## 四、是否值得尝试的建议

**结论：值得尝试，建议立项，按三期推进。**

理由：(1) 病灶诊断与本仓库独立记录一致（S1）；(2) 方案的核心结构正是 DeltaP 用重大代价验证过的正确结构（S2/S3），其相对现状的优势有历史定量背书；(3) 目标技术（实空间权重）在本仓库历史中是空白区，无既有否定结论；(4) 骨架可复用（S6），一期工程量可控。

**一期（判决性实验，先做最便宜的）**：仅 PW 路径 + Becke 权重 + 单/双电荷约束 + 逐分量 secant（补 κ 限幅与翻号检测）+ μ_max/残差平台联合熔断。验收只做 V1（sum rule）+ V2（Hirshfeld 基准 vs 文献）+ V3（小 q 扫描可达性）+ 反假收敛检验。**若 V3 显示物理可达域依然过窄（R4），及时止损——这是本方案最大的物理不确定性。**

**二期**：LCAO veff 网格积分通道（按新建通道估算工程量）+ PW≡LCAO 逐位一致性 + 力 FD（stationary4 协议，网格按 R7 处方）+ DeltaSpin 通道复用。

**三期**：偶极约束（V4 按 R5 细化协议）、应力（R6 补验收）、Hirshfeld 权重、多约束 Broyden（R3）、第七部分输出规范（R11）。

**明确不做**：Hirshfeld-I/ISA 作约束（S3，活算符极限环）；斜投影/Mulliken 作约束（方案已排除，与仓库记录一致）；γ-hold 式"任意大靶点"承诺（R4）。
