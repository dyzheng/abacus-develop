# 2026-10-30 混合层正则化的数学原理与可行性判断

## 1. 固定点迭代与混合的线性代数

SCF 求固定点 `ρ* = F(ρ*)`，残差 `r(ρ) = F(ρ) − ρ`。普通混合：

```
ρ_{n+1} = ρ_n + β (F(ρ_n) − ρ_n) = ρ_n − β r(ρ_n)
```

线性化 `δρ_{n+1} = M δρ_n`，其中
`M = (1−β)I + βF' = I − β J`，`J = I − F'`。
对 `J` 的一个特征方向（特征值 `j = 1 − g`，`g` 为 `F'` 的特征值）：

```
μ = 1 − β j = 1 − β (1 − g) = 1 − β + β g
```

收敛要求 `|μ| < 1`。分四种情形：

| `g` | 含义 | `μ` | 行为 |
|---|---|---|---|
| `g > 1` | 响应放大（电荷 sloshing） | `1 + β(g−1) > 1` | 发散，除非 Kerker 预条件压低 `g` |
| `g ≈ 1` | **近零模**（`F−I` 近奇异） | `≈ 1` | 临界稳定，**不过收敛** |
| `g < 0` | 反相关 | 可 `< −1` | **2-周期振荡** |
| `0 < g < 1` | 正常收缩 | `∈(1−β, 1)` | 收敛 |

我们 3.8 的观测正对应：β=0.4 时 2-周期（`g<0` 或 Broyden 病态）；β=0.1 时
能量收敛而 Δρ 卡住（`g≈1`，近零模）。

## 2. Broyden 为什么在近零模上失效

Newton/Broyden 解 `J δρ = −r`：

```
δρ_j = − r_j / (g_j − 1)
```

- 若 `g_j → 1`，分母 → 0。若 `r_j` 也 → 0（自洽），则 **0/0 不定**；
- 若存在一个**偏移** `r_j → ε ≠ 0`（例如 λ 在步间的小抖动、占据数的非光滑
  跳变），则 `δρ_j = −ε/(g_j − 1) → ∞` —— **这就是放大/2-周期的来源**。

Broyden 用割线对构造 `B ≈ J^{-1}`。近零模使 `y_k = r_{k+1} − r_k` 在该方向
≈0，而 `s_k ≠ 0`，逆 Broyden 公式分母 `sᵀ B y` 病态 → `B` 爆炸 → 迭代崩。

## 3. Tikhonov 正则化做了什么（以及没做什么）

把 `J δρ = −r` 换成

```
δź = (Jᵀ J + λ_reg I)^{-1} Jᵀ (−r)
```

沿特征方向：

```
δρ_j = − (g_j − 1) r_j / [ (g_j − 1)² + λ_reg ]
```

### 情形 A：自洽（无偏移），`r_j = (g_j − 1) δρ*_j`

```
δρ_j = − (g_j − 1)² δρ*_j / [ (g_j − 1)² + λ_reg ]
```

`g_j → 1` 时 `δρ_j → 0`：正则化把该方向的**修正压掉**，于是**不修正也不爆炸**。
但 `δρ*_j` 这个误差**原封不动地留着** → **停滞**。正则化**不会**把近零模收敛掉。

### 情形 B：有偏移，`r_j = ε`

```
δρ_j = − (g_j − 1) ε / [ (g_j − 1)² + λ_reg ]
```

修正被**上界** `ε/(2√λ_reg)` 卡住（不再爆炸），一步后的残余：

```
r_j' = ε · λ_reg / [ (g_j − 1)² + λ_reg ]
```

- 当 `g_j = 1`（严格零模）：**`r_j' = ε`，完全不变**；
- 当 `g_j ≈ 1`：残余被压到 `≈ ε λ_reg`（有限，但**不为零**）。

**结论（数学上确定）**：正则化只能**消除放大/2-周期（把发散变成有界停滞）**；
对真正 `g≈1` 的零模，它**不能把残余降到 0**，最多把残余从"发散"变成"平台"。

## 4. 预条件（Kerker/模型介电）与正则化的区别

预条件是**改变 `g`**：`g'_j = P_j g_j`（`P` 为预条件子）。只有当近零模是
**混合度量/表示造成**的（例如密度范数 vs 介电加权范数）时，选 `P` 才能把
`g'_j` 推离 1，从而真正收敛该模。若它是**物理/表示上的真零方向**
（`F` 对该分量确实不敏感，如占据/规范冗余），**任何 `P` 都无效**。

Kerker 针对的是 `g>1` 的长波 Coulomb 模（本体系电荷 Kerker 已开仍振荡），
与本处的 `g≈1` 零模不是同一类问题。

## 5. 对本 3.8 用例的判断

观测：β=0.1 时 `|ΔE| ~ 1e-9 eV`（能量已收敛）而 `Δρ ≡ 2.2e-6`（恒平台）；
β=0.02 时 `Δρ` 以 ~0.98/步**缓慢**衰减；β≥0.05 变 2-周期。

这与 §3 的情形 B 完全吻合：存在近零模 `g≈1` + 一个小偏移 `ε`；
**正则化会把 2-周期压成有界平台（残余 ≈ ε λ_reg），但预期仍 > 1e-8**，
因为 `ε` 本身（~1e-5~2e-6 量级）没有被消除。

**因此**：
- 若目标是"让 3.8 的 `Δρ<1e-8` 判收敛"：**单靠混合正则化，成功率低**
  （数学上只能到 `ε λ_reg` 量级），**不值得作为首要方案**。
- 若目标是"通用提升 SCF 对 2-周期/病态模态的鲁棒性"：**值得**，但要与
  **物理判据**（`|ΔE|`+`‖Mi−target‖`）或**消除偏移源**配套，单做不够。

## 6. 更高价值的替代：消除 `ε` 或改判据

1. **查 ε 的来源**：λ 是否在步间有 ~1e-5 抖动（内层 `sc_thr` 之下的残余）？
   占据数在 4 个 k 点上是否跳变？若 ε 来自 λ，应让 λ 在收敛后**冻结**
   （`sc_scf_thr_mode` 门控 / λ 单调锁）而不是每步重解。
2. **物理判据**：用 `|ΔE| < ε_E` 且 `‖Mi − target‖ < ε_M` 代替 `‖Δρ‖`。
   β=0.1 时这两条都满足，而 `Δρ=2.2e-6` 只是零模；这才是与"物理是否收敛"
   对齐的判据。实现小、可测、与网格无关。
3. 若近零模是**真实物理软模**（电荷/自旋歧化），只能给泛函**加曲率**
   （约束/罚项）来消除，正则化与判据都只是绕开它。

## 7. 最终判断（是否值得尝试）

| 目标 | 正则化混合是否值得 | 说明 |
|---|---|---|
| 消除 β=0.4 的 2-周期/放大 | **值得**（对症） | 把发散变有界 |
| 让 3.8 的 Δρ 降到 1e-8 | **不值得单独做** | 数学上只能到 `ε λ_reg`，非 0 |
| 通用鲁棒性 | 值得作为**补充** | 需与判据/ε 消除配套 |

**建议顺序**：
1. 先做**低成本诊断**：判定 3.8 的近零模是"真零模"还是"λ/占据驱动的偏移"。
2. 优先实现**物理判据**（小改动、直接命中"能量已收敛而 Δρ 卡住"）。
3. 若在物理判据下仍出现 2-周期，再实现**正则化混合**作为稳定性补充。
4. **不要**再把"加密 k 网格 / 放宽 `scf_thr`"当作修复手段。
