# 2026-10-30 KL 目标退化：D 不能用于选解；Newton 退化回退 Picard

## 0. 关键发现（更正）

KL 目标
```
D = Σ_A ∫ ρ_A^pro ln(ρ_A^pro / ρ_A) dr,   ρ_A = w_A ρ,  w_A = pro_A / Σ pro
```
在 **`ζ_A → 0`（pro 均匀，位置无关）** 时：`pro_A = N_A ζ³/8π` 为**常数**，若 `N_A` 相等则
`w_A = 1/nat`，于是 `ρ_A = ρ/nat`，`D = Σ (ρ/nat) ln( (ρ/nat)/(ρ/nat) ) = 0`
⇒ **全局最小值**。这是一个**平凡、非物理**的"均匀分割"。

**结论**：**"按最低 D 选解"是退化的**，会选中 `ζ→0` 的平凡解。此前"通过最低 D 得到唯一解"
的说法**撤回**。这与"MBIS 是**带布居约束的不动点**、不是自由 D 最小化"**一致**。

## 1. 修复

- `compute_mbis_newton_fp`：**拒绝退化解**（任一 `ζ<0.05`、`N≤0`、或 `D≤0`），
  退化时**回退到 Picard 不动点**（物理起点 `ζ~1`）——Picard 在此**收缩（ρ<1）**、
  **对称**、稳定。
- Newton 迭代 `trial` 增加 `ζ≥5e-2` 的下界；`picard_F`/`compute_mbis` 的 `ζ` 更新加
  `ζ≥1e-2` 下界（排除 `ζ→0` 的平凡根）。

## 3. 正确的求解语义

- **规范求解器 = 物理起点（ζ~1）的 Picard 不动点**（稳定，ρ<1）。
- **D 仅作诊断**，**不用于选解**（退化）。
- "唯一性"来自**不动点的稳定性/物理起点**，**不是** D 的最小化。
