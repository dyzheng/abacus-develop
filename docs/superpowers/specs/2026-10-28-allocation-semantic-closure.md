# 2026-10-28 Allocation 语义闭环：三个磁矩/电荷观测量与 `target_l` 依赖

## 1. 测试计划

解决批判性对比评估 §8.3 第 4 条（语义闭环）：
固定同一电子态/同一目标，弄清 allocation 坐标 `q = Tr[ρ A_i]` 与

1. **原始壳层投影矩** `M_i^raw = Σ_{a∈i} Σ_{k,n} f |⟨α_a|ψ_n⟩|² σ`（非正交 onsite
   projector；DeltaSpin 的 `cal_moment` 同口径）；
2. **Becke 空间矩** `m_i^Becke = ∫ w_i(r) ν(r) dr`；
3. **allocation 坐标** `q_i = Tr(ρ A_i σ)`，`A_i = Q_i^orth + Q_c W_i Q_c`

三者之间的关系，以及 `constraint_alloc_target_l` 对三者的影响。分别在
Fe2（spin，目标 ±3.8 μB）与 LiCl（charge，delta=0 空操作）上测量。

## 3. 结果

### 3.1 Fe2：同靶 ±3.8 μB 的三个观测量

`ALLOC-PW` 报告与 `CONSTRAINT_AUDIT` 直接给出（atom 0 / atom 1，μB）：

| 方法 / target_l | 电子迭代 | 最终状态 | ETOT / eV | 约束坐标 `q` | 原始投影 `m_T` | Becke `m` |
|---|---:|---|---:|---:|---:|---:|
| **DeltaSpin** | **13** | CONVERGED | **-6369.985258** | ±3.800（其约束量即原始投影） | ±3.800 | 未输出 |
| allocation l=2 (d) | 82 | CONVERGED | -6370.610151 | **-3.800 / +3.800** | **-3.599 / +3.600** | **-2.819 / +2.819** |
| allocation l=0 (s) | 200 | RUNNING（res 0.62 / 1.12） | -6370.031823 | -3.180 / +2.681 | +0.017 / -0.021 | -2.751 / +3.196 |
| allocation l=1 (p) | 200 | RUNNING（res 0.90 / 0.89） | -6370.235007 | -2.903 / +2.911 | -0.063 / +0.074 | -2.944 / +2.978 |
| allocation l=3 (f) | 200 | RUNNING（res 1.16 / 1.13） | -6370.155128 | -2.641 / +2.667 | +0.102 / -0.102 | -2.950 / +2.957 |

- l=2 收敛态：`q = ±3.800`（命中目标）、`m_T = ±3.599`、`m_Becke = ∓2.819`。
  **三者互不相等**；`q − m_T ≈ ∓0.20`，`q − m_Becke ≈ ±0.98`。
- 求和审计（l=2）：`dsum_n = 6.5e-11`、`dsum_m = 4.8e-15`；`Σm_Becke = tot_mag`。
- **只有承载磁矩的通道（d）能到达目标**：s/p/f 目标集的原始投影 ≈0，
  约束残差 0.6–1.2 μB，200 步内不收敛（信赖半径塌缩、预算耗尽）。
- **DeltaSpin 与 allocation 同靶但不同态**：ETOT 差 **0.625 eV**
  （-6369.985 vs -6370.610）；13 vs 82 步。

- Becke 电荷与 target_l 无关（同一密度）：`n_Li = 3.0959`。
- 原始投影随通道剧烈变化：Li 的 s 通道 2.00、p 0.74、d **0.00**

### 3.3 报告字段的口径缺陷（必须修正）

`ALLOC-PW` 的 `n_c/m_c` 在代码中定义为

```
m_c(iat) = m_tot(iat) − m_T(iat)        // alloc_pw_report.cpp:95
```

其中 `m_tot` 是 **Becke 空间矩**、`m_T` 是**原始投影矩**。因此：

- `m_c` 是"Becke − 原始投影"的差，**不是**设计定义的
  `Tr(ρ Q_c W_i Q_c σ)`（算子互补通道）；
- 打印的 `m` 恒等于 `m_tot`（Becke），**不是**约束坐标 `q`；
- 结果：报告的 `m`（-2.819）与审计的 `q`（-3.800）看起来矛盾，
  实际是两个不同观测量被同一个标签 `m` 表达。

这是语义闭环暴露出的**首要代码缺陷**：当时没有输出算子一致的三分解
`(q_T, q_c, q)`。本轮已修复（见 §3.4），并在 `ALLOC-PW` 头行标注了字段口径。

### 3.4 算子一致的三分解（本轮新增 `ALLOC-SPLIT`）

代码内部原本已分别累加 `q_T = Tr(ρ Q_i^orth)` 与
`q_c = Tr(ρ Q_c W_i Q_c)`，但只输出二者的和。本轮把它们作为可选输出暴露，
并在每个被接受的（收敛）SCF 状态打印。Fe2 l=2：

```text
ALLOC-SPLIT c[0] n_T=5.9313 n_c=10.2456 n=16.1769 m_T=-3.59852 m_c=-0.201498 m=-3.80001
ALLOC-SPLIT c[1] n_T=5.9312 n_c=10.2683 n=16.1995 m_T=3.59994 m_c=0.199958 m=3.7999
ALLOC-SPLIT audit sum_n=32.3764 nelec=32 dsum_n=0.376351 sum_m=-0.000111458
```

- **自旋恒等式成立**：`m = m_T + m_c = -3.59852 + (-0.201498) = -3.80001`，
  与 `CONSTRAINT_AUDIT` 的 `q = -3.800013938` 一致；两原子 `sum_m` = `tot_mag`。
- **正交化不改变壳层迹**：`ALLOC-SPLIT` 的 `m_T = -3.5985` 与报告里
  **原始**投影 `m_T = -3.5985` 相同（目标子空间投影算符的迹在正交化下不变）。
  因此 `q` 与原始壳层矩的差 **全部来自互补通道**（0.201 μB），
  而不是"正交化改变了 d 矩"。
- 对比：报告 `ALLOC-PW` 的 `m_c = +0.7797` 是"Becke − 原始投影"的差，
  与算子的真实互补 `m_c = -0.2015` 完全不同——§3.3 的口径缺陷由此定量证实。

**由此得到 allocation 坐标的精确语义**：

```
q_i = M_i^shell（与 DeltaSpin 同口径的原始壳层投影）
    + Tr(ρ Q_c W_i Q_c)（非壳层磁化的空间分配）
```

### 3.5 未闭合的正确性问题：电荷通道的互补归一化

`ALLOC-SPLIT audit` 在 Fe2（两个片段构成完整划分）上给出：

```text
sum_n = 32.3764   nelec = 32   dsum_n = +0.376351 e
sum_m = -1.11e-4  （等于 tot_mag，精确）
```

- **自旋差（↑−↓）精确、电荷和（↑+↓）偏差**：互补积分
  `∫w|Q_cψ|²` 的总量被高估约 1.9%（0.376 / 20.51），且该误差在当前数据中
  表现为**自旋对称**（在 m 中抵消，在 n 中暴露）。
- 含义：**电荷 allocation 观测量（以及以它为约束的 charge 模式）目前存在
  ~1.9% 的互补归一化误差，不可用于生产**。自旋约束因差分抵消在数值上自洽，
  但 `m_c` 幅值同样被高估，对 `q` 目标的系统偏移约 0.004 μB。
- 候选原因（待专项定位）：互补实空间积分的 `1/nxyz` 归一化与目标重叠内积
  （`⟨φ|ψ⟩`）的归一化约定不一致；或未归属目标行（`owner < 0`）参与/未参与
  互补的处理不完整。与 `kpar` 无关（kpar=1 与 kpar=2 的 `dsum_n` 相同）。
- 处置：`ALLOC-SPLIT audit` 的 `dsum_n` 已作为回归守卫打印；修复前 charge
  allocation 只保留为诊断，不得进入约束生产路径。

## 4. 分析

1. **三个观测量回答三个不同问题**：
   - `m_T`（原始 onsite 投影）：指定角动量壳层的占据差，DeltaSpin/XMCD 口径；
   - `m_Becke`（空间分区）：原子附近区域的净自旋；中子 site moment 的同类量；
   - `q`（allocation）：**原始壳层投影 + 空间互补**的混合坐标
     （`q = m_T + Tr(ρ Q_c W Q_c)`；正交化不改变子空间迹，§3.4）；
     求和精确、正性成立，但**没有直接的实验对应物**。
2. **allocation 可行域由目标集决定**：只有承载目标量的通道能到达目标
   （Fe 自旋必须 l=2）；这不是数值问题，而是坐标定义问题。`target_l` 必须
   按物理选择并随结果报告（对应设计风险 R13）。
3. **电荷场景的性质**：互补分量承担主量，目标集只做修正，所以 Li（无 d）
   的 q 仍接近 Becke（差 ≤0.15 e）。这正好回应用户此前的担心：
   d 投影不能代表电荷，但"投影+互补"可以——代价是 q 不再是纯轨道量。
4. **同靶不同态**：DeltaSpin 约束原始投影，allocation 约束 q；两者在同一
   数值目标下收敛到不同电子态，ETOT 差 0.625 eV。**不能把该能量差当作
   误差**，也不应把 q=3.8 当作"3.8 μB 的 d 矩"。
5. **语义闭环结论（自旋通过、电荷待修）**：allocation 坐标是**定义清晰、
   可复现、求和精确的建模坐标**，且其分解已在自旋通道上逐位验证
   （`q = m_T + m_c`）。但它不是"原子磁矩"的通用替代物；电荷通道另有
   §3.5 的 ~1.9% 互补归一化问题，修复前不可作为 charge 约束坐标。只有在
   "目标壳层 + 空间互补"正是研究意图（如配体空穴、电荷转移、多片段分配），
   且三量并报时，它才是合理的；作为"通用局域磁矩约束"不成立。
