# 2026-10-30 尝试：FD 探针 + Newton 起步 / 放大半径（负结果）

## 0. 尝试内容

在参考相末对 MBIS 触发 FD 响应探针（`fd_probe_converged`：逐分量 `μ=h e_i` 测
`J=∂Q/∂μ`，`seed_jacobian` + `newton_seed`），并把初始信任半径从 0.2 放大到 0.8。

## 1. 结果（LCAO LiCl，目标 2.0，100 步）

| 初始半径 | Newton seed μ | seed 后 q | 100 步末 q | 备注 |
|---:|---:|---:|---:|---|
| 0.2 | **0.2**（=半径，被截断） | 2.0239 | 2.0181 | 半径截断了 Newton 步 |
| 0.8 | **0.7595** | **2.0239** | 2.0239（几乎不动） | Newton 步不再被截断，但 μ=0.76 时 q 仍≈参考值 |

关键观察：
- 半径 0.2 时的 `mu=0.2` 是**半径截断**（真实 Newton 步 ≈0.76），不是模型步小。
- 放大半径后 Newton 步 = 0.76 被采用，但 **μ=0.76 时 q 仍为 2.0239**
  （参考 2.0241），即 **Δq/Δμ ≈ 3e-4**，而探针预测 χ≈0.03（差 ~100×）。
- → **不是信任域/模型的数值门槛问题**；是 **MBIS 约束观测量在 LCAO+冻结权重下
  对 μ 的响应异常小/不一致**。

## 2. 分析（新根因假设）

- 探针测得的 J 与"实际 μ=0.76 的响应"矛盾 → 探针本身在该路径下**不可靠**，
  或 **约束势注入没有真正改变密度**（`V=μ·cw_` 未生效/权重异常）。
- 最可疑：**冻结权重取自初始密度**（`build_mbis` 只在首个观测建一次），
  或 **LCAO 的 `constraint_inject_lcao` 没有用 `build_mbis` 填的 `cw_`**
  （LCAO 走 Gint 网格，可能与 `pw_rhod` 的 `cw_` 不一致）。
- 这解释了"加大半径/Newton 步都无效"：**势根本没推动密度**。

## 3. 结论与下一步

- FD 探针 + Newton 起步 / 放大半径：**负结果**（不改善），已**回退**未验证改动。
- 真正要查的是 **LCAO 的 MBIS 约束注入是否生效**：
  1. 打印/核验 `cw_` 的大小与 `V=Σμ cw_` 是否进入 LCAO 的 `Veff`；
  2. 对比 PW（85 步收敛，说明 PW 注入生效）与 LCAO 的注入路径；
  3. 若 LCAO 注入未生效，修 `constraint_inject_lcao` 使用 MBIS 的 `cw_`；
  4. 冻结权重 vs 参考相末重建：确认权重取自已收敛的参考密度（而非初始密度）。
- 在注入确认生效前，讨论信任域/模型参数为时过早。

## 5. 确认结果（参考相重建版本，LCAO LiCl，目标 2.0）

先前"μ=0.76 时 q 不动"的异常来自**冻结权重取自初始密度**（试验性未提交改动）。
回退到已提交的**参考相重建**版本后：

| 量 | 值 |
|---|---|
| 参考 q（μ≈0） | **2.039**（≈ cube 收敛自由密度 2.0447 ✓） |
| 响应 χ | ~0.016（μ 0.349→0.749，q 2.0393→2.0328） |
| 信任半径 | 0.2→0.4（增长、零拒绝） |
| 100 步末 | q=2.033（目标 2.0，需更大 μ≈2.4） |

**确认**：
1. 注入链路正确：`inject_potential_lcao` → `ConstraintInjectPW::inject(*wg_, mu_eff_, channels_, v_eff)`
   （用 MBIS `cw_`）→ `pelec->pot->get_eff_v()` → Hsolver；`V=Σμ cw_` 确实进 LCAO 势。
2. `cw_` 正确：参考 q=2.039 与 cube 2.0447 一致。
3. 冻结权重的"零响应"是**初始密度权重不匹配**的假象；参考相重建后响应一致。
4. **LCAO 的约束响应（χ≈0.016）比 PW 小**，需要很大的 μ（≈2.4）；100 步不够。
   **不是 bug**，是响应幅度 + 步长/预算问题。

**下一步**：把外层步长（信任域/Newton，或 `constraint_mu_max`/迭代预算）按 χ≈0.016
放大；或接受 PW（ecutwfc 50，85 步）作为主平台，LCAO 仅作加速探索（每步 5.5 s）。
