# III-1 电荷转移对 + CDFT/Marcus 接口（H₂O 二聚体起步轮）

日期：2026-09-14（用户批复"可开始不依赖力的 SCF 级物理"后的首个算例；依据
`2026-09-09-validation-case-suite-design.md` §3 算例 III-1）

## 1. 测试计划

**目的**：验证框架的旗舰物理接口——**双片段混合电荷约束**在真实给体-受体对上的
可用性，并给出 CDFT/Marcus 重组能所需的基础量。

**算例**（设计文档原定苯-TCNE/Na⁺···芳烃，此处按其"零资源门槛"备选起步）：
H₂O 二聚体，给体-受体角色明确（O2–H···O1 氢键，O1···H = 2.02 Å）。

**协议**：v2 靶文件（逐约束 type），两条 charge 约束同 run：
- 受体片段 `[0,2,3]`（O1 + 两个 H）目标 **+δ e**；
- 给体片段 `[1,4,5]`（O2 + 两个 H）目标 **−δ e**（净零 CT，转移 δ 个电子）。
`constraint_target_mode delta` ⇒ 靶点 = 参考态读数 + 偏移。

**判据**（设计文档 §3）：
1. 双片段同时收敛（A6 混合能力的真实场景复用）；
2. 正反向（+δ/−δ）两次约束的 μ 差 → 重组能量级（CDFT 文献带宽 ~0.1–1 eV，口径级）；
3. 约束功 W = ΣμᵢΔQᵢ 自洽（并复用 I-1 的能量恒等式 −dE_tot/dδ ↔ (μ_acc − μ_don)）。

## 2. 测试设置

- 体系/输入：`tests/constraint_ct_dimer/h2o_dimer/{INPUT,STRU,KPT}`（LCAO，
  gamma-only，15 Å 盒，nbands 20，nelec 20，ecutwfc 60 / ecutrho 240 = 4×，
  O_gga_7au_60Ry_2s2p1d + H_gga_8au_60Ry_2s1p，O.upf + H_ONCV_PBE-1.0.upf）。
- 扫描：δ = 0, ±0.05, ±0.10, ±0.15, ±0.20 e（9 点，冷启动，同二进制/网格/初猜）。
- 运行：`bash tests/constraint_ct_dimer/run_ct_scan.sh 4`；`build_rel/abacus_basic_para`，
  np4，**OMP_NUM_THREADS=1**（可复现性纪律 §3.5）；单点墙钟 21–189 s，总计 ~15 min。
- 产物：`tests/constraint_ct_dimer/results/d_*.audit` + `summary.txt`。

## 4. 分析

- **旗舰接口可用**：9/9 点 CONVERGED（残差 ≤1e-4 e）；`total_charge = 20 = nelec` 每点
  成立（maxdev ~5.6e-16，Becke 分区的 sum rule 在分子体系同样精确）；受体/给体
  **μ 严格反对称**（max|μ_acc + μ_don| = 0，即两条约束互为镜像，无通道串扰）；
  δ=0 点给出 μ=0、E_tot 最低 ⇒ 自由态即该 CT 坐标的极小，物理正确。
- **能量恒等式**：−dE_tot/dδ（换算到 Ry/e）与 (μ_acc − μ_don) 在 |δ| ≥ 0.05 的 8 个区间
  内偏差 **+0.00% … +2.34%**（I-1 判据 <1% 多数满足），证明 μ 与能量路线自洽、μ 不是
  纯读数装饰。
- **强非线性和角色不对称（本轮的主要物理发现）**：分支局部斜率
  dμ_acc/dδ 在负侧（受体失电子）为 −1.63…−0.90 Ry/e，在正侧（受体得电子）快速降到
  −0.30 Ry/e（δ>+0.05 后稳定）⇒ 平均 κ 差 **≈ 3.7×**（−1.12 vs −0.30 Ry/e）。
  即"给体→受体"方向（本氢键二聚体的自然方向）的电荷响应比反向软得多；
  这也意味着**单一全局 κ 无意义**，必须按分支报告。
- **δ≈0 附近需加密**：区间 [0.00, +0.05] 的恒等式偏差跳到 +22.3%（其余 ≤2.34%），
  且正侧斜率在 +0.05…+0.10 间有 4× 突变——在给出重组能定量之前必须先在
  δ ∈ [−0.05, +0.10] 加密扫描，否则无法区分"真实曲率/拐点"与 5 点/0.05 e 分辨率不足。
- **Marcus 接口的量级（口径级，不外推）**：正反向 μ 差在 q = 0.1 e 处为
  |μ(+0.1) − μ(−0.1)| = 0.2308 Ry ≈ **3.14 eV**；CT 态垂直能（相对自由态）
  δ=+0.10 为 0.154 eV、δ=−0.10 为 0.216 eV。把它们换算成"每电子"的重组能需要
  先定义估计式并做文献对照，本轮**只登记原始量与量级**，不作重组能结论。
- **成本画像**：单点 21 s（δ=0）–189 s（δ=+0.05），全扫 ~15 min —— LCAO 小分子体系
  使 III 组算例成为最廉价的一类，可反复加密。
