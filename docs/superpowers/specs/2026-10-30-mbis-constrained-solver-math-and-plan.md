# MBIS 约束求解的数学理解与 100 步收敛方案

> 基于 LiCl（PW/LCAO）、Fe2 的一手实验数据，提炼约束 SCF 的数学结构，
> 解释"为何 100 步装不下"，并给出详细的可行方案（目标：≤2 次 SCF 求解、≤100 步）。

---

## 1. 实验提炼的数学事实

### 1.1 约束 SCF 是一个复合映射

```
内层:  给定 μ，解 SCF 固定点 ρ_σ = G_σ[ V_H[ρ]+V_xc[ρ]+V_ext + μ w_A ]   （每解一次 ~N_inner 步）
观测量: Q(μ) = F(μ)   （MBIS 电荷/自旋：∫ w_A ρ / ∫ w_A m）
外层:  r(μ) = F(μ) − t = 0
响应:  J = dF/dμ < 0 ，χ = −J > 0   （约束"硬度/磁化率"）
```
- Newton：`μ_{k+1} = μ_k − J_k^{-1} r_k`；线性响应下 **一步到位**：`μ* = r_0/χ`。

### 1.2 实测数据（LiCl，目标 N_Li=2.0；μ 单位 Ry）

| 量 | PW ecutwfc 50 | LCAO（192³ 网格） |
|---|---:|---:|
| 参考 q0（μ=0） | 2.032 | **2.04466182**（= cube 2.0447） |
| χ | ~0.039 | **~0.045**（探针）/ ~0.024（secant） |
| μ* | ~0.83 | **~0.996** |
| 每次 SCF 求解 N_inner | ~? | **29–35 步** |
| 收敛步数 | **85**（多 μ 步） | 100 步未收敛 |

### 1.3 100 步的实测预算分解（LCAO）

| 阶段 | SCF 迭代 | 步数 |
|---|---|---:|
| 参考相（μ=0） | 0→29 | 29 |
| FD 探针（μ=h=0.005） | 29→62 | 33 |
| 约束相（Newton μ=0.9965） | 62→100 | >38（未收敛） |

**关键事实**：
- Newton 步 `μ*=0.9965` 是**正确**的（参考 q0=2.0447、χ≈0.045）。
- 每次 SCF 求解约 **30 步**；100 步只够 **~3 次求解**。
- 当前结构（参考 + 探针 + 约束）**恰好 3 次** → 临界超预算。

## 2. 数学框架：复合/非精确 Newton 与成本模型

### 2.1 成本模型

设外层第 k 步把内层解到容差 `ε_k`，代价 `N(ε_k)`（SCF 步数）。总代价
```
B_total = Σ_{k=0}^{K-1} N(ε_k)
```
要 `B_total ≤ 100`。实测 `N(scf_thr)≈30`，故 `K·30 ≤ 100 ⇒ K ≤ 3`。

### 2.2 非精确 Newton（Eisenstat–Walker）

内层不必解到 `scf_thr`；只需满足
```
ε_k = η ||r_k|| ,   η ∈ [0.1, 0.3]
```
即可保持外层超线性收敛，且**内层成本随外层残差下降**（早期宽松、后期严格）。
这直接把 `N(ε_k)` 从 ~30 降到 ~10–15（早期），使 K 可以更大或总成本更小。

### 2.3 探针的信噪比与"生产率"

FD 探针测 `J ≈ (Q(μ+h)−Q(μ))/h`：
```
信号 ΔQ = χ h ； 需 ΔQ >> δQ（观测量噪声） ⇒ h >> δQ/χ
```
- 精度上 `h=0.005` 足够（χ=0.045 ⇒ ΔQ≈2.2e-4，若 δQ~1e-5，SNR≈22）。
- **但"生产率"差**：`h=0.005` 时 `Q(μ+h)≈Q(μ)`，这次 SCF **几乎不推进 μ**，
  是**纯额外成本**；真正的推进靠随后的 Newton 解（第 3 次求解）。

### 2.4 一步 Newton 的条件（核心）

若 χ 已知，`μ* = r_0/χ`，**在 μ* 解一次 SCF 即得 Q=t**（线性响应精确）。
故**最少只需 2 次求解**：参考（得 Q0、r0）+ 在 μ* 求解。
**前提**：`μ*` 的估计足够准（χ 的估计）。

## 3. 当前方案为何失败（不是信任域，是"求解次数"）

1. `h=0.005` 的探针 SCFF 只测 J、不推进 μ → **浪费 ~33 步**。
2. 之后 Newton 在 μ=0.9965 再解一次（第 3 次）→ 参考(29)+探针(33)+约束(>38) > 100。
3. 加 `scf_nmax` 无用：secant 步长仅 ~0.12，要走 ~14 个 μ 步（每步重解 SCF ~30 步）
   ⇒ ~400 步；只是把"3 次求解"变"14 次"，成本结构不变。
4. 信任域/模型（Broyden/secant）把步压小（0.05–0.14）是"多次求解"的直接原因；
   但根因是**需要 χ**，而当前用一次**近参考的冗余 SCF** 去测它。

## 4. 详细方案（目标：≤2 次 SCF 求解）

### 4.1 方案 A：大 h 试探（探针=约束解，推荐）

把 FD 探针的差分步从 `h=0.005` 换成**Newton 量级** `h ≈ μ*` 的估计：
```
1) 参考 SCF → Q0, r0 = Q0 − t
2) 取试探 μ1 = clamp(r0 / χ_guess, 0, μ_max)   （χ_guess 由廉价估计或固定量级，如 0.05）
3) 在 μ1 解一次 SCF（**这次就是约束解**）→ Q1
   - 若 |Q1 − t| < tol：**接受并收敛**（共 2 次求解）
4) 否则用实测 χ = (Q1 − Q0)/μ1 做 Newton：
   μ2 = μ1 − (Q1 − t)/χ ；在 μ2 解一次 → 通常收敛（共 3 次求解）
```
- 关键：**试探 μ1 本身是生产性的**（接近目标），不是冗余探针。
- 对 LiCl：r0=0.0447、χ_guess≈0.05 ⇒ μ1≈0.89，Q1 已很近 2.0；**2 次求解**即可。
  （实测 μ*=0.9965，χ=0.045；μ1=0.89 或直接用探针测得的 χ 反推会更准。）

### 4.2 方案 B：absolute 目标跳过参考相

- absolute 目标下 `t` 已知，参考相只为 Q0/δ 语义；可**省掉 29 步**。
- 直接：用初始 Q（第一迭代）估 r0，取 μ1=clamp(r0/χ_guess)，解一次 → Newton 修正。
- 代价：1–2 次求解。

### 4.3 方案 C：非精确内层（Eisenstat–Walker）

每个内层解到 `ε_k = max(η·|r_k|, scf_thr)`（η≈0.2）：
- 参考/试探步的内层 ~10–15 步（不是 30），**同样 2 次求解总 ~30–50 步**；
- 外层残差大时宽松、接近目标时收紧，保持收敛且省步。

### 4.4 方案 D：信任域只作安全网

- 主步用方案 A/B 的 Newton；信任域只用于**过冲保护**（`|Q−t|` 增大时回退/减半），
  不作为步长主驱动（当前正是信任域把步压到 0.12）。

### 4.5 组合（推荐）

```
A（大 h 试探=约束解）+ C（非精确内层）+ B（absolute 跳参考）
```
预期：LiCl **1–2 次求解、总 ~30–60 步**，稳进 100。

## 5. 具体代码改动点

1. **FD 探针步长**：`constraint_alloc_fd_step`（当前 0.005）→ 对 MBIS 用
   `h = clamp(r0/χ_guess, h_min, step_max)`；或新增 `constraint_mbis_probe_step`。
   - `fd_probe_converged()`（`constraint_loop.cpp:1431`）里 `h=cfg_.alloc_fd_step` 改为上述。
2. **试探即接受**：在 `fd_probe_converged()` 的全列完成后，**先检查** `|Q(h)−t|<tol`，
   满足则 `phase_=DONE; mu_=h`，**不再调 newton_seed 重解**。
3. **跳过参考相（absolute）**：在 `outer_step()` 的参考→约束转移处，若 `target_mode==absolute`
   且已能估 r0，则直接进入试探/约束，不跑完整参考相。
4. **非精确内层**：把约束相的 SCF 收敛阈值 `ε_k` 设为 `max(η|r_k|, scf_thr)`
   （`on_iteration` 里按 `|r|` 调 `conv_esolver`；或复用 `inner_thr`）。
5. **信任域降级为安全网**：`constraint_trust_region=1` 保留，但主步由 Newton 的
   `newton_seed`（实测 J）给出；半径上限允许到 `μ_max`（`step_max` 已可 3.0）。
6. **χ_guess 的来源**：廉价估计——(i) 固定量级（如 0.05）；(ii) 第一次试探后回填；
   (iii) 之前几何/体系的 χ 缓存。

## 6. 预期预算（LiCl LCAO，N_inner~30）

| 方案 | 求解次数 | 总步数（N=30） | 总步数（inexact N=12） |
|---|---|---:|---:|
| 当前（参考+小 h 探针+约束） | 3 | >100（实测） | ~75 |
| A（参考+大 h 试探） | 2 | **~60** | ~25 |
| A+B（跳参考） | 1–2 | ~30–60 | ~15–25 |

## 7. 风险与注意

- **χ_guess 不准**：μ1 偏离 μ*，Q1 不达 tol → 走 Newton 修正（第 3 次求解），仍在预算内。
- **过冲**：μ1 过大导致 Q 越过 t；用信任域/减半回退（方案 D）。
- **非线性/非单调**：小 χ 或近零模时线性响应失效；此时 A 退化为 secant 多次，
  需 C（非精确）+ 足够 K。但不再是"冗余探针"的浪费。
- **absolute vs delta**：B 只对 absolute 安全；delta 需参考相定义 Q0。
- **稳定性**：非精确内层（C）必须保证 `ε_k ≤ η|r_k|`，否则外层 Newton 失去收敛性。

---

## 8. 一句话结论

**约束 SCF 的瓶颈是"每次 SCF ~30 步 × 求解次数"。当前"参考+小 h 探针+约束"=3 次
求解必然超过 100。正确做法是让"探针"变成"生产性的约束求解"（大 h 试探，方案 A），
并用非精确内层（C）把单次求解从 ~30 降到 ~12、absolute 时跳过参考相（B）——
目标 **1–2 次求解、≤100 步**。**
