# DeltaP 旋转等价性测试 — P_x = P_y = P_z

> 日期: 2026-07-13  
> 测试系统: BN (闪锌矿, 非极性)  
> 问题: 对立方晶系, 沿 x / y / z 的极化分量应相等。验证算法是否正确。

---

## 一、测试设计

### 1.1 原理

立方晶系 BN 中, B 在 (0,0,0), N 在 (0.25, 0.25, 0.25)。三个方向等价, `P_x = P_y = P_z`。

测试三次独立计算, 使用相同的 k 点总数 (nks=4), 仅改变 k-string 方向和极化方向:

| 计算 | deltap_gdir | KPT | mp_沿方向 | total_strings | nppstr |
|------|:---:|------|:---:|:---:|:---:|
| P_z | 3 | 2×1×2 | 2 (z) | 2 | 3 |
| P_x | 1 | 2×2×1 | 2 (x) | 2 | 3 |
| P_y | 2 | 1×2×2 | 2 (y) | 2 | 3 |

每条 string 有 2 个 k 点沿极化方向, 2 条 string 覆盖垂直平面。三个计算是全等的旋转。

### 1.2 参数

```
BN zinc blende, B (0,0,0), N (0.25,0.25,0.25)
scf_nmax=6, scf_thr=1e-8, mixing_beta=0.4, ecutwfc=100 Ry
symmetry=-1, deltap_lambda_init=0 (无约束,仅诊断)
```

---

## 二、结果

### 2.1 极化总量 P_total (a.u.)

| SCF 迭代 | P_z | P_x | P_y | 一致性 |
|:---:|:---:|:---:|:---:|:---:|
| 1 (原子猜测) | +1.769×10⁻² | −1.261×10⁻² | −1.261×10⁻² | ❌ 不等 |
| 2 (更新电荷) | +1.185×10⁻² | +1.185×10⁻² | +1.185×10⁻² | ✅ 全等 |

**迭代 2 三者完全一致** (到 8 位有效数字)。

### 2.2 逐原子 Gamma (迭代 2)

| 原子 | P_z | P_x | P_y |
|------|:---:|:---:|:---:|
| B (atom 0) | 1.1166 | 1.1166 | 1.1166 |
| N (atom 1) | 1.3406 | 1.3406 | 1.3406 |

三个方向原子级 gamma 也完全一致, σ ≤ 1.3×10⁻³ rad, 全部 OK。

### 2.3 迭代 1 为何不一致?

迭代 1 的电荷密度来自原子猜测 (未自洽), 导致:

```
P_z, iter 1 (γ 为正):
  B: raw=+0.130, sel=+1.667  [0]  raw=+0.125, sel=+1.669  [1]

P_x, iter 1 (γ 为负):
  B: raw=−0.043, sel=−1.147  [0]  raw=+0.125, sel=−1.191  [1]

P_y, iter 1 (与 P_x 相同):
  B: raw=−0.043, sel=−1.147  [0]  raw=+0.125, sel=−1.191  [1]
```

P_x 和 P_y 的第一条 string 的 raw gamma 为负 (P_z 的为正)。原因:

1. **pre-branch raw gamma = Σ w_In × γ_unwrapped[n]**, 其中 w_In 来自 SMO 投影权重, 随 k 点位置变化
2. P_z 的 strings 经过 k_z=0 和 k_z=0.5, P_x 的 strings 经过 k_x=0 和 k_x=0.5, **采样了 BZ 的不同区域**
3. 在 4 点稀疏采样下, SMO 投影的 w_In 在不同 k 点有系统差异 → raw gamma 符号不同

迭代 2 中电荷密度更新后, 波函数趋于自洽, **三个方向的 raw gamma 收敛到相同符号和相近数值**, 最终 P_total 一致。

## 三、跨 String 一致性

| 方向 | γ(B) σ | γ(N) σ | BRANCH |
|------|:---:|:---:|:---:|
| P_z | 1.3×10⁻³ | 3.7×10⁻³ | OK |
| P_x | 3.2×10⁻² | 2.9×10⁻² | OK |
| P_y | 3.2×10⁻² | 2.9×10⁻² | OK |

P_x 和 P_y 的 σ 较大 (~3×10⁻²) 但远小于 2π·w_sum (~5-9 rad), 未触发分支不一致。较大的 σ 来自 iter 1 中两条 string 的 raw gamma 符号相反 —— 说明稀疏采样下 string 之间确有物理差异。

## 四、结论

### 4.1 已验证

| 项目 | 结果 |
|------|------|
| P_x = P_y = P_z (立方对称性) | ✅ 迭代 2 三者精确相等 (1.185×10⁻²) |
| 逐原子 γ 旋转不变 | ✅ 迭代 2 完全一致 |
| 跨 string 分支选择 | ✅ 所有方向 OK |
| 不同方向 k-string 网络的等价性 | ✅ 同一 k 点总数 (4) 的正确旋转 |

### 4.2 局限

| 项目 | 说明 |
|------|------|
| k 点稀疏 | 仅 4 点, P_x/P_y 的 σ > P_z |
| SCF 未收敛 | 仅 2 轮有效迭代 |
| 绝对值未对标 | 非极性 BN 的 P ≈ 0.012 a.u. ≠ 0 (需 Wannier90 验证) |
| 非铁电体系 | 无本征极化分支跳变测试 |
