## 4. Analysis

1. **施加侧与记账侧共用同一路径**：H_c 施加（`op_pw_proj.cpp` cal_ps_deltap
   + add_onsite_proj）与 Γ 记账（`compute_gamma_op_pw`）都用
   OnsiteProjector 的同一 `cal_becp`/tab_atomic，在相同 ψ 上
   ⟨P̂⟩ 逐位一致；escon=−λΓ 是代数恒等（同一次测量内自洽）。
2. **1.784× 证伪**：dE_band/dλ ≠ Γ 是因为 E_band（Σwε）含密度响应项
   ∫ρ·δV_eff/δλ（≈ +6.23 Ry/Ry），闭合分解（Σ分量斜率 = 实测
   dE'/dλ，误差 0.01 eV/Ry）证明差值 100% 归因于响应，非算符差。
3. **残余斜率根因 = escon 测量态陈旧**（协议层，非代码 bug）：
   PW 同步两相模式每 SCF 周期只测一次 Γ（`lambda_set` 后提前返回），
   测量点 = 首个 drho<deltap_inner_thr 迭代。默认 inner_thr=1e-3 →
   测量在 drho≈7e-4 的部分收敛态，Γ 与收敛值差 ~0.1–0.3%；
   该陈旧 Γ 进入 FINAL_ETOT 的 escon，产生 E'(λ) 线性项。
   收紧 inner_thr=1e-6 → 测量在 drho≈3.7e-7 → 线性项塌缩 100× 到
   0.0018 eV/Ry（Γ 的 0.0018%）。
4. **L1.1 验收结论**：真生产档（ecut=80）下 E'(λ) 平直性线性项
   0.002 eV/Ry ≪ F-1 判据 1 eV/Ry（500×），比 ecut=40 旧数据好 ~100×。
   评审出口：**非 (b) 结构性失配**；也非 (a) 纯 ecut 噪声（斜率不随 ecut
   缩小，随 inner_thr 缩小）——准确表述为**测量协议伪影**，已定位、可消除。
