## 3. 根因分析（分支锚定机制）

1. **global target-aware branch selection**（`deltap_wannier.cpp:1333`）**每次
   compute_gamma 都把报告 γ 拉到"离 t_γ 最近的分支"**（移位幅度 = 2π·w_In/w_tot，
   per-atom 量子 ~0.07–0.105 rad @ 2-k 点网格）。
2. t_γ=自然时该选择与物理一致（T2/T3 协议成立的前提）；t_γ≠自然时，**λ=0 首测
   就跳变 0.105 rad 上靶点分支** → 外循环判 |γ−t_γ|≈0 → 假收敛。物理 γ 从未
   移动，λ 全程 0。
3. 这印证设计文档 §5 的 Phase 0.3（分支连续性）"作用域缩到外循环读数"——但实测
   表明：**读数连续性不是 T4 之后的收尾，而是外循环可验证性的硬前置**。评审修正 1
   的 0.98 靶点（Δγ=0.11 rad）恰好落在分支量子（~0.105 rad）之下，低于该可观测量的
   分辨率；0.9 靶点（Δγ=0.55）在量子之上，但 λ*≈1.9 Ry 暴力区（评审已排除）。

## 4. 建议的修复路径（Phase 0.3-lite，待评审）

1. **分支参考与 t_γ 解耦**：报告的 γ 锚定到**上一次测量值**（跨步连续性，
   W_prev_ 已有机制），而不是每次重锚到 t_γ；t_γ 仅在无参考分支时（首测/无
   branch.dat）用于初始化分支。
2. **自然参考分支**：外循环运行前先做一次 λ=0 自由跑（或加载 branch.dat）钉住
   自然分支；之后 γ(t_Γ) = 自然 γ + 物理响应（斜率 ~0.07），外循环才有真实的
   收敛对象（0.98 靶点需 Δγ=0.11 的物理移动，预言 2–4 步）。
3. **回归安全性**：t_γ=自然 的运行（T2/T3/全部 gamma 锚点）里
   "t_γ 锚"与"prev 锚"一致 → 改动应为 no-op；仍需跑 natural-target 对照 +
   gamma 模式零回归验证。
4. 修复后重跑 T4a（0.98 靶点，机制验证）+ T4b（0.95→0.9 窗口测绘，
   "力残差 vs |λ*|"曲线）。
