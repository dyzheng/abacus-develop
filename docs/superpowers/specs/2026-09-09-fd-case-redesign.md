# FD 验证算例重设计（纸面，不提交任何计算）

> 起因：用户三点修正——LCAO 快、bulk PW 快、dav_subspace 快；此前成本分析
> （2026-09-09-fd-cost-analysis.md）只覆盖了构建类型/网格/协议三个维度，
> **漏了基组选择、体系选择、求解器选择三个维度**。本文重做算例设计。
> 本轮零代码改动、零计算提交。

## 1. 完整成本模型（连乘分解）

```
FD 总成本 = 腿数 × 每腿外步数 × 每外步 SCF 迭代数 × 每迭代成本
              │         │            │                │
              │         │            │                └─ 基组 × 体系 × 求解器 × 构建类型 × 网格
              │         │            └─ 收敛性质（体系固有）
              │         └─ fixed-μ（1）vs 重优化-μ（2）【协议】
              └─ 覆盖策略（全轴 18 vs 冒烟 2–4）【验证设计】
```

每迭代成本的六个因子此前只分析了后三个（构建/网格/协议）。补上前三个：

| 因子 | 选项对比 | 量级（H₂O R7 口径） |
|---|---|---|
| **基组** | PW（96k 平面波，对角化主导）vs LCAO（~24 基函数，对角化可忽略） | LCAO 腿实测 ~2 min/整腿 vs PW ~24 min/外步——**~10–20×** |
| **体系** | 分子大盒（15 Bohr，大量平面波描述真空）vs bulk 小原胞（无真空、基组利用率高） | bulk（diamond/BN 原胞）同 ecut 下 npw 低 1–2 个量级——**~10–30×** |
| **求解器** | DiagoCG（逐带 CG，BLAS1/2 为主）vs dav_subspace（块 Davidson，BLAS3 子空间） | 文献/经验 **~2–5×**（估计值，未经本仓库实测——标注） |

与已有三因子（release 3–10×、fixed-μ 2×、网格标定 3–4×）**全部可乘**。

## 2. 关键判断：验证对象 × 最便宜载体的匹配

力 FD 验的不是化学，是**代码路径**。把要验的东西拆开后，每条路径都有最便宜载体：

| 要验的东西 | 最便宜的充分载体 | 理由 |
|---|---|---|
| 约束力核 + 通道折叠（charge/spin/mixed） | **LCAO H₂O 全轴** | 核是共享的、与基组无关；LCAO 整腿 ~2 min（实测基准），18 腿 ≈ 40–70 min |
| PW 嵌入路径（Forces/SCC/vnew 生命周期） | **PW 冒烟 2 轴** | 该路径的 bug 模式（势生命周期丢 μw）已被电荷通道根因+修复+全轴验证覆盖；自旋/混合只需确认无新签名（净力指纹检查即可捕捉） |
| LCAO 嵌入路径（Pulay 生命周期） | **LCAO 冒烟已含在全轴内** | 同上 |
| bulk 正确性/生产行为 | **V6 Au:Si（本职场景，另立）** | bulk 的价值在生产表征，不必挤进 FD 验收轮 |

**为什么不把 FD 整体迁到 bulk PW**：(a) LCAO H₂O 全轴比 bulk PW 还便宜（24 基函数 vs 数千平面波）；(b) 证据链连续性——2.6 闭合的包络声明建立在 H₂O 上，换体系要重建基线；(c) bulk 的正确位置是 V6 生产表征（Au:Si 电荷态扫描本就是计划内）。若未来确需 PW 全轴，bulk + dav_subspace + release 是正确载体（登记）。

## 3. 重设计后的验证算例矩阵

| 验证项 | 载体 | 设置 | 覆盖 | 预估成本 |
|---|---|---|---|---|
| spin 力 FD 全轴 | H₂O（212 几何） | LCAO、gamma_only、R7（ecutrho=400/scf_thr=1e-8）、fixed-μ | 18 腿 | **~40–70 min** |
| spin 力 FD 冒烟 | H₂O | PW、**dav_subspace**、R7、**release 构建**、fixed-μ | 2 轴（O-z=权重导数最强 + H1-x=历史变化最大）4 腿 | ~15–30 min（估计） |
| mixed 力 FD 全轴 | H₂O（213 几何） | 同 spin LCAO | 18 腿 | **~1–1.5 h** |
| mixed 力 FD 冒烟 | H₂O | 同 spin PW | 2 轴 4 腿 | ~15–30 min（估计） |
| torque FD（未来复查） | H₂O | LCAO | 3 腿 | ~10 min |
| bulk 生产表征 | Au:Si（V6，另立计划） | PW、dav_subspace、bulk 标定网格 | 按 V6 | 另立 |

**vs 原方案**（PW debug CG 全 18 腿 ×2 通道 ≈ 17–18 h）：**总成本 ~17 h → ~2.5–4 h，且覆盖不降**（通道级全轴仍在，只是换到便宜基组；PW 侧从全轴降为冒烟，与 LCAO 在 2.6 享受的减轴逻辑同型——机制已根因、最坏轴已验、净力指纹兜底）。

## 4. 每条腿的参数处方（写死）

- **协议**：fixed-μ（ABA_CONSTRAINT_FIXED_MU=base μ*）+ raw-E 口径；首次使用前跑 1 条对照腿（fixed vs 重优化）确认等价性在新通道成立（电荷通道已双证，自旋/混合需各 1 条）；
- **PW 腿**：`ks_solver=dav_subspace`、release 构建、R7 网格（egrid 标定后若 ecutwfc=60 噪声 ≪ 判据/3 则降档——标定本身是 2 条腿的成本，一次投入）；
- **LCAO 腿**：gamma_only、R7（ecutrho=400）、release 构建；
- **标准检查**（每腿自动）：净力 ≈ 0、补偿前后双值、raw-E；
- **构建类型纪律**：同一批次同一二进制；spec 记录构建类型。

## 5. 当前在跑的 V1 PW 18 腿（debug/CG）处置建议

已产出 wave 1（O-x/O-y）+ wave 2（O-z）≈ 3 轴数据。**建议：跑完 wave 3（H1-x）后停**——

剩余 wave 4–6（H1-y/z、H2-x/y/z）在新设计下由 LCAO 全轴覆盖，属冗余（省 ~3–4 h）。

## 6. 风险与诚实标注

- dav_subspace 的 2–5× 是经验估计，**本仓库无实测**——V2 首批先跑 1 条标定腿确认收益与收敛行为（不收敛则回退 CG，属已知 ks_solver 选择风险）；
- LCAO ~2 min/腿是 fixed-μ 实测基准（LCAO Pulay 修复验证轮）；重优化-μ 的 LCAO 腿会更贵，故协议统一 fixed-μ；
- "PW 冒烟 2 轴足够"依赖净力指纹的判别力（7.08 eV/Å 案证明其敏感）——若冒烟轴出现非零净力签名，立即升级全轴，不豁免；
- 换 release 后 result.ref 类绝对值对拍须同构建类型重生成（FD 差分量预期不受影响，1 条对照腿验证）。
