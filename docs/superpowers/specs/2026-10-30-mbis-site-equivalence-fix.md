# 2026-10-30 MBIS 位点等价（symmetrize）修复：公式与实现

## 1. MBIS 基本公式

原子 A 的 s 型 Slater pro-density（`N_A` 布居，`ζ_A` 展宽）：
```
ρ_A^pro(r) = N_A · ζ_A^3 / (8π) · exp( −ζ_A |r − R_A| )
```
权重与原子密度（`Σ_A w_A(r) = 1`）：
```
w_A(r) = ρ_A^pro(r) / Σ_B ρ_B^pro(r)
ρ_A(r) = w_A(r) ρ(r) ,   m_A(r) = w_A(r) m(r)
```
约束观测量：
```
N_A = ∫ w_A(r) ρ(r) dr = ∫ ρ_A(r) dr
M_A = ∫ w_A(r) m(r) dr = ∫ m_A(r) dr
```
KL 固定点（均值半径匹配）：
```
N_A = ∫ w_A ρ dr
ζ_A = 3 N_A / ∫ r w_A(r) ρ(r) dr = 3 / ⟨r⟩_A
```
迭代：`w ← pro/Σpro` → 更新 `N_A, ζ_A` → 重复到 `max|ΔN_A| < tol`。

## 2. 位点等价投影（修复）

设 `G` 为一组**电荷密度下等价**的格位（同种原子、同一局域环境；bcc 常规胞的两个 Fe
由体心平移相联系，`G={Fe1,Fe2}`）。在**每次** `N_A, ζ_A` 更新后（阻尼之前）做投影：
```
N_A ← (1/|G|) Σ_{B∈G} N_B ,   ζ_A ← (1/|G|) Σ_{B∈G} ζ_B ,   ∀A ∈ G
```
即把 pro-density 参数投到"位点等价子空间"。

**为什么正确**：若 A、B 由保电荷密度的空间对称（平移/旋转）相联系，则精确 MBIS 解
必满足 `N_A=N_B`、`ζ_A=ζ_B`。投影强制该不变量，从而：
```
N_A = N_B ,   w_A(r) = w_B(r + T)  （若由平移 T 相联系）
⇒ 逐原子观测量对等价位点一致（AFM 则 ∓）
⇒ 目标 ± 与分区自洽，约束**良定**
```
并去掉 KL 迭代中**不稳定的破缺模式**（对称子空间内自由度减少），迭代更稳。

**限定**：仅用于**真正等价**的格位（同种原子且同一局域环境）。若两个同种原子不等价
（如不同配位），平均会引入错误；此时应改用**原胞**或**原胞平移格**的镜像求和。

## 3. 与"图像求和"的关系

常规胞的周期图像格是晶体平移群的**子格**（缺体心平移），这是 `q=0.075/7.92`
破缺的数值来源。两条修法：
- **(a) 位点等价投影**（本文，`constraint_mbis_symmetrize 1`）：务实、通用性受限；
- **(b) 原胞平移格镜像求和**：更本质，但需从常规胞推出原胞平移（实现更复杂）。
当前先实现 (a) 并显式暴露开关。

## 4. 实现（输入与代码）

新增 INPUT：
```
constraint_mbis_symmetrize 1   # 对同种等价原子投影 (N,ζ)（默认 0）
constraint_mbis_images 2       # MBIS pro-density 的周期镜像层数（默认 0）
```
代码：`WeightGrid::build_mbis()` 的 `MbisConfig` 从这两项取 `symmetrize/images`；
`MbisConfig::symmetrize` 的投影在 `compute_mbis()` 内、阻尼更新之前执行（已实现）。

## 5. 验证

- Fe2（bcc 常规胞）PW、MBIS 自旋、`symmetrize=1, images=2`：
  两个 Fe 的 `N` 应相等、`M` 应 ∓ 相等（AFM），而非 0.075/7.92；
- 目标用 **MBIS-native**（空间自旋自然值 ~2.65 附近，如 ±2.8），而非投影口径 ±3.8。
