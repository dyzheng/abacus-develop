## 1. 技术评审（逐点）

### 1.1 成立且价值高的部分

| 点 | 评价 |
|----|------|
| 双通道分解（Ô_θ 链接相位 + Ô_w 投影权重） | **正确且深刻**。γ_I = Σ_n w_In·θ_n 的两条 ψ 依赖通道分离是精确算符推导的正确起点 |
| Ô_w = θ_n·P̂_I（带分辨在位势） | 推导正确（w_In 只依赖同带 ψ_n），DFT+U 同型，实现代价低 |
| **核心定理（§1.4）**：H_HR 是把 θ_n 替换为 τ_α(I) 的几何代理，误差 ∝ λ_I·spread_I | **本文档最大贡献**。它把"Route A+ 何时可信"从经验判断变成可计算判据——这是当前用户文档的空白 |
| H_HK 应力推导（§4） | 固定约化网格约定下相位应力项恒为零的论证正确；复用重叠应力内核可行；本来就是 Route A+ 的 LIMITATION 计划项，直接采纳 |
| PW 记账统一（§5） | 恒等式链与 LCAO 侧逐字同构（只用"H_c λ-线性"性质），L1 零风险，采纳 |
| ⟨η⟩ 完备性审计（§6） | 采纳。γ_I 逐原子归属的投影依赖此前无量化手段 |
| 类比失效边界（§9） | 诚实且必要（分支/时间结构/规范不变性三点不可类比） |

### 1.2 需要修正或降调的声明

| 声明 | 评审意见 |
|------|----------|
| "η → 1（构造性保证）"、λ* 下降 ≥5× | **过度声明**。η=1 只是定义层面的恒等（Ô_a=Ô_b 时 χ 比值为 1）；λ* 缩小倍数依赖算符范数对比，Cauchy–Schwarz 只给出 χ^{γγ} ≥ (χ^{γΓ})²/χ^{ΓΓ} ≈ 0.021（弱下界），真实增益必须实测。执行方案中 V-H3 的判据改为"实测记录"，不写 ≥0.9 的硬预言 |
| Tr[ρ·Ô_θ]=0（Euler 齐次性，§2.2 记账退役 escon 的地基） | 形式推导成立，但离散 Wick 梯度 + 厄米化 + C†SC=I 归一化约定下是否精确保持零值**未经数值验证**。**新增 V-H0 作为 Ô_θ 实现后的第一个测试**（见 §3），地基不成立则 §2.2 记账方案整体回退 |
| Ô_w 的分支性 | **文档低估了的风险**：θ_n 直接进入哈密顿量（λ·θ_n·P̂），分支跳变改变的是**势本身**（λ·2π·P̂ 的突变），不只是测量读数——大 λ 下可直接打翻 SCF。Route A+ 的代理 τ_α 是连续的，这是 EFC 相对 A+ 新增的 SCF 稳定性风险。执行方案加入设计约束（§3-D2）与 V-H8 |
| Route W | 结构正确，但属研究预研。近期不投入，仅保留为解除 KPAR=1 的候选方向 |

### 1.3 总体判断

- 推导质量高，§1.4 定理与 spread_I 判据是实质进展；
- **EFC 的确定性收益**：概念统一（约束泛函的梯度 = SCF 所解的算符，HF 定理严格适用）、大靶点可达性的候选解法、Born 电荷新通道；
- **EFC 的不确定收益**：小 λ 力精度（与 A+ 同为 O(λ) 泄漏结构，未必更好）、η/λ* 增益幅度（待测）；
- **EFC 的新增风险**：状态依赖算符的 SCF 稳定性（类 SIC 振荡）、分支跳变进哈密顿量、Ô_θ 实现复杂度（L3 上限）。

## 2. 调整后的执行方案（三层）

### 层级与内容

```
基线（生产）：Route A+（已过 T3，0.0138 eV/Å 机制闭合）
  └ 不再做 T4b 窗口测绘（与 V-H3 数据需求合并，见 §3-T4）

L1（本周，零风险，直接并入基线）：
  L1.1 PW escon → Γ^PW 记账（§5 最小补丁）
  L1.2 ⟨η⟩ 完备性输出（scf 收敛后打印带/k 平均）
  L1.3 spread_I 诊断输出（仅测量，不改算符）

L2（L1 数据定标后，低风险）：
  L2.1 H_HK 应力（§4 推导，复用重叠应力内核）→ V-H7
  L2.2 PW 应力（同批）
  L2.3 权重重整化 w̃（⟨η⟩ 实测 >5% 体系出现时再启用，否则缓）

L3（研究轨道，编译开关 deltap_operator_mode=proxy|efc，Route A+ 全程可回退）：
  L3.1 Ô_w：θ_n·P̂_I 替换 τ_α 代理（改动最小、预期收益最大）
        → V-H0（齐次性）+ V-H8（SCF 稳定性）+ V-H3（耦合效率）
  L3.2 Ô_θ：A^{(j)} 传播子 + 滞后 SCF（V-H0/H8 通过后）
        → V-H1（均匀极限≡efield）+ V-H6（Born 电荷闭合）
  L3.3 记账双读数 E_tot/E_phys + secant 代理环退役（Ô_θ 稳定后）
```

## 3. 执行纪律（七条，含对 Route A++ 文档纪律的修正）

- **D1 基线不可破坏**：EFC 全程编译开关隔离；Route A+ 的 gamma/operator 两模式
  回归锚（逐字节）在任何 EFC 提交前必须通过。
- **D2 分支进哈密顿量的设计约束**：Ô_w 的 θ_n 用**初始化锚定的连续值**
  （首轮测量定参考，SCF 内禁跳；|Δθ_n|>π/2 的迭代冻结该步更新并重置
  Broyden 历史）。无此约束不得合并 Ô_w。
- **D3 每级门槛未过不升级**：L1→L2 需 V-H2/V-H5 数据落档；
  L2→L3.1 需 V-H7；L3.1→L3.2 需 V-H0+V-H8+V-H3 全绿。
- **D4 预言降级规则**：Route A++ 文档中"η≥0.9""λ* 降 ≥5×"等数值预言一律
  按"实测记录"处理，不作通过判据；判据只写机制性恒等式
  （齐次性、均匀极限、Born 闭合）。
- **D5 数据两用**：V-H3 的 λ 扫描同时产出 T4b 的 Γ→γ 映射窗口数据，
  不重复跑。
- **D6 文档分层**：L1/L2 落地并入 Route A+ 主文档；EFC 在 V-H 全绿前只在
  研究分支文档，主算法文档（2026-08-05 版）不标注 A++。
- **D7 锚点纪律**：L3 全绿前不重建锚点（第 4 次重建只做一次）。
