# 2026-10-30 MBIS KL 多解性：来源、Hessian 能/不能做什么、如何取"正确解"

## 0. 直接回答

- **是的**，核心是 **KL 自洽解的多解性**：KL 目标对 pro-density 参数 `p={N_A,ζ_A}` **非凸**，
  `∇D(p)=0` 可有**多个**解；定常迭代只收敛到其**初值所在盆地**的一个。
- **Hessian `H=∇²D`** 只能给**局部**信息：`H≻0` ⇒ 严格局部极小（局部唯一/稳定）；
  有**负本征值** ⇒ 鞍点；有**零本征值** ⇒ 退化。它**不能证明全局唯一**（非凸可有多个极小）。
- 但 Hessian **能判别**"对称点是极小还是鞍点"，从而区分**伪对称破缺**（对称点是极小，
  破缺解是别的极小 → 数值/多解造成）与**真对称破缺**（对称点是鞍点，破缺极小更低 D）。

## 1. 为什么 KL 多解（数学结构）

```
D(p) = Σ_A ∫ ρ_A^pro ln(ρ_A^pro / ρ_A) dr ,   ρ_A = w_A ρ ,   w_A = ρ_A^pro/Σ_B ρ_B^pro
```
- 对**单个** `p_A`（固定其他原子/权重）`D_A` 近似"凸拟合"；
- 但 `w_A` 是 **pro-density 的 softmax 型比值**，依赖**所有** `p` → **反馈耦合**；
- 于是 `D(p)` 对全体 `p` **非凸**，`∇D=0` 可有**多个**驻点（极小/鞍点）。
- 定常迭代 `p_{k+1}=F(p_k)`（`F` 由 `N_A=∫w_Aρ`、`ζ_A=3N_A/∫r w_Aρ` 定义）的
  **收敛与选择**由 `∂F/∂p` 的谱半径/盆地决定；不同初值/数值镜像→不同解。

## 2. 什么情况容易多解

1. **等价原子/对称性**：对称解放存在，但**破缺解**也是驻点（自发对称破缺）。
2. **pro-density 强重叠/原子很近**：`w_A` 对 `p` 极敏感，非凸性变强。
3. **小周期胞且镜像不全/图像格不对**（bcc 常规胞案例）：数值上制造近简并。
4. **电荷转移/双稳态**：两原子间"谁多谁少"存在两套自洽解。
5. **初值**：纯操作层面——从不同 `p_0` 落到不同盆地。

## 3. Hessian 的准确用途

- **局部稳定性/唯一性**：在解 `p*` 处算 `H`。
  - `H≻0` ⇒ 严格局部极小（Newton 二次收敛、局部唯一）；
  - `H` 有负本征值 ⇒ 鞍点（迭代若"收敛"到这里是假收敛）；
  - `H` 有零/近零本征值 ⇒ 退化/近零模（多解或平坦方向）。
- **判别伪破缺 vs 真破缺**：在**对称点** `p_sym` 算 `H`：
  - `H(p_sym)` 在**破缺方向**上**正**（对称点是极小）→ 破缺解是**别的极小**，
    多半是**数值/多解**造成；对称化（投影到对称子空间）选出**正确解**是合理的；
  - `H(p_sym)` 在破缺方向上**负**（对称点是鞍点）→ **破缺极小 D 更低**，是**真**对称破缺；
    此时强行对称化会选到**更高 D 的鞍点 → 错误**。
- **不能**：靠 Hessian 证明"全局只有这一个解"（非凸）。全局唯一需**多初值扫描 + 比较 D**，
  或**证明凸性/单调性**（一般没有）。

## 4. 如何取"正确（MBIS 定义下）的解"

1. **变分选择**：在同一体系下找**最低 `D`** 的驻点（多初值/多镜像层数），最低者即 MBIS 最小。
2. **对称约束**（仅当对称点是极小，即 §3 判据为正）：在**对称子空间**内求解/投影 → 唯一。
   这就是 `symmetrize` 的合理前提。
3. **Newton + Hessian（带信赖域）**：比定常迭代更快、可靠地到驻点，并用 `H` 的本征值
   **分类**（极小/鞍点），必要时**逃出鞍点**（沿负曲率方向）。
4. **稳健性检查**：解不随初值/镜像层数漂移；`D` 与解一致。

## 5. 对 Fe2 的判据（应做的一步）

- 计算**对称分区**与**破缺分区**的 `D`（以及对称点处的 Hessian 破缺方向曲率）：
  - 若 `D(sym) < D(broken)` 且对称点是极小 ⇒ 破缺是**伪解**，对称化正确；
  - 若 `D(broken) < D(sym)` 或对称点是鞍点 ⇒ 破缺是**真解**，不应强制对称化（而应修
    "图像/周期"而非平均参数）。
- 这比"看代码/凭经验"严格：**用 D 和 Hessian 判定**。

## 6. 结论

- 根因是 **KL 目标非凸 → 多自洽解**；对称破缺只是**等价原子上**的一种表现。
- **Hessian 给局部判据**（极小/鞍点、局部唯一），**不给全局唯一**；全局唯一需多初值/最低 D。
- 要取"正确解"：**比较 D + Hessian 判别（伪/真破缺）+ 对称约束（仅在对称点为极小时）**；
  必要时用 **Newton/Hessian 分类并逃离鞍点**。
