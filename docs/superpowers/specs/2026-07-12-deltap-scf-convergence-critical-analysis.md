# DeltaP SCF 收敛问题批判性分析 (2026-07-12)

> 对比磁性、杂化泛函、DFT+U 等经典 SCF 收敛困难，分析 DeltaP 算法的独特挑战。

## 1. 问题的本质：双变量耦合不动点

DeltaP 的 SCF 收敛问题与经典问题（磁性、杂化泛函、DFT+U）有本质区别。核心差异在于：**DeltaP 是一个双变量耦合不动点问题，其中"约束可观测量"（gamma/Berry 相位）是一个拓扑全局量，而非局域密度。**

经典 SCF 困难：
- **磁性体系**：电荷密度 ρ(r) 与磁化强度 M(r) 之间的振荡，两者都是实空间局域量
- **DFT+U**：占据矩阵 n_{mm'} 的不连续变化，但是局域在单个原子上
- **杂化泛函**：精确交换算符对轨道的非线性依赖，但是平滑的泛函关系

**DeltaP 的独特之处**：
- γ 是通过 Wilson loop 计算的 Berry 相位：`W = O_0 · O_1 · ... · O_{N-1}`，其中 `O_j = <ψ_m(k_L)|ψ_n(k_R)>`
- γ 是 **波函数的全局拓扑性质**，不是局域密度
- γ 对 ψ 的微小变化极度敏感（特征值的辐角）

## 2. DeltaP 收敛困难的三个独特根源

### 2.1 拓扑分支不连续性（经典问题中不存在）

Wilson loop 矩阵的特征值 λ_n = |λ_n| exp(iζ_n)，gamma 来自相位 ζ_n 的连续退绕。当 SCF 迭代中 ψ 连续变化时：
- 特征值可以在复平面上绕原点旋转，导致 ζ_n 跳变 2π
- 不同 SCF 迭代可能选择不同的分支，导致 γ 跳变 ~1 rad

**对比**：磁性体系的 M(r)、DFT+U 的 n_{mm'} 都是连续函数，不存在这种拓扑不连续性。杂化泛函的精确交换也是轨道的平滑泛函。

**文档证据**：
- "iter=6: gamma 翻转为 -0.08（drho 仍在下降但 gamma 突变）" — `2026-07-12-scf-convergence-fix-plan.md`
- "Branch unwrapping inconsistent across λ — blocks dγ/dλ" (B16) — `deltap-development-log.md`

这是 **根本性的拓扑障碍**，经典混合方案（Broyden、Pulay、Kerker）完全无法处理。

### 2.2 信噪比倒置问题

根因分析文档明确记录（`2026-07-12-deltap-root-cause-analysis.md`）：
> "SCF 收敛过程中 gamma 的变化（~0.1 rad）远大于 λ 驱动的 HK correction 信号（~0.02 rad）"

即：**"噪声"（电荷波动引起的 γ 漂移）比"控制信号"（λ 调整引起的 γ 修正）大 5 倍**。

**对比**：
- **DFT+U**：U 修正项（通常 2-8 eV）远大于电荷涨落对占据矩阵的影响
- **磁性**：交换分裂（~1 eV）主导自旋密度振荡
- **杂化泛函**：精确交换比例（~25%）显著改变势场

在 DeltaP 中，λ 是一个 Lagrange 乘子，通过 HK 修正进入 Hamiltonian。HK 修正的量级 ~λ · w_eff · SC，被设计为微扰。**控制信号的强度被人为限制在微扰级别，而拓扑可观测量对波函数的敏感度却是"原始"的**。

这意味着：即使 BFGS 内循环在固定电荷下完美收敛（γ → target），下一次外循环的电荷更新也会将 γ 推离 target，而且偏移量 > λ 能修正的量。

### 2.3 Gate 触发的哈密顿量突变

内循环的激活条件（`esolver_ks_lcao.cpp:605-615`）：
```cpp
bool gate = iter > 1 && (dp_dp->inner_loop_triggered()
             || (this->drho > 0 && this->drho < PARAM.inp.deltap_inner_thr));
```

当 drho 首次降至阈值以下时，gate 打开，HK 修正突然加入 Hamiltonian。这造成：
1. Hamiltonian 突变 → 电荷变得不那么收敛 → drho 增大 → gate 关闭
2. HK 消失 → 电荷重新收敛 → gate 再次打开 → 振荡

**对比**：
- **DFT+U/磁性/杂化泛函**：额外项从第一步就存在于 Hamiltonian 中，不存在"开关"过渡
- **DeltaSpin**（同类算法）：也有内循环，但磁矩是局域量，gate 的影响较小

这是 **算法设计引入的非物理不连续性**，纯粹的数值产物。

## 3. 修复方案的批判性评估

### 方案 A（降低 mixing_beta + 推迟 gate）：治标不治本
- `mixing_beta: 0.4 → 0.1`：减缓电荷更新，但也会大幅减慢 SCF 收敛
- `deltap_inner_thr: 5e-7 → 1e-8`：推迟 gate，但根本问题是 gate 本身的不连续性
- **无法解决**：拓扑分支跳变、信噪比倒置

### 方案 B（gamma 稳定性 gate）：方向正确但不完备
- 检查最近 3 次 γ 的标准差 < 0.01 rad，确保 γ 稳定后才激活内循环
- **优点**：避免在 γ 振荡时启动内循环
- **缺陷**：
  1. 仍未解决信噪比倒置——即使 γ 稳定后激活内循环，电荷更新仍会将 γ 推离 target
  2. 0.01 rad 阈值是经验值，缺乏理论依据
  3. 不处理分支跳变——如果稳定性窗口内发生了 2π 跳变，标准差可能仍然很小

### 方案 C（分离三阶段）：物理上最正确，但工程量大
- 完全分离电荷和 λ 的优化
- **优点**：消除了耦合振荡的根源
- **缺陷**：
  1. 需要大量重构
  2. 可能收敛更慢（需要更多外循环来交替优化）
  3. 不处理拓扑分支问题

## 4. 被低估的问题：HK 修正的 ψ 依赖性

当前实现中，`compute_hk_correction` 依赖于当前波函数 ψ（`deltap_wannier.cpp:1141-1319`）：
```cpp
// HK = f(psi, lambda)
// M = F * C_L^dagger   ← 直接依赖 psi
```

这意味着内循环中即使冻结电荷密度，重新对角化也会改变 ψ，从而改变 HK 本身。这创造了一个 **自洽性问题**：内循环优化 λ 时假设 ψ 只通过重对角化变化，但 HK 本身也依赖 ψ，形成了内层不动点。

经典类比：这就像 DFT+U 中 U 矩阵依赖于轨道，但 U 矩阵又在构建 Hamiltonian——只不过 DeltaP 的情况更复杂，因为 HK 是 k 空间非局域的。

## 5. 总结：DeltaP 的独特困难层次

| 层次 | 问题 | 经典类比 | DeltaP 独有？ |
|------|------|----------|---------------|
| 1 | 双变量耦合振荡 | 磁性、DFT+U | 否（但更严重） |
| 2 | 信噪比倒置 | 无 | **是** |
| 3 | 拓扑分支不连续 | 无 | **是** |
| 4 | Gate 触发突变 | 无 | **是** |
| 5 | HK 的 ψ 自洽性 | DFT+U 的 n(ψ) 依赖 | 部分类比 |

**结论**：DeltaP 的 SCF 收敛困难不能简单套用经典方案（加强混合、Kerker 过滤等）。根本原因是 **拓扑可观测量对波函数的非平滑依赖** 与 **微扰级控制信号** 之间的结构性矛盾。方案 B 是合理的工程折衷，但长期需要：
1. 分支退绕的一致性保障（B16 修复）
2. HK 修正的自洽处理（内循环中 HK 应随 ψ 更新）
3. 可能需要在 λ 优化中显式考虑 dγ/dψ 的 Jacobian，而非将 γ 视为仅依赖 λ 的函数
