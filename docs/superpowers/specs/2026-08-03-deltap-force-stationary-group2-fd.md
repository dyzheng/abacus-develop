# DeltaP 组② 驻点协议判决 FD：O5 代理差距定量（2026-08-03）

## 0. 结论先行（重要）

知识文档（`2026-08-03-deltap-force-knowledge-update.md`）路线第 1 项的判决实验已执行
（最小判决矩阵：h2o1 O1-z，三几何全部收敛到 λ 驻点后做 FD）：

- **判决结果：FAIL，残差 84.8 eV/Å（判据 0.0129，超 6600 倍）——且是结构性失败，不是"差一点"。**
- **残差 100% 归因于 λ-leakage**：
  `∂E'/∂λ_O1 × (λ_st(plus) − λ_st(minus)) / 2δ = 224.4 eV/Ry × 0.002 Ry / 0.005292 Å = 84.82 eV/Å`，
  与实测残差 84.82 eV/Å **闭合到 5 位有效数字**。
- **根因**：dspin 定理的 DeltaP 版前提（λ 在约束驻点时 ∂E'/∂λ = −(γ−t) = 0）
  **不成立**——escon 记账观测量 γ（Wilson loop）≠ H_c 算符期望 ⟨Ô⟩_proxy（H_HR/H_HK）。
  实测 `∂E'/∂λ ≈ 222–224 eV/Ry`（O1 分量，线性），DeltaSpin（精确算符）情形下该量为 0。
- **推论**：任何"约束激活（γ≡t）"的 relax（内循环模式强收敛 λ）**力都不一致**——
  即使修好 D-8 内循环极限环，约束路径上的力仍错 ~85–420 eV/Å。
  **补 C 不解决**（C+R 在约束路径上已相消，本实验 λ≈2e-3 时 ≤0.01 eV/Å 量级）。
  出路是 O5（算符/记账形式），不是 C。

### 3.5 λ-leakage 闭合（判决的关键定量）

```
实测残差（分支 A）= 84.8164 eV/Å
∂E'/∂λ_O1（disp_plus，0→+0.002 实测）= 224.4 eV/Ry
Δλ_st/2δ = (0.002 − 0)/0.00529177 = 0.3780 Ry/Å
leak = 224.4 × 0.3780 = 84.82 eV/Å   ← 与实测残差闭合到 5 位有效数字
```

FD(驻点) = FD(λ=0) − leak = −0.7476 − 84.82 = −85.56 eV/Å ✓（与实测逐位一致）。

## 4. 分析

### 4.1 判决结论：A1+A2+B 不是约束路径上的精确力

FD 沿约束路径（γ≡t，λ=λ_st(R)）测量 `−dE'/dR|_constrained`。理论分解：

```
F_FD(驻点) = F_ana + (C+R) + λ-leakage
           = F_ana + λ·dγ/dR|_path − ∂E'/∂λ·dλ_st/dR
```

- 约束路径上 dγ/dR=0 → C+R=0（本实验 λ≈2e-3，实测上界 ≤0.01 eV/Å，可忽略）✓
- 但 ∂E'/∂λ ≈ 224 eV/Ry ≠ 0，且 dλ_st/dR ≠ 0（约束要求 λ 随几何移动）→
  **λ-leakage = 84.8 eV/Å 完全主导**。
- dspin 定理成立的前提是 ∂E'/∂λ=0，即 escon 观测量 = 算符期望（DeltaSpin 中 M≡⟨M̂⟩，
  `cal_mw_from_lambda` 同一算符构造 H 与观测量）。DeltaP 中 γ(Wilson)≠⟨Ô⟩_proxy，
  前提被破坏 → 判决为结构性 FAIL。

### 4.2 附带发现：驻点协议本身不适定

|γ_report−t|<1e-3 的停止判据在 disp_plus 有两个解（λ=+0.002 与 λ=+0.01），
E' 相差 1.768 eV → F_FD 从 −85.6 变到 −419.8 eV/Å，**结果取决于分支选择**。
根因：target-aware 分支选择使 γ_report(λ) 成阶梯（步长 ~6e-3 rad > 容差 1e-3）。
若改用 γ_raw（单调）作停止判据，λ_st(plus)≈−3e-3，E' 偏移 ~−0.67 eV → FD ≈ −125 eV/Å，
**仍 FAIL**。结论对 γ 定义稳健。

### 4.3 代理差距的构成（O5 定量的下一步）

- ⟨Ô⟩_proxy（H_HR 算符期望，E_H_HR/λ）≈ τ_O1⟨P̂_O1⟩ = 0.5×7.2 = +3.6（无量纲，Ry/Ry），
  escon 观测量 γ_report ≈ −5.5 → 记账差距量级 ~9 Ry/Ry ≈ 120 eV/Ry；
  实测 ∂E'/∂λ ≈ 222 eV/Ry，其余 ~100 eV/Ry 来自密度响应（ψ 重收敛）。
- 精确分解需 hhrdbg 打印（⟨P̂_I⟩ 现 #if 0）——列为下一步测量的候选。

### 4.4 对生产 relax 的含义（量化）

| 场景 | 力误差（O1-z 为代表） | 说明 |
|---|---|---|
| 同步弱 GD（λ≈0.001(γ−t)，λ≈1e-6） | 0.02–0.32 eV/Å | 上轮组②，λ 漂移主导；约束实际很弱 |
| 同步 target=0（λ*=−5.5e-3） | +0.615 eV/Å | 上轮组①，C+R 主导 |
| 约束激活（γ≡t，内循环/驻点 λ） | **84.8–419 eV/Å** | 本轮，λ-leakage 主导 → 结构性不可用 |
| 纯 DFT（无 deltap） | 3e-4 eV/Å | 对照，标准力自洽 |

**生产 relax 若以"约束激活"为目标（内循环模式是知识文档认定的正确 λ 收敛方式），
力必然不一致。** 同步弱 GD 的"可用性"只是约束未被真正满足的表象（B-6 后 γ 常到不了
target，知识文档 D-5 已记录）。
