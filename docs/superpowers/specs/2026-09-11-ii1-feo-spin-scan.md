## 2. 测试设置

### 2.1 体系修正：计划点名的基线不是 FeO

计划 §II-1.1 写「继承 `tests/17_DS_DFTU/11_PW_DFTU_S2_FeO` 的 STRU/KPT 原样
（rocksalt FeO，AFM）」。**该目录名与内容不符**：`11_PW_DFTU_S2_FeO/STRU`
只有 `TOTAL ATOM NUMBER = 2`、唯一元素 `Fe`，两个原子位于 (0,0,0) 与
(1/2,1/2,1/2)——正是 rocksalt 原胞的 **Fe 子晶格**，不含 O。

真正的 FeO 算例是 `tests/17_DS_DFTU/50_FeO_O_first_Fe_second`（O 2 + Fe 2，
同一 rocksalt 原胞，`ecutwfc 50`，`orbital_corr -1 2`，`hubbard_u 0 5.0`）。
**本算例改继承 50 号**：(a) II-1 问的是「TM d 矩在氧化物中的约束能力」，无 O
的 Fe 子晶格回答不了；(b) 计划自己写的「Fe 基态矩 ~3.5 μB 量级」正是 50 号
收敛出的 ±3.485 μB，11 号的 Becke 读数 3.24 对不上；(c) 50 号 Γ 点 4 原子，
比 11 号（2×2×2 MP × 2 spin）更便宜。11 号仍跑了同一约束作旁证（§3.5）。

### 2.2 生产设置

- FeO rocksalt 原胞，2 O + 2 Fe，a = 8.190 Bohr；
- **下标：0,1 = O；2,3 = Fe**（Fe 2 = `mag +2`，Fe 3 = `mag −2`，参考态 AFM）；
- PW / `dav_subspace` / nspin 2 / `symmetry 0` / Γ 点（1×1×1，继承基线）/
  `ecutwfc 50` / Gaussian smearing 0.01 Ry；
- DFT+U：`orbital_corr -1 2`、`hubbard_u 0 5.0`、`onsite_radius 3.0`；
- 参考态 Fe 矩：`atomic mag: 2 +3.48496887` / `atomic mag: 3 −3.48496515`；
- 约束：`type spin`、`weight becke`、`target_mode delta`、`mu_max 5.0 Ry`、
  `thr 1e-4`、单原子下标 2；
- 生产 `scf_thr 1e-7`、`scf_nmax 900`（依据见 §3.3）；力 FD 不在本算例。

### 3.6 根因：继承基线的参考态是亚稳态（本轮最重要的发现）

W2 实验：把 W1（一次被扰动过的密度）当作初猜，跑**无约束** SCF：

| 用例 | 约束 | E_tot [eV] | Fe on-site 矩 [μB] | TMAG | AMAG | drho |
|---|---|---|---|---|---|---|
| S0B / S1x_base_1e8（harness 参考） | 关 | −7652.3958756613 | +3.48497 / −3.48497 | 0 | 7.653 | 8.7e-9 |
| **X_lowstate_unconstrained（W2）** | **关** | **−7653.0079614903** | **+3.71484 / −3.71484** | 0 | 7.883 | **3.4e-9** |

两个都是收敛的自洽解（AFM，TMAG 均 ≈ 0）。**后者比 harness 参考态低
0.612 eV**。也就是说 `50_FeO_O_first_Fe_second` 在它自己的 Γ-only k 网格
上至少有两条 AFM 解，而 `result.ref` 记录的是**高的那一条**。

这一个事实解释了本轮几乎所有的异常：

- 约束扫描里那些「比参考态还低」的 CONVERGED 点（§3.4 正侧 +0.3/+0.5、
  §3.3 的 1e-8 点、§3.4 冷启动 −0.1/−0.3）不是约束能量记账错误，而是 SCF
  掉进了这条更低的无约束解；
- 由此这些点的 μ* 是在**另一条分支**上测的，与 δ=+0.1 点的 κ 不可比；
- 也解释了为什么冷/热启动给互斥答案——两者只是恰好落入不同解的盆地。

顺带记录一个**协议陷阱**：单侧一点的 μ\* vs dE/dQ 校核会稳定地差 2 倍。
δ=+0.1 点：dE/dQ = +0.03754 Ry/μB，−μ* = +0.073595 Ry/μB，比值 1.96。
无约束态是 E₀(Q) 的驻点（λ(Q_ref) = 0），单侧割线等于 λ(Q\*)/2；I-1 用
的「μ\*(midpoint) vs −dE_tot/dδ」正是补掉这个 2 的中点口径。直接把端点
dE/dQ 对 μ\* 会稳定差 2，容易被误读成 bug。

## 4. 分析

### 4.1 三个验证问题的裁定

| 问题 | 裁定 | 依据 |
|---|---|---|
| 1. TM d 矩自旋约束能力 | **有资格通过**：机制可用、能收敛、读数可复现——FeO δ=+0.1（μ* = −0.0736 Ry，三次运行差 ≤6.7e-7）与 Fe 子晶格 δ=+0.1（μ* = −0.00811 Ry）两点 CONVERGED；但**只有 FeO δ=+0.1 一个点落在可信分支上**，尚不足以给出 κ | §3.2、§3.5 |
| 2. DFT+U 与约束同开兼容性 | **通过（首测）**：两条势通道同开、约束全程活跃、两个独立体系均收敛（含 CONVERGED 与 maxdev=0），未见通道冲突 | §3.5、§3.2 |
| 3. μ vs λ 口径归因 | **未启动**（II-1b，等 V3b） | 计划拆分 |

### 4.2 计划假设的可达窗口不成立，但根因是体系不是框架

计划 §II-1.1 假定 ±0.1/±0.3/±0.5 μB 是「温和扰动」。实测：

- **正向（加矩）**：冷启动只有 δ=+0.1 可信；δ=+0.3/+0.5 冷启动失败、
  热启动「收敛」但落在低 0.6/0.32 eV 的另一条分支上。
- **负向（减矩）**：六次尝试（冷/热 × 400/900 迭代）**全部失败**；
  μ = +0.05 Ry（硬编码首步）已足以翻转 Fe 2 的磁矩。

但 §3.6 表明，主因**不是**框架的 μ 步长或收敛控制，而是**继承基线的
参考态本身是亚稳态**。在这个基线上，任何扰动（包括一个正确的小 μ）都可能
把 SCF 推进另一条低 0.6 eV 的解，而外环只检查 `|Q − target| < thr`，
无从分辨「达标」与「换了状态」。

框架侧确实仍有三条独立的改进项（在修好基线后仍然需要）：

1. **首步步长不能配**：`step_max` 硬编码 0.05 Ry，首步无信息时必取满量程；
   软响应通道（本体系负侧 dQ/dμ ≈ +24 μB/Ry）需要小一个量级的首步。
2. **没有分支/局域性守卫**：突变（Q 跳 0.33）没有任何拒绝或回退机制，
   外环会接受任何撞上靶点的 Q。
3. **可观测量与目标物理量脱钩**：掉分支后 Becke 读数 1.5–1.9 μB 而
   on-site Fe 矩仍是 ±3.7 μB（§3.4）。这正是 II-1b 的核心，且已经证明它
   不只是口径校核、而是决定约束能不能用。

### 4.3 计划风险的兑现情况

| 计划风险 | 兑现 | 说明 |
|---|---|---|
| 「DFT+U + 约束同开若 SCF 震荡 → 先关 U 做对照隔离」 | **部分** | 震荡确实存在（§3.3），但不需要关 U 的对照就能归因：无约束同阈值 18 步收敛，所以震荡来自约束通道 + §3.6 的多解 |
| 「AFM 反平行子晶格需约束两个 Fe」 | **命中** | 单原子约束在 δ≥+0.3（冷启动）把 `TMAG` 从 0 拉到 2.0，单侧约束会破坏反平行配对 |
| 「nbands 不足（基线注释掉了 nbands=28）」 | **未命中** | 默认 `nbands = 33`（22 占据 + 11 空），空带充足 |

1. **先修基线（阻塞一切）**：在给 50 号算例加重约束之前，必须先确认其
   参考态。最小做法：把 S1 的判据从「与 `result.ref` 一致」扩成
   「与 `result.ref` 一致 **且** 参考态是无约束 SCF 的最低解得」——
   本轮 W2 显示后者不成立。候选修法：(a) 换 2×2×2 MP（Γ-only 的
   FeO 磁序描述本就不可靠）；(b) 用 `51_FeO_Fe_first_O_second` 交叉校验；
   (c) 若必须保留 Γ-only，就在 S1 阶段显式多初猜搜索并把最低解写进
   `result.ref`。
2. **框架侧（阻塞 stage B）**：
   a. 把 `MuSolverParams::step_max` 提成输入参数；首步用**试探步**
      （例如先探 0.005 Ry 估斜率）而不是固定满量程。
   b. 加**分支守卫**：外环比较连续两个外步的 Q 跳变量，超阈值时拒绝该步
      并回退（复用上一步密度）或直接把该点判 FAIL，而不是记 CONVERGED。
   c. 补 `RUNNING` 与 `UNREACHABLE` 之间的第四态（「状态跳变」）。
3. **II-1 复跑**：基线 + 守卫 + 试探步落地后重跑 S3 六点、S4 熔断、S5
   DeltaSpin 对照、S2R 已验证可保留。
4. **II-1b**：等 V3b 只读观测口，用同一收敛密度同时读 Becke 矩与 on-site
   投影矩，定量给出两条口径的映射；§4.2 第 3 条是它的直接输入。
