## 1. 结论先行

1. **D1 的 κ 拟合判据不可执行（病态），定性结论转向 D2 直接测量**：
   E'(λ) 曲率被算符通道（escon/Γ）主导——proxy 模式曲率 b ≈ 15–30 eV/Ry²，
   γ 通道极化能贡献仅 ~0.8 meV（占 42 meV 总变化的 ~2%），E'(G) 不构成单值
   抛物线；ow 模式（T-18 a2）ΔE=−0.13 eV @ λ_O=−0.0156，曲率 ≥10²–10³ eV/Ry²
   量级。两模式均无法从 E'(λ) 拟合 κ（假说 §3 D1 判据作废，改用 D2）。
2. **D2 实测 dG/dE_field = 0.316 ± 0.01 rad/a.u.**（LSQ 残差 9.3e-5 rad），
   假说预言 πα/L = 1.03 rad/a.u. —— **实测低 3.3×，超 2× 判据线（FAIL）**。
   换算 α_LCAO = 3.02 Bohr³（假说用实验值 9.8，LCAO 紧缩基低估 ~3.3×）；
   κ_phys(D2) = (eL/π)²/α = **60.4 Ry/rad²**（假说 18.6 的 3.2×，同量级偏硬）。
3. **物理刚度叙事被加强而非削弱**：真实均匀电场也只能以 0.32 rad/a.u. 移动 G——
   把 γ 推离自然值 0.1 rad 需要 E ≈ 0.3 a.u. ≈ 15 V/Å（暴力场）。弱耦合是
   体系物理（小基组极化率锁死），不是算符失配；T-18 的 0.26 rad/Ry 已是
   物理尺度。§4.1 路线（叙事修正 + EFC 换锚 + A+ 窗口产品化）成立，但窗口
   数字需按 α=3.0、κ=60 重算（更窄）。
4. **E_eff 公式裁决：现行代码 (a) λ/(2a) 低估 5–10×，(b) πλ/L 更优但低估
   1.6–4×**。实测（proxy，ΣG 口径）E_eff^(meas) = 0.177 a.u./Ha =
   (a) 的 5.3×、(b) 的 1.7×；ow 口径（O 原子）0.329 a.u./Ha = (b) 的 3.1×。
   代码 `[E-field operator-ramp]` 打印沿用 (a)，建议换 (b) 并标注实测换算。
5. **附赠确认**：E'(E) 线性项给出 μ₀ = 0.763 e·Bohr = **1.94 D**（实验 1.85 D，
   5% 吻合）——h2o1 的 z 轴永久偶极和 FINAL_ETOT_IS 含 etotefield 的记账自洽；
   E'(E) 二次项同样被约束态响应污染（与 E'(λ) 同族），α 只能从 γ(E) 取。

## 5. 分析

1. **D1 病态的根因**：E' = E_KS(ψ*) 的 λ 依赖被 escon = −ΣλΓ 通道主导
   （Γ 随 λ 线性漂移 dΓ/dλ≈−4.2，T2/T3 已证），γ 通道能量 ∝ ½κΔG² 在
   |λ|≤0.05 下仅 ~1 meV，被淹没 50×；因此"沿约束路径拟合 E(G) 抛物"的
   前提（能量由极化决定）在算符-记账框架内不成立——这是假说的测量协议问题，
   不是物理刚度命题的证伪。
2. **D2 的直接性**：真实锯齿场绕开算符通道，γ(E) 是干净的极化响应
   （残差 1e-4 rad 量级），α_LCAO = 3.0 Bohr³ 是 h2o1 LCAO 基组的实测极化率。
   物理刚度假说在"数值体系"层面成立且更强（κ=60 而非 18.6 Ry/rad²）；
   假说与实验的差距（9.8）归因于基组，不归因于算符。
3. **对 T-18 的重新解读**：ow 的 0.26 rad/Ry 相对物理上限 1/κ≈0.017 rad/Ry
   （D2 口径）已放大 ~15×（算符范数放大），proxy 的 −0.05 也达 ~3×——
   两模式都远超真实场响应，不存在"算符再准 10×"的空间。L3.1/Ô_θ 立项的
   定量基础（响应放大）由此削弱；EFC 价值重锚到路径泄漏消除（§4.1 路线 2）。
4. **工作窗（按泄漏预算反解，评审 2026-08-13 修正——不按可达性拍）**：
   泄漏锚 T3（Γ-hold）残差 0.0138 eV/Å @ λ*=1.09e-3 Ry → 斜率 ~12.7 eV/Å/Ry；
   T3'（γ-drive）0.502 @ λ*_avg=1.05e-2 → 斜率 ~48。按 0.02 eV/Å 预算：
   **|λ*|_max ≈ 0.4–1.6e-3 Ry → |ΔG|_max ≈ 1e-5–5e-5 rad（0.01–0.1 mrad）**。
   生产 γ-hold 只允许靶点≈自然值；ΔG=0.005 rad → λ*=0.18 Ry → leak≈2.3
   （T3 线性）–8.6（T3' 线性）eV/Å ≫ 0.02（判据 100–400×）。T-5' 的 ±0.013 rad
   只是"SCF 可收敛"可达域，不是力精度窗。
   EFC（E_phys=E_tot+λ(G−t)，∂E/∂λ≡0）是大 λ 场景下恢复力精度的唯一路径
   （§4.1 路线 2）。
