## 1. 问题的理论收拢（为什么对不上）

约束路径（λ*(R) 使 γ≡t）上的精确力：

```
F_path = F_Pulay + (Γ_op − t)·(∂γ/∂R)/(∂γ/∂λ)
         │           │                │            └ ∂γ/∂λ：γ 对 λ 的响应（可测）
         │           │                └ ∂γ/∂R：Wilson 环梯度（未实现）
         │           └ Γ_op = Tr[ρ·Ô_c]，H_c 算符期望（≠ γ，实测差距 ~224 eV/Ry 来源）
         └ 已实现且验证（A1+A2+B）
```

三个乘子的可消除性分析：
- **(Γ_op − t)**：可通过改 escon 记账消除（Route A）；
- **dλ*/dR = −(∂γ/∂R)/(∂γ/∂λ)**：γ 软（∂γ/∂λ~10³ rad/Ry）使其病态放大，
  且**分支阶梯使其不适定**（disp_plus 两个"驻点"λ，E' 差 1.77 eV）——
  必须先修分支连续性，否则任何路线都无法验证；
- **∂γ/∂R**：只有解析实现才能严格归零残差（Route B）。

**已排除的方向**：补 C 项（约束路径上 C+R≡0，对驻点残差无效）；
修内循环极限环（只解决 λ 收敛机制，不解决 λ-leakage 本身）。

## 2. 三条路线

### Route A（O5b）：escon 改用算符期望记账（先做，1–2 天原型）
escon = −λ·⟨Ô⟩（⟨Ô⟩ = E_H_HR/λ + E_HK/λ，hhrdbg 机制已有）⇒ E' ≡ E_KS(ψ*_constr)，
(Γ_op−t) 项恒消。残余误差 = λ·dΓ/dR|path ≈ **0.05 eV/Å** 量级（λ~2e-3 Ry ×
∂Γ/∂λ~10³ × dλ*/dR~1.7e-3 Ry/Å 估算）——仍 4× 超严格判据，但比现状改善 ~2000×，
对多数 relax 场景可用（力误差 0.05 eV/Å → 平衡键长误差 ~0.005 Å）。
代价：E' 物理含义改变（= 约束态 KS 能量）；偶极/极化率记账链（F1/F2/F3）
联动重验；锚点重建。

### Route B：解析实现 ∂γ/∂R（严格解，~1 周）
修正项 (Γ_op−t)·(∂γ/∂R)/(∂γ/∂λ) 全解析实现。∂γ/∂R 需要 Wilson 环连乘的
本征相位梯度（∂M_j/∂R 与 compute_hk_force 共享 SMO 导数链，~300 行 +
分支感知链式法则）。副产品：C 项、Born 有效电荷、冻结 λ 扫描力全部解锁。
这是**唯一严格**的路线，也是对"极化-力耦合"物理（Z*）的直接实现。

### Route C（O5c）：弱约束产品化（兜底，纯文档）
同步弱 GD 现状（力误差 0.02–0.32 eV/Å）明确定位为"采样/定性"用途，
写入 LIMITATION。若 A、B 均不达预期，这是发布底线。
