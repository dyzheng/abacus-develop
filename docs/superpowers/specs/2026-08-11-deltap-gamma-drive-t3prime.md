## 5. 分析

1. **评审定理正确但不足以支撑 T3'**："力一致性是记账性质、与驱动信号无关"
   对——E'=E_KS(ψ*) 恒等式在任意 λ*(R) 路径成立。但 **FD 残差 ∝ λ*²**，
   而 λ* 强烈依赖驱动信号：γ 驱动需要 λ* = Δγ/(dγ/dλ)，γ 耦合弱 → λ* 大。
2. **弱耦合定量（用评审自己的 Q1 数据）**：dγ/dλ ≈ −0.3 rad/Ry（Q1/T2 §3.4）
   vs dΓ/dλ ≈ −4.2 Ry/Ry → 同一位移下 λ*_γdrive ≈ 14× λ*_proxy；
   O(λ)² 泄漏 ≈ 200×。T3 闭合式 leak = −λ*·(dΓ/dλ)·Δλ*/(2δ)：
   代理版 λ*=1.09e-3 → leak=0.0127 eV/Å（实测 0.0138 ✓）；γ 驱动 λ*≈0.011
   → leak≈1.3 eV/Å（实测 −0.50 同量级）。**T3' 即使 γ 完美收敛也过不了
   0.02 判据**——"更干净"的前提（λ* 小）被弱耦合破坏。
3. **单发内循环的冻结-自洽符号分裂**：+δ 腿内循环在冻结密度下把 |γ−t| 收敛到
   6e-4（λ=−0.021），密度再平衡后自洽 γ 残差回到 4.9e-3——冻结响应与自洽
   响应符号相反（§4.4），且无重触发机制。这正是 T-2 根因②"单 α 线搜索反号
   分量"在 γ 空间的重现，印证 T-7'（per-atom Jacobian）是两套驱动共同需要
   的基建。
4. **装置教训（首轮踩坑）**：T3' 首轮缺 `branch.dat` → 连续性锚无参考 →
   Stage-B 回退 target-aware → 报告 γ 钉在靶点（自证循环，T4a 同款伪影）→
   内循环追 2e-3 的伪残差、λ 漂到 6.4e-3。补参考后 base 干净（8.9e-16）。
   **任何用 γ 报告做判据的协议必须先确认连续性锚已激活**（branch.dat 存在
   且 `branch_anchor=continuity`）。
5. **历史印证**：08-03 驻点实验（旧记账 γ 驱动）残差 84.8 eV/Å，λ-leakage
   闭合到 5 位有效数字；Route A+ 换 Γ 代理记账才到 0.0138。T3' 本质是
   08-03 的 γ 驱动驻点 FD 换新记账重跑——新记账修的是 escon 恒等式，
   **没修 γ↔λ 弱耦合本身**，所以失败是继承性的。

## 6. 结论与下一步

- **T3' 不纳入生产协议**。驻点 FD 的唯一合法协议 = Γ 代理驱动（T3 已 PASS，
  0.0138 ≤ 0.02，机制闭合 1.07）。γ 直驱保留为显式开关（`deltap_drive=gamma`），
  合法工作区 = 自然点附近的小靶点（base 验证 ✓），不用于 FD 腿。
- **T-7' 前置证据 +1**：冻结-自洽响应分裂 + 弱耦合非单调 = per-atom Jacobian /
  自洽 λ 重触发是刚需（评审已列 T-7'）。
- **T-5' 窗口测绘**：0.995/1.005 双向单侧可达域记录改用 proxy 驱动（Γ 约束），
  γ 报告仅作外循环读数。
