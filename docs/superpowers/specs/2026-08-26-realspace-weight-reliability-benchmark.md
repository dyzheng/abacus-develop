# 实空间权重框架：约束可靠性机制与电荷划分 benchmark 对标

> 问题：(1) 方案如何保证约束可靠性；(2) 其电荷划分方式可对标哪些成熟算法做 benchmark。
> 依据：方案文本 + 前三轮评审（2026-08-26 三份）+ DeltaP/DeltaSpin 历史记录。
> 本轮无代码改动，属评审轮（同日第四轮）。

## 一、约束可靠性的保证机制（方案内建，分四层）

### 1. 测量层（口径良定义）——方案最强的一层
- **逐点 sum rule 断言**：预处理 assert max|Σ_I w_I − 1| < 1e-12（数学恒等，非统计）；
- **永久审计行**：每 SCF 打印 Σ_I N_I vs N_el——把 SMO 时代"口径错误潜伏数月"的病（2026-07-11 raw_sum 5.91 才发现）变成每步可见；
- **观测量 = 注入算符**：V_con=Σμw 与读数 ∫w·d 用同一权重，天然满足 dspin 恒等式三条件——约束"量的就是推的"，这是 DeltaP 用 84.8→0.0138 eV/Å 力残差改善验证过的可靠性根基；
- **可复现性元数据**：权重类型/半径表或 promolecule 版本哈希随输出走（§7.4）——口径脱离元数据不可引用。

### 2. 物理层（目标可达、μ 有界）
- **delta 模式**（t=Q_ref+Δ）：吸收口径偏移与 Hirshfeld 参考密度依赖；
- **熔断**：|μ|>μ_max 判不可达并报告 Q(μ) 扫描端点，而非放任发散（与 DeltaP λ 预算护栏同族且已被失控事件证明必要）；
- **可达性余量标签**（§7.1）：距饱和边界多远，防重蹈 SZV 假封顶。
- 缺口（前轮 R1/R4）：μ 量级诊断表（0.01–0.1 Ry 正常区）无仓库内定标依据；物理可达域由体系刚度封顶且不可跨体系外推——可靠性保证只能到"不可达时如实报告"，不能保证"目标必达"。

### 3. 数值层（SCF 收敛、力正确）
- 外环收敛后才更新 μ + 步长截断；冻结权重（T-17 背书的稳定模式）；罚函数可选平滑；
- 力由包络定理只剩显式项，FD 验收走 stationary4 协议（三体系 21/21 腿 PASS 的现成工具）；
- 缺口（前轮 R2/R3/R9）：secant 缺 κ 限幅/翻号检测；反假收敛检验（μ=0 不得收敛到非自然靶点）未列入 V1–V7；多约束 Broyden 在噪声下有精神病史（T-7''）。

### 4. 验证层（V1–V7 + 输出证书）
- 验证矩阵覆盖 sum rule/基准电荷/可达性/偶极对偶/力/回归/熔断；第七部分把残差、线性度、收敛元数据定义为机器可读证书。
- 缺口（前轮 R5/R6）：V4（偶极↔efield 对偶）是历史最高危验证类型，通过标准需细化；应力完全无验收项。

**一句话**：方案的可靠性设计哲学是"数学恒等式兜底（sum rule）+ 记账一致性兜底（观测量=算符）+ 护栏兜底（熔断）+ 证书兜底（输出残差）"，四层中三层有仓库历史直接背书；真正未闭环的是"物理可达性"这一层——它只能诊断、不能保证，且窗口不可外推。

## 二、电荷划分的算法对标

### 2.1 方法论谱系定位
方案的权重划分不是新发明，而是量子化学最成熟的两类实空间布局分析（population analysis）：
- **Becke 分区**：Becke (1988) JCP 88, 2547—— multicenter 数值积分的模糊 Voronoi 分区（ABACUS `module_grid/partition.h` 已实现原语）；作电荷分析即 Becke 电荷；
- **Hirshfeld 分区**：Hirshfeld (1977) 的 stockholder 划分；其迭代改进 Hirshfeld-I / ISA / MBIS 是文献 benchmark 数据最丰富的电荷方法族（方案明确只取固定 promolecule 版作约束，迭代版留作后分析——正确决策，见前轮 §4 负向验证）。

### 2.2 关键事实：该框架 = 文献标准 CDFT
方案 §6.4 自己点破了接口：**"空间权重 × 密度通道 + Lagrange 乘子"正是 Wu & Van Voorhis 约束 DFT（CDFT）的标准形态**。CDFT 文献三十年积累本身就是最权威的 benchmark 库：
- **Q-Chem / NWChem / CP2K 的 CDFT 实现**：均用 Hirshfeld 或 Becke 权重约束电荷/自旋——同样的权重定义、同样的约束形式，可直接对拍 Q(μ) 曲线、约束能 W=ΣμΔQ、透热态能隙；
- **Marcus 重组能 λ**：给体-受体体系（H₂O₂ 解离、CT 复合物）的 CDFT 重组能是文献标准考题（§6.4 的正反向 μ 差估计）；
- 自旋约束对标：CDFT 磁矩约束文献 + 本仓库 DeltaSpin 现有实现同靶点对拍（口径偏移可解释即可）。

### 2.3 可执行 benchmark 清单（按成本排序）

| # | 对标对象 | 对拍内容 | 精度预期 |
|---|---|---|---|
| B1 | 文献 Hirshfeld 电荷（H₂O 等小分子，Hirshfeld/MBIS 论文表） | 无约束自然电荷（方案 V2 已含：O ∈ [−0.35,−0.20] e） | 同泛函同基组下 ~0.01 e |
| B2 | **Multiwfn 等后处理工具**在同一收敛密度上算 Hirshfeld/Becke | 权重实现正确性（消掉电子结构差异，纯对拍分账规则） | 逐位/1e-6 级 |
| B3 | ABACUS 内部 PW≡LCAO | 同一权重、同一密度网格，两基组读数逐位一致（方案 §3.6 核心卖点） | 1e-8 级 |
| B4 | Q-Chem/CP2K CDFT | 给体-受体对 ΔQ 扫描：Q(μ) 曲线形状、约束能、重组能 | 趋势+5–10%（泛函/基组差异） |
| B5 | DeltaSpin 现有实现 | 同磁矩靶点下的约束态能量/自旋密度 | 趋势一致、口径偏移可解释 |
| B6 | 有限电场（ABACUS efield 模块） | 偶极约束 Lagrange 对偶（方案 V4） | 前轮 R5：历史最高危，需细化协议 |
| B7 | Bader（Henkelman 工具）/DDEC | 仅作电荷趋势对照（口径不同，数值不可比） | 定性 |
| B8 | Berry 相位极化（ABACUS/DeltaP） | 分子/周期体系的偶极-极化交叉核对 | 定性-半定量 |

### 2.4 对标的护城河与坑
- **护城河**：B2+B3 组合是别的路线给不了的——SMO/Löwdin 路线基组相关，不存在"PW≡LCAO 逐位一致"的 benchmark；实空间权重使 ABACUS 第一次能做基组无关的内部自对拍。
- **坑**：Hirshfeld 电荷系统性偏小（方案 4.2 自承）——绝对值对标必须同泛函同基组同 promolecule 构造，否则 0.05–0.1 e 级口径差会淹没结论；B4 跨代码对拍同理，只能比曲线形状与导数（硬度矩阵），不能比绝对能量。
