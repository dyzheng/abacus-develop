## 1. D1：E_eff 等效电场公式重推导

### 1.1 旧公式的退役原因

现代码（`deltap_scf.cpp:442-456`）：`E_eff = −λ_avg·π/(2·a_α)` a.u.。
其推导基于 λ–γ 共轭（−λγ ↔ −E·P·Ω），π 因子来自 γ↔P 换算的 2π 泄漏；
π/2 因子从未定稿（F1 备忘录悬案）。**λ 共轭对象改为 Γ 后，该推导基础消失。**

### 1.2 新推导（算符斜坡定义，第一性原理）

约束算符的物理内容本身就是 ramp 势——与记账无关，直接从 H_HR 读：

```
电子权重全在原子 I 上时感受的势：V_I = λ_I·τ_α(I) = λ_I·z_I/a_α
（τ_α = z_I/a_α 分数坐标，a_α = 该方向晶胞周期，Bohr）
均匀电场 E（Ha/Bohr）给电子的势能：V = +E·z（电子电荷 −1 a.u.）
逐项匹配 ⇒  E_eff = λ_I / (2·a_α)  [a.u.]     （Ry→Ha 因子 1/2）
                     = λ_I / (2·a_α) × 51.422  [V/Å]
```

**注意**：π 消失。新公式与旧公式差 π 倍且符号相反——旧公式是
γ-共轭推导的遗留，F1 备忘录的"π/2 悬案"很可能就是错配的共轭对象所致。
符号约定在实现时与 efield（锯齿场）对照实验一次性钉死（见验证锚点 V1）。

### 1.3 交叉验证定义（焓斜率，可测量）

```
E_eff^(enthalpy) ≡ ∂E'/∂μ|path = (∂E'/∂λ)/(∂μ/∂λ)
Route A+ 下 ∂E'/∂λ = −λ·∂Γ/∂λ（O(λ)，§2.2）
⇒ E_eff^(enthalpy) = λ·(∂Γ/∂λ)/(∂μ/∂λ)
```

两个定义的比值 = 代理质量的现场诊断：Γ 与 γ 完全同构时两者相等。
每次运行可同时打印两个 E_eff，差异即 Γ–γ 失配的直接观测量。

### 1.4 验证锚点

- **V1**：H2O 锯齿场对照（P10 机制）：同一 Δμ 下 DeltaP 的 λ 与 efield 的 E
  比对，钉死符号与数值因子（预期 E_eff = λ/(2a) 在 10% 内，误差=代理差距）。

## 2. D2：力公式全集（Route A+ 严格版）

### 2.1 E' 恒等式

```
E' = E_tot + escon_new = E_tot − Σ_I λ_I·Γ_I ≡ E_KS(ψ*)
```

### 2.2 λ 响应（dspin 形态恢复）

```
∂E'/∂λ_I = Γ_I − Γ_I − λ_I·∂Γ_I/∂λ = −λ_I·(∂Γ_I/∂λ)     （O(λ)，一阶小量）
```

对照现状（γ 记账）：∂E'/∂λ = Γ_I − γ_I − λ∂γ/∂λ ≈ 224 eV/Ry（O(1)）。
**预言**：Route A+ 后重测 λ 扫描，斜率应降至 ~λ×(∂Γ/∂λ) 量级
（λ=0.01 Ry 时 ≲ 1 eV/Ry，相比 224 缩小 200+ 倍）。

### 2.3 冻结 λ（组①）精确力

```
F_exact = F_std + Pulay(λÔ) + λ·dΓ/dR|full
          └已实现=A1+A2+B┘   └残余项┘
残差 = λ·dΓ/dR|full ≈ 0.002 Ry × O(1 rad/Å) ≈ 0.01–0.05 eV/Å（估算）
```

### 2.4 约束路径（组②/relax）精确力

Γ 激活（dΓ/dR|path = 0）时响应-Pulay 恒等式恢复（dspin 同构）：

```
F_exact(path) = F_std + Pulay(λÔ) − λ(∂Γ/∂λ)·dλ*/dR
                              └ O(λ) 路径泄漏 ┘
```

**可证伪预言（T3）**：驻点组② 残差 84.8 eV/Å → **≤0.02 eV/Å**。
（附带：λ 更新残差改用平滑 Γ 后，dλ*/dR 的分支阶梯污染消失。）

### 2.5 实现注意

Pulay(λÔ) = A1+A2+B **一行不改**——恒等式恢复后它们自动是正确代表。
力接线无需任何改动，改动只在 escon 与残差口径。

## 3. D3：应力公式（与力同构）

```
σ = −(1/Ω)·dE'/dε
dE'/dε = dE_KS/dε（标准应力模块，W 含全 ε，自动）+ S1（H_HR 对形式应力，已实现）
        + H_HK 应力（未实现，同 B 的应力版）+ escon_new 的应变导数
escon 侧：−λ·dΓ/dε = −λ[∂Γ/∂ε|_ψ + (δΓ/δψ)(dψ/dε)]
```

- τ 是分数坐标 ⇒ 固定分数坐标应变下 ∂τ/∂ε = 0，无 A2 类应力项（与旧结论一致）；
- E_tot 侧的 +λ∂Γ/∂ε（Pulay 应力 S1）与 escon 侧的 −λ∂Γ/∂ε 对消，
  残余 = **λ·dΓ/dε|full**，Γ-激活路径上 → 0（与力完全同构）；
- **遗留**：H_HK 应力未实现（B 的应力版），Route A+ 不解决，列 LIMITATION。

**验证锚点 V2**：变胞 ±0.1% FD 应力（h2o1，约束激活），残差预言 ≤0.02 eV/Å
对应应力判据。

## 4. D4：E(λ)/E(γ) PES 扫描口径（F3 语义修复）

```
旧记账：E'_old(λ) = E_KS(ψ*(λ)) + λ(Γ−γ)  ← 被失配项污染，PES 不可直接物理解读
新记账：E'(λ)   = E_KS(ψ*(λ))            ← 约束态 KS 能量，物理上干净
```

沿约束路径的能量面 E(P)：通过外循环建立的 (t_Γ, γ, E') 轨迹直接采样：

```
E₀(μ) 曲线：横轴 μ(γ)（F2 换算，不变），纵轴 E'（新记账）
逆极化率：α⁻¹ = d²E₀/dμ²（直接二次拟合，无需任何场换算）
```

**这是 Route A+ 的隐藏红利**：旧记账下 PES 扫描的能量口径一直有
λ(Γ−γ) 污染（BN 采样轮"能量在噪声底"的结论不受污染影响——E 差 <1e-5 Ry，
但该轮 λ 也极小；大 λ 扫描的结论需用新记账重做）。

**验证锚点 V3**：BN 9 点采样用新记账重跑（或事后重算 escon_new），
确认刚度 <1e-6 Ry/rad² 结论在新口径下不变。

## 5. D5：极化率提取链（P01/P05/P10）

### 5.1 μ 的提取（F2，不变）

γ → unwrap → ÷自旋因子 2 → μ（Debye）。γ 照常测量，不受影响。

### 5.2 α 的两个新公式（λ→0 极限）

```
算符斜坡口径：α = dμ/dE_eff = 2·a_α·(dμ/dλ)|_{λ→0}
焓斜率口径：  α = (∂μ/∂λ)² / (∂Γ/∂λ)|_{λ→0}
```

两口径应在代理良好时一致；**与 efield FD 参考 α（P01 通道①）三方比对**。

### 5.3 P10（E-D 曲线对照）的新判据公式

efield 侧给的是电焓 F(E) = E₀ − E·μ；DeltaP 侧给的是约束能量 E'(λ) = E₀(μ)。
统一口径：**两侧都画 E₀(μ)**。

```
DeltaP：直接得 (μ(λ), E'(λ)) 点列
efield：μ* = −dF/dE；E₀(μ*) = F(E) + E·μ*
判据：两条 E₀(μ) 曲线在窗口内偏差 < 1e-3 eV（拟定）
```

旧判据依赖 F1 的 E=−πλ/(2a) 换算——**判据公式随 §1.2 全部替换**。

**验证锚点 V4**：H2O 的 P10 双通道 E₀(μ) 曲线重合度。

## 6. D6：P17 场致弛豫对照协议

匹配条件从"场相等"改为"**极化相等**"（唯一无歧义的观测量）：

```
1. efield relax @ 场强 E → 末态 (R_ef, μ_ef)
2. DeltaP relax：t_γ = γ(μ_ef)（F2 反算），外循环收敛后 → (R_dp, μ_dp)
3. 判据：|μ_dp − μ_ef| < 0.01 D 且 RMSD(R_dp, R_ef) < 0.01 Å（拟定）
```

旧协议用 F1 换算匹配场强——废除。

## 7. D7：外循环 secant 公式

```
t_Γ^(k+1) = t_Γ^(k) + κ^(k)·(t_γ − γ^(k))
κ^(k) = (t_Γ^(k) − t_Γ^(k−1)) / (γ^(k) − γ^(k−1))     （secant，k≥1）
κ^(0) = 1（Γ 与 γ 对 λ 响应同号同量级；实现后用数据核实）
保护措施：κ clamp 到 [0.3, 3]；|Δt_Γ| 单步限幅 0.5 rad
收敛判据：|γ^(k) − t_γ| < 1e-2 rad
收敛阶：secant 超线性（~1.6 阶），预期 2–4 步（T4 验证）
```

发散兜底：连续 2 步 |γ−t_γ| 增大 → κ 减半重来；仍失败 → WARNING 并保持
当前结构（relax 不中断，记录该步未达约束）。
