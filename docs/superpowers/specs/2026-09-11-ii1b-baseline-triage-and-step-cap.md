## 3. 结果

### 3.1 S1T：继承基线在 Γ-only 上至少两条解，`result.ref` 是高的那条

无约束、`scf_thr 1e-7`、全部 `#SCF IS CONVERGED#`：

| 用例 | k 网格 | STRU `mag` | 启动 | E_tot [eV] | Fe on-site 矩 [μB] | SCF 迭代 |
|---|---|---|---|---|---|---|
| T1 | 1×1×1 | 2.0 / −2.0 | 冷（= harness） | −7652.3958756613 | +3.48497 / −3.48497 | 18 |
| T2 | 1×1×1 | **4.0 / −4.0** | 冷 | **−7653.0079657872** | **+3.71486 / −3.71486** | 25 |
| T3 | 1×1×1 | 1.0 / −1.0 | 冷 | −7652.3959199779 | +3.48500 / −3.48499 | 47 |
| T4 | 1×1×1 | 0.2 / −0.2 | 冷 | −7652.3959173652 | +3.48499 / −3.48500 | 66 |
| T5 | 1×1×1 | 2.0 / −2.0 | 热（T1） | −7652.3958948158 | +3.48498 / −3.48497 | 24 |
| T6 | 1×1×1 | 2.0 / −2.0 | 热（T2） | −7653.0079623294 | +3.71472 / −3.71472 | 19 |
| T7 | 2×2×2 | 2.0 / −2.0 | 冷 | −7655.1236556580 | +1.47722 / −1.47726 | 16 |
| T8 | 2×2×2 | 4.0 / −4.0 | 冷 | −7655.1251164576 | +1.47263 / −1.47231 | 81 |
| T9 | 4×4×4 | 2.0 / −2.0 | 冷 | −7655.6855424833 | +3.09738 / −3.09733 | 17 |

三条结论：

1. **多解是真的，不是扰动假象**：`mag = 4.0` 的**冷启动**直接落到低解
   （−7653.0079658 eV，低 0.612 eV），而 `mag ≤ 2.0` 全部落到 harness
   参考态。初始磁矩猜测决定盆地；
2. **两个盆地都是驻点**：T5 从参考态热重入回到参考态（−7652.3958948），
   T6 从低解热重入回到低解（−7653.0079623），偏差 1e-8 eV 量级；
3. **Γ-only 网格本身没收敛**：2×2×2 两种猜测都塌到同一条低矩解
   （±1.477 μB，−7655.1237/−7655.1251 eV，互差 1.5 meV），4×4×4 又回到
   ±3.097 μB、−7655.6855 eV。E 随 k 网格单调下降 3.3 eV、矩在
   3.48 → 1.48 → 3.10 之间摆动 ⇒ 这一算例在 Γ-only 上既不是基态也不是
   k 收敛态。

### 3.2 F1/F2：外环步长上限 INPUT 化（框架改动）

新增两个 INPUT（默认值 = 改动前行为，逐位不变）：

| INPUT | 默认 | 语义 |
|---|---|---|
| `constraint_step_max` | 0.05 Ry | 每个外步 `\|dμ\|` 上限（原 `MuSolverParams::step_max` 硬编码） |
| `constraint_step_probe` | 0.0 | **只作用于无历史的首步**的 `\|dμ\|` 上限；0 = 退回 `step_max`（legacy） |

首步无历史 ⇒ 割线斜率回落 `kappa_min` ⇒ 步长恒等于 cap（"固定过冲"）。
`step_probe` 让首步先量一个局部斜率，之后由 `step_max` 接管。
守卫：`step_max > 0`；`0 ≤ step_probe ≤ step_max`（越界 ERROR）。

单测（`build`，debug）：

| 目标 | 结果 |
|---|---|
| `MODULE_ESTATE_constraint_mu_solver` | 9/9 通过（含新 `StepProbeCapsOnlyTheFirstStep`：首步 = probe、次步 = step_max、probe=0 退回 step_max） |
| `MODULE_ESTATE_constraint_io` | 12/12 通过（含新 `OuterStepCapGuards`：默认值落盘、probe 透传、probe>cap / cap≤0 / probe<0 三例 ERROR） |
| `MODULE_ESTATE_constraint_loop` | 12/12 通过 |
| `ctest -R constraint` | 9/11 通过；2 项失败为**既有、与本轮无关**：`MODULE_ESTATE_constraint_weight_grid_mpi` 链接失败（`undefined reference to constraint::build_channel_profile`）——该 MPI 目标的 SOURCES 未列出定义它的 `constraint_io.cpp` |

端到端（真实计算，非单测）：`constraint_step_probe = 0.004` 时首条 audit
行恰为 `mu = -0.004`，即首步精确等于 probe 上限。

### 3.3 S2R-L：新锚点上 δ=0 空操作（通过）

低解锚点（T2/T6D）：**E_anchor = −7653.0079657872 eV**，
**Q_ref（Becke 自旋矩，Fe 2）= 3.384107449 μB**（参考态的对应值是
3.137543567 μB，两者不同 ⇒ 换锚点后所有 δ 必须重新标定）。
δ=0 走完整约束路径：`res = 0` 精确、`mu = 0`、`e_con = 0`，E 与无约束锚点
逐位一致（同一值 −7653.0079623 / −7653.0079658，差在 SCF 噪声地板）。

## 4. 分析

### 4.1 判决：II-1 的定量窗口在该体系上不可达，根因是地貌不是外环

1. **Γ-only 的 `50_FeO` 不能作为约束扫描的锚**：它既有多解
   （0.612 eV 之内两条 AFM 解，且 `result.ref` 是高的那条），又没 k 收敛
   （2×2×2 / 4×4×4 给出截然不同的 E 与矩）。I-1（MgO）能给出干净的
   κ 表，正是因为它的参考态唯一且平滑；
2. **重锚定到低解后，可测窗口只有 ±0.1 μB**：两点都过了 B1/B2/B3，
   μ\* = −0.06552 / +0.05951 Ry（κ_eff ≈ 1.53 / 1.68 μB/Ry，
   同量级、方向相反）；而 ±0.3 处出现了**固定 μ 双稳**，
   ±0.5 亦然。这比计划假设的"±0.5 是温和扰动"窄得多；
3. **这不是外环缺陷**：步长压到 0.01（默认的 1/5）后 δ=+0.1 的 μ\*
   只变 0.1%（−0.0655152 → −0.0655807），而 δ=+0.3 仍然是固定 μ 双稳
   ⇒ 0.05 Ry 首步过冲（II-1a 的诊断）**确实存在且已修好**，但它不是
   本轮扫描上限的唯一原因；
4. **能量记账口径已判定**：δ=+0.1 的能升 0.04392 eV 与线性响应预言
   ½·δ·|μ\*| = 0.04456 eV 吻合到 1.4% ⇒ 打印的 `E_tot` 就是 E[ρ]
   （约束项的双计数已在标准 KS 公式里被 ∫V_eff ρ 抵消，无需额外修正），
   B1 判据因此成立。

### 4.2 框架侧：本轮修好了一条，另一条仍缺

- **已修（F1）**：`step_max` / `step_probe` INPUT 化。legacy 默认逐位不变；
  单测锁定"probe 只作用于无历史首步"这条语义；真实计算里首步精确等于
  probe（μ = −0.004）。
- **仍缺（阻塞 stage B）**：**在线分支守卫**。本轮只能事后用 B1/B2/B3
  判定（工具 `tools/summarize_low_scan.py`），运行中没有任何机制阻止外环
  把一个换态后的 Q 当成"达标"。II-1a 记录过的"Q 突变被记成 CONVERGED"
  在本轮以另一种形态复现（固定 μ 双稳下的极限环）。
  实现前必须先定判据口径：能量式（`E < E_ref − tol`）物理最硬，但需要把
  `E_tot` 从 esolver 传进 `ConstraintLoop::on_scf_converged`；
  ΔQ 式（`|ΔQ| > tol_jump`）无需新管线但阈值带量纲、且实测正常响应也能
  达到同量级（FeO δ=+0.3 第 5→6 步 |ΔQ| ≈ 0.6 μB，与合法首步同阶）。
  **本轮已把能量口径的经验依据补齐（§4.1 第 4 条），建议下一步就按
  能量式落地。**
- **仍未动（II-1b 前提，本轮升级为阻塞级）**：Becke 加权矩与 d 局域矩
  脱钩，且幅度大到足以决定约束是否有物理意义：

  | 状态 | Becke Q [μB] | on-site 矩 [μB] | 说明 |
  |---|---|---|---|
  | 锚点（δ=0） | 3.3841 | +3.7149 / −3.7149 | 二者同量级 |
  | δ=+0.3 链 A 的换态点 | 4.2248 | +3.8849 / −3.8374 | Becke 涨 0.84，on-site 只涨 0.17 |
  | δ=−0.3 链 B 的塌陷点 | **2.1012** | **+3.5180 / −3.6585** | Becke 塌 1.28，on-site 只降 0.20 |

  最后一行是关键：约束直接作用在 Becke 加权自旋矩上，一个 −0.3 μB 的
  靶点把 Becke 读数压掉 1.28 μB，而**物理的 d 局域矩几乎没动**。
  换句话说，本框架当前的观测量未必是它声称约束的那个量；这条如果不澄清，
  II-1 的 κ 与"约束 d 局域矩"的能力结论都不能成立。II-1b（V3b 只读观测口）
  因此从"口径归因"升级为**能力结论的前提**。
