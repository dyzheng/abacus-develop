   （能量/力/收敛步数）——"力平滑"与"能量下降"的对照基准。

   t_Γ*=自然 Γ，几何弛豫期间 λ 每 SCF 重收敛（4.2 已验证的驻点力路径）。

   力平滑、λ 处于合法小 λ 工作区。

   该行为是否源于"无 target = 隐式 t_Γ=0（Γ→0 约束）"的实现缺口，并评估

### 3.4 无 target 语义缺口：根因与修复

- **根因**：`esolver_ks_lcao.cpp` 中无 target 文件时
  `p.target = ucell.get_dp_target()` 返回全零向量 {0,0,0}（STRU 未写
  dp_target 的默认值），**非空**。λ 更新残差门 `!tgt.empty()` 放行，
  t_Γ(κ=1)=t_γ={0,0,0} → 隐式"约束 Γ→0"：λ 积累、力被污染——4.1 无
  target relax 的 λ→1.7e-2 Ry、步 2 力 2.18 eV/Å 的真实成因。代码注释
  声明的意图是"无 target = 自由跑（λ 保持初值）"，实现未达成。
- **修复**（`esolver_ks_lcao.cpp`，13+/4−）：无任何 target（文件缺省且
  STRU dp_target 全零）时 `p.target.clear()`——实现与注释意图对齐。
  **PW 路径不改**（`deltap_pw.cpp:444-447` 是显式文档化的历史语义
  "无 target = 约束 γ→0"，两条路径语义不同，各自保持）。
- **验证（修复后）**：无 target relax（relax_free）λ≡(0,0,0)、
  |γ−t|=0、escon=0；能量/力与纯 DFT 基线一致到 1e-13 eV / 1e-6 eV/Å；
  4 离子步收敛，轨迹完全相同。目标驱动路径零回归：center 用例 λ、
  Γ、E' 与锚点 #3 逐位一致（−4.000592e-3/−2.262259e-3，
  E'=−338.7136166249902 eV）。deltap 单测 5/5 PASS。
- 影响面审计：仅 `tests/deltap_relax`（无 target）受影响；bn_sampling
  全部 9 标签用 target 文件、test_stru_target 用 STRU dp_target、
  其余 λ 冻结——均不受修复影响。

## 4. 分析

- **4.1 "已知 relax 限制（F_H1z ...）"归因修正**：4.1 文档将步 2 力
  反号放大与非单调能量归因于 HK 力项（F_H1z），本轮证明是双重误读：
  ① 该行为在纯 DFT relax 中原样出现（本征 BFGS 过冲 + 人工短键几何），
  与 HK 力无关；② 4.1 无 target 跑的额外污染来自隐式 t_Γ=0（Γ→0
  约束），已修复。4.1 文档对应行已加更正注记。
- **4.3 判据裁定**："≥3 离子步能量下降、力平滑"按严格逐步单调读法在
  纯 DFT 基线即不成立（BFGS 过冲是优化器行为，非力场错误）。按生产
  语义读法 PASS：≥3 离子步 ✓、收敛（力 < 阈值）✓、终值能量下降 ✓、
  力轨迹与纯 DFT 一致（无 deltap 特有退化）✓。判据表述建议今后写为
  "与纯 DFT 基线轨迹一致 + 收敛"，而非绝对单调。
- **Γ-path relax 是合法的生产用法**：冻结 t_Γ*=自然 Γ 时 λ 自动落在
  1e-5–1e-4 Ry 合法区，力 = 4.2 已验证的驻点力，端到端行为与纯 DFT
  无差。任意大靶点（弱耦合 λ 预算）仍受 Route A+ 工作区限制（已在
  LIMITATION）。
