# 2026-10-30 3.8 近零模诊断报告（按建议①完成）

## 目标

判定 target 3.8、2×2×2 下"能量已收敛而 Δρ 卡在 ~2e-6"的偏移 ε 来源：
(a) λ 每步重解驱动？(b) 占据跳变驱动？还是 (c) SCF/表示固有的真近零模？

## 诊断 1：冻结 λ（排除 λ 驱动）

从 DS 收敛日志取 λ（eV/uB）：Fe1=`-1.6204812408`、Fe2=`+1.6217808258`。
写入 STRU 的 `lambda` 关键字（按解析器约定为 eV/uB，内部再转 Ry），并设
`sc_scf_thr_mode off`（**完全关闭 λ 内层更新**，`Inner optimization` 计数为 0）。

结果（≤100 步）：

| 量 | 冻结 λ（固定外场） | 原 DS（λ 每步重解） |
|---|---|---|
| ETOT (eV) | -6775.890538 | -6775.890621 |
| Mulliken Fe1 | 3.6323 | 3.6323 |
| SCF | **不收敛** | 不收敛 |
| Δρ | **1.0e-5 ~ 1.5e-5 振荡** | 4e-6 ~ 1.3e-5 振荡 |

→ **λ 完全冻结后仍以相同方式失败、同一 ETOT/磁矩。近零模不是 λ 驱动。**

## 诊断 2：占据/带隙（排除占据驱动）

解析末态 `eig_occ.txt`（每 k、每自旋的 HOMO-LUMO 与占据）：

| 态 | 最小带隙 | 分数占据 | 结果 |
|---|---:|---|---|
| **3.8 @2×2×2** | **1.56 eV** | **无（全为 0.25/0）** | **失败** |
| 3.6 @2×2×2 | 1.64 eV | 有（0.24985, 0.00023） | 收敛 |
| 4.0 @2×2×2 | 1.49 eV | 无 | 收敛 |
| 3.8 @4×4×4 | 0.147 eV | 无 | 收敛 |

→ 失败态恰恰是**最绝缘、占据最整数**的；收敛的 3.6 反而是弱金属。
**不是费米能级/占据跳变。**（也说明"4×4×4 修复"不是靠平滑占据。）

## 诊断 3：DMR/restart 混合（排除"网格不可表示分量"）

LCAO 默认混合**实空间电荷密度**；`mixing_dmr`（混密度矩阵）只在
`mixing_restart>0 && mixing_restart_count>0` 时启用。测试：
`mixing_restart 1e-3` + `mixing_dmr 1`，对照 `mixing_dmr 0`。

| 设置 | Δρ 末段 | SCF |
|---|---|---|
| `mixing_dmr 1` + restart | 2.1e-6 平台 | 不收敛 |
| `mixing_dmr 0` + restart | 2.1e-6 平台 | 不收敛 |

→ 两者**逐位相同**；DMR 混合路径要么未真正触发，要么对近零模无效。
至少可排除"简单地改混 DMR 就能消除"。

## 结论

三项诊断一致指向：**近零模是固定外势下 SCF 映射 `F(ρ)` 本身固有的近奇异方向**
（`g≈1`），**不是** λ 驱动、**不是**占据驱动、**不是**单纯网格/ DMR 表示问题。
其物理量（能量、磁矩、带隙、整数占据）均已收敛，密度沿该方向的变化
（~2e-6）几乎不改变能量。

## 对"修法"的判定（结合上一份数学文档）

1. **混合层正则化**：数学上只能把发散/2-周期压成有界平台（`≈ ε λ_reg`），
   而本诊断确认偏移 `ε` 不是 λ/占据驱动、是**真零模残差**，因此正则化
   **不能把它降到 1e-8**。→ **确认不值得作为首要方案**，仅可作 2-周期补充。
2. **加密 k 网格**：是**离散化正则化**（4×4×4 下该态最小带隙 0.147 eV、近零模
   被"展宽"），能收敛但不可迁移。→ 仍是 workaround。
3. **物理判据（推荐）**：既然能量/磁矩/带隙/占据都收敛、且近零模不驱动 λ 或
   占据，应以 `|ΔE| < ε_E` 且 `‖Mi−target‖ < ε_M`（辅以带隙/占据健康度）作为
   收敛判据，而不是把 `‖Δρ‖` 卡在 1e-8。
   - 注意：现有 `scf_ene_thr` **不能**解决（它只在 `drho<scf_thr` 时才额外
     收紧，逻辑上仍是 Δρ 主导）。需要改"收敛判定"逻辑：当检测到
     "E、M 稳定 K 步而 Δρ 非下降"的近零模停滞时，按物理量判收敛。
4. **待补验证**：该近零模是否影响**力/应力**（本诊断未跑 `cal_force`）。
   若力也稳定，则判据修法完全成立；若力不稳定，则需显式消除该零模
   （投影掉或加曲率），而不仅是改判据。
