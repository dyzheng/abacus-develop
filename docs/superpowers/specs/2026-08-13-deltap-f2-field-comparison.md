## 4. 结果

### 4.1 设置层发现（协议教训，先于对拍）

- **dip_cor 常数偏移**：`efield_flag 1`+`dip_cor_flag 1` 在任何 amp（含 0）下
  比 efield-off 高 **+3.70 meV**（amp=0 实测 −481.694069657 vs base_clean
  −481.697769875）= 偶极镜像自能 ½·4πμ₀²/Ω = 3.69 meV（μ₀=0.76316 精确吻合）。
  结论：**efield 通道 E₀(μ) 的基线必须是 efield-on amp=0 运行**，不能用
  efield-off 的 base_clean（否则引入 3.7 meV 伪偏差——本轮首轮对比即踩此坑）。
- **无 dip_cor 力锚点一致**：no-dip_cor E=0 力 = DeltaP λ=0 力（O1z 差
  0.003%）；dip_cor 使 O1z 力整体偏移 +5.7 meV/Å（镜像场力）——力对比用
  no-dip_cor 系列（与 DeltaP 同静电口径）。
- **efield 通道 Legendre 变换自洽**：用 amp=0 基线后，E₀_B(μ) 全 E 范围平坦到
  ±0.003 meV——μ(E)（γ 口径）与 F(E)（能量口径）完全自洽，efield 侧零污染。

## 5. 分析（机制分解，100% 闭合）

1. **能量偏差 ∝ λ²（escon 通道）**：E'(λ)=E₀(μ)+bλ² 的 b=14.26 eV/Ry² 来自
   −ΣλΓ 记账（Γ 随 λ 线性漂移 dΓ/dλ=−4.2）；物理极化能 ½κΔμ² 仅 0.026 meV
   （Δμ=2.4 me·Bohr）。efield 侧 Legendre 后平坦（±0.003 meV）证明 efield 通道
   干净，dev 无 efield 侧贡献。
2. **力偏差 ∝ λ（约束反作用项）**：F_DP = −dE'(λ)/dR = F_PES + (∂E₀/∂μ)·dμ/dR，
   而 ∂E₀/∂μ = −λ·杠杆 ≠ 0（约束态非 E₀(μ) 驻点）；真实场力 F_EF = F_PES
   （∂E₀/∂μ=E 于平衡）。缺项即"约束路径力 vs 场路径力"之差——T3'/T3 的
   λ²-泄漏家族在场模式下的对应物。数值验证：dev 与 λ 线性（2.7%@0.001 →
   21%@0.01，10×λ → ~8×dev）。
3. **杠杆不匹配的物理含义**：同一算符 λÔ，其力响应（1.31 a.u./Ry）与极化响应
   （0.084 a.u./Ry）隐含不同场强——算符不是均匀电场的严格模拟（H_HR 代理的
   已知近似性；τ_α·P̂ 的 Γ 通道杠杆放大）。这解释并量化了"D2 的 1.6–3.1×
   E_eff 校准"为何不能同时用于能量与力。
4. **与既有结论自洽**：T3（Γ-hold 力对 E' FD 精确）不受影响——那是"约束面上
   的力"的记账一致性；F-2 测的是"场等价性"（约束面 ≠ 场路径面），T3' 的
   Γ-面 vs γ-面力差在此呈现为场模式版。

## 6. 结论与下一步

- **F-2 判决：严格判据不通过，机制 100% 闭合**。场模式能力定位：
  - 可用（已实测）：E₀(μ) 能量曲线、极化响应（γ/μ）——|λ|≤0.007 Ry 窗口内
    与 efield 一致 <1e-3 eV。
  - 不可用（实测边界）：力侧 relax——约束反作用项使力偏离真实场力
    2.6%(@|λ|=0.001) → 21%(@0.01)；对齐需 EFC（E_phys 力，P3 的 Ô_θ/EFC
    立项依据从此有了场模式定量实测）。
- **建议**（按用户规定回评审）：
  1. 场模式文档主推限定"能量/响应用途 + |λ|≤0.007 窗口"，力侧标注 EFC 依赖；
  2. EFC（P3）优先级维持挂起，但动机条目补 F-2 力杠杆 15.6× 实测；
  3. F-2 的 efield 基线协议教训（dip_cor 常数 + 基线 = efield-on amp=0）写入
     P 系列备忘录，后续任何 efield 对拍沿用。
