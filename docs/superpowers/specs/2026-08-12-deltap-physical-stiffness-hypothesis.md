## 2. 定量推导链（γ̄ ↔ μ ↔ α ↔ κ）

### 2.1 γ̄–μ 换算（F2 实测校准过，0.9% 吻合实验）

```
定义 G ≡ unwrap(Σγ_raw)/2（每自旋通道的总 Berry 相位）
μ = e·L·G/π        （L = 盒边长，Bohr；F2 轮验证：μ = 24.28 D/rad × G）
h2o1：L = 30 Bohr ⇒ 换算系数 = L/π = 9.55 e·Bohr/rad = 24.28 D/rad
```

### 2.2 极化能 → κ 的物理估计

```
均匀场中分子能量：E(μ) = μ²/(2α)
⇒ E(G) = (eL/π)²·G²/(2α)
κ_phys ≡ d²E/dG² = (eL/π)²/α = (9.55)²/9.8 ≈ 9.3 Ha/rad² ≈ 18.6 Ry/rad²
```

### 2.3 κ 的既有数据估计（T2 抛物线 + T-18 响应）

```
λ = ±0.01 Ry 时：ΔG ≈ 0.26 rad/Ry × 0.01 Ry = 2.6e-3 rad（T-18 响应）
                  ΔE' = +1.3~1.55 meV（T2 抛物线）
κ_est = 2ΔE/ΔG² = 2×1.4e-3 eV / (2.6e-3)² ≈ 414 eV/rad² ≈ 30 Ry/rad²
```

κ_est(30) vs κ_phys(18.6)：同量级，因子 1.6——**在全部估算误差之内一致**。
若 κ 成立，则精确共轭算符（归一化后）的响应上限 1/κ ≈ 0.03–0.05 rad/Ry；
实测响应 0.26 对应"算符范数放大" dλ̃/dλ ≈ 8（λ̃ = 有效共轭力）——
数学上自洽，无矛盾。要点：**响应 0.26 已经处于物理尺度，不存在 10× 的提升空间**。

### 2.4 三条 E_eff 候选公式的张力（必须同场对照）

| 公式 | 来源 | λ=0.01 Ry 时的 E_eff | 备注 |
|------|------|----------------------|------|
| (a) λ/(2a) | 算符斜坡（H_HR ramp 直读，现行代码） | 1.67e-4 a.u. | 低估：未含 Γ 放大 |
| (b) πλ/L | γ̄-共轭匹配（−λG ↔ −Eμ，μ=eLG/π） | 1.05e-3 a.u. | 旧 −πλ/(2a) 的近亲 |
| (c) λ·(∂Γ/∂λ)/(∂μ/∂λ) | 焓斜率（可测量） | 待测 | 与 (b) 的差距=dΓ/dG≈16 的代理泄漏 |

→ λ=0.005 Ha 时 E_eff ≈ 6.3e-4 a.u.，**介于 (a) 与 (b) 之间、更靠近 (b)**。
D2 实验直接裁决。

## 3. 判决实验

### D1：κ 直接测量（核心，~半天，复用优先）

**协议**：沿约束路径采 (G, E'_KS) 对，拟合 E = E₀ + ½κ(G−G₀)²。
- 数据源（复用）：T2 五点 λ 扫描、T-18 S1 扫描、T3' 两腿——提取
  (λ, γ_meas 连续锚定值, E')；
- 缺口补跑：±0.02, ±0.05 Ry 四个冻结 λ 点（h2o1，生产设置，每点 ~1 min）；
  预期 E 变化 ½×25×(0.26×0.05)² ≈ 2e-3 Ry ≈ 27 meV ≫ 噪声底；
- **判据**：
  - κ ∈ [10, 40] Ry/rad² → **物理刚度坐实**（与 κ_phys=18.6 同量级）；
  - κ ≲ 2 Ry/rad²（软）→ 响应 0.26 远低于上限 1/κ≈0.5+，算符权限问题成立，
    Ô_θ 重新立项有据；
- 附带产出：E(G) 曲面的首个直接测量（PES 口径，Route A+ 记账下 E' 是干净
  的约束态能量，D4 红利兑现）。

### D2：锯齿场交叉验证（~2 小时）

- h2o1 + efield（锯齿场沿 z，E = ±0.001, ±0.002 a.u.）测 dG/dE_field；
- 与 DeltaP 的 dG/dλ 对比，给出 E_eff 实测换算（§2.4 公式 (a)/(b) 裁决）；
- 判据：dG/dE_field 与 κ 自洽（dG/dE = πα/L ≈ 1.03 rad/a.u. 的 2× 内），
  且 E_eff^(meas) 落在 (a)/(b) 区间内。

### D3：γ 测量噪声底（~1 小时，D1 的前置）

- 同一 INPUT 同 λ 重复 3–5 次（不同 branch.dat 种子/轻微初值扰动），
  测 γ_meas 散差 σ_γ；
- 背景：T-18 局部弦斜率 ±0.8±1.4 rad/Ry，而每 λ 步信号 ΔG≈2.6e-3 rad——
  若 σ_γ ≳ 0.005 rad，则 T-18 的非单调是噪声主导，响应数字只有定性意义，
  D1 的 κ 拟合必须带误差棒；
- 判据：σ_γ < 1e-3 rad → 现有响应数据定量可用；σ_γ ~ 0.01 rad → D1 需加密
  λ 点 + 多点平均。
