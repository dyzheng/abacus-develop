## 1. 根因定案（证据链，全部来自现有数据，零新 SCF）

**指纹 1——净力（平移不变性违反）**：文档 §3.4 分解表中 COM 修正 = −2.3594 eV/Å
（O-z），即补偿前净力 net_z = 3×2.3594 = **7.078 eV/Å**。plain LCAO 通过 FD
（其 net≈0，否则补偿后解析力会偏 FD net/3）→ 该净力是**约束态特有**的解析力
组合误差，与 FD 无关。

**指纹 2——净力恰好等于 Σ_J forcecon**：R0（fixed-μ，oz_0_tf）CONSTRAINT 力块
实测 O z=+0.109099、H1/H2 z=+0.083147 Ry/Bohr，Σ_z = 0.275393 Ry/Bohr
× 25.7117 = **7.081 eV/Å**，与 net_z = 7.078 吻合到 **0.04%**。

**推论**：解析力 = [正确的 KS 部分] + forcecon，而 forcecon 只是 μw 力的**显式
一半**；另一半 μw Pulay（基函数随原子移动经 fvl_dphi 对 μw 的导数）**完全缺失**
——若它存在且正确，Σ_J[Pulay_μw + forcecon] = 0（Q 平移不变），净力不可能
恰好等于 Σ forcecon。

**机制（代码结构级证实）**：μw 注入在 `hamilt2rho_single` 内 HSolver 之前
（esolver_ks_lcao.cpp:769）；而 v_eff 在每轮 iter_finish 由 update_pot 从输出
密度**重建（不含 μw）**（Task 2.3 spec §4 自己的生命周期描述）。最后一个 SCF
迭代后不再有注入 → **力求值时 `pelec->pot` 已不含 μw** →
`PulayForceStress::cal_pulay_fs(..., pelec->pot, ...)`（FORCE_STRESS.cpp:222/258）
的 VL_dPHI 自然没有 μw Pulay。PW 不受影响（PW 力不用 veff 网格 Pulay）；
plain LCAO 不受影响（无 μw）。**与 PW SCC-μw bug 同族：都是"μw 在势生命周期
末端丢失"，PW 丢在 vnew 快照、LCAO 丢在力求值前的 v_eff 重建。**

对文档候选的裁决：候选 A 方向正确但机制需修正——不是"LCAO 基下闭合不精确"
（不是求积精度问题），而是**力求值时刻 μw 根本不在势里**（生命周期缺失）；
候选 B（快照不同步）被净力指纹排除（标量记账错位不会产生违反平移的净力）。

## 2. 定点修复（与 SCC 修复同型，最小侵入）

在 LCAO 力/应力求值路径中，对 `cal_pulay_fs` 所用势做**修正副本**：
`pot_corrected = pelec->pot->get_eff_v() + Σμ_α w_α`（复用已存在的
`ConstraintLoop::add_back_constraint_potential()`——PW SCC 修复同一工具，
spin 通道 ±、charge 全自旋已处理；约束关/μ=0 时 no-op）。
注意按 SCC 修复先例用**副本**而非改写共享 pot，避免污染其他读 pot 的分量。

## 3. 可证伪验证序列（替代原 4 腿方案，更便宜）

1. 实现修复 → 重建 → **重跑 O-z 冒烟腿**（同一 R7 协议）。**预言**：
   net_z ≈ 0（COM 修正 ≈0）且 |F_FD − F_ana| ≪ 0.0128555 eV/Å。
   若预言不成立 → 根因定案有误，回到候选池（保留原 4 腿方案作后备）。
2. 旁证（可选，~2 次 SCF）：fixed-μ 模式下 μ=0 vs μ=μ* 两次 R0 跑，打印
   VL_dPHI——修复前两者应**逐位相同**（证明 μw 此前不在力路径势里），
   修复后差异 = μw Pulay。
3. 通过后按计划续：LCAO 18 腿全量 → 残余∝|Q−t| 档 → 2.6.3 力矩 FD。
