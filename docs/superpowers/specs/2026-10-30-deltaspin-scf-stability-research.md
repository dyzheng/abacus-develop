## 摘要

Fe2（nspin=2、target ±3.8）在 **LCAO + 2×2×2 k 网格**下 DeltaSpin 跑 600 步
`SCF IS NOT CONVERGED`，而 PW 同条件 13 步收敛。经系统诊断，结论是：

1. **DeltaSpin 约束本身没有问题**：局域投影矩 `Mi→3.7991`（目标 3.8）、
   λ 从第 7 步起恒定；内层 λ 循环每步都收敛。
2. **失败的是外层电荷 SCF**，其固定点映射在一条**近零曲率方向**上临界稳定：
   β=0.4 时呈 **2-周期**（能量变化交替变号），β=0.1 时能量已收敛到 ~1e-9 eV
   而 Δρ 恒在 ~2e-6；没有任何 β∈[0.02,0.4] 能把 Δρ 降到 `scf_thr=1e-8`。
3. **根因是"粗 k 网格造成的假带隙 + 亚稳绝缘分支"**：
   - 2×2×2 下该态带隙 **1.56 eV**（E_F 全程稳定在带隙内、占据全整数）；
   - 4×4×4 下带隙塌缩到 **0.147 eV**，27 步收敛；
   - 增大展宽 σ=0.03/0.05 Ry 使态变**金属**（18/24 个分数占据）、20–21 步收敛。
   → **收敛解是金属/近金属；"绝缘"是被陷住的亚稳分支**，该分支上恰好有电荷近零模。
4. **数学上**：混合迭代的谱 `μ=1−β(1−g)`。`g≈1` 是近零模（临界稳定）；
   `g<0` 且大则可出 2-周期。**Tikhonov 正则化只能把发散压成有界平台
   （真零模残余 `r'=ε` 不变），不能把真零模收敛到 0**。因此纯正则化不是本问题的解。
5. **可迁移修法排序**：充分 k 采样 / 金属分支逃逸 ＞ 物理收敛判据 ＞
   正则化混合（补充）＞ 展宽/放宽阈值（仅诊断，勿作生产修复）。
6. **DeltaSpin 不应按"是否绝缘"禁算**：它约束**局域投影矩**，绝缘体可调；
   不可调的是**总磁矩**（量子化）。应守卫"目标不可达 / λ 发散"，而非"绝缘"。

## 1. 体系与现象

- Fe2 bcc 二聚体，nspin=2（collinear），27 bands，kpar=2，2×2×2 MP k 网格，
  gaussian 展宽 σ=0.01 Ry，`scf_thr=1e-8`，`sc_thr=1e-3`。
- 目标：AFM ±3.8 μB（`mag 0 0 ±3.8 sc 0 0 1`）。
- 现象：LCAO 600 步不收敛；PW 13 步收敛；LCAO 用 4×4×4 或大展宽则正常收敛。

## 2. 完整因果链

```
粗 k 网格（2×2×2，4 个 k 点）
   └─ 费米面欠采样 → 虚假大带隙（1.56 eV，真实 0.147 eV）
        └─ SCF 落入"绝缘"亚稳分支（占据全整数、E_F 稳定在带隙内）
             └─ 该分支的电荷响应出现近零曲率方向（g≈1）
                  └─ 固定点混合 μ≈1（临界稳定）：β 小则缓慢爬、β 大则跨 -1 变 2-周期
                       └─ Δρ 卡在 ~2e-6，`SCF IS NOT CONVERGED`（而能量/磁矩已收敛）
```

反过来：加密 k（带隙 0.147 eV）或增大 σ（金属占据）→ 亚稳绝缘分支消失 →
近零模消失 → SCF 正常收敛（20–27 步）。

## 3. 关键证据

### 3.1 λ 与磁矩早已收敛（问题不在约束算法）

从 DS 外层 `initial lambda` / `initial spin` 轨迹：

| 外层步 | Mi(Fe1) | λ(Fe1) [eV/uB] |
|---|---:|---:|
| 1 | 2.5271 | 0.0000 |
| 2 | 3.8442 | −1.6215 |
| 4 | 3.7844 | −1.6188 |
| 7 | 3.7996 | −1.6205 |
| 8…600 | **3.7991（恒定）** | **−1.6205（恒定）** |

内层 λ 循环每步 `Meet convergence`（RMS<`sc_thr`），无 `Reach maximum`。

### 3.2 外层电荷 SCF 的 β 扫描（2×2×2，≤100 步）

| β | 末段 \|ΔE\| (eV) | 末段 Δρ | 形态 |
|---|---|---|---|
| 0.02 | 5e-8 ~ 9e-7 | 2.7→2.5e-6（~0.98/步） | 近零模缓慢衰减 |
| 0.05 | 部分 1e-4 | 2.2e-6 ~ 1.1e-5（振荡） | 2-周期 |
| 0.10 | **2e-9 ~ 2e-8** | **恒 2.2e-6** | 能量已收敛，密度卡住 |
| 0.20 | ~1e-5 | 6e-6 ~ 1.6e-5（振荡） | 2-周期 |
| 0.40 | ~1e-4（变号） | 4e-6 ~ 1.3e-5（振荡） | 明显 2-周期 |
| 3.6 对照 (β=0.4) | → 8.8e-9 | → 8.3e-9 | 正常收敛 |

**无任何 β 能到 1e-8** → 不是"某个混合参数没调对"。

### 3.3 排除"驱动源"（诊断 1/2/3）

1. **冻结 λ**：把收敛 λ 写入 STRU、`sc_scf_thr_mode off`（内层 0 次）→
   **仍同样失败**，ETOT=−6775.890538、Mulliken=3.6323，与原 DS 一致。
   → **不是 λ 每步重解驱动。**
2. **占据/带隙**：失败态（3.8@2×2×2）最小带隙 **1.56 eV、占据全整数**；
   收敛的 3.6 反而是弱金属（有分数占据）。
   → **不是费米能级/占据跳变驱动。**
3. **DMR/restart 混合**：`mixing_dmr=1`+restart 与 `=0` 逐位相同（Δρ 平台 2.1e-6）。
   → 不是简单网格/表示可修问题。

### 3.4 真因：假带隙 + 亚稳绝缘分支

| target 3.8 | 最小带隙 | 分数占据 | 迭代 | 结果 |
|---|---:|---:|---:|---|
| 2×2×2, σ=0.01 | **1.56 eV** | 0 | 600 | **不收敛** |
| **4×4×4, σ=0.01** | **0.147 eV** | 0 | **27** | **收敛**（Mull 3.7345） |
| 2×2×2, σ=0.03 Ry | — | 18 | **21** | **收敛**（Mull 3.6160） |
| 2×2×2, σ=0.05 Ry | — | 24 | **20** | **收敛**（Mull 3.5979） |

- 2×2×2 下 `E_F=11.99 eV` 每步波动仅 ~1e-3 eV，稳定落在 HOMO 11.63/LUMO 13.60
  的带隙内 → **全程绝缘、不是迭代中金属↔绝缘跳变**。
- 但 k 加密使带隙 **1.56→0.147 eV**，大展宽使占据变分数 → **收敛解是金属**。
- 结论：**"绝缘"是粗 k 假带隙诱导的亚稳分支**，SCF 被陷在其中；真解近金属。

## 4. 数学分析

### 4.1 固定点混合的谱

SCF 固定点 `ρ*=F(ρ*)`，混合 `ρ_{n+1}=(1−β)ρ_n+βF(ρ_n)`。线性化

```
δρ_{n+1} = M δρ_n,   M = (1−β)I + βF' = I − β J,   J = I − F'
μ = 1 − β(1 − g) = 1 − β + β g        (g = F' 的特征值)
```

| `g` | 含义 | `μ` | 行为 |
|---|---|---|---|
| `g > 1` | 响应放大（sloshing） | `1 + β(g−1) > 1` | 发散（需预条件压低 `g`） |
| `g ≈ 1` | 近零模（`F−I` 近奇异） | `≈ 1` | 临界稳定，不收敛 |
| `g < 0` | 反相关 | 可 `< −1` | 2-周期 |
| `0 < g < 1` | 正常 | `∈(1−β, 1)` | 收敛 |

对观测：β=0.02 的 ~0.98/步 ⇒ 主导慢模 `g≈0`；β=0.4 的 2-周期 ⇒ 存在
强负响应模 `g<−4`。两类模并存 ⇒ **没有单一 β 能同时满足**。

### 4.2 为什么 Newton/Broyden 在近零模上失效

解 `(F'−I)δρ = −r`：`δρ_j = −r_j/(g_j−1)`。`g_j→1` 时：
- 自洽（`r_j→0`）：0/0 不定；
- 有偏移 `r_j=ε≠0`：`δρ_j=−ε/(g_j−1)→∞`（放大/2-周期来源）。
Broyden 的割线分母 `sᵀBy` 在 `y≈0` 时病态，逆 Jacobian 爆炸。

### 4.3 Tikhonov 正则化能做什么、不能做什么

```
δρ = (JᵀJ + λ_reg I)^{-1} Jᵀ(−r),   J = F'−I
沿特征方向：δρ_j = −(g_j−1) r_j / [(g_j−1)² + λ_reg]
```

- 自洽无偏移：`g→1` 时 `δρ_j→0`，**误差保留**（停滞，不解决）；
- 有偏移 ε：残余 `r_j' = ε λ_reg/[(g_j−1)²+λ_reg]`；
  **`g=1` 时 `r_j'=ε`（完全不变）**，`g≈1` 时压到 `≈ελ_reg`（有界但非零）。

**结论**：正则化只能把"发散/2-周期"变成"有界停滞"，**不能把真零模收敛到 0**。
预条件（Kerker/模型介电）只有在近零模是"混合度量/表示"造成时才有效；对真零模无效。

## 5. 物理与算法结论

### 5.1 DeltaSpin 与绝缘体

- DS 约束的是**局域投影矩 `Mi`**，绝缘体中可通过占据态内部自旋极化调整
  （本例 1.56 eV 带隙下 `Mi` 仍到 3.7991）。
- **总磁矩**在带隙下量子化为整数，连续 λ 无法改；若 target 需要改变总磁矩，
  λ 会发散 → **这才是应报错的情形**。
- 因此**不能**用"检测到绝缘态就退出"作为规则（FeO 等 DS 主力用例就是绝缘体）。

### 5.2 应加的守卫

1. **目标不可达**：`|Mi−target|` 长期不降且 `|λ|` 持续增大/触顶 →
   `WARNING_QUIT`（提示检查 target/初猜/k 采样）。
2. **疑似假带隙分支**：SCF 停滞 + 大带隙 → **警告**（提示加密 k 或金属初猜），
   而非硬退出。

### 5.3 收敛判据问题

β=0.1 时能量已收敛到 ~1e-9 eV 而 Δρ 卡在 2.2e-6：`‖Δρ‖` 被物理无关的平坦方向
主导。**建议以约束泛函的驻点条件**（`|ΔE|` + `‖Mi−target‖`，辅以带隙/占据健康度）
作为判据；注意现有 `scf_ene_thr` 仅在 `drho<scf_thr` 时额外收紧，逻辑上仍被 Δρ
卡住，需要改"判定"逻辑。

## 6. 可迁移的修复策略（按优先级）

1. **充分 k 采样**（本体系 ≥4×4×4）：本质是消除假带隙；最可靠。
2. **分支逃逸 / 金属初猜**：从邻近 target 或金属态热启动，避免落入亚稳绝缘分支。
3. **物理收敛判据**：`|ΔE|`+`‖Mi−target‖` 的停滞检测（需改判定逻辑）。
4. **正则化混合（补充）**：仅对 2-周期/病态放大有效，不能解决真零模停滞。
5. **展宽 / 放宽 `scf_thr`**：仅用于**诊断/识别**假带隙，不作为生产修复
   （改变自由能/力，且对真实带隙无效）。

## 7. 不应做的事

- 不应以"是否绝缘"禁止 DeltaSpin。
- 不应把加密 k 网格或放宽 `scf_thr` 当作"算法修复"（它们是离散化正则化/判据放行）。
- 不应在真实带隙体系里靠大 `smearing_sigma` 强行金属化。
- 不应在没有区分"假带隙分支"前，把 3.8 的失败归咎于 DeltaSpin 约束算法。
