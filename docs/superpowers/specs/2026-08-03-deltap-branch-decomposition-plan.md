# 判别实验方案：Δλ_st 的分支步进 vs 平滑物理响应分解

> 2026-08-03 · 前置：驻点组② FD 结构性 FAIL（`2026-08-03-deltap-force-stationary-group2-fd.md`，
> 残差 84.8 eV/Å，5 位闭合于 λ-leakage 项 224.4 eV/Ry × 0.378 Ry/Å）。
> 本实验回答唯一问题：**dλ*/dR = 0.378 Ry/Å 中，分支离散步进占多少、平滑物理响应占多少**。
> 判决结果决定下一步走向：分支主导 → 先修分支连续性（O5 无效）；物理主导 → 走 O5 分解。

---

## 1. 判决逻辑

驻点 λ* 由约束方程 γ_sel(R, λ*) = t 决定。对 R 求导：

```
dλ*/dR = −(∂γ_sel/∂R|_λ) / (∂γ_sel/∂λ|_R)
```

γ_sel（target-aware 分支选择后的报告值，`deltap_wannier.cpp:1288-1470`）
= 平滑物理部分 γ_phys + 离散分支步进 b（量子 = 2π·w_In，per-band 权重，dev log #5）。
两条路径产生 dλ*/dR：

- **平滑路径**：∂γ_phys/∂R ≈ 1.7 rad/Å（T7-b 实测）；∂γ/∂λ 很大（γ 软，
  λ≈−5.5e-3 Ry 驱动 γ≈−5.5 rad ⇒ 量级 10³ rad/Ry）⇒ dλ*/dR|smooth ~ 1.7e-3 Ry/Å；
- **分支路径**：几何微扰 → 候选分支相对 target 的远近易位 → γ_sel 跳变
  ~2π·w（O(1) rad）→ λ* 跳变 s·O(1)（s=GD 步长 1e-3）⇒ dλ*/dR|branch ~ 0.2–0.4 Ry/Å。

**量级预言已可分辨**：平滑路径预言残差 ≈ 224 eV/Ry × 1.7e-3 Ry/Å ≈ **0.4 eV/Å**；
实测 84.8 eV/Å 是其 200 倍 ⇒ 先验上分支主导，但需实证分解。

**Exhibit A（既有证据）**：disp_plus 同一几何存在两个"驻点" λ，E' 差 1.77 eV
——约束能面本身不适定的直接证据。

## 2. 方案 A：离线轨迹重放分解（零新算，先做，~2 小时）

数据：`/tmp/dp_stat/{base,disp_plus,disp_minus}/` 的逐迭代日志。

### A1. 提取逐迭代序列
从每个几何的 run.log 提取每次迭代的：
- λ_n（`[DeltaP P3]` 行，6 位有效数字已加）；
- γ_report,n（同行，target-aware 选择后）；
- γ_raw,n / γ_unwrapped,n（`[rawG]` 行 / `deltap_gamma_debug.dat`，若逐迭代
  输出缺失则用最接近的连续可观测量替代并注明）。

### A2. 重放分解
GD 更新是线性的，λ* 可精确重放：

```
λ* = λ_0 + s·Σ_n (γ_sel,n − t)                     （实测轨迹，已知）
   = λ*_cont + s·Σ_n b_n
     │            └ 分支贡献：γ_sel 与连续值之差按 2π·w 量子识别
     └ λ*_cont = λ_0 + s·Σ_n (γ_cont,n − t)        （连续分支重放）
```

γ_cont 的构造：以 base 收敛态为参考做 2π 连续性展开（沿迭代序号，
|Δγ_cont| < π 原则逐iter展开），与 target-aware 选择无关。

### A3. 三个几何分别分解，输出表格

| 几何 | λ*（实测） | λ*_cont（重放） | 分支贡献 s·Σb | 占比 |
|------|-----------|----------------|---------------|------|

**判据**：|Δλ_st| = |λ*(+) − λ*(−)| 中，分支贡献占比
- > 80% → **分支主导**，转 §5 决策树左支；
- < 20% → **物理主导**，转 O5 分解实验；
- 中间 → 两者都要修，按占比排序。

### A4. 附带检验（成本为零，必须做）
- **阶梯性自证**：γ_report 随 λ 的轨迹应呈阶梯（步长 = 2π·w 量子），
  标出每个台阶高度并与 w_In（日志 per-band 权重）对照；
- **步长依赖**：λ* 应不依赖 GD 步长 s（驻点定义）；若 λ*(s) 有依赖 →
  轨迹路径依赖，本身就是不适定证据。

## 3. 方案 B：分支连续性对照重跑（在线，~6 次短算，A 不确定时或需终局确认时）

### B1. 机制核实（先读代码，15 分钟）
`load_branch`（deltap_wannier.cpp:308）在 init 时读 `deltap_branch.dat`，
影响的是 **2π unwrap 的参考**；target-aware 选择（:1288+）在其后独立执行。
**需确认**：target=γ*(base)≠0 时 target-aware 是否覆盖连续性 unwrap。
若是，则方案 B 需一个调试开关（临时 patch）：
`DELTAP_BRANCH_CONTINUITY_ONLY=1` 时跳过 target-aware 搜索，只做跨迭代
连续性 unwrap（gamma_prev / unwrap_2pi 路径）。改动 < 20 行，不入库。

### B2. 运行矩阵（h2o1，O1-z，沿用驻点协议）
| run | 分支模式 | 几何 |
|-----|----------|------|
| B-base | 连续性-only | base |
| B-plus | 连续性-only（seed=base 的 deltap_branch.dat） | +δ |
| B-minus | 连续性-only（同上 seed） | −δ |

### B3. 测量与判据
- λ* 三点 → dλ*/dR|cont；
- E' 三点 → F_FD；与 F_ana = −0.747 比：
  - 残差落入 **0.3–0.5 eV/Å**（平滑预言 0.4）→ 分支主导坐实，
    且定量给出"修好分支后"的剩余物理缺口；
  - 残差仍 ~85 eV/Å → 分支假说证伪，直接转 O5；
  - 残差 < 判据 0.0129 → 意外之喜，dspin 定理恢复成立，重新评估全部结论。

## 4. 决策树

```
方案 A 分解占比
├── 分支 > 80% ──→ 方案 B 确认
│     └── B 残差 ~0.4 eV/Å ──→ ① 修分支连续性（per-string 跨迭代跟踪 +
│        outlier 拒绝，07-21 提案转正）；② 修后残差仍超判据 30×
│        → 带准确数字进 O5 决策（O5a/O5b/O5c）
│     └── B 残差 ~85 ──→ 分支非主因（反直觉），直接 O5
└── 物理 > 80% ──→ 直接 O5 分解实验（hhrdbg 归因 H_HR vs H_HK）
```

**O5 决策所需的输入数字（本实验产出）**：dλ*/dR|smooth、∂γ/∂λ、
∂E'/∂λ、分支修复后的残差下限。O5c（弱约束产品化）评估可并行开始
（纯文档估算：力误差 0.1–0.3 eV/Å ÷ 结构刚度 → 平衡结构误差 Å 量级）。
