# 2026-08-13 DeltaP F-2b（HK-only 场模式对拍）：链接算符力通道的可证伪判决

> 分支 `feat/deltap`。依据：F-2 评审（2026-08-13）"EFC 之前先做 HK-only
> 场模式（F-2b，~半天）"——把"链接算符（H_HK）力通道"与"H_HR 代理力通道"
> 分离，检验可证伪预言：*若链接算符是正确的场算符，matched-μ 力偏差应从
> 21% 塌缩到百分之几*。执行纪律：一次一个串行任务（`OMP_NUM_THREADS=1`
> 单 MPI 进程），无并行启动。

## 1. 判决先行

**F-2b 可证伪预言未确认（FAIL）**，但本轮把 F-2 力失配的根因从"H_HR 代理
荷错位"（已证伪）重新定位到"H_HK 离散 Berry 联络力通道"（实测内禀）：

| 判据 | 预言 | 实测 | 裁定 |
|---|---|---|---|
| matched-μ 力偏差 @\|λ\|=0.01 | 塌缩到百分之几 | **−26.1% / +26.2%**（hk，dev/F_EF 口径；同批 proxy −26.2/+26.7；F-2 文档 −35.6/+21.0 为 dev/F_DP 口径） | **FAIL** |
| hk vs proxy 总力差 | （隐含）H_HR 贡献显著 | ≤6.1 meV/Å @\|λ\|=0.01（< 偏差的 3%） | **H_HR 对力失配可忽略** |
| E'(λ) 曲率 b | 去掉 H_HR 后大头缩小 | b(hk)=14.66 vs b(proxy)=14.26 eV/Ry² | **未缩小** |
| γ 响应 dΣγ/dλ | hk 更直接（响应更大） | hk 0.046 vs proxy 0.053 rad/Ry（批内 Σγ 口径） | **略小，未放大** |

**结论**：链接算符（H_HK）是合格的*极化算符*（μ 通道、能量通道），但其*力
通道*（∂Γ^HK/∂R 杠杆）不是真实场力通道——力/μ 隐含场杠杆比 17.7×（hk；
proxy 15.7×）为算符内禀性质，与 τ·P̂ 代理无关。场模式**能量侧可交付**
（E₀(μ) 窗口 \|λ\|≤0.007 Ry <1e-3 eV，hk 与 proxy 差 ≤34 μeV），**力侧不可
交付，需力级 EFC**（EFC 立项保留，目标函数更新为力杠杆正确性）。

## 5. 分析

1. **H_HR 对力失配可忽略（F-2 根因归因被证伪）**：hk vs proxy 总力差
   ≤0.6%（@\|λ\|=0.01 为 6.1 meV/Å，偏差 200 meV/Å 的 3%）。F-2 §5.3
   "力-杠杆 15.6× 来自 H_HR τ·P̂ 打在原始布居（⟨P̂_O⟩=7.2、⟨P̂_H⟩=2.14）"
   不成立——移除 H_HR（H_c 与力双通道）后力几乎不变。
2. **失配内禀于 H_HK 力通道**：B 项 F_HK = −λ·∂Γ^HK/∂R 杠杆 −30.1 eV/Å/Ry，
   F_std 密度响应 +9.4（抵消 ~31%），净力杠杆 −20.7。∂Γ^HK(O1)/∂R_z ≈
   +1.17 rad/Bohr——链接算符的 ∂/∂R 耦合是 Wilson 相位的几何导数，不是
   真实场力（Born 有效电荷 Z*·E）。正确场算符要求 L_F = L_μ（两通道同一
   隐含场）；实测 17.7×，为算符内禀。
3. **能量曲率不由 H_HR 决定**：b(hk)=14.66 ≈ b(proxy)=14.26。D1 "曲率
   98% 来自 escon/Γ 漂移记账（dΓ/dλ=−4.2）"的表述不精确——E' 的 λ 线性项
   （H-F λΓ 与 escon −λΓ）精确抵消，b 是 H_HK 密度响应谱矩的净曲率；
   H_HR 对密度响应的贡献 <3%。注：b 与朴素 −½Γ₁ 预测（29.3 eV/Ry²）差
   因子 2，escon/总能抵消的精确二次结构记为开放项（不影响判决）。
4. **γ 响应 hk(0.046) < proxy(0.053)**：τ·P̂ 微扰对 γ 是加性正贡献；移除
   后响应略降。与"Ô_w/hk 响应放大"旧叙事（T-18 冻结口径 0.26、D2 反推
   0.052）不同——批内自洽口径下 hk 无放大（同 D2 批内 proxy 0.028 与
   T-18 0.26 的协议差异同族：冻结 vs 自洽差 5–10×）。
5. **与既有结论自洽**：T3（Γ-hold 力对 E' FD 精确）与 T3'（γ-hold 物理路径
   力 FAIL）不受影响——那是约束面记账一致性问题；F-2b 是场等价性问题
   （算符力通道 vs 真实场力通道），0.502 eV/Å（T3'）与 0.2 eV/Å（F-2b
   @λ=0.01）同族：约束面 ≠ 场路径面。

## 6. 结论与下一步

- **F-2b 判决：FAIL（可证伪预言未确认），但测量价值高**：把力失配根因从
  "H_HR 代理荷错位"（证伪）重新定位到"H_HK ∂Γ^HK/∂R 力通道"（实测
  17.7× 杠杆比）。

  Ry <1e-3 eV）；力侧挂起，需力级 EFC——目标函数 = 使 L_F = L_μ

  <2%）。能量侧 EFC 动机不再成立（已闭合）。
