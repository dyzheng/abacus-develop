## 4. 分析

1. **平直性 PASS**：端点弦斜率 −0.0127 eV/Ry（判据 ≲1 的 ~1/80；T2 修复后
   −0.013 逐点复现）。弦斜率随 |λ| 增大（±0.001: −2.8e-5、±0.003: −1.0e-3、
   ±0.01: −1.3e-2 eV/Ry）——线性分量 a=−0.0127 eV/Ry + 曲率 b=+14.3 eV/Ry²
   （E'(λ)=E₀+aλ+bλ² 精确分解，端点三点闭合）。b 与 D1 的 proxy 曲率
   15–30 eV/Ry² 同量级（escon=−ΣλΓ 通道主导，已知）。
2. **变分下界恢复**：全部 λ≠0 点 E' > E'(0)（+1.55/−0.01 侧、+1.30/+0.01 侧
   meV，与 T2 逐位一致）；λ=0 为严格极小。
3. **±0.001 对称**：E'(−0.001)−E'(+0.001)=+5.7e-8 eV（13 位精度下的残差；
   8 位打印 −481.6977557 = −481.6977557 逐位一致，与 T2 同）。
4. **记账恒等式**：escon = −ΣλΓ 逐点精确（−0.01: −(−0.01×10.697)=+0.106977 ✓）；
   dΣΓ/dλ = −4.15 Ry/Ry（T2/D1 的 −4.2 ✓）；dΣγ_raw/dλ = +0.053 rad/Ry
   （D1 proxy 自洽口径 +0.056 ✓）——均匀 λ 下 γ 响应的场模式基线。
5. **E_eff 打印**（formula (b)）：±2.693e-2 V/Å @ |λ|=0.01，线性（D1/D2 轮
   已核：λ=−0.02 → −5.386e-2 ✓）。响应校准 ×1.6（proxy）注释随行。
6. **锚定约定说明**：本批自由跑（无 branch.dat 种子）自然 γ=(−7.958, −2.380,
   −2.380)，与 D1/D2 base_clean 约定（−5.515, −3.601, −3.601）差一个分支量子
   约定（不同锚种子），不影响 E'（FINAL_ETOT_IS 与 base_clean 仅差 7e-13 eV，
   12 位一致）。
