### 4.3 DeltaP 位移：Resta-Z (Mulliken) 方法

DeltaP 使用 Mulliken 布居分析 + 位置矩阵计算逐原子电子中心位移：

```
<r_elec^I> = Σ_{μ,ν∈I} D_{μν} · <φ_μ|r|φ_ν(R)> / Σ_{μ,ν∈I} D_{μν} · <φ_μ|φ_ν(R)>
δ^I = r_ion^I - <r_elec^I>
```

其中 `D_{μν} = Σ_n c_{n,μ}·c*_{n,ν}` 是 Γ 点密度矩阵，`<φ_μ|r|φ_ν>` 是 LCAO 位置矩阵（良定义，局域基）。

**优点**：不需要 Wilson loop 特征分解、不需要能带追踪、不需要 Wannier90、r 在局域基下良定义。

**限制**：Mulliken 布居使用非正交基，与 Berry Phase 极化的分解不完全一致。

#### H₂O 分子位移对比

| 原子 | Resta-Z δ (Å) | Wannier90 δ (Å) | 偏差 (Å) |
|------|-------------|----------------|---------|
| O | -0.186 | +0.133 | 0.319 |
| H1 | -0.551 | +0.262 | 0.813 |
| H2 | -0.551 | +0.262 | 0.813 |

#### 液态水位移对比

| 原子 | Resta-Z δ (Å) | Wannier90 δ (Å) | 偏差 (Å) |
|------|-------------|----------------|---------|
| O0 | +0.001 | +0.065 | 0.064 |
| O1 | -0.012 | -0.050 | 0.038 |
| O2 | -0.165 | +0.050 | 0.215 |
| O3 | -0.109 | +0.124 | 0.233 |
| H0 | -0.169 | 0.000 | 0.169 |
| H1 | -0.158 | 0.000 | 0.158 |
| H2 | -0.166 | -0.269 | 0.103 |
| H3 | -0.171 | +0.012 | 0.183 |
| H4 | -0.551 | +0.304 | 0.855 |
| H5 | -0.546 | +0.088 | 0.634 |
| H6 | -0.524 | 0.000 | 0.524 |
| H7 | -0.535 | +0.298 | 0.833 |
| **O 均值** | **-0.071** | **+0.047** | 0.119 |
| **H 均值** | **-0.353** | **+0.054** | 0.407 |

**分析**：
- **符号**：Resta-Z 全部为负（电子中心在核上方），Wannier90 有正有负
- **O 位移**：量级一致（~0.01-0.17 Å），但符号不同
- **H 位移**：Resta-Z ~0.55 Å，Wannier90 ~0-0.3 Å，差异较大
- **原因**：两种方法本质不同
  - Resta-Z：Mulliken 布居（非正交基，密度矩阵 × 位置矩阵）
  - Wannier90：最近原子硬归属（WF 中心平均）
  - 两者给出不同的逐原子分解，但总极化一致

## 5. 逐原子分配差异的根源

DeltaP 和 Wannier90 的逐原子**总和**一致，但**分配**不同。原因是两种方法使用了不同的权重定义：

| | DeltaP | Wannier90 |
|---|--------|-----------|
| **权重** | SMO 投影 $w^I_n = \sum_{a \in I} |\langle v_n | \alpha_a \rangle|^2$ | 最近原子（0 或 1） |
| **连续性** | 连续 (0~1) | 离散 |
| **H₂O O/H 比** | O 39% / H 61% | O 48% / H 52% |
| **液态水 O/H 比** | O 37% / H 63% | O 65% / H 35% |
| **BN B/N 比** | B 57% / N 43% | B 100% / N 0% |

**液态水 O/H "反转"分析**（非 bug）：
- Wannier90: 16 个 WF 中 11 个归属给 O（最近原子），5 个给 H → O 65%
- DeltaP: SMO 投影权重偏向 H 的原子轨道 → H 63%
- 物理理想值：O ~85%（O 电负性大，O-H 键电子密度偏向 O）
- 两种方法都偏离理想值，因为"逐原子极化分解"本质上不唯一——总极化唯一，但如何分配给各原子没有唯一答案

**分支切割修正不是反转的原因**：比例修正保持原始 O/H 比例不变（修正前 65%/35%，修正后仍 65%/35%）。

---

## 5. 结论

1. **总极化**: DeltaP、Wannier90、Berry Phase 三者电子极化一致（≤0.1%）
2. **逐原子电子极化总和**: DeltaP 和 Wannier90 一致（≤0.1%）
3. **逐原子分配**: 不同，因为权重定义不同（SMO 连续 vs 最近原子离散）
4. **液态水 O/H 反转**: 非 bug，Wannier90 因 11/16 WF 归 O 而给 O 65%，DeltaP 因 SMO 权重偏向 H 而给 H 63%；两者都偏离物理理想值 O ~85%
5. **BN Wannier90**: disentanglement 导致总极化 74% 偏差，不可用
6. **逐原子极化分解本质上不唯一**: 总极化唯一，但分配给各原子的方式没有唯一答案
