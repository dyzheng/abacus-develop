# 2026-10-30 更正：MBIS 是"带约束的不动点"，不是自由最小化 D(p)

## 0. 更正

之前尝试"自由最小化 KL 目标 `D(p)`"（`p={N_A,ζ_A}`）作为唯一解算法，**这是错的**：
- **自由**最小化 `D(p)` 不满足电子数守恒，会把某个 `N_A→0`（实验：`N=(0, 42.6)`，
  `ΣN≠∫ρ`，sum rule 破坏，`D` 甚至为负）。
- MBIS 的 pro-density 参数是**带布居约束**的最小化：
  ```
  min D_A(p_A)  s.t.  ∫ρ_A^pro = ∫ρ_A   （即 N_A = ∫w_Aρ）
  ```
  这等价于**不动点**：
  ```
  N_A = ∫ w_A ρ ,   ζ_A = 3 N_A / ∫ r w_A ρ
  ```
  不动点**自动**保证 `Σ_A N_A = ∫ρ`（因 `Σw_A=1`）。
- 因此 **Picard 不动点迭代才是 MBIS 的正确求解器**；"自由 D 的 Newton 最小化"求解的是
  **另一个（退化）问题**，已删除。

## 1. 已删除的错误实现

- `compute_mbis_newton` / `minimise_D`（自由 D 的 Newton + 负曲率逃逸）——**移除**。
- 原因：违反 `ΣN=N`（sum rule），得到物理上无意义的 `N→0`。

## 2. 正确的通用框架（当前）

1. **通用周期图像**：`detect_cosets` 从原子构型**自动探测晶体平移群**
   （含 bcc 体心平移等非胞平移），用于 pro-density 镜像求和。**通用、无物种平均启发式**。
   （`constraint_mbis_symmetrize` 已删除。）
2. **求解**：**不动点迭代** `compute_mbis`（带布居/均值半径约束，满足 sum rule）。
3. **多解选择**：`compute_mbis_unique`（多初值 `init_zeta∈{0.5,1,2,4}`，取**自洽解中
   最低 D**）；这是"固定点多重性"下的选解。
4. **诊断/认证（启发式）**：`mbis_hessian_eigenvalues` + `classification` 计算
   **自由 D** 的 Hessian 并分类。**注意**：由于 MBIS 是**约束**不动点，自由 D 的 Hessian
   **不是**严格的稳定性对象；严格稳定性应看**不动点映射的 Jacobian `∂F/∂p`**（未实现）。
   该 Hessian 仅作诊断参考。

## 3. 关于"对称破缺"

- 修正后的图像求和（含**探测到的平移**）应使等价原子在 **pro-density 层面**等价。
- 但**Picard 迭代本身可能不稳定**（对称固定点可能是**不动点映射的鞍点**，即使对称图像和
  正确也会漂移）。这属于**迭代稳定性**问题，需用**不动点 Jacobian `∂F/∂p`** 分析
  （而非自由 D 的 Hessian）。
- 合成 bcc toy（等高斯、常规胞）被证实**病态**，不宜作为通用测试；应以**真实密度**
  （LiCl/Fe2）验证。

## 4. 现状与下一步

- 已实现（通用、可复用）：平移探测图像和、固定点求解、多初值最低 D 选解、自由 D Hessian 诊断。
- **下一步（严谨唯一性）**：
  1. 计算**不动点 Jacobian** `J = ∂F/∂p` 的特征值，判定固定点稳定性（|eig|<1），
     对称破缺对应 `J` 在破缺方向 |eig|≥1；
  2. 用**约束 Newton/KKT**（对 `N_A=∫w_Aρ` 的根）代替 Picard，收敛更快、可分类；
  3. 在**真实 LiCl/Fe2** 上验证等价原子是否自然对称（平移图像和 + 稳定不动点）。
