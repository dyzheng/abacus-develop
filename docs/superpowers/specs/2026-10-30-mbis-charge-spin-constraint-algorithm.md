# 2026-10-30 基于 MBIS 权重的电荷+自旋联合约束算法（能量/哈密顿量/力/应力）

> 目标：在 Kohn–Sham DFT 中，用 **MBIS 实空间权重** `w_A(r)` 同时约束每个原子的
> 电子数 `N_A` 与自旋矩 `M_A`（非共线时 `M_A` 为矢量），给出
> 能量修正项、约束哈密顿量、力与 stress，以及 λ 更新与算法流程。
> 这是 cDFT / DeltaSpin 的 MBIS 版本；当 `w_A → onsite 投影` 退化为 DeltaSpin，
> 当 `w_A →` 固定 Hirshfeld 权重退化为 Hirshfeld 约束。

## 0. 记号与观测量

密度：`ρ = ρ↑+ρ↓`，自旋密度 `m = ρ↑−ρ↓`（非共线时为矢量 `m`）。
MBIS 权重（`Σ_A w_A(r)=1`）：
```
w_A(r) = ρ_A^pro(r) / Σ_B ρ_B^pro(r),   ρ_A^pro(r)=N_A ζ_A^3/8π e^{−ζ_A|r−R_A|}
```
约束观测量（电子数 / 自旋）：
```
N_A[ρ] = ∫ w_A(r) ρ(r) dr          (目标 N̄_A；净电荷 Q_A=Z_A^val−N_A)
M_A[ρ] = ∫ w_A(r) m(r) dr          (目标 M̄_A；非共线为矢量 M̄_A)
```
**关键**：`w_A = w_A[ρ, R]` 依赖密度（KL 迭代的 `N_A, ζ_A`）与几何 `R`。

## 1. 约束泛函与能量修正项

拉格朗日（Lagrange）约束泛函：
```
E_c[ρ; λ] = E_KS[ρ] − Σ_A [ λ_A^c (N_A[ρ]−N̄_A) + λ_A^s (M_A[ρ]−M̄_A) ]
```
- `λ_A^c`：电荷乘子（Ry/e）；`λ_A^s`：自旋乘子（Ry/μ_B；非共线为矢量）。
- **能量修正项**（约束能）：`ΔE_con = −Σ_A[λ_A^c(N_A−N̄_A)+λ_A^s(M_A−M̄_A)]`。
  收敛时 `N_A=N̄_A, M_A=M̄_A ⇒ ΔE_con=0`；物理能量仍是 `E_KS[ρ_c]`。

**增广拉格朗日（推荐，改善外层条件数）**：
```
E_c^AL = E_KS[ρ] − Σ_A λ_A^c(N_A−N̄_A) + (k_A^c/2)(N_A−N̄_A)²
               − Σ_A λ_A^s(M_A−M̄_A) + (k_A^s/2)(M_A−M̄_A)²
```
其中 `λ` 用标准 AL 更新 `λ^{n+1}=λ^n − k(N−N̄)`；罚项给约束方向加曲率，
等价于把有效乘子换成 `λ^c_eff = λ^c − k^c(N_A−N̄_A)`、`λ^s_eff = λ^s − k^s(M_A−M̄_A)`。
（对之前观察到的近零模/2-周期，罚项提供正曲率，是结构性稳定手段。）

## 2. 约束哈密顿量 / 势算符

对 `ρ_σ` 变分（`σ=±1` 对应 ↑/↓；`∂M_A/∂ρ_σ=σ w_A`）：

```
δE_c/δρ_σ(r) = V_eff,σ(r) − Σ_A (λ_A^c + σ λ_A^s) w_A(r)
```

因此 KS 方程 `[T̂+V_eff,σ+V_con,σ]ψ=V_cψ` 中的**约束势**为

```
V_con,σ(r) = − Σ_A ( λ_A^c + σ λ_A^s ) w_A(r)
```

即算符（二次量子化形式，共线 nspin=2）：
```
V̂_con = Σ_σ ∫ dr ψ̂†_σ(r) [ −Σ_A Λ_{Aσ} w_A(r) ] ψ̂_σ(r),
Λ_{Aσ} = λ_A^c + σ λ_A^s
```
- **电荷部分** `∓λ^c_A w_A` 对 ↑↓ 同号（电荷约束）；
- **自旋部分** `±λ^s_A w_A` 对 ↑↓ 反号（自旋约束），即 `ΔĤ = Σλ^c Â⊗I + Σλ^s Â⊗σ_z`。
- **非共线（nspin=4）**：`V̂_con = Σ_A [ λ_A^c w_A I + w_A (λ_A^s·σ) ]`，`σ` 为 Pauli 矩阵。
- **AL 罚项**：把 `λ^c,s` 换成 `λ^{c,s}_eff(r)`（含 `−k(N−N̄)`），形式不变。

> 权重是密度依赖的：在**冻结权重近似**（每个 μ/SCF 步固定 `w_A`）内，上式线性；
> 步间用 `ρ` 重建 `w_A`（嵌套固定点）。

## 3. λ 更新（约束响应）

残差 `r_A^c=N_A−N̄_A`、`r_A^s=M_A−M̄_A`。一阶响应：
```
δN_A = Σ_B ( ∂N_A/∂λ_B^c δλ_B^c + ∂N_A/∂λ_B^s δλ_B^s )  (+ 由 w[ρ] 引起的项)
∂N_A/∂λ_B^c = −∫∫ w_A(r) χ_↑↑(r,r') w_B(r') + (↑↓/↓↓)   ...  (加权密度响应)
```
实践上用 **Broyden/有限差分** 解 `J δλ = −r`（`J` 为加权响应矩阵），并做
**Tikhonov 正则化** 处理近零模；或直接用 **AL 罚项**（免去精确 J）。
**R8 冗余**：约束全部 `N_A` + 固定总电子数 → 线性相关；用"全局模式 + N−1 个
差异模式"，自旋同理（均匀场模式）。

## 4. 力（Hellmann–Feynman）

约束泛函在自洽点对 `ψ`、λ 驻定，故
```
F_{Jα} = −dE_c/dR_{Jα} = −∂E_c/∂R_{Jα} |_{ψ,λ}
       = F_{Jα}^{DFT} + F_{Jα}^{con}
```
**约束力**（由 `V̂_con` 的显式几何依赖，冻结 `ζ_A`）：
```
F_{Jα}^{con} = ⟨ −∂_{R_{Jα}} V̂_con ⟩
             = Σ_A ∫ (∂_{R_{Jα}} w_A(r)) [ λ_A^c ρ(r) + λ_A^s m(r) ] dr
```
权重的几何导数（`P=Σ_B ρ_B^pro`）：
```
∂w_A/∂R_{Jα} = (1/P)( ∂_{R_{Jα}}ρ_A^pro − w_A ∂_{R_{Jα}}P )
∂_{R_{Jα}}ρ_J^pro = ζ_J (r−R_J)_α/|r−R_J| · ρ_J^pro      (仅 J 中心项)
```
合并为可实现的积分形式：
```
F_{Jα}^{con} = ∫ ∂_{R_{Jα}}ρ_J^pro · (1/P) Σ_A (δ_{AJ}−w_A)[λ_A^c ρ+λ_A^s m] dr
```
- **DFT 部分** `F^{DFT}`：常规离子/电子 H-F + Pulay（LCAO 基组依赖 R：需含
  约束势在 H 中的 Pulay 项；PW 走常规网格修正）。
- **冻结参数近似的误差项**：若 `ζ_A` 也随几何变（KL 在固定 ρ 下重解），需加
  `−Σ_A λ_A ∂N_A/∂ζ_A · ∂ζ_A/∂R`（MBIS 参数 Pulay 项，需求解线性化 KL 响应）。
  冻结参数近似下省略；要求高精度时补上（包络定理不适用，因 KL 目标与约束能不同）。

## 5. 应力（周期性，均匀应变 ε）

`σ_{αβ} = −(1/Ω) ∂E_c/∂ε_{αβ}`。约束部分：
```
σ^{con}_{αβ} = (1/Ω) Σ_A [ λ_A^c ∂N_A/∂ε_{αβ} + λ_A^s ∂M_A/∂ε_{αβ} ]
∂N_A/∂ε_{αβ} = ∫ (∂_{ε_{αβ}} w_A) ρ dr + ∫ w_A (∂_{ε_{αβ}} ρ) dr
∂_{ε_{αβ}} ρ = −δ_{αβ} ρ − r_β ∂_α ρ        (密度随应变的缩放/平移)
```
`∂_ε w_A` 由 pro-density 的应变依赖给出：中心 `R_B→(1+ε)R_B`、
`r_B=|r−R_B|` 同步缩放（若宽度随晶胞缩放，另含 `∂ζ/∂ε`）。冻结参数近似下
只保留中心/度量项。
- 总应力 = 常规 DFT 应力（动能+Hartree+XC+外势 Pulay）+ `σ^{con}`。
- 实现可用**解析权重应变核**（现有 `WeightGrid::build_derivatives` 的推广）
  或**数值有限差分应变**（对复杂胞/非共线更稳）。

## 6. 算法流程（MBIS 电荷+自旋联合约束）

```
初始化 ρ, w_A (MBIS KL 迭代至收敛), λ=0
repeat (外层 μ/SCF):
  1. 由当前 ρ 求 MBIS pro-density (N_A,ζ_A) → w_A; 构建 P=Σρ^pro
  2. 构建 V_con,σ(r)=−Σ_A(λ_A^c+σλ_A^s)w_A   (AL 时用 λ_eff)
  3. 求解 KS: [T+V_eff,σ+V_con,σ]ψ=εψ  (内层 SCF 或直接对角化)
  4. 由 ψ 得 ρ,m; 计算 N_A=∫w_Aρ, M_A=∫w_Am
  5. 更新 λ: AL λ←λ−k(N−N̄) 或 Broyden/正则化 Newton
  6. 若 |N−N̄|,|M−M̄|<thr 且 SCF 收敛 → 结束
until 收敛
力/应力: F=F^{DFT}+F^{con}, σ=σ^{DFT}+σ^{con}  (§4/§5)
```
- **嵌套层级**：最内 KS 对角化；中层 λ/AL 约束；最外 MBIS KL（权重）。
  `w_A` 变化 → 重解 `V_con` → 重收敛 SCF（与 allocation 的外层 μ 迭代同构）。
- **收敛判据**：`|ΔE|`、`‖N−N̄‖`、`‖M−M̄‖`（物理量），并用 `Δρ` 作健康度
  （近零模时 `Δρ` 可能不降，见 `2026-10-30-scf-near-null-mode-stability.md`）。

## 7. 退化与一致性检查

- `w_A → Q_A^on-site`（onsite 投影）：`N_A,M_A` 成 onsite 占据 → **DeltaSpin**
  （`m_T`），`V_con` 为 `λ P̂_A σ`。
- `w_A →` 固定 Hirshfeld/Becke：退化为 **Hirshfeld/Becke 约束**（无 KL 迭代）。
- `w_A` 用 MBIS（迭代 Slater）：本文方案，电荷/自旋同时且**空间/基组鲁棒**；
  与 Mulliken/onsite 投影是**不同口径**（见 `2026-10-30-mbis-fe2-test.md`、
  `...-in-basin-l-projection-test.md`）。
- 若只需电荷：去掉 `λ^s`；只需自旋：去掉 `λ^c`。二者共用同一 `w_A`，在自旋
  空间对易（`I` 与 `σ_z`）。

## 8. 注意/风险

1. **权重密度依赖**：`w_A[ρ]` 使约束非线性；NL 项 `∂w/∂ρ` 进入精确 J 与力的
   响应；冻结权重近似是务实选择（外层迭代 + 冻结分区力）。
2. **KL 参数 Pulay**：`ζ_A` 随 R/ε 变，严格力/应力需线性化 KL 响应；近似可略。
3. **电荷冗余 (R8)**：全原子电荷约束 + 固定 N 线性相关，用 N−1+全局模式。
4. **周期/网格**：MBIS 需周期镜像求和（bcc 常规胞还要对称化，见 Fe2 测试）；
   偶极/多极在 PBC 用 Berry 相位。
5. **单位**：`λ^c` Ry/e，`λ^s` Ry/μB；自旋矩单位按代码约定（μB）。
6. **数值稳定**：优先 **AL 罚项** + 正则化 λ 更新，避免之前观测到的临界稳定/
   2-周期。
7. **可扩展**：同一框架可把约束换成 MBIS 原子偶极/四极（`∫w_A(r−R_A)ρ`），
   用于可极化力场/铁电（需相应的 `V_con` 与力核）。

## 9. 与现有代码的接法

- 权重后端：`WeightGrid` 增 `WeightType::MBIS`（Slater + KL 迭代 + 周期镜像），
  复用 `build_derivatives` 的 `∂w/∂R` 核；
- 约束注入：`ConstraintInjectLCAO/PW` 的单通道 `w_α` 直接换成 `w_A^MBIS`，
  电荷/自旋两通道用 `I_σ`/`σ_z`（`constraint_io.h` 的 `ConstraintKind` 已支持）；
- 力/应力：`constraint_deriv` 的权重导数核 + `alloc_lcao` 的加权重叠；
- λ/AL：`constraint_alm`/`mu_solver` 已有调度，可直接用。
