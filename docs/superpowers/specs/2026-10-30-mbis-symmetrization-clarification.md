# 2026-10-30 "对称化"澄清：是 MBIS 位点等价，不是时空/时间反演对称

## 0. 先澄清两个完全不同的"对称化"

| | (a) 我说的"symmetrize" | (b) 时空对称性（k 点约化/density symmetrize） |
|---|---|---|
| 对象 | **MBIS pro-density 参数 `(N_A, ζ_A)`** | 波函数/密度在空间群+时间反演下 |
| 依据 | **电荷密度的位点等价**（同种原子、等价格位） | 晶体空间群、时间反演 |
| 作用 | 防止 MBIS 迭代落到**破缺解**；使两等价原子的分区一致 | 减少 k 点/对称化密度以提速 |
| 与 SOC | **无关**（用电荷，不用时间反演） | SOC 会破坏时间反演（除非 PT 等组合对称） |

**我建议的是 (a)，不是 (b)。** 因此"SOC 下时间反演不存在、可考虑对称性很少"这一点**不影响 (a)**。

## 1. 具体是什么对称性

- bcc 常规胞（角点 Fe + 体心 Fe）中，两 Fe 由**晶体平移群**的**体心平移**
  `(a/2)(1,1,1)` 相联系——这是**无限晶体**的空间对称（平移），与自旋/时间反演无关。
- MBIS 权重 `w_A(r)=ρ_A^pro/Σρ^pro` 由**电荷密度** `ρ=ρ↑+ρ↓` 决定，故其"位点等价"
  只看**电荷的空间等价**。**SOC 破坏自旋旋转/时间反演，但电荷密度仍尊重晶体空间群**，
  所以 (a) 在 SOC 下依然成立。

## 2. 为什么对 Fe2 的收敛/一致性有帮助（此前观察到的 0.075/7.92）

- 之前 `build_mbis` 在**常规胞**、`images=0`、`symmetrize=false` 下，KL 迭代落到
  **破缺解**：两 Fe 的 `q=0.075 / 7.92`。
- 根因是**数值/离散化**：常规胞的**周期图像格**只是晶体平移群的**子格**（不含体心平移），
  于是图像求和**不把两 Fe 当等价**→ 迭代偏向一侧 → 破缺。
- 后果：逐原子观测量极不对称 → 目标 ±3.8 **对不上任何一致的态** → 约束**不良定**。
- 强制位点等价（`symmetrize` 平均 `N,ζ`，或更好：用**原胞**/**原胞平移格**的镜像求和）
  → 分区**位点对称** → 逐原子观测量 ±一致 → **约束良定**；同时去掉一个不稳定的破缺模式
  （KL 的独立自由度减少），迭代更稳。

## 3. 它**不**做的事

- **不加速一般 SCF**：它修的是 **MBIS 权重/约束的良定性**，不是电荷混合/DIAG。
- 我此前"bcc symmetrize 有助于收敛"的表述**不准确**：应说"它让 Fe2 的 MBIS 自旋约束
  能被**正确施加**（否则 ±目标与破缺分区不一致），从而可谈收敛"。

## 4. SOC / 非共线（nspin=4）下是否适用

- **适用**（对权重/电荷）：MBIS 权重由电荷建；电荷的**空间位点等价**与时间反演无关。
- **自旋约束**是**向量矩** `M_A`：权重 `w_A` 仍由电荷（空间等价）给出；目标向量按
  相应空间操作（可能含自旋旋转）变换。**不需要时间反演**。
- 若两格位**不是**空间等价的（不同局域环境/不同物种），**不可**强行平均——会引入
  错误。正确做法是**原胞**或**符合晶体平移群的镜像求和**，而非无条件平均。

## 5. 结论

- 这里的"对称化" = **MBIS pro-density 参数的位点等价投影**（电荷/空间），
  **不是** 时间反演/时空对称性约化。
- 它对 Fe2 有帮助是因为**修好 MBIS 分区的位点等价与约束良定性**；
  **不是**给 SCF 提速，也**不依赖 SOC 下是否保留时间反演**。
- 更"干净"的实现：用**原胞**（bcc 1 原子）或把**原胞平移**纳入 MBIS 镜像求和；
  `symmetrize` 是对等价位点的**务实投影**，仅限真正等价的位点。
