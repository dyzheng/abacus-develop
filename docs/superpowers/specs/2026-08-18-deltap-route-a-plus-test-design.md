# Route A+ 测试设计：能力展示与边界暴露（2026-08-18）

> 目的：用**当前实现即可运行**（零新代码）的一组测试，完整展示 Route A+
> 方案的能力边界——A 组展示能力（每个都有已验证的预言值），B 组暴露不足
> （每个不足都能被定量复现，而非含糊的"已知问题"）。
> 设计纪律：预言先行（数值全部来自既往验收记录）；判据先定；
> 高精度档（LCAO ecutwfc=100/ecutrho=400/scf_thr=1e-8，PW≥80）。

## A 组：能力展示（预期 PASS，展示"能做什么"）

### A1. 逐原子极化约束 SCF（基础能力）
- **设置**：h2o1，per-atom γ 靶点（小窗口内，如 O 通道 Δγ=+0.005 rad），
  同步驱动；
- **测量**：γ 收敛到靶点（连续性锚定读数）、λ* 有限、E′ 平直；
- **预言**：收敛，|γ−t_γ| < 1e-4 rad；E′(λ) 斜率 ~−0.013 eV/Ry 量级；
- **展示点**：约束机制本身工作；escon 记账恒等式成立。

### A2. 约束力精度（核心交付物）
- **设置**：tests/deltap_fd_force 三体系（hf/co/h2o_asym）驻点 FD 全矩阵
  （run_stationary4.sh 协议，λ 冻结在约束面值）；
- **判据**：逐腿 |ΔF| ≤ 0.0129 eV/Å；
- **预言**：21/21 PASS，最大残差 ~0.0066 eV/Å（Stage 4.2 复现）；
- **展示点**：小窗口 Γ 路径力 = 约束面精确梯度，生产可用。

### A3. 约束 relax 端到端（应用形态）
- **设置**：h2o1 Γ 路径 relax（≥4 离子步）+ 无 target 对照（应退化自由跑）；
- **判据**：与纯 DFT 基线轨迹一致（力轨迹差 < 1e-2 eV/Å 量级）；
  无 target 时 λ≡0、能量一致到 1e-13 eV；
- **展示点**：界面反场补偿类应用的直接形态。

### A4. 场模式能量与极化响应（bulk 场的独特价值）
- **设置**：co 或 h2o1，均匀 λ 五点扫描（0/±0.0025/±0.005 Ry），
  efield 锯齿场对照（dip_cor 基线 amp=0 协议）；
- **判据**：E₀(μ) 双口径偏差 < 1e-3 eV；
- **预言**：|λ|≤0.007 窗口内 < 1 meV（F-2 复现）；E_eff = πλ/(2a) 换算
  成立（response 校准 ×1.6）；
- **展示点**：无真空层 bulk 周期体系的电场能量探针。

### A5. 应力（新交付物）
- **设置**：hf 轴向 σ_zz，内部 Maxwell 双侧测量（FD λ → σ(λ) 斜率
  vs FD 应变 → Γ(ε) 斜率）；
- **预言**：|V·∂σ/∂λ + ∂Γ/∂ε|/|∂Γ/∂ε| ≈ 6.8–7.0%（L12 冻结-C 隙，
  机制级通过）；efield 压电对照杠杆 ~1.78×；
- **展示点**：变胞/压电入口已通；应力不受场模式力问题影响。

### A6. 物理观测量链（物理正确性的宏观证据）
- **设置**：h2o1 自然态；BN 面内 κ 测量；
- **预言**：H2O 偶极 1.838 D（实验 1.855，0.9%）；BN 约束刚度 κ≈0
  （零刚度发现复核）；
- **展示点**：γ→μ 物理链通；"约束刚度测量"是新观测手段。

### A7. MPI 一致性
- **设置**：deltap_mpi_smoke 4 用例 + h2o_asym 4-rank vs 2-rank vs 串行；
- **判据**：E′/γ/力逐位一致（FP 噪声 ≤2.5e-5 eV 经 λ 累积除外，需注明）；
- **展示点**：三轮 MPI 修复后的生产并行能力（含非方网格）。

### A8. 诊断输出
- **设置**：h2o1 + co 各一次 SCF；
- **预言**：⟨η⟩：h2o1≈0，co≈1.67%；spread_I：h2o1≈(0.11,0.12,0.12)，
  co≈(0.26,0.20) rad；
- **展示点**：SMO 完备性/string 局域度定量自检能力（附注：⟨η⟩ 1% 线
  不预测力残差，L13）。

## B 组：边界暴露（预期"定量失败"，展示"不能做什么、为什么"）

### B1. γ-hold 路径力泄漏（约束模式 relax 的禁区）
- **设置**：h2o1，λ 驱动钉死 γ 靶点（λ*≈0.02 Ry），驻点 FD 对拍；
- **预言**：残差 ~0.5 eV/Å（判据 25×），且残差 ∝ λ²（两个 λ 点验证标度）；
- **暴露点**：Γ 约束面 ≠ γ 物理面；**γ 靶点 relax 物理不可用**。

### B2. 场模式力的 Maxwell 失配（最大已知不足）
- **设置**：h2o1 + hf，F-2b 双口径协议（ΔP 力杠杆 L_F vs μ 杠杆 L_μ，
  efield 独立参照）；
- **预言**：L_F/L_μ ≈ 17.7×（h2o）/ 52.5×（hf）；力偏差随 λ 增长
  （2.6%@0.001 → 21–26%@0.01）；
- **暴露点**：Ô 算符的非极化几何通道；EFC/Ô_θ 的唯一剩余动机。
  **对照展示**：同体系应力杠杆仅 ~1.78×（A5）——力路径特有。

### B3. 可达域窗口（物理刚度的定量边界）
- **设置**：h2o1，T-5′ 式窗口测绘（λ 预算 0.1 Ry，O/H 通道分别扫靶点）；
- **预言**：O 通道 Δγ∈[−0.004, +0.013] rad 可达；**H 通道双侧死**
  （±0.001 rad 噪声级）；超窗靶点表现为 λ 饱和/不收敛（非报错）；
- **暴露点**：κ≈60 Ry/rad² + 传递效率 7% 是物理，不是 bug；
  大 Δγ 应用（铁电翻转）不可达。

### B4. 基组对极化率的低估
- **设置**：h2o1，efield 有限场测 α（DZP 基组），与实验值对照；
- **预言**：α_LCAO ≈ 3.02 Bohr³ vs 实验 9.8（低估 ~3.3×）；
- **暴露点**：紧缩基组效应——极化率类定量结论必须按基组定标。

### B5. 冻结-C 近似隙（L12）
- **设置**：A2/A5 的 FD 对拍中直接读数；
- **预言**：解析力/应力与全弛豫 FD 的相对差 ~7%（闭合率 1.07 同族）；
- **暴露点**：解析导数缺密度响应 C 项；高精度需求需线性响应扩展
  （未立项）。

### B6. 守卫行为（防误用，应"优雅失败"）
- **设置**：四个输入各跑一次——KPAR=2；ow 模式 + 应力；ow 模式力；
  金属性体系（近简并）；
- **预言**：前三者 WARNING_QUIT 拒绝（守卫工作）；金属体系无守卫但
  分支跟踪不可信（文档声明，不属验收）；
- **暴露点**：能力边界的代码化表达。

### B7. 内循环冻密度失效（驱动方式边界）
- **设置**：h2o1，deltap_inner_nmax>0 冻密度内循环驱动 γ；
- **预言**：振荡不收敛（冻密度 dγ/dλ = −1.28 vs 自洽 +0.03，符号反转）；
  对照组（proxy 驱动内循环）正常；
- **暴露点**：生产必须用同步/SCF 级驱动（默认即正确配置）。
