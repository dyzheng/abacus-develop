## 四、负向验证（已被历史实验否决，方案相应设计正确）

方案中几处排除性设计与 DeltaP 的否决性实验吻合，等于这些坑**已经被花钱探明**：

| 方案设计 | 否决性实验证据 |
|---|---|
| 排除 Hirshfeld-I/ISA（权重依赖密度） | T-17 活算符极限环（#1） |
| 外环收敛后才更新 μ（非同步 GD） | 同步梯度下降永不收敛实录（γ 反弹 ±3–5 rad，2026-07-20） |
| 不做冻密度内环优化 μ | T-7'' 冻密度响应符号反转、结构性不收敛（F-4 封口） |
| 排除斜投影/Mulliken 作约束 | 方案 toy model 布居越界 + 仓库 SMO 评估（非正定算子作约束病态）一致 |

## 五、结论

- 方案的**承重结构几乎全部有已验证支点**：权重原语（#15）、两条注入/积分路径（#2/#3）、外环与护栏（#4/#5）、自旋与片段扩展（#6/#7）、力与验收方法论（#9/#10）、负向设计排除（第四节）。一期真正的新写代码集中在 #15 的扩展（χ_ij、导数）+ #16/#17/#18 四个点。
- 意外收获：**Becke 原语已在仓库中（含单测）**，方案的"首选权重"不需要从零实现数学核，但异核修正与力导数仍是缺口。
- 未实现清单中风险最高的仍是 #21（偶极对偶验证）与 #22（应力），与前两轮结论一致。
