# 2026-10-29 Allocation 响应层（全空间 FD Jacobian）时间盒实验：负结果

## 1. 测试计划

按批判性评估的 D6/D7 方向，在现有架构内实现**全空间精确 Jacobian**：

```
J_ij = dQ_i/dmu_j  (含密度响应，非冻结密度 J0)
```

做法：参考相之后，对每个约束分量跑一次 `mu = +h e_i` 的 SCF 探针，用
`(Q(h e_i) − Q_ref)/h` 填 J 的列；随后 `mu* = −J^{-1}(Q_ref − t)` 做一次
Newton 起步，再用现有 trust/Broyden 继续。目标是检验"用 n_c 次 SCF 探针
换掉若干外层步"是否划算（n_c=2 的 Fe2）。

## 2. 测试设置

- 新开关：`constraint_alloc_fd_jacobian`（默认 false）、
  `constraint_alloc_fd_step`（默认 0.005 Ry）；仅 allocation 模式生效。
- 实现：`LoopPhase::FD_PROBE` + `MuSolver::seed_jacobian/newton_seed`；
  子空间 rotation 关闭以隔离算符。
- Fe2-bcc 同前（±3.8 μB、20/80 Ry、kpar=2、l=2、absolute）；4 MPI。

## 3. 结果

### 3.1 首版缺陷（已修）

首版在 `on_scf_converged` 的 FD_PROBE 分支**未检查 `conv_esolver`**，
每次 SCF 迭代都记录一列 → J 来自未收敛密度、探针两个迭代就"走完"：

```text
148 次电子迭代，26 个外层步，墙钟 39 s（远差于基线）
```

修复：FD_PROBE 只在**真实 SCF 收敛**时记录/推进。

### 3.2 修复后

```text
参考相             iter 14
探针 c0 (h,0)      iter 15–29   （15 次迭代）
探针 c1 (0,h)      iter 30–42   （13 次迭代）
Newton 种子        mu = -0.0165263 / +0.0112641 Ry
随后外层步         iter 43…116（8 个外层步）
合计：116 次电子迭代，墙钟 24 s，CONVERGED，ETOT -6370.603964
```

| 配置 | 电子迭代 | 墙钟 | 备注 |
|---|---:|---:|---|
| 基线（fd=0，rotation=0） | **63** | **11 s** | 本次修复后复核，`dsum_n=5.1e-11` |
| FD probe（首版，无收敛守卫） | 148 | 39 s | J 来自未收敛密度 |
| FD probe（修复后） | **116** | 24 s | 探针 28 步 + 外层 74 步 |

## 4. 分析

1. **探针不便宜**：J 的对角量级约 **−22**（μ 仅 0.005 Ry 就使 Q 变 0.1 μB），
   所以每个探针仍要一次**完整 SCF 收敛**（15 / 13 步），与它想省掉的外层步
   同价；n_c=2 时探针成本（28 步）无法摊薄。
2. **前向差分的 J 仍不够准**：Newton 种子 `(−0.0165, +0.0113)` 偏离最终
   `(−0.0166, +0.0160)`（c1 差 ~30%），随后仍需 8 个外层步纠正——
   非线性/分支使单次 Newton 不足以收尾（若要中心差分，探针成本再翻倍）。
3. **与调研结论一致**："每列一次完整 SCF 只适合作为验证基准，不适合生产"。
   真正的响应层需要**线性化 SCF**（只做 `T_ρ` 的矩阵自由作用，用
   Krylov 解 `(I−T_ρ)y=b`），把每列成本从"一次完整 SCF"降到"一次线性求解"；
   这是当前代码没有的新能力，且不解决 Fe2 第 3 步的**分支偏离**（线性响应
   预测不到 Δq≈1.17 的跳变）。
4. **默认路径不受影响**：`constraint_alloc_fd_jacobian=false` 时
   REFERENCE 分支不进入 FD_PROBE；复核 Fe2 仍为 **63 步 / 11 s /
   `dsum_n=5.1e-11`**，23/23 测试通过。

## 5. 下一步

1. **响应层（FD probe 版）结论：负**。保留开关（默认关闭）作为"精确 J"的
   验证/诊断基准，不进入生产路径。
2. 若仍要投入真正的响应层，需要实现**线性化 SCF（T_ρ 的矩阵自由作用）**，
   属于新能力（DFPT 级），建议单独立项并先做成本探针（D6）。
3. 性能现实选择：
   - 接受 63 步 / 11 s 作为 allocation 的实用基线；
   - 或转 **continuation/更保守 trial** 处理 Fe2 第 3 步的分支偏离
     （这是当前浪费最大的一次 trial）；
   - 只读/Γ 场景已 1.08×，可直接使用。
4. 语义/回归任务不受影响（多片段/非共线/kpar>1 分区审计、语义表更新）。
