## 4. 分析

### 4.1 S1 机制：冻结核 = 消除 C 依赖模态的充分条件

S0 已证极限环模态在 H_ow 的 C 依赖侧（外积 (A·C)(C†)ₙ）。S1 把 K_I = Σ_lm
S_k·D_I、C、θ 在渡边冻结，渡边之间 H_ow = sym(Σ_n θ_n·(Σ_I λ_I·K_I)·C†) 对 ψ
完全固定（λ 依赖精确且廉价——内循环 BFGS 试验可直接缩放冻结核）。γ 报告
（compute_gamma_scf）在两种 drive 下保持 live：drive 机制（λ 更新信号）不受
影响，S1 只冻结算符构造。

### 4.2 渡边定义（核重建时机）

1. **首次测量**（kernel invalid）：iter-1 ψ/θ 建核；
2. **P2 λ 更新**（esolver `on_phase2` → `mark_ow_kernel_stale`）：密度沉降后
   重捕 θ/ψ（h2o1 实测 iter 13 一次重建）；
3. **freeze_branch_ref**（SCF 收敛/外循环锚点）：下一轮/下一离子步首测重锚。

**D2 冻结恢复不再标记 stale**（本轮修正）：冻结 λ 扫描下算符本应固定，D2 恢复
只更新 live θ 报告；若恢复也重建核，近简并体系（BN）会周期性被踢（实测
0.004→0.08）。h2o1 D2 零触发，不受影响；驱动的合法跨分支演化由 P2/freeze 渡边
覆盖。

### 4.3 R5 新结果 vs 旧：a=0 的来源

冻结核协议下 H_ow 的 ψ 依赖在 P1 起点（自然态）冻结，E'(λ) 严格偶函数
（两弦斜率等值反号），线性系数精确为零。记账恒等式（escon ≡ −⟨H_ow⟩）在收敛
窗内逐点成立。λ² 曲率 b=247.6 eV/Ry² 为算符-密度二次响应，属协议内合法项
（T2/T3 同族的 O(λ²) 泄漏结构）。

### 4.4 BN 定位（既有限制，非 S1 回归）

BN（近简并带）θ 每 ~50 冻结步触发 D2 恢复：旧代码（活算符 + 恢复重建）密度在
0.004↔0.08 间往返；S1 移除恢复重建后，ow 与 proxy（pre-S1 等价）都只剩 ~0.003–
0.013 小振荡且行为同型 → 定位为活 H_HK 对近简并体系的刚性。证据链完整：gamma
模式（无 H_c）16 iter 收敛 → H_c（H_HK）是 BN 的唯一振荡源。

### 4.5 与 S1 手记 point 5 的偏差（有证据）

手记原定"γ-drive 不做冻结"；实测 **所有扫描 INPUT（l0/l±0.003/l±0.01/long/
beta）均为 `deltap_drive gamma`**（日志打印确认），T-17 验收对象正是 γ-drive 冻结
λ 路径——按原门控冻结将不触及任何实测用例。冻结不 gate drive：γ 报告两种 drive
均 live（drive 机制零接触），冻结只作用于 ow 算符构造。proxy/legacy gamma 零回归
（§3.5）。
