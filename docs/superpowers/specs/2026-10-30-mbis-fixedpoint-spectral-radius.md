# 2026-10-30 真实谱半径 ρ(∂F/∂p)：Picard 稳定（更正"不稳定"判断）

## 0. 实现

- `mbis_fixedpoint_spectral_radius`：**Faddeev–LeVerrier** 求特征多项式
  `det(λI−J)`，**Durand–Kerner** 求全部根 → `ρ(J)=max|λ|`（真实谱半径，非奇异值）。
- 判据：`ρ(∂F/∂p) < 1` ⇒ Picard 收缩（稳定）。

## 1. 结果（`make_toy`）

```
[RHO] rho(J)=0.8099  ||J||_2=32.7311
```
- **`ρ(J)=0.81 < 1`** ⇒ Picard **是收缩的（稳定）**。
- 之前的 `||J||_2=32.7` 只是**奇异值（谱范数）上界**，**过于宽松**，据此得出"可能不稳定"
  是**错误**的。**更正**：Picard 对 `make_toy` 稳定。

## 2. 对"对称破缺"的解释更正

- 破缺**不是** Picard 在该固定点不稳定（ρ<1）。更可能是：
  1. **多个固定点**（Picard 从不同初值落到不同自洽解），或
  2. 修复前的**常规胞图像和不保持等价**（bcc 体心平移缺失）→ 落到破缺固定点。
- 修复（`detect_cosets` 自动纳入平移）后，等价原子在 pro-density 层面对等；真实体系
  应验证其落在**对称且稳定（ρ<1）**的固定点。

## 3. 意义

- **稳定性判据**应为 **`ρ(∂F/∂p)<1`**（真实谱半径），**不是**自由 D 的 Hessian，
  也**不是** `||J||_2`（仅保守上界）。
- 当前通用框架最终形态：
  ```
  探测平移图像和 → 约束不动点(Newton/Picard，保 sum rule)
  → 多初值 + 最低 D 选解 → ρ(∂F/∂p) 判稳
  ```
