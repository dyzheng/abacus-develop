## 二、测试结果

### 2.1 Per-atom Gamma（迭代 1）

| | 测试 A (4 strings) | 测试 B (2 strings) | 差异 |
|------|:---:|:---:|:---:|
| Atom 0 (B) mean γ | 1.645 | 1.668 | +1.4% |
| Atom 0 σ | 1.2×10⁻³ | 1.3×10⁻³ | — |
| Atom 1 (N) mean γ | 1.992 | 2.000 | +0.4% |
| Atom 1 σ | 2.0×10⁻³ | 3.7×10⁻³ | — |
| P_total (a.u.) | 1.75×10⁻² | 1.77×10⁻² | +1.1% |

**结论: 两种网格布局给出高度一致的极化值（差异 < 1.4%）**，说明：
1. 沿 (ix,iy) 不同的 k-string 的 Wilson loop 结果一致
2. 匈牙利特征值跟踪（测试 B 中的 2-link string）不影响最终极化

### 2.2 跨 String 一致性

| 指标 | 测试 A | 测试 B | 判定 |
|------|:---:|:---:|:---:|
| σ(γ_atom0) | 1.2×10⁻³ | 1.3×10⁻³ | ≪ 2π·w_sum ≈ 5 |
| σ(γ_atom1) | 2.0×10⁻³ | 3.7×10⁻³ | ≪ 2π·w_sum ≈ 6 |
| 分支跳变 Δ | 全 0 | 全 0 | ✓ |
| BRANCH 判定 | OK | OK | ✓ |

σ 的量级（~10⁻³ rad）远小于 2π·w_sum^I（~5-10 rad），且远小于单带分支跳变尺度（~3 rad）。**跨 string 分支选择完全一致**。

### 2.3 SCF 迭代间变化

| | 测试 B iter 1 | 测试 B iter 2 | 变化 |
|------|:---:|:---:|:---:|
| Atom 0 γ | 1.668 | 1.117 | −33% |
| Atom 1 γ | 2.000 | 1.341 | −33% |
| P_total | 1.77×10⁻² | 1.20×10⁻² | −32% |

γ 在 SCF 迭代间显著变化（~33%）——这是电荷密度未收敛导致的，正常现象。**关键观察**：尽管绝对值在变化，跨 string 一致性始终 OK，说明分支选择在任意电荷密度下都能正确工作。

## 三、物理合理性检验

### 3.1 Per-band 投影与 SMO 权重

```
DeltaP: n=0 raw_sum=0.034  tilde_sum=0.034   → 成键带 (B-N)
DeltaP: n=1 raw_sum=0.061  tilde_sum=0.061   → 成键带
DeltaP: n=2 raw_sum=1.625  tilde_sum=1.625   → 孤对电子带 (N)
DeltaP: n=3 raw_sum=0.016  tilde_sum=0.016   → 反键带 (above EF)
```

| 指标 | B | N | 物理解释 |
|------|:---:|:---:|------|
| w_sum | 0.79 | 0.94 | N 轨道占据更大比重（电负性更高） |
| per-atom γ | 1.67 | 2.00 | N 贡献更大极化 |

- 4 个占据带中，带 2 (raw_sum=1.625) 主要定域在 N 上（孤对电子），带 0/1 是 B-N 成键带，带 3 是反键带（权重接近 0）
- 这符合 BN 闪锌矿的电子结构预期
- N 贡献更大的极化 → 电负性高，电荷密度更偏 N

### 3.2 极化总量

结构为 BN 闪锌矿（非极性，B 在 (0,0,0), N 在 (0.25,0.25,0.25)）。

| 量 | 数值 |
|------|------|
| P_total (DeltaP) | ~1.8×10⁻² a.u. |
| P_total (ABACUS) | 0 (berry_phase 未启用) |

DeltaP 计算的总极化非零。对于非极性结构，Berry phase 极化应为 0 或 2π 的整数倍。**当前非零值可能来源于**：

1. **SMO 基组不完备**：Löwdin 正交化 `<alpha_a | psi_n>` 无法完全归一化 per-atom 极化权重（w_sum ≠ 1），zeta rescaling 只能做线性修正
2. **k 点网格太稀疏**：2×2×1 仅有 4 个 k 点，Berry phase 未收敛
3. **SCF 未收敛**：仅 2 轮迭代，电荷密度还在变化

**需要参考计算才能确定绝对精度**（Wannier90 对标或 ABACUS berry_phase 对比）。

### 4.3 解决方案

要在更高 k 点密度下测试：

1. **降低 SCF 精度**：增大 `scf_thr`，减少迭代数
2. **使用平面波模式**（如果可用）：对于小体系 BN，PW 模式可能更快
3. **离线测试**：将测试提交到计算集群（更长的 walltime）

## 五、已知局限与风险

### 5.1 k-index 映射 (B14)

`setup_kstring` 使用 Monkhorst-Pack 索引公式 `ix + iy*mp_x + iz*mp_x*mp_y`，假设 ABACUS 按此顺序存储 kvec_d。当 `symmetry=-1` 时，此假设**可能成立但没有独立验证**。

如果 kvec_d 顺序不匹配，`psi->fix_k(k_index_[istring][j])` 会加载错误的波函数，O_j 矩阵错误，最终 gamma 值偏移。

**当前证据建议映射正确**：两种网格布局的结果高度一致，且 per-band SMO 权重符合电负性预期。但这并非严格证明。**建议验证**：打印 kvec_d 的前 N 个分量并与 MP 公式比较。

### 5.2 Per-atom 极化绝对值

如上分析，当前 P_total ≈ 0.018 a.u. 对于非极性 BN 偏高。需要：
1. Wannier90 对标
2. 更密的 k 点网格
3. SCF 完全收敛

### 5.3 分支跳变的物理触发

当前所有测试中 Δ = 0（无分支跳变）。分支选择代码虽然已经修好（H3 per-band spacing），但**从未被真正触发过**。需要在以下场景中验证：
- 极化的位移结构（`STRU_disp`）
- 更大 cell 的网格（mp_z ≥ 3 → 每条 string ≥ 2 links）
- 铁电材料（BTO）的自发极化
