# 2026-10-30 MBIS 的"正确分解"判据 与 对称破缺的适用范围

## 0. 两个问题的直接回答

1. **等价原子会有这个问题吗？** —— **"对称破缺"这一特定病理**只在**等价原子**上出现
   （精确解应对称，迭代却落到破缺不动点）。但**KL 不动点的多重性/局部极小**是**一般**的
   （任何体系、包括不等价原子/LiCl 都可能依赖初值收敛到不同解）。
2. **`w_A/N_A` 不含电子结构，怎么判"正确"？** —— 其实 `w_A` **隐式依赖**密度：
   `(N_A, ζ_A)` 由**KL 最小化**从 `ρ` 拟合而来。**MBIS 的"正确"由它的变分定义给出**
   （自洽地最小化 `D_KL` + 求和规则 + 对称性 + 物理可观测量），**不存在与定义无关的
   绝对正确 AIM 分解**。

## 1. `w_A` 并非"不含电子结构"——它通过 pro-density 参数隐式依赖 ρ

```
ρ_A^pro(r) = N_A ζ_A³/(8π) e^{−ζ_A|r−R_A|}
w_A(r)     = ρ_A^pro / Σ_B ρ_B^pro
```
- 形式上看 `w_A` 只依赖 `(N_A, ζ_A, R_A)`；
- 但 **`(N_A, ζ_A)` 是从密度 `ρ` 拟合出来的**：
```
N_A = ∫ w_A ρ = ∫ ρ_A
ζ_A = 3 N_A / ∫ r w_A ρ   （KL 对 s-Slater 的驻点 ≈ 布居+均值半径匹配）
```
- 所以 `w_A` 是"密度 → pro-density 参数 → 权重"的**自洽固定点**，**确实携带电子结构信息**
  （经 `N_A, ζ_A` 间接体现）。

## 2. MBIS 的"正确性"＝相对其变分定义，而非绝对

MBIS 的定义（Verstraelen 等）是**信息论 stockholder**：
```
D_A = D_KL(ρ_A^pro ‖ ρ_A) = ∫ ρ_A^pro ln(ρ_A^pro / ρ_A) dr
```
在**最小基（s 型 Slater）**族内，选择 `(N_A, ζ_A)` 使 `D_A` 最小（与 `w_A` 自洽）。
因此"正确分解"的**判据**是：

1. **变分自洽**：`ρ_A^pro` 是 `ρ_A=w_Aρ` 的 KL-最优 s-Slater 拟合（固定点方程成立）；
2. **求和规则**：`Σ_A N_A = N`、`Σ_A w_A(r)=1`；
3. **对称性**：等价原子必须给相等参数（破缺=落到非物理的局部解）；
4. **物理可观测量**：由分区重建的偶极/ESP/多极与实验/参考一致
   （如 LiCl 的 MBIS 分子偶极 6.48 D ≈ 实验 ~6.3 D）。

**AIM 分解本质上不唯一**：Hirshfeld、Becke、Bader、MBIS 都满足求和，但数值不同
（LiCl：MBIS +0.96、Mulliken +0.52、allocation −0.08）。所以**没有"绝对正确"的 AIM 电荷**；
"正确"只能是"**对某一变分定义自洽 + 物理可验证**"。MBIS 的正确性属于这一类。

## 3. 对称破缺：等价原子特有；非唯一性：普遍

- **对称破缺**（`N_A≠N_B` 而本应相等）：只在**等价原子**上成为"错误"——因为存在一个
  **已知的对称解**作参照；落到破缺解即违反对称 → 是**伪解**。
- **不动点多重性/局部极小**：普遍存在。KL 方程是**非线性**的，可能存在多个解；迭代从不同
  初值/不同数值镜像可落到不同解。即使**不等价原子**，也可能因初值不同得到不同（但都"自洽"）
  的分解。**AIM 本身无唯一解**。

## 4. 为什么"对称化"是"把解修正确"

- 对等价原子，物理正确的解**必须**在对称子空间内（`N_A=N_B`、`ζ_A=ζ_B`）。
- 迭代落到破缺解，是**数值（镜像/初值）不对称**被非线性放大造成的**错误不动点**。
- 位点等价投影 = 把迭代**限制在已知的对称子空间**，从多个 KL 不动点中**选出物理正确的那个**。
  因此它不是"人为平均"，而是**利用已知对称性消除伪解**。

## 5. 结论

- **等价原子**才会有"对称破缺"这个病理；**非唯一性**是 AIM/MBIS 的一般性质。
- `w_A/N_A` **通过 KL 拟合隐式依赖密度**；"正确分解"= **KL 自洽最优 + 求和 + 对称 + 物理可观测**，
  不是与定义无关的绝对量。
- 对称化的作用是**在多个自洽解中选出保持已知对称性的那个**，而非改变物理。

## 6. 实用判据（可执行的"正确性"检查）

1. `Σ_A N_A = N`（求和审计）；
2. 等价原子 `|N_A−N_B|<tol`、`|ζ_A−ζ_B|<tol`（对称性）；
3. KL 残差/RMS 单调收敛到固定点；
4. 偶极/ESP 等与参考一致（物理）；
5. 对初值/镜像层数做稳健性检查（解不随数值设置漂移）。
