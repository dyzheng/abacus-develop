# DeltaP 算符谱系分析：γ / Ô / Ô_w / Ô_θ 的区别与各自解决的问题（2026-08-18）

> 起因：一个常见误解——"Route A+ 已经换了算符"。**没有。** Route A+ 换的是
> 记账观测量（escon 从 −λγ 改为 −λΓ），哈密顿量 H_c = Σλ_I·Ô_I 中的约束
> 算符 Ô 从未改变。场模式力问题住在算符里，需要的是另一次、不同层面的
> 更换（→ Ô_θ）。本文档厘清四个"算符/观测量"的区别、各自解决与未解决
> 的问题。

---

## 1. 分析框架：DeltaP 机制中"观测量"的三个角色

整套机制里有三个**不同的位置**各需要一个"量"，混淆它们是一切误解之源：

| 角色 | 作用 | 当前用什么 |
|------|------|-----------|
| **(a) 驱动观测量** | λ 的调节目标：SCF 中计算残差、驱动 λ 直到其命中靶点 | **γ**（Berry 相位，Wilson loop + SMO 投影；从未改变） |
| **(b) 哈密顿量算符** | 实际加进 H = H_KS + Σλ_I·Ô_I 的算符，产生约束/场的物理作用 | **Ô**（H_HR + H_HK；从未改变；Ô_w 为实验性替代） |
| **(c) 记账观测量** | escon = −Σλ_I·(此量)，从报告能量中扣除约束代价 | **γ（旧，2026-08-05 前）→ Γ = ⟨Ô⟩（Route A+）** |

**Route A+ 改的是 (c)**：旧方案 escon = −λγ，但 ⟨H_c⟩ = λΓ，两者不等
（γ ≠ Γ），失配 (Γ−γ) 导致 E'(λ) 斜率 O(1)（实测 224 eV/Ry）和力泄漏。
Route A+ 令 escon = −λΓ ≡ −⟨H_c⟩，恒等式精确成立（斜率 → −0.013 eV/Ry）。
**(b) 自始至终是同一个 Ô。**

对照 DeltaSpin：它的三个角色是**同一个对象**（M_I = ⟨P̂σ⟩ 同时是驱动
观测量、哈密顿量算符期望、记账量），所以那里从不存在这类问题。

## 2. 谱系成员逐一分析

### 2.1 γ —— 物理观测量（不是算符）

- **定义**：γ_I = Im ln det（Wilson loop 本征值相位，经 SMO 投影逐原子分解）；
- **性质**：**非线性泛函**（log-det 而非 trace）；**多值**（mod 2π，需分支
  跟踪/连续性锚定）；极化的微观定义，有独立物理存在（可用 berryphase
  模块、efield 响应独立测量）；
- **角色**：(a) 驱动观测量；生产靶点的物理语言；
- **它"不是算符"这件事正是一切的根源**：γ 不能直接放进哈密顿量，
  必须找一个算符来"代理"它——以下三个算符是三代代理方案。

### 2.2 Ô —— 现行约束算符（"hk" 模式，生产用）

- **构造**：Ô = H_HR + H_HK 两部分——
  - H_HR（实空间）：τ_α(I)·P̂_I，on-site 投影（布居型通道）；
  - H_HK（k 空间）：由 k 近邻重叠 S_dk、SMO 权重 w_eff、Gram 结构搭建，
    Γ^HK = −0.5·Im[Σ w_eff·T·Π]，T = C_L†·S_dk·C_R，Π = C_L†·C_L（全迹）；
- **与 γ 的关系**：**Γ = ⟨Ô⟩ 是 γ 的线性化（微分）对应物**——Ô 的构造
  使其期望复现 dγ 的一阶形式。差异来源：① trace vs log-det 的 O(dk²)
  数学差；② SMO 权重约定；③ **Γ 无分支**（算符期望，天然免锚定）——
  这也是 Route A+ 记账换 Γ 后数值更干净的副收益；
- **R 依赖（场模式问题的住所）**：Ô 的构造件（S_dk、SMO 权重、string
  几何）**显式依赖原子位置**，故 ∂Γ/∂R 含两个通道——
  极化通道（物理，给出 Z\*）+ **非极化几何通道**（伪力，实测力杠杆
  17.7×/52.5×，F-2b）；
- **验证状态**：约束模式全链通过（T3/Stage 4.2 FD 21/21）；场模式能量/
  响应/应力通过；**场模式力 FAIL**；
- **解决了**：约束模式自洽性（配合 Route A+ 记账）；**没解决**：场物理
  的力级 Maxwell 一致性。

### 2.3 Ô_w —— 精确权重算符（"ow" 模式，实验性，已挂起）

- **设计意图**：修正 Ô 的权重覆盖（精确 SMO 权重），让算符期望更精确地
  追踪 γ——是 (b) 的一次**增量改良**，不是换物理；
- **判决（T-18）**：**FAIL**——响应 dγ/dλ ≈ 0.26 rad/Ry vs 预言 ≥3
  （差 ~10×），且 γ(λ) 非单调。**精确权重不提升响应、不扩大窗口**；
- **完成度**：F_ow 未实现；多 string 网格仅 string-0 覆盖；应力守卫拒绝；
  MPI 门控跳过；
- **现状**：实验性挂起（约束模式封口后无动机）。教训落档：**算符期望值
  更接近 γ ≠ 物理响应更强**——传递效率的瓶颈在密度弛豫，不在算符精度。

### 2.4 Ô_θ —— EFC 全阶算符（提案，未立项）

- **设计意图**：**⟨Ô_θ⟩ ≡ γ（全阶，构造上恒等）**——直接以 Berry 相位
  对密度矩阵的泛函导数为算符。ΔSpin 式三位一体由此恢复：
  (a)=(b)=(c)=γ；
- **关键性质**：其 R 导数**构造上就是纯极化通道**（∂γ/∂R = Z\* 型物理），
  非极化几何通道不存在 ⇒ 场模式力杠杆 L_F = L_μ 自动成立（Maxwell 恢复）；
- **附带收益**：约束面 = 物理面，γ-hold 力泄漏（0.502 eV/Å，λ² 族）的
  源头消失，γ 靶点 relax 可能复活；Γ/γ 二元分裂、锚定纪律负担随之消失；
- **代价与风险**：实现涉及 log-det 泛函导数、Wilson 本征矢、分支处理、
  k 近邻耦合，工程量 L3 级；换算符后**全验证链重跑**（记账恒等式/T2/
  T3/MPI/应力）；**不改善响应窗口**（T-18 已钉死传递瓶颈在密度弛豫）；
- **验收预言（立项时须先写下）**：F-2b 对拍 L_F/L_μ：17.7×/52.5× → 1±5%；
  E₀(μ) 能量窗不退化（<1 meV）；γ-hold 力残差 0.502 → Γ-path 同量级
  （~0.01 eV/Å）。

### 2.5 （旁支）PW 侧的 Γ^PW

PW 不构造 k 空间 Ô，Γ^PW_I = ⟨P̂_I^onsite⟩（becp 期望），H_c 用对应的
onsite 形式。角色与 LCAO 的 Ô 相同，构造不同；应力由既有 onsite 路径
覆盖；力未独立验收。

## 4. 结论

1. **Route A+ 换的是记账观测量（角色 c），不是算符（角色 b）**。
   它解决的是**自洽性**（E′ 恒等、约束力=约束面精确梯度），并且已验收；
2. **场模式力问题是算符（角色 b）的物理缺陷**：Ô 的几何依赖超出极化
   本身。修记账修不到它——这正是 F-2b 证明"实现的力自洽 ∧ 场物理错误"
   双命题并存的原因；
3. **Ô_w 的失败说明增量改良（让 ⟨Ô⟩ 更接近 γ）此路不通**——问题不在
   权重精度，而在算符的几何构造；
4. **Ô_θ（EFC）是唯一第一性解法**：期望值恒等于 γ ⇒ R 导数纯极化通道
   ⇒ Maxwell 一致性构造上成立。它是"换算符"，且是三代代理中唯一从
   γ 本身出发（而非从 γ 的线性化出发）构造的算符；
5. 立项门槛：L3 工程量 + 全验证链重跑 + 明确的非目标（不改善窗口）。
   过渡期场模式力禁用，或用带纪律的半经验 Z\* 补丁。
