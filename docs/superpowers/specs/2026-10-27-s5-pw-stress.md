# S5.1 PW allocation 目标应力

日期：2026-10-27

计划：`docs/superpowers/plans/2026-10-21-unified-allocation-execution.md`，Task S5.1。

本轮补上 PW allocation 的几何应变导数：共享网格核继续计算
`Q_c dW_i/deps Q_c`，新增目标 projector 的显式应变项
`mu dQ_T/deps`，两者在 `ConstraintLoop::compute_stress()` 中相加后交给
`Stress_PW::cal_stress()`。

## 1. 测试计划

1. 验证目标 shell 选择使用全局 onsite-projector 行号，而不是每原子局部偏移。
2. 用 `np=2/4` 检查中心构型的能量、约束应力和总应力是否一致。
3. 对 H2O/H-s 的 `eps_xy` 做多点中心差分，与解析总应力比较。
4. 对等容应变 `eps_iso` 检查总应力迹。
5. 复跑 H2O/O-d `l=2` 中心构型，确认目标应力没有破坏既有 S5.1 结果。
6. 检查清理后的日志不再包含临时 `ALLOC-TARGET-RAW` / `ALLOC-STRESS-SPLIT`。

## 2. 测试设置

- 分支：`feat/unified-local-moment-allocation`
- 构建：`build/abacus_basic_para`，CPU，OpenMPI
- H-s 体系：畸变 H2O，目标为 H1 的 `l=0` s 投影
- `nspin=1`、`charge` 约束、Becke 权重、`fixed_mu=0.01 Ry`
- `nbands=8`、`ecutwfc=20 Ry`、`ecutrho=80 Ry`、`symmetry=0`、Gamma only
- `scf_thr=1e-9`、`scf_nmax=200`、`constraint_alloc_target_l=0`
- 立方盒 `15 x 15 x 15 Angstrom`，`Omega=3375 Angstrom^3`
- L2 体系：H2O/O-d、`nspin=2`、`spin` 约束、`target_l=2`、`scf_thr=1e-8`
- PW 测试只跑 MPI 多进程；OpenMP、OpenBLAS、MKL 固定为单线程：

```bash
export OMP_NUM_THREADS=1
export OPENBLAS_NUM_THREADS=1
export MKL_NUM_THREADS=1
export OMPI_ALLOW_RUN_AS_ROOT=1
export OMPI_ALLOW_RUN_AS_ROOT_CONFIRM=1
```

总能差分按

```text
sigma_ab(FD) = -[E(+h)-E(-h)] / (2 h Omega)
```

换算，`1 eV/Angstrom^3 = 1602.176634 kbar`。

## 3. 实现

1. `select_pw_target_shell()` 返回全局 onsite-projector 行号。原实现返回每原子
   局部行号，`l=0/1` 时所有原子都会误读第一个原子的目标，导致目标空间塌缩。
2. `Onsite_Proj_tools` 新增 `cal_dbecp_s_custom()`，对任意 band 向量计算
   `<d alpha/d eps_ab|vec>`；复用现有 VKB 应变导数核，只把 GEMM 的右端换成
   allocation 的 band/target/WQ 向量。
3. `compute_pw_alloc_target_stress()` 汇总以下三项：

   ```text
   D_ab       = <d alpha_a/d eps|alpha_b>
   dST        = D + D^H
   dQ_owner   = 2 Re sum_{a in owner} conj(d_orth_a) orth_a
   cross      = sum_a [conj(orth_a) d_orth_wq_a
                     + conj(d_orth_a) orth_wq_a]
   s_ab      -= f mu sign (dQ_owner - 2 Re cross)
   ```

4. `ConstraintLoop` 新增 `set_allocation_target_stress()`。目标项在
   `constraint_stress()` 的网格项之后相加。
5. `Stress_PW::cal_stress()` 新增可选 `extra_stress`，在对称化和打印前并入总应力；
   并打印独立的 `CONSTRAINT STRESS`。
6. 应力累加器存的是 `s=-dE/d eps`，最终物理应力使用
   `+0.5*sym(s)/Omega`。上一轮的负号已修正。
7. 临时双次 `compute_stress` 与逐项原始诊断已删除。

## 5. 分析

1. 全局行号修复是必需的：旧结果把 H1/H2 的 s 目标都映射到 O 的 projector，
   因此早期 `l=0` 应力结论全部作废；修复后 `ntarget=3`、`rank=3`、`cond=4.62`。
2. 目标应力与网格应力的符号约定已经统一。总能、`q`、约束力和应力在
   `np=2/4` 下一致到 `1e-10` 量级。
3. 剪切通道用两侧解析应力平均值验收，相对 FD 误差约 `0.86%-0.88%`；等容迹误差
   `0.39%`。这满足 S5.1 应力门限。
4. **已知边界**：精确零应变的立方构型给出 `sigma_xy=0.7938876324 kbar`，
   相对 FD 偏低 `5.70%`。但 `eps_xy=5e-5/1e-4/2e-4/5e-4` 的解析值都约为
   `0.8344-0.8418 kbar`，且在 `1e-5` 时也已经是 `0.8344 kbar`。这说明不是
   应变非线性，而是精确高对称点的 projector 应变导数存在残余数值/缓存边界问题。
   本轮不改动底层非局域应变核；验收采用两侧平均，并把零应变点列为下一轮待查项。
5. `bndpar>1` 仍未验证，PW allocation 应力路径显式拒绝。
