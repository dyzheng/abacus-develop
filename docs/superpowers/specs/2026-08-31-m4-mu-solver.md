# 2026-08-31 M4：外环 μ 求解器（逐分量 secant + 护栏 + 熔断）

## 1. Test plan
- `SecantKnownRoot`：合成映射 Q(μ)=2.0−0.5μ，target=1.9 → 根 μ*=0.2；
  断言 6 步内 CONVERGED、|Q−t|<1e-6、μ 单调逼近根。
- `SecantKnownRootTwoComponents`：双通道 μ0*=0.2、μ1*=0.05 独立收敛。
- `SignFlipGuardAndFuse`：非单调通道 Q(μ)=2.0+0.5μ → 每步 secant 斜率翻号；
  护栏触发（sign_flip_count>0）、μ 顶到 mu_max 后不再增大、熔断
  UNREACHABLE 且报告 Q(mu) 端点。
- `FlatChannelFuse`：Q(μ)≡2.0（双侧不可达死通道）→ μ 顶到 mu_max、
  残差平台 → UNREACHABLE（残差报告 0.1），μ 全程不越界。
- `SoftChannelFuseAtCap`：Q(μ)=2.0−0.001μ（真根 μ=100 超界）→
  kappa_min 护栏保持步长有限，熔断于 mu_max，报告端点残差。
- `AntiFakeConvergence`：μ=0 且 Q==target 首步即 CONVERGED；Q!=target
  永不报 CONVERGED（最终熔断）。
- `StiffChannelBoundedLimitCycle`：Q(μ)=2.0−100μ（真根低于步长分辨率）
  → 有界极限环：不发散、不假收敛、残差有界。

## 2. Test setup
- 平台：容器 gcc C++17（编译档 C++14 兼容）+ GoogleTest；
  `MODULE_ESTATE_constraint_mu_solver`。
- 输入：纯合成 mock Q(μ)（无 SCF、无网格），逐分量历史
  (mu_prev, Q_prev) 由求解器维护。

## 3. Results
- 7/7 PASS。修复 1 个实现缺陷：历史记录误存更新后 μ 导致 secant 观测步
  恒为 0（翻号检测失效）；改为记录观测点 μ（更新前值）后全部通过。
- 关键行为：翻号通道 11 步熔断（mu 0→0.5 顶限 + 3 步平台窗）；平通道
  10 步熔断；软通道（κ=0.001→clamp 0.3）10 步到顶熔断；硬通道 50 步
  有界极限环（RUNNING，|μ|≤5、残差≤5）。

## 4. Analysis
- 熔断判据 = μ 顶限 + plateau_window 步残差改进 <1%，双条件联合避免
  "顶限但仍在收敛"误熔断（收敛时改进 100%）。
- 反假收敛由收敛检查先于更新保证：任何 |Q−t|≥conv_tol 的调用不可能返回
  CONVERGED。
- 单步限幅 + κ clamp 把发散护栏落地为确定性行为（R2/R3 缺口补齐）；
  硬通道极限环是步长分辨率的固有代价，后续由 V3 实测判物理可达域。
