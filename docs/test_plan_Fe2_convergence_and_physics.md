## 一、投影电荷求和 vs 总电荷：投影完备性分析

### 1.1 物理背景

DeltaQS 使用 first-zeta 投影算符 P_I 定义原子电荷：

$$N_I = \text{Tr}[\rho \cdot P_I]$$

由于 first-zeta 投影空间不完备（仅包含每个角动量通道的第一个zeta），存在"间隙电荷"：

$$N_{gap} = N_{total} - \sum_I N_I > 0$$

**关键问题**：约束 N_I 时，只能控制投影子空间内的电荷分布，无法控制间隙区域的电荷。这影响约束的物理含义和可达范围。

### 1.2 测试步骤

**T0: 无约束基线**

```
INPUT:
  sc_mag_switch    0
  sc_charge_switch 0
```

**记录**：
- N_total（SCF输出，应 = 32.0000）
- Ni_0, Ni_1（通过 cal_ni_lcao 或临时输出获取）
- ΣNi = Ni_0 + Ni_1
- N_gap = N_total - ΣNi
- 投影完备性 p = ΣNi / N_total

**预期**：
- N_total = 32.0000（SCF自洽保证）
- Ni_0 = Ni_1（BCC对称性）
- p ≈ 0.6-0.9（first-zeta不完备）
- N_gap ≈ 3-13 e（间隙电荷）

### 1.3 通过标准

- [ ] N_total = 32.000 ± 0.001
- [ ] Ni_0 = Ni_1（差异 < 0.001 e）
- [ ] 0.4 < p < 1.0
- [ ] N_gap > 0（投影确实不完备）

### 1.4 物理含义分析

| p 值范围 | 含义 | 影响 |
|----------|------|------|
| p ≈ 0.9 | 投影接近完备 | 约束物理含义清晰 |
| p ≈ 0.7 | 中等不完备 | 约束控制~70%电荷 |
| p < 0.5 | 严重不完备 | 约束物理含义模糊，需谨慎解读 |

**风险**：如果 p 太小，约束 Ni 的物理含义不明确——你只控制了部分电荷，其余电荷在间隙区域自由分布。

## 二、单原子约束下的电荷守恒与重分配响应

### 2.1 物理问题

约束一个原子的投影电荷时：
1. **总电子数是否严格守恒？** N_total = 32.0000？
2. **未约束原子如何响应？** 另一个原子的投影电荷是否补偿？
3. **间隙区域如何响应？** N_gap 是否变化？

### 2.2 对称约束测试（T1）

**设置**：两原子反向偏移，总投影电荷守恒

```
STRU:
  atom 0: tc = Ni_0^0 + 0.3   cq = 1
  atom 1: tc = Ni_1^0 - 0.3   cq = 1
```

**记录**：
- N_total, Ni_0, Ni_1, ΣNi, N_gap
- μ_0, μ_1

**预期**：
- N_total = 32.0000（严格守恒）
- Ni_0 ≈ Ni_0^0 + 0.3, Ni_1 ≈ Ni_1^0 - 0.3
- μ_0 ≈ -μ_1（反对称）
- ΣNi ≈ 2·Ni_0^0（总投影电荷守恒）
- N_gap ≈ 常数（间隙电荷不变）

**通过标准**：
- [ ] |N_total - 32| < 1e-8
- [ ] |μ_0 + μ_1| / |μ_0| < 0.01（反对称性）
- [ ] |ΣNi - 2·Ni_0^0| < 0.01 e

### 2.3 单原子约束测试（T2）

**设置**：只约束 atom 0，atom 1 自由

```
STRU:
  atom 0: tc = Ni_0^0 + δ   cq = 1
  atom 1: 无约束              cq = 0

δ ∈ {0.1, 0.3, 0.5, 0.8, 1.0}
```

**记录每个δ**：

| δ | Ni_0 | Ni_1 | ΔNi_1 | α | N_total | ΔN_gap | μ_0 |
|---|------|------|-------|---|---------|--------|-----|
| 0.0 | Ni_0^0 | Ni_1^0 | 0 | - | 32.000 | N_gap^0 | 0 |
| 0.1 | | | | | 32.000? | | |
| 0.3 | | | | | 32.000? | | |
| 0.5 | | | | | 32.000? | | |
| 0.8 | | | | | 32.000? | | |
| 1.0 | | | | | 32.000? | | |

**关键量**：
- ΔNi_1 = Ni_1 - Ni_1^0（未约束原子的响应）
- α = -ΔNi_1 / δ（补偿系数，0 ≤ α ≤ 1）
- ΔN_gap = N_gap - N_gap^0（间隙电荷变化）

**预期物理**：

1. **N_total 严格守恒**：|N_total - 32| < 1e-8
2. **未约束原子部分补偿**：ΔNi_1 < 0（当δ>0时），但 |ΔNi_1| < δ
3. **间隙区域也参与补偿**：ΔN_gap < 0（间隙电荷减少，补充给约束原子）
4. **补偿系数**：α ≈ 0.3-0.8（取决于投影完备性）

**电荷守恒方程**：

$$\delta = (-\Delta N_{i,1}) + (-\Delta N_{gap}) = \alpha\delta + (1-\alpha)\delta$$

- αδ 来自未约束原子的投影电荷减少
- (1-α)δ 来自间隙区域的电荷减少

**通过标准**：
- [ ] 所有δ：|N_total - 32| < 1e-8
- [ ] ΔNi_1 与 δ 符号相反
- [ ] 0.1 < α < 0.9
- [ ] μ_0 随 δ 单调增加

### 2.4 结果分析

**画出以下曲线**：
1. Ni_1(δ) vs δ → 线性区斜率 = -α
2. N_gap(δ) vs δ → 线性区斜率 = -(1-α)
3. μ_0(δ) vs δ → 线性区斜率 = k_eff（有效电荷硬度）
4. E(δ) vs δ → 二次拟合得到 ½k_N

**物理洞察**：
- α 大（→1）：投影接近完备，约束主要通过原子间电荷转移实现
- α 小（→0）：投影严重不完备，约束主要通过间隙电荷重分配实现
- α ≈ p（投影完备性）：理想情况下，补偿比例等于投影比例

## 三、总电荷可变场景：当前算法不支持，需明确风险

### 3.1 场景描述

用户可能期望的"总电荷可变"场景：
- 固定外部化学势 μ_ext（而非电子数）
- 体系与电子库接触，电子数自由调整
- 类似电化学反应中的电极-电解质界面

### 3.2 当前算法行为

**当前实现**：
- SCF 填充固定数量的电子（nelec = 32）
- 电荷约束 μ·P_I 改变 Hamiltonian，但不改变 nelec
- 费米能级由电子数决定（自动调整）
- **N_total 始终 = 32**，不可变

**结论**：当前算法**不支持**总电荷可变的计算。

### 3.3 如果要实现"总电荷可变"

需要修改 SCF 填充逻辑：
1. 固定费米能级 E_F（而非电子数）
2. 用 Fermi-Dirac 分布填充能带
3. N_total = Σ f(ε_i, E_F, T) 自动确定
4. 需要新增参数：`sc_fixed_eferm`（固定费米能级值）

**代码改动**：
- `calculate_weights()` 函数：改为固定 E_F 模式
- 新增 `fixed_eferm` 参数
- 输出 N_total 作为计算结果（而非输入）

### 3.4 风险评估

| 风险 | 严重度 | 说明 |
|------|--------|------|
| 用户误以为当前支持总电荷可变 | **高** | 需要文档明确说明 |
| 强行修改 nelec 模拟 | **中** | 破坏体系电中性，物理不合理 |
| 需要此功能但无法使用 | **中** | 需等待新feature开发 |

### 3.5 当前可行的替代方案

**方案A：大超胞近似**
- 用大超胞包含"电子库"原子
- 约束目标原子的电荷，让"库"原子自由响应
- 近似模拟开放体系

**方案B：手动扫描 nelec**
- 手动改变 INPUT 中的 nelec（如果有此参数）
- 对每个 nelec 做一次约束计算
- 画出 E(nelec) 曲线，提取化学势

**方案C：等待新功能**
- 开发 `sc_fixed_eferm` 功能
- 真正实现巨正则系综

### 3.6 测试建议

**当前无法测试**总电荷可变场景。建议：
1. 在文档中明确标注此限制
2. 在 INPUT 参数说明中注明
3. 未来开发此功能后补充测试

## 四、Q+S 联合约束的内循环收敛测试

### 4.1 测试目标

验证统一的 Polak-Ribière CG 内循环可以同时收敛自旋约束（S）和电荷约束（Q）。

### 4.2 基本收敛测试（T3）

**设置**：

```
INPUT:
  sc_mag_switch     1
  sc_charge_switch  1
  sc_thr            1e-4
  sc_charge_thr     0.05
  nsc               40
  alpha_trial       0.01
  sc_charge_alpha   0.1
  sccut             3.0
  sc_charge_sccut   5.0

STRU:
  atom 0: mag 2.0  sc 1 1 1  tc Ni_0+0.3  cq 1
  atom 1: mag -2.0 sc 1 1 1  tc Ni_1-0.3  cq 1
```

**每步记录**：
- RMS_total = sqrt((ΔM_0² + ΔM_1² + ΔN_0² + ΔN_1²) / 4)
- RMS_spin = sqrt((ΔM_0² + ΔM_1²) / 2)
- RMS_charge = sqrt((ΔN_0² + ΔN_1²) / 2)
- N_total（每步都应 = 32）

**通过标准**：
- [ ] 20步内 RMS_total < max(sc_thr, sc_charge_thr)
- [ ] RMS_spin 和 RMS_charge 同步下降
- [ ] 无严重振荡（允许2-3步轻微波动）
- [ ] 每步 N_total = 32.0000

### 4.3 收敛曲线诊断

**画出三条曲线**：
1. RMS_total vs step
2. RMS_spin vs step
3. RMS_charge vs step

**理想行为**：
```
RMS
 |  \
 |   \___
 |       \___
 |           \___
 |               \___  ← 三条曲线同步下降
 |_______________________ step
```

**异常行为诊断**：

| 现象 | 可能原因 | 解决方案 |
|------|---------|---------|
| RMS_spin 收敛，RMS_charge 不收敛 | charge CG 步长太小 | 增大 sc_charge_alpha |
| RMS_charge 收敛，RMS_spin 不收敛 | spin 和 charge 耦合太强 | 减小约束强度 |
| 两者交替振荡 | CG 方向问题 | 需要重启机制（β→0） |
| RMS_total 发散 | 严重 bug 或参数不合理 | 检查 alpha_trial, sccut |
| RMS_charge 先降后升 | 线搜索失败 | 检查线搜索逻辑 |

### 4.4 分量分解分析

**额外输出**（需修改代码或解析log）：

```
Step 0:
  ΔM_0 = +0.15 μB, ΔM_1 = -0.15 μB
  ΔN_0 = +0.25 e,  ΔN_1 = -0.25 e
  RMS_spin = 0.15, RMS_charge = 0.25

Step 5:
  ΔM_0 = +0.03 μB, ΔM_1 = -0.03 μB
  ΔN_0 = +0.08 e,  ΔN_1 = -0.08 e
  RMS_spin = 0.03, RMS_charge = 0.08
```

**分析**：
- 各分量的收敛速率是否一致？
- 是否存在某个分量"拖后腿"？
- 反对称性是否保持（ΔM_0 ≈ -ΔM_1, ΔN_0 ≈ -ΔN_1）？

## 七、能量一致性验证（T7）

**对T3的收敛态**：

```
E_KS   ← OUT文件中报告的总能（含约束H'的本征值）
E_scon ← -Σ(λ_i·M_i + μ_i·N_i)
E_DFT  ← E_KS + E_scon
```

**验证**：
- E_scon_spin = -Σλ_i·M_i 非零
- E_scon_charge = -Σμ_i·N_i 非零
- E_scon = E_scon_spin + E_scon_charge
- E_DFT 物理合理（与无约束能量差异 < 5 Ry）

### 8.2 关键物理判定

1. **投影电荷 vs 总电荷**：first-zeta投影不完备，ΣNi < N_total，约束只能控制部分电荷
2. **电荷守恒**：任何约束操作都不改变N_total，这是SCF的基本保证
3. **电荷重分配**：约束一个原子时，其他原子和间隙区域自动补偿
4. **CG收敛性**：统一CG可以同时处理spin和charge约束，且对初始值和约束强度鲁棒
5. **热力学一致性**：μ = dE/dN 成立，验证约束DFT的变分原理
6. **总电荷可变**：当前算法不支持，需要新功能开发

### 8.3 已知限制与风险

| 限制 | 影响 | 建议 |
|------|------|------|
| 投影不完备 (p < 1) | 约束物理含义模糊 | 记录p值，谨慎解读结果 |
| 不支持总电荷可变 | 无法模拟开放体系 | 等待新功能或使用大超胞近似 |
| CG可能振荡 | 强约束下收敛困难 | 使用重启机制，减小约束强度 |
