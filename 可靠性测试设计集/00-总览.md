# DeltaP / DeltaQ 算法可靠性测试设计集——总览

> 本测试集针对的核心问题：ABACUS 中新实现的 DeltaP（约束极化）与 DeltaQ（约束电荷）算法**到底是否可靠**。
>
> **统一对标原则**（用户确立）：
> - DeltaP：LCAO 结果 ≈ PW 结果 ≈ 传统 Berry-phase（或能量差分）结果 ≈ wannier90 结果；
> - DeltaQ：LCAO 结果 ≈ PW 结果 ≈ 实验值或传统算法（CDFT/ΔSCF/恒电位）结果。
>
> 共 28 个测试：DeltaP 系列 P01–P18，DeltaQ 系列 Q01–Q10。每个测试为独立 markdown 设计文档，含目的原理、对标锚点、算例、工作流、通过判据、前置阻塞、风险注意七节。

## 全局红线（继承此前全部分析结论）

1. **同设置裁判原则**：任何跨方法对比必须同盒、同基组/同精度基组、同泛函；响应性质的绝对值只与同设置参照（能量 FD）比，不与 CCSD(T) 直接比（基组误差另计）。
2. **raw γ 红线**：响应测量只用 raw γ（Wilson 行列式）；branch γ 的 per-atom 分支选择破坏 Σ 守恒，仅作诊断。
3. **盒子/基组红线**：极化率 ≥15 Å（30 Bohr）+ TZDP 起；偶极对比 ≥12 Å；<12 Å 禁止绝对值对比。
4. **因子备忘录前置**：λ↔E（Ry/Ha）、γ↔μ（spin）、frozen-λ 能量记账三项代码核实（《单位与符号备忘录》）是 P01/P05/P08/P10/P15/P17/P18 的前置。
5. **PW 约束核**：R6 已证实 PW 响应被 SMO 覆盖率（~19%）压制；PW 响应类测试仅在 P16 整改通过后有效；PW 平衡类测试（λ=0）不受影响。
6. **DeltaQ 非中性协议**：跨荷电态能量比较必须经 Makov–Payne/FNV 修正 + 电位对齐 + 双尺寸缩放；离域过剩电荷（偶极束缚）以缩放外推为准；分数 t 仅作 μ 斜率工具。
7. **DeltaQ 门槛**：Q01（CP-0）未通过前，Q 系列一切应用测试的结果不可引用。

## 可靠性声明的达成条件

- **DeltaP 可靠**：P01 通过 + P02/P04 平衡组通过 + P08/P09 数值稳定通过 + P16 PW 整改闭环；
- **DeltaQ 可靠**：Q01 + Q06 正确性通过 + Q02 能量对标通过 + Q09 收敛图谱无系统性失败；
- 其余 P1/P2 项为**增强证据**与应用展示，允许个别项标注"部分通过"。
