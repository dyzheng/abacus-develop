Conclusion (calibration):
1. Correctness: the gate is a pure cost knob.  Across all three systems the mu*
   spread is <= 0.34% and |dE_tot| <= 4.2e-7 eV between gate values, inside the
   equivalence criteria (< 1% / < 1e-6 eV).  No correctness reason to change the
   default.
2. Cost: the sign of the gate effect is SYSTEM-DEPENDENT -- 212 improves
   (+4.8% -> -9.5% vs OUTER), 213 is flat (-46% / -47% / -45%), MgO degrades
   (-75% -> -72% -> -66%).  A stricter gate always means fewer in-SCF mu updates
   (212: 27/11/10, 213: 28/25/24, MgO: 31/22/22), so what changes is whether the
   saved mixing churn outweighs the longer approach phase -- that balance is
   system-specific.
3. Recommendation: KEEP the default 1e-3 (DeltaSpin convention).  Treat
   constraint_inner_thr as a per-system knob: if INNER loses to OUTER on a system,
   a 2-3 point scan (1e-3 / 1e-4 / 1e-5) can recover the deficit (as on 212) but
   can also hurt (as on MgO) -- never tune it blindly.
4. The settle check fires at every gate value (1-2 bounces per point, MgO 0), so
   it is not an artifact of a loose gate; keep it on unconditionally.
