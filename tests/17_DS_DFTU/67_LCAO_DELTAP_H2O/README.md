# H2O 分子 DeltaP 测试

## 测试目的
在简单分子体系上验证 DeltaP 逐原子极化分解，并与 Berry phase 和 Wannier90 对比。

## 体系参数
- **结构**: H2O 分子，15 Å 立方盒子
- **赝势/轨道**: O.upf + O_gga_6au_100Ry_2s2p1d.orb, H.upf + H_gga_6au_100Ry_2s1p.orb
- **k-mesh**: 4×4×4 (64 k-points)
- **电子结构**: 8 价电子, nocc = 4

## 结果对比

| 方法 | d_z (e·Bohr) | 与参考值偏差 |
|------|-------------|------------|
| **电荷密度 (参考)** | 0.765362 | 0% |
| **Berry Phase** | 0.766660 | **0.17%** ✓ |
| **DeltaP** | 7.77e-3 | **-99%** ✗ |
| Wannier90 | 不物理 | — |

## 关键发现

1. **Berry Phase 正确**: 与电荷密度偶极矩一致 (0.17% 偏差)
2. **DeltaP 失败**: 给出的极化接近零 (3.4e-7 e/bohr²)，比实际值小 6 个数量级
3. **Wannier90 不收敛**: 所有 4 个 Wannier centers 都在 O 原子位置，不物理

## 失败原因分析

### DeltaP 失败
- Wilson loop 特征值 γ_n ≈ -1.7e-4（接近零）
- 原因：孤立分子在大盒子中，能带完全平坦，Wilson loop 矩阵接近单位矩阵
- SMO 权重方法对这种"绝缘体极限"不适用

### Wannier90 失败
- 初始投影 "O:s;p" 将所有 4 个投影集中在 O 原子
- 对于 H2O，应该用孤对电子和 O-H 键轨道作为初始投影
- 需要更复杂的投影设置（如指定键中心）

## 结论

**H2O 分子测试不适合验证 DeltaP**，原因：
1. 孤立分子在大盒子中，极化定义不明确
2. DeltaP 的 Wilson loop 方法对平坦能带失效
3. Wannier90 需要精心设计初始投影

**建议**: 使用周期性体系（如冰或晶体）进行测试，或回到 BN 闪锌矿等简单晶体体系。
